# 《随时修仙》两局体验样例（设计演示）

> 样例日期：2026-09-18。本文是《随时修仙》的原创改编演示，不是批准的剧情定稿。
> 关联框架：[产品与叙事玩法设计框架](./SUISHI_XIUXIAN_DESIGN_FRAMEWORK.md)。
> 下文假定四幕与整局通关保存，只为说明体验节奏；幕数、地点、时序和具体战役均未锁定。

## 共同边界

- 核心体验是事件抉择、自由构筑、个人自动战斗和章节连贯故事。
- 贯穿主线提案：商周兵争牵动两教旧约，一宗有传承争议的散修法脉被卷入局部杀劫。
- 起初争的是谁有资格修这门法，随后人物履约与师门报偿把局部斗法推入杀劫。
- 玩家先争得能修之法，再炼为己用，选择站在何人一边，但不被强制定终身阵营。
- 玩家只对自己承担的那一战负责，并收束自己参与的局部因果；不是幕后主谋控制所有人，也不是推翻全部封神命运。
- 每局开局随机抽取几条彼此兼容的核心人物线，线索在共同主干中交汇；两局不是两款游戏。
- 四幕工作名统一为：**夺缘入局、炼法成势、破阵定因、应劫出关**。
- 四幕是宏观章节，每幕可含几次事件和战斗，具体数量不定。
- 每幕都写清具体目标、两种讲得通的选择、本局取法、人物反馈、下一幕因果和修行爽点。
- 长事件按起因、选择、可暂停或转向、人物反馈、斗法兑现推进，不把每幕都写成二选一领奖。
- 四幕机缘不是四块固定套装，人物线不强制唯一 build；名称和具体物品都只是本演示的观察样例。
- 自动战斗只验证本人的存活、资源循环和输出兑现；一场只面对一个明确敌人的压力。
- 任何战中释放都只能由已配置的行为条件自动触发，不手动点引爆，不添加操作小游戏。
- NPC可以提供条件、情报、炼化机会或场外履约，不替玩家临场代打，也不直接把原著重宝永久赠予无名主角。
- 关键能力可来自可用法诀、自炼成果或赢得的炼化机会；不是每次获得能力都附带反噬或期限。
- 能力一旦被玩家真正赢得或炼成，就可以直接成为变强结果；代价主要来自互斥机会、战斗风险和人物关系。
- 当幕积累的层数、护势或资源可以在战斗中消耗，不等于永久烧毁已经修成的能力。
- 公开斗法可让玩家在局部战场扬名并改变可接路线，但名声不自动变成永久光环。
- 样例胜利均声明为“以下为构筑通过验证后的成功路径示意，选择本身不保证成功”。
- 通关后可自愿保存本人的已修机制，参加尚未定形的自动封神大战；不预设封神榜为保存载体。
- 大战只写不同单一敌人的压力假设，不写胜率、平衡结论或既定赛制；PvP、PvE、异步、排名均未定。

## 同一局部封神主干

争议法脉的旧约要求各方在边关一战前交还一件传承凭据；商周双方都把它视为师门报偿的证据。
玩家可以帮阐教人物收束一项旧约，也可以按截教人物的履约方式先完成军令再争法缘。
姜子牙关注旧约能否收束，哪吒关注战场能否尽快结束；闻仲关注军令与师门信用，云霄关注法门是否被滥用。
他们都有自己的利益，不会因主角做了正确选择就全员赞扬；原创人物则可作为实际争夺传承的敌手。
本稿不锁定原著人物的准确时序、地点或具体战役，人物只承担本候选局部故事所需的动机。

## 样例 A：护住自己，再把压力送回去

### 角色承诺与构筑起点

- A侧重与姜子牙的共同利益，哪吒作为交错人物；双方都不把玩家自动编入阐教。
- 玩家先争得可试用的`回脉承法`，再以自炼的`归流匣`把承压转成资源回流。
- 核心循环是获得`护脉层`、在配置条件满足时触发`反照式`，以反击回收下一轮资源。
- `回脉承法`来自争议传承的可用法诀，`归流匣`来自玩家赢得的炼化机会，不是NPC赠送的成品。
- 这条循环不是“跟哪吒就必然走火”，身份只改变人物关系和事件压力，不决定元素或流派。

### 第一幕：夺缘入局

- 目标：先用起始已有的护身与攻伐手段，在炼坛前哨战中争得争议法诀的法缘；获法后，本幕后续的一场单敌战再浅层试用`回脉承法`，验证承压能否回流。
- 选项：接受姜子牙的有条件旧约，用起始手段承担炼坛正面一战，先争得法缘；或拒绝旧约，直接追夺法凭，较快但会在没有法诀支撑时承受更高压力。
- 本局取前者：首场只用起始已有手段争得法缘，获法后的下一场才出现承压回流萌芽；这不代表前者通用正确，后者可能更早拿到稀有材料。
- 自动战斗验证：首场只验证起始手段能否撑住单一敌人的持续压迫；法缘到手后的下一场，浅层`回脉承法`才按预设条件触发承压回流，不能靠姜子牙代打或预先使用尚未获得的能力。
- 战后反馈：姜子牙只封住扩散的旧约因果，仍要求玩家自己炼法；哪吒认为这种稳妥可能让敌手逃脱。
- 代价与因果：谷魄子带走一页旁支口诀，下一幕既可继续深炼回脉，也可改炼更快的反击版本；本局选择不是免费优势。
- 修行爽点：先用已有手段抢到法缘，再在下一场看见刚获得的浅层法诀把压力转成自己的资源。玩家表达：“先让我争到能修的法，再让它证明自己。”

### 第二幕：炼法成势

- 目标：把`归流匣`炼到能稳定回流的程度，并在一场单敌战中证明防护不会只是拖延。
- 选项：继续投入已有机缘，提升护脉层与回流效率；或改炼为短窗穿透反击，放弃部分长战上限。
- 本局取前者：下一幕要面对会打断蓄势的敌手，先让循环有稳定底座；若玩家的资源预算更激进，后者同样讲得通。
- 自动战斗验证：敌人周期性穿刺，系统按预设条件在护脉层足够时自动触发反照，观察存活、回流和伤害是否连续。
- 能力约束：获得回流机制本身没有额外反噬或期限；限制是本次炼化机会只能二选一，不能同时取得穿透版本。
- 失败改道：若战斗验证表明回流仍不稳定，玩家可暂停后续专精，在下一次调整机会补上更稳的启动条件；代价是放弃另一路强化机会，而不是把结果归因于隐藏的炼制失败。
- 人物与因果：哪吒承认玩家撑过了穿刺，却拒绝替玩家承担下一战；姜子牙因此把法脉归属争议提前公开。
- 修行爽点：原本只会挨打的构筑开始用一次反击补回资源，强势来自自己投入的炼法。

### 第三幕：破阵定因

- 目标：在公开斗法中解决谷魄子对法脉的归属争执，打赢玩家主动承担的那一战。
- 选项：立即以已成循环挑战谷魄子，赢回法凭；或先履行姜子牙的旧约，换取旁支证言后再斗法。
- 本局取前者：前两幕已验证防护和回流，主动出战能尽快夺回法凭；若构筑尚未成形，后者更稳也更合理。
- 自动战斗验证：只面对谷魄子本人，反照式在层数达到条件时自动释放；胜负取决于玩家的承压、资源和输出兑现，不由场外人物代打。
- 失败改道：若公开斗法落败，玩家可承认欠下旧约，改走证言路线并保留已修机制；代价是谷魄子先拿走一项炼化材料，终幕压力提高。
- 人物与因果：哪吒因玩家敢应战而减少质疑，却仍批评玩家把风险押得过重；姜子牙只承认局部法凭归还，不承诺替玩家背下全部杀劫。
- 修行爽点：防御不再是被动苟活，玩家用自己炼出的循环赢回法脉归属和下一步选择权。

### 第四幕：应劫出关

- 目标：在局部杀劫压到炼坛时，完成旧约与终幕小修正方向的取舍，并收束玩家参与的因果。
- 选项：履行姜子牙的封约，把已赢得的一次炼化机会用于补强既有回流循环的首轮稳定与恢复；或不再承接进一步承诺，把同档调整机会转向反击输出，牺牲部分稳定性。
- 本局取前者：履约路线用已赢得的炼化机会补足既有循环的首轮稳定与恢复；不再承诺的路线则把同档机会偏向反击输出。两者都是终幕小修正，不是临末核心毕业装。
- 自动战斗验证：单一“断脉主将”施加高压，构筑自动承压、回流并在条件满足时反照，终局只验既有循环能否完成收束。
- 可观测收益与代价：本局关闭断脉通道、保住炼坛退路；履约所选的永久小修正落在首轮稳定与恢复，代价是同档机会没有转向反击输出，而不是少掉一档永久成长。战中消耗的护脉层不抹掉永久修成的回流与反击。
- 人物变化：姜子牙接受玩家完成局部旧约，却不称其为阐教门人；哪吒提供追兵情报但不替玩家赢战，名声和情报只改变当局条件，不补偿永久成长档位。
- 封存：可保存回脉承法、归流匣、护脉层转化、反照条件和本局选定的终幕同档永久调整；姜子牙封路、哪吒情报、炼坛地形和旧约临时保护不带出。
- 修行爽点：终局只是验证已有成果，没有临末天降毕业装；玩家真正赢下自己承诺的那一战。

### A局替代构筑与大战假设

- 不用“承压回流反击”也可完成同一目标：改走护势延迟、净化续命和一次性穿透，靠减少受压次数来赢回法凭。
- 两种构筑得到的永久成长档位应可比较，但尚未验证强度；不能因为站在阐教人物一侧就天然高一档。
- 封神大战中，穿刺型单敌会检验A的启动前存活；高频压制型单敌会检验回流是否断节奏。
- 观察的是承压到第一次反击的时间、资源回补和反击后的残余风险，不声明胜率或赛制。

## 样例 B：留下痕迹，再把积势压成一击

### 角色承诺与构筑起点

- B侧重截教因缘，主线人物可为闻仲，云霄作为交错人物；他们的目标并不等于玩家目标。
- 玩家从同一争议法脉的另一段口诀中取得可用的`留痕续势`，再自炼`照骨炉`累积引爆条件。
- 核心循环是持续施加痕迹、积累势层、在预设条件满足时自动压成一次爆发，再重建施加。
- 闻仲要保住师门履约的军令信用，云霄担心痕迹法被拿来追索无关之人；两人都可能阻止玩家的捷径。
- 这条循环不是“跟闻仲就必然走雷”，人物关系改变净化、蓄积和旧约压力，不决定元素或流派。

### 第一幕：夺缘入局

- 目标：在原创敌手“青旻客”改写传承凭据前，夺到一段能实际施加痕迹的口诀和一次炼化窗口。
- 选项：先对残碑投入一轮自炼，建立稳定施加；或改炼成一次性穿透，尽快打断改写但没有持续积势。
- 本局取前者：想验证痕迹被抹除后能否靠自己的重建再次生效；后者同样合理，适合担心首战被净化的构筑。
- 自动战斗验证：单一敌人周期性抹去痕迹，系统按已配置条件维持施加，不手动选目标或点击爆发。
- 战后反馈：闻仲只开放下一处旧约战场，要求玩家自己证明痕迹有用；云霄指出玩家留下的痕迹可能伤及旁支。
- 代价与因果：青旻客带走一块残碑，下一幕的蓄积上限降低但路线没有终止；玩家可转向更短的引爆窗口。
- 修行爽点：第一道痕迹不是伤害数字，而是能在敌人清除后重新留下的个人法门。

### 第二幕：炼法成势

- 目标：把`照骨炉`炼成可持续积势的自用成果，并在一次高耐久单敌战中兑现引爆。
- 选项：继续投入已有痕迹，换更平滑的积势与重建；或改炼为较快的单次引爆，牺牲最高层数。
- 本局取前者：下幕需要主动解决归属争执，保留重建能力比一次峰值更适合；若已有快速启动优势，后者也讲得通。
- 自动战斗验证：敌人净化后，系统按条件重新施痕；达到门槛时自动引爆，并观察爆发后是否仍能恢复施加。
- 能力约束：留痕续势本身没有反噬、期限或永久扣除；代价只是本次炼化机会不能同时拿到较快引爆版本。
- 失败改道：若积势在爆发前被清空，可改为低层数频爆，承认峰值下降但保留事件线和已修机制。
- 人物与因果：闻仲承认玩家没有把痕迹交给军令驱使，却要求玩家偿还一项旧约；云霄仍不认可把旁支卷入斗法。
- 修行爽点：持续施加不再只是铺垫，蓄积到自动引爆的一刻能实际改变敌人的应战节奏。

### 第三幕：破阵定因

- 目标：前期阶段承诺提前到期，闻仲要求按原约完成一场履约战；云霄提出具体边界，先斩断青旻客正在滥用的一处追索法门，再决定是否继续旧约。玩家要在一场单人自动战中完成选定条件，并把结果带入终幕。
- 选项：直接履行原约，完成闻仲指定的那场战斗；或与闻仲当场改约，先斩断一处被敌手滥用的法门，再承担终幕更高的追索压力。
- 本局取后者：已有施加、重建和引爆机制足以支撑改约；玩家先暂停后续专精，再投入一次已有的重建调整，并在现场谈妥更高终幕压力，不把代价留到战后才宣布。
- 自动战斗验证：改约路线只与青旻客一战，痕迹、重建和引爆均按条件自动处理，用这一场单人自动战斩断被滥用的法门；闻仲和云霄只在场外兑现已谈妥的条件，不临场代打。
- 事件推进：阶段承诺提前到期后，玩家可暂停或再投入已有机制；改变条件后立即进入单人自动战验证，战后闻仲按已谈妥的既定回报兑现。
- 失败改道：若改约后的单人自动战失利，玩家可改回原约要求的后续路径，或保留重建机制直接承受终幕压力；代价是提高终幕压力或失去本幕既定回报，失败不自动触发保底。
- 人物与因果：闻仲在改约现场说明让步边界与终幕压力，云霄只支持斩断这一处滥用法门；战后闻仲按约兑现既定回报，不把他人的宽恕写成事后补偿。
- 修行爽点：玩家不是换一个敌人重复斗法，而是先暂停、再投入重建，改清楚自己要承担的条件。玩家表达：“先把你拿来追人的那道门断掉，再谈我还不还这笔约。”

### 第四幕：应劫出关

- 目标：承受改约带来的更高追索压力，在净化敌人面前决定是否继续旧约，完成玩家承担的最后一战并保住自己的修行。
- 选项：继续旧约，用现有痕迹链替闻仲完成一场履约，换较稳的局部收束；或留下自己的修行方向，切断外部追索联系与本场已积层数，承担更高压力。
- 本局取后者：已有循环足以重建，选择留下自己的修行；切断的是外部追索联系和本场已积层数，不是烧掉本人持续施加痕迹的能力。前者更适合愿意继续旧约、换取较稳收束的构筑。
- 自动战斗验证：单一“净痕执印者”反复净化，构筑自动施痕、积势、引爆并处理残余压力，不依赖审判场顺序。
- 可观测收益与代价：本局切断外部追索联系并清掉本场已积层数，保留玩家继续施痕和重建的能力；代价是失去闻仲提供的临时军令情报，并承担改约后的更高压力。
- 人物变化：闻仲只按已谈妥的条件兑现既定回报，不替玩家承担净化敌人的战斗；云霄提供离场机会，但不授予永久护身光环。
- 封存：可保存施痕、积势、自动引爆和重建机制；本场已积层数、外部追索联系、闻仲情报、云霄离场机会、战场净化规则和旧军令不带出。
- 修行爽点：终幕检验第二幕已经炼成的重建能力，切断旧约是有代价的选择，不是临时拿到新毕业装。

### B局替代构筑与大战假设

- 不用“持续施加蓄积引爆”也可完成同一目标：改走稳定弱化、资源回收和短窗穿透，在单人自动战中更快斩断被滥用的法门，再承受终幕追索压力。
- 两种构筑的永久成长档位应可比较，但尚未验证强度；截教因缘不天然高于其他路线。
- 封神大战中，净化型单敌会检验B的重建速度；高耐久单敌会检验爆发后空档是否可承受。
- 观察的是痕迹恢复、势层积累、爆发后余压，以及切断外部追索和本场层数的真实代价，不声明胜率或赛制。

## 两局对照

| 比较项 | 样例A：护脉回流反击 | 样例B：留痕积势引爆 |
|---|---|---|
| 同一主干中的目标 | 争回可修法凭并收束炼坛局部因果 | 争回可修法凭并截断滥用追索 |
| 主要人物利益 | 姜子牙要收束旧约，哪吒要尽快结束战斗 | 闻仲要守军令信用，云霄要限制法门滥用 |
| 个人核心循环 | 承压、护脉、资源回流、条件反击 | 施痕、积势、条件引爆、重新施加 |
| 第三幕事件推进 | 主动挑战单敌夺回法凭，或先履约再战 | 阶段承诺提前到期，可暂停或再投入；当场改约后单人自动战斩断一处滥用法门，闻仲战后按约兑现回报 |
| 本局主动放弃 | 把同档终幕修正用于首轮稳定与恢复，未转成反击输出 | 外部追索联系、本场已积层数与临时军令情报 |
| 同目标替代办法 | 护势延迟、净化续命、一次穿透 | 稳定弱化、资源回收、短窗穿透 |
| 下一局想改什么 | 让反击更早启动，改选同档输出方向，接受首轮稳定性下降 | 降低被净化后的重建空档，接受峰值下降 |

这两局只是随机选中几条相容人物线的成功样例，不能等同两套职业剧本。
其他人物线可以中立、混搭或暂不表态，在同一主干的归属争执中仍应有完整成局机会。
人物身份不锁定唯一元素或流派；永久成长机会应能跨路线比较，具体档位和数值仍待验证。

## 保存边界与待定项

- 在规则允许保存的时点，只纳入玩家本人修成的机制：自炼法诀、资源转化、自动行为条件和已完成的能力组合；本示例采用整局通关后保存，正式保存时机待定。
- 不保存盟友情报、临时助力、场地规则、人物关系本身的光环或当幕保护。
- 友人提供的机会若已被玩家自行炼成能力，可保存能力；友人本人不会变成永久被动。
- 保存资格究竟在幕尾获得还是整局通关后获得未定，保存载体是否为封神榜未定。
- 后续自动封神大战的对手压力、PVP/PVE、异步、排名和匹配方式均未定。
- 本稿用于检验两种修行承诺能否在同一故事骨架中成立，不构成剧情、数值或赛制批准。
