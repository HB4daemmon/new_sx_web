## 路线与生命

10 步包含重大命运和首领。一张幕图有 26 个候选点，每次只走其中 10 个。各三岔口按种子打乱左右位置，只能进入相邻路线。

| 步数 | 候选内容 |
|---|---|
| 1 | 普通战斗，三个不同敌人 |
| 2 | 奇遇 |
| 3 | 战斗 / 战斗 / 坊市 |
| 4 | 修整 / 精英 / 奇遇 |
| 5 | 奇遇 / 秘境 / 奇遇 |
| 6 | 战斗 / 精英 / 战斗 |
| 7 | 坊市 / 奇遇 / 修整 |
| 8 | 重大命运 |
| 9 | 修整 / 遗宝 / 修整 |
| 10 | 当幕首领 |

普通和精英敌人采用无放回袋，耗尽后才重新打乱。首领开局固定，地图可见。事件仍在进入时按当前因果抽取。遗宝提供三件当局常规法宝，择一或放弃。

跨幕时，在首领奖励及换装完成后，根据最终装备、境界、命格与额外属性算出最大生命并回满。普通节点、读档和终局不会额外回满。

## 流派与开局筛选

| 基础流派 | 循环 |
|---|---|
| 怒潮 | 回怒、怒技连发 |
| 焚劫 | 燃烧累积与引爆 |
| 玄甲 | 护盾、反击与护盾转换 |
| 破阵 | 破甲累积、易伤与处决 |
| 星煞 | 暴击、暴击追击与回怒 |
| 御风 | 闪避、速度成长与身法反击 |
| 归元 | 真实治疗、治疗追击、恢复转盾 |
| 咒厄 | 虚弱、易伤、消耗厄印追加伤害 |

六种混合流派：雷火轮转（怒潮 / 焚劫）、狂澜裂阵（怒潮 / 破阵）、炉心金身（焚劫 / 玄甲）、铁壁摧锋（玄甲 / 破阵）、惊鸿夺势（星煞 / 御风）、枯荣同契（归元 / 咒厄）。

开局一次性选出 4 个基础流派和 2 个兼容混合流派，保存在 `RunState.contentPool`。保证出身主轴和选定命格引导均在其中。奖励、坊市、秘境随机赠宝、遗宝共用筛选；普通能力要求所有声明的流派均在本局池中，专属混合件要求该混合流派入选。

已拥有能力可继续升阶；具名剧情神话奖励不受常规掉落池限制，获得后保持原有效果。八槽和每次一条主混合共鸣的结构不变。命盘的折叠规则中可查阅本局道缘，道藏按当局可得内容显示。

新增通用 `on_heal` 只在实际恢复生命后触发，有防递归保护。归元治疗转盾按实际恢复量算，满血空转不能刷盾。暴击追击不会再触发暴击。新内容没有为单件法宝写 ID 特判。

## 事件与人物

保留哪吒、杨戬、申公豹、赵公明原有因缘，增加姜子牙、雷震子、土行孙、云霄，各三次相遇。

- 姜子牙：粮册、军粮与家书、无名者的名册；旧约可借打神鞭。
- 雷震子：断木救人、风浪渡船、云关渡众；旧约可借风雷双翅。
- 土行孙：军印来路、归印与库损、阵下归路；旧约可借地行旗。
- 云霄：黄沙救人、药与仇怨、为敌留生；旧约可借混元金斗。赵公明救粮的旧事可建立额外信任。

新人物后续必须先相识；随机权重受已立承诺影响，神话奖励需真正践约。不是所有局都会把每条线遇齐。额外八个公开地点与四个秘境包含成本选择、公开检定、前事解锁和阶段推进。八个地点 / 秘境有不同随机开场。开场在进入时确定并保存，查看和读档不重抽。

每个选项继续展示收益与风险，正文承担叙事，数字由规则生成；不在人物页列出未来相遇次数或结局攻略。

## 节奏与平衡

节点增加后，境界阈值调整为 0 / 75 / 200 / 380 / 620。普通、精英、首领按幕序分别校准强度，首领 60% 生命阶段施加 2 层破甲，意图明确提示。散修改用引雷咒起手、入战额外回怒从 15 改为 25；武者基础属性及共享能力未削弱。

使用原有固定模拟策略、相同 120 个种子，不修改选路或装备评分来改善指标。自动策略不能代表真实玩家，武者仍偏强，新增流派也还需要真实游玩反馈。模拟详细记录见 `verification/simulation.json`。
