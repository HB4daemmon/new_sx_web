## 玩家可见改动

- 首页保留题名、一句氛围文案与出身选择。形貌、种子收进“形貌与命数”；保留覆盖旧进度的警告。
- 桌面从三栏收为两栏。地图只保留路线、当前位置、可走节点；图例折叠。移除重复的成长面板和算法建议。
- 六维属性仍在桌面角色栏；手机点击人物可查七项数值（含生命）及来源。战斗期间不重复显示尚未结算的局外生命，避免两个生命数值相互矛盾。
- 八槽保留“基 / 怒 / 辅 / 宝 / 策”及稀有度差异。卡面优先列出当前阶效果、耗怒、冷却。各阶变化另行展开。
- 命盘只突出已经形成的主轴与联动；四路共鸣、战策、法相条件均在“共鸣与法相”展开，不删除计算机制。
- 奖励保留三种取舍，但不解释抽取算法；同名奖励、同名商品预览升阶后的实际数值。
- 事件保留人物、关系、现场叙事及选项得失。未获得的剧情前提不剧透；灵石/生命不足的可见选项仍解释条件。成败概率和损失始终可见。
- 因缘页只展示已经照面的人物；按事件折叠往事。不展示剧本预设相遇总数、不默认展示四种结局的攻略门槛。
- 战报按时间顺序排列，默认简录。追随最新与回看历史可切换，重绘后保持滚动位置。详细战报及设置仍独立于规则。
- 弹窗补充键盘焦点保持和 Tab 限制；关闭后回到入口。背景动作不能透过弹窗执行；键盘操作折叠项不再误触暂停。
- 不再渲染页面底部的版本/存档/技术介绍；版本与种子仍可在静室查看。

## 内容审校

`data/presentation.json` 覆盖 24 个事件、100 个阶段选项，提供独立事后叙述及检定成败文本。没有用随机生成剧情替代策划。

重点纠正：
1. 风雷前夜、旧债来门、刀下问路、两教密札、最后一诺区分陌生人与旧识，不在初见时宣称“认出你”“上一次”。
2. 可重复的人物事件有再遇文案，不反复自我介绍。
3. 西岐的“把龙鳞放回海边”改成“将龙鳞托人送还”，与当前位置一致。
4. 赵公明的最后一赌原有失败代价是生命，不是灵石；选择标题明确“以气血再赌”，失败叙事解释该代价，不暗改扣血规则。
5. 封妖火只清除妖力印记，并不撤回早先攻击加成；选项牵连说明准确，不夸称完全重置。
6. 万仙余烬不再把尚未完成的终幕杀劫写成已经全部结束。
7. 申公豹债务被见证不等于免除，不能在文案中承诺免债。

## 规则与存档

引擎 `src/engine.ts`、模拟策略 `tests/policy.mjs` 完全不变。去掉新增的 `presentation` 字段后，全部内容配置与基线深度相等。冻结哈希记录在 `tests/fixtures/v12-contract.json`。

内容和规则版本仍是 **2.9.0**，界面修订号为 **13.1**。新叙述仅按旧记录的 eventId/phase/choiceId 映射显示，不改写 ActionLog、StoryLog、随机游标或存档。已有 2.9.0 命途可以继续。

## 验证与边界

- `npm test`：76 个原规则测试 + 12 个新增视图/文案纯函数测试。
- `npm run simulate`：固定原策略的 120 局；与基线同为散修 9/40、武者 12/40、方士 6/40。这不是人工玩家胜率。
- `python tests/immersion-browser.py`：真实 Chromium DOM 交互，覆盖全部事件页、6 个视口、地图/命盘/事件/坊市/修整/奖励/战斗/因缘/结局、对话框、简详日志、滚动与旧存档。测试场景明确使用 fixtures，不能据此宣称人工通玩所有分支。
- 容器中 file:// 被浏览器策略拦截，因此本地先用单文件 HTML 的 set_content 执行。CI 再用 `--url http://127.0.0.1:4173` 从构建目录 HTTP 加载验证。
- 浏览器使用 Playwright 1.57.0。视觉检查对象为实际生成截图，不是设计稿。
- 神话素材仍是原有程序 SVG，本轮没有承诺或加入新的美术资源。
- 没有增加人物、好感数值、Boss 反制或新的 Build 层。原人物支线触发权重与结算机制不在本轮变更范围。

## 维护方式

显示文案集中在 `data/presentation.json`；`scripts/create-content.py` 将其并入内容包。新字段只在 `src/presentation.ts` 读取。更改机械字段会触发冻结契约测试失败，需要另行明确升级规则版本，不能借文案更新暗改平衡。
