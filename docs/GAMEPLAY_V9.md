# Gameplay V9 — Keystone Routes

V9 turns several passive stat pieces into build-changing choices without adding a fifth primary school.

- `on_crit` and `on_evade` are deterministic typed trigger points shared by player and enemies.
- 七星剑 turns critical hits into break pressure and a deterministic follow-up.
- 通宝钱 turns critical hits into rage + shield, bridging offensive luck into resource engines.
- 御风 and 追风羽 create an evasive counter route: evade -> rage / speed counter.
- 清心玉 converts leftover shield after a victory into persistent healing, connecting guard combat power to run attrition.
- Warrior correction is isolated to origin stats; shared guard abilities and enemy kits are unchanged.
- Content/rules version: 2.6.0.
