# 《随时修仙》功法树：KF01-KF03

- 日期：2026-09-19
- 状态：设计稿，只定义行为，不承诺平衡数值。
- 总览：[功法树共同规则](./CULTIVATION_TREES.md)。
- 本稿保留三门普通功法的完整四层树；中国神话意象只作原创风味。

## 统一规则

- 一门当前主修功法同时提供普攻、怒技、四层天赋树和行旅作用。换法时旧树卸载，已经结算的修为和属性保留。
- 开局为炼气；随后四次三选一，依次对应筑基、金丹、元婴、化神，每层只取一个节点。不同层可以交叉选取。
- 战斗为单人自动战斗；足够怒气时按当前功法的自动门槛使用怒技，否则使用普攻。无战斗内手动选目标、选属性或切换模式。
- 全局只有怒气作为可充能资源，不添加灵息或能量条。KF02 的引息印、动作记录和其他标记都是有上限的短期战斗状态，不是第二资源条。
- 每方每次只进行一次原生主动作。由该动作派生的伤害、反击、毒伤或延迟开花可以立即或按节点结算，但不能开启第二次完整主动作。
- 普攻动作完成后必得基础怒气，不依赖命中。任何写作“返怒”的效果在触发动作之后登记，最早于下一次己方主动作结算，不在同一动作连开怒技。
- 护盾生成、敌伤实际耗盾、怒技主动耗盾是不同事件；只有节点明确写出的触发器可以观察它们。主动耗盾不冒充敌伤耗盾。
- 治疗先拆成有效治疗与溢出治疗。同一份治疗量只能进入其中一类；被转成伤害、毒或护盾的那一部分不再重复记为原治疗类。附加效果可以观察已经结算的治疗事件，但不能把同一份资源再次完整消费。
- 候选属性仅为攻击、防御、最大气血、暴击率。本文所有基础伤害、护盾和治疗都明确指出读取属性，不假定未写出的传奇标签。
- 法宝属于统一池，持有和生效数量不设装备位上限；节点不复制法宝，也不增加本稿专属槽位。
- 所有行旅效果均在节点进入时绑定当前功法，在节点完成时结算一次；未完成不结算，不能因进入、换法或重返直接领奖。行旅只使用统一修为进度、节点本身的治疗和下一战准备盾，不增加额外状态名词。
- 所有系数、门槛、上限和间隔使用相对描述，待实测量化。每个节点必须能由基础动作或自身事件启动；上层节点只提供叠加、升级或额外产物，不是后层的唯一输入。

## KF01 金刚功

- 稀有度：普通。
- 取得：可作为开局功法，或在普通事件“断碑承雨”中从震动山纹悟得；不要求人物长线。
- 特色：以最大气血造山甲，以防御承山势，以部分主动耗盾换后续攻击。
- 普攻“叠岳式”：造成按基础攻击结算的伤害；动作完成获得基础怒气，并生成按最大气血结算的山甲，山甲有战斗内上限。
- 怒技“山门回返”：达到本门基础怒气门槛后自动使用，先支付怒气，再锁定并扣除当前山甲的一小部分；耗盾额度有独立上限且最多为当前盾量的一半，不以清空护盾为默认。之后结算基础攻击伤害与按实际耗盾量计算的追加伤害。无盾时仍造成基础怒技伤害；后续节点读取同一份消费记录，不另扣盾。
- 反击类节点读取敌方主动作造成的实际耗盾；同一事件的同类反击合并为一个反击实例，升级其伤害或附加物，不生成两个相同反击。
- 行旅：休整节点进入时绑定金刚功，节点完成时额外获得一段统一修为进度，并准备一次下一战起始山甲；准备盾按最大气血结算，战斗开始后只使用一次。
- 关键状态：山甲、山势、山痕、敌伤耗盾、主动耗盾、盾返、转锋。均为有限战斗状态，战斗结束清除。

### KF01 路径与审查点

- 盾返路径：`KF01-J1-B → KF01-J2-C → KF01-J3-A → KF01-J4-A`。基础普攻造盾，敌伤耗盾被记录，怒技读取记录追加伤害，化神在击碎时保残甲并升级同一次反击；没有把一次耗盾重复扣除。
- 叠势路径：`KF01-J1-A → KF01-J2-B → KF01-J3-B → KF01-J4-B`。普攻累积有限山势，怒技只耗部分盾并将其转攻击，镇脉保留受击窗口，化神读取余盾追加转锋；J2-B 的加成不会被 J4-B 替代。
- 碎甲路径：`KF01-J1-C → KF01-J2-A → KF01-J3-C → KF01-J4-C`。敌伤耗盾返怒，击碎留痕，击碎再给一次怒技折让，怒技后的余盾触发下一次反击；每个节点都有基础事件来源。
- 基础攻击读取攻击，山甲和准备盾读取最大气血，山势和镇脉读取防御。普通功法的后期优势只依赖这些真实属性与法宝标签，不假定传奇功法的未定义效果。
- 主要待测边界：部分耗盾的相对额度、山势与山痕的持续和上限、同一击碎事件的反击合并顺序、护盾穿透的实际耗盾定义。

## KF02 归元诀

- 稀有度：普通。
- 取得：可作为开局功法，或在普通事件“古松听雷”中循树根雷光学会吐纳节律。
- 特色：以基础门槛稳定开怒，以蓄怒门槛组织重击，以连续普攻和怒技穿插形成多拍输出。
- 本门固定两个相对门槛：基础门槛 `M` 小于蓄怒门槛 `H`，且 `H` 不高于怒气上限。未被节点改写时，怒气达到 `M` 就自动使用怒技。
- 普攻“周天引息”：造成按基础攻击结算的伤害，动作完成获得基础怒气，并获得一枚有限引息印，印有上限，满印时不再增加。
- 怒技“周天贯脉”：通常达到 `M` 后支付 `M` 怒气并造成按攻击结算的伤害；若有引息印，消耗一枚并追加伤害，无印仍有基础输出。获得蓄怒节点后，高门槛释放支付 `H`，并获得该节点明确给予的更强伤害，不只是延迟释放。
- 选中提高门槛的节点后，自动逻辑从 `M` 开始允许继续普攻蓄怒；达到 `H` 必须释放，不能在 `H` 以上继续等待。战斗开始已达到 `H` 时直接释放。引息印只是有限动作记录，除此之外不添加新资源。
- 行旅：非战斗节点进入时绑定归元诀，节点完成时额外获得一段统一修为进度；战斗节点、未完成节点不结算。
- 关键状态：引息印、连续普攻记录、怒技后普攻记录、一次性门槛记录。它们只记录动作顺序或有限印，不是新的充能条。

### KF02 路径与审查点

- 回怒路径：`KF02-J1-A → KF02-J2-A → KF02-J3-A → KF02-J4-A`。普攻造印，怒技耗印与后续普攻分别回流，反复怒技积累周天增益，完整动作顺序再给一次怒技追加；返怒只供后续行动。
- 蓄怒重击路径：`KF02-J1-B → KF02-J2-B → KF02-J3-B → KF02-J4-B`。从 `M` 到 `H` 期间继续普攻，达到 `H` 必须释放，单枚引息印只消费一次但可同时产生重击和重鸣的追加产物，化神保留早期重击并追加下一行动增益。
- 多拍穿插路径：`KF02-J1-C → KF02-J2-C → KF02-J3-C → KF02-J4-C`。连续普攻形成追加段，怒技后强制接一发强化普攻，完成后额外积怒，再按当前门槛开怒；化神升级该怒技的引息追加。
- 基础普攻与怒技伤害均读取基础攻击；引息印只改变怒技追加，不是第二怒气条。普通功法的成长来自真实攻击、暴击率和法宝标签，不假定未写出的属性选择。
- 主要待测边界：`M/H` 相对值、蓄怒时普攻次数、引息印上限、同一枚印的重击与重鸣结算顺序、强制普攻与达到门槛时的自动优先级。

## KF03 回春功

- 稀有度：普通。
- 取得：可作为开局功法，或在普通事件“枯圃生春”中以露水救活药草、循新叶脉络悟得。
- 特色：基础动作始终有攻击，治疗拆成有效和溢出；溢出可走直接草伤或草毒，满血也不使行动失效。
- 普攻“春芽点穴”：造成按基础攻击结算的伤害，动作完成获得基础怒气，并进行一次按基础攻击结算的小额自疗。先算有效治疗，再算溢出；满血时有效治疗为零，溢出仍转为基础直接草伤。
- 怒技“百草回春”：达到统一怒气门槛后自动消耗怒气，造成按基础攻击结算的怒技伤害，并进行一次按基础攻击结算的较大自疗。受伤时先填有效治疗，剩余为溢出；满血时全为溢出，仍有基础输出。
- 基础溢出出口是直接草伤；毒奶节点可以把溢出改走草毒，或另从真实治疗事件追加草毒，但不能把同一份量同时算作有效和溢出。治疗作用于自己，毒和附加伤害作用于当前敌人。草毒在回合末结算、每层有有限寿命，追加层不刷新旧层寿命。
- 行旅：任一实际节点进入时绑定回春功，节点完成时恢复一小段按基础攻击结算的气血；药地、药圃或采药类节点完成时另获一段统一修为进度。满血时小额治疗不转成第二资源。
- 关键状态：有效治疗、溢出治疗、生机、草毒、借锋记录、枯花记录。每种状态均有有限上限或一次性结算，战斗结束清除。

### KF03 路径与审查点

- 有效治疗路径：`KF03-J1-A → KF03-J2-A → KF03-J3-A → KF03-J4-A`。基础治疗拆分，顺势和借锋读取有效治疗，化神把怒技治疗接到下一次普攻并在下一行动返怒；满血时有效治疗节点可以不触发，但基础攻击和溢出仍行动。
- 满血毒奶路径：`KF03-J1-B → KF03-J2-B → KF03-J3-B → KF03-J4-C`。满血普攻即可施毒，药爆只放大当前毒出口，腐草在毒结算后接下一次溢出，枯花增加一次有限延迟输出；没有把毒来源全部覆盖掉。
- 枯荣跨路路径：`KF03-J1-C → KF03-J2-C → KF03-J3-C → KF03-J4-B`。生机明确提供防御和按基础攻击追加治疗，怒技自身施毒，低血时把部分有效治疗换为护盾，化神读取溢出追加攻击增益；C-C-C-B 不需要 J1-B 才能启动草毒。
- 基础攻击、怒技伤害和自疗均读取基础攻击；生机额外读取防御和基础攻击，枯荣护盾读取被改出的有效治疗量。普通功法只依赖真实属性和本门已写出的机制。
- 主要待测边界：有效/溢出拆分顺序、生机追加治疗的上限、草毒持续和合并档位、毒伤结算与回甘记录的时点、枯花在敌方主动作前后死亡时的清除时点。

## 自检清单

- 三门均为普通档，分别为 KF01 金刚功、KF02 归元诀、KF03 回春功；每门 4 层，每层 A/B/C，共 36 个唯一 ID。
- 每门列出 3 条完整四节点路径；路径只是展示典型构筑，所有层级组合均允许交叉。
- 每门结构上有 `3^4 = 81` 种跨层选法。本文逐节点核查基础输入，不等于已经运行全部组合；三门合计 243 种选法仍需在实现后检查自动优先级与法宝交互。
- KF01 的山甲和准备盾明确读取最大气血，山势和镇脉读取防御，攻击和盾返读取攻击或实际耗盾；基础怒技只耗当前盾的一小部分，J2-B/J4-B 同选仍只扣一次。
- KF02 只有引息印这一种额外有限状态；`M < H <= 怒气上限`，达到 `M` 后若启用蓄怒逻辑可以继续普攻，达到 `H` 必须释放；无印的怒技始终有基础伤害。
- KF03 基础普攻和怒技始终有攻击与治疗行为；满血时有效治疗为零但溢出仍转直接草伤，毒奶和药爆只读取明确出口；J2-C、J3-B 各自具备不依赖 J1-B 的施毒来源。
- 同一已发生的耗盾或有效治疗可以被多个追加效果观察；禁止的是同一份盾或治疗被多个“替代/消费”效果再次全额扣除。毒奶不会把同一治疗同时算成全额有效和全额溢出。
- 行旅统一为“进入绑定、完成结算”：KF01 休整给修为和下一战准备盾，KF02 完成非战斗节点给修为，KF03 每个实际节点完成回血且药地完成额外给修为。
- 尚待量化或由主文档统一的边界：怒气上限与相对门槛、护盾部分耗用比例、三门状态上限、毒持续/叠加、治疗转盾比例、行旅节点是否可重复完成，以及法宝标签命名和冲突组。
