## KF01 金刚功（普通）

- 稀有度：普通。
- 特色：护盾既能承伤，也能换成反击或怒技追加伤害。
- 普攻：造成攻击伤害，并按最大气血获得护盾。
- 怒技：造成基础伤害；有护盾时自动消耗部分护盾追加伤害，无盾仍有基础伤害。
- 行旅：休整节点完成后获得修为，下一战开始带护盾。

### KF01 路线

- 盾返承伤：`KF01-J1-B → KF01-J2-B → KF01-J3-A → KF01-J4-A`，以反伤、防御和首次破盾再起拖长战斗。
- 耗盾进攻：`KF01-J1-A → KF01-J2-C → KF01-J3-B → KF01-J4-B`，用更厚的盾换怒技追加伤害。
- 普攻续盾：`KF01-J1-C → KF01-J2-A → KF01-J3-C → KF01-J4-C`，提高怒气、盾上限、耗盾回流和持盾普攻。

## KF02 归元诀（普通）

- 稀有度：普通。
- 特色：普攻积怒、怒技回怒，选择更快循环或更重的一击。
- 普攻：造成普通攻击伤害并获得基础怒气。
- 怒技：达到当前怒气门槛后自动施放，造成基础伤害并返还少量怒气。
- 行旅：非战斗节点完成后获得修为。

- 回怒循环：`KF02-J1-A → KF02-J2-A → KF02-J3-A → KF02-J4-A`，把每次怒技的回流继续投入下一轮。
- 怒技强化：`KF02-J1-B → KF02-J2-B → KF02-J3-B → KF02-J4-B`，蓄满更高门槛后用余怒放大本次怒技。
- 普攻穿插：`KF02-J1-C → KF02-J2-C → KF02-J3-C → KF02-J4-C`，怒技后强制普攻，再用追加和直伤强化普攻。

## KF03 回春功（普通）

- 稀有度：普通。
- 特色：治疗先保命，溢出可继续造成伤害，也可改作中毒。
- 普攻：造成攻击伤害并自疗；治疗先补气血，溢出直接造成伤害。
- 怒技：造成较高伤害并自疗；治疗先补气血，溢出直接造成伤害。
- 行旅：每个节点完成后恢复气血，药地节点另得修为。

### KF03 路线

- 回春续战：`KF03-J1-A → KF03-J2-C → KF03-J3-A → KF03-J4-C`，强化治疗、降怒耗、回怒和怒技后护盾。
- 溢出毒伤：`KF03-J1-B → KF03-J2-B → KF03-J3-B → KF03-J4-B`，把溢出和怒技治疗叠成通用中毒。
- 低血强疗：`KF03-J1-C → KF03-J2-A → KF03-J3-C → KF03-J4-A`，以当前主修的血量、普攻和低血治疗放大怒技。
