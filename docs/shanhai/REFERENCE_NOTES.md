## 逐条转译为本作提议

### 借鉴《杀戮尖塔》

- 将“每次路线不同”转译为山海潮下的事件节点分支：安全求稳、冒险求法、回访人物线都必须改变后续机会或敌人压力。
- 将“卡牌与遗物交互”转译为功法、法宝、天赋之间的可解释触发：功法管常态行动，法宝改作用方式，天赋改规则取舍。
- 将“遗物可能有代价”转译为事件中的真实取舍，例如拿到强法同时暴露因果、消耗本局资源或改变后续人物态度；代价必须在选择前可见。
- 将“会助益或伤害的事件”转译为长事件的阶段节点，允许继续、止步、回访和失败后带着部分修成离开。

### 借鉴《以撒的结合：重生》

- 将“随机宝藏改变形态/能力”转译为法宝改变自动斗法的释放方式、触发窗口或资源转换，不复制动作射击和房间清怪。
- 将“随机生成与秘密”转译为每局只出现部分人物线、机缘池和回访条件，使同一构筑在不同故事因果中产生不同经历。
- 将“大量道具与解锁”转译为受控的候选池和内容解锁，不把永久伤害、生命或保存战力做成无限滚雪球。
- 组合效果只写成可核验的本作规则提议：允许强组合超出单件相加，但必须有资源、时机、次数或冲突边界。

### 借鉴《王者万象棋》的公开表达

- 借鉴其公开卡牌类别、关键词、品阶和阵容命名的可读性，为本作候选功法、法宝、天赋提供清晰标签；不照搬英雄牌或阵营表。
- 借鉴官方教学把能量、搜牌、阵容强化、天赋、拍卖、牌库分别讲解的分层方式，把本作事件奖励拆成来源、消耗、触发和冲突四项说明。
- 借鉴官方阵容页的“核心”和推荐构筑展示，改造成个人修成的构筑摘要；最终战斗仍是个人自动斗法，不要求棋盘站位或外援编队。
- 若本作使用讨价、竞逐或交换主题，只做一次有故事后果的事件选项；不能把官方“拍卖环节”扩大解释为交易行、利息或共享经济。

## 五项设计准则：事件选择落地到自动斗法

1. 每个长事件至少给出两种实质路径，并在选择前说明立即所得、立即付出、会改变的未来机会和可能的敌人压力。
2. 每次获得的功法、法宝或天赋至少说明来源、启动资源、产出结果、消耗、触发窗口和冲突；允许跳过不合适奖励或有限重选。
3. 自动斗法使用公开的战前倾向和固定优先级解析；玩家不手动出牌、不躲避、不站位、不点选引爆，也不操控外援。
4. 协同可以明显强于单件相加，但必须有资源门槛、时机、次数、冷却或互斥；禁止零成本无限自触发，敌人压力应有多种解法。
5. 经济成长与战斗成长分开：事件不能无限刷可保存战力；保存只保留个人修成能力，不保存借来的外援、场景优势或一次性事件资源。

## 明确不照搬

- 不照搬《杀戮尖塔》的手动出牌、完整牌组、地图节点、遗物名称、角色牌表或事件文本。
- 不照搬《以撒的结合：重生》的动作射击、房间清怪、主角形变表现、道具表、敌人图鉴、结局和美术内容。
- 不把《王者万象棋》改写成传统自走棋：不预设棋盘站位、羁绊、商店刷新、共享卡池、利息或固定人口经济。
- 不把官方页出现的“阵容、能量、搜牌、拍卖、牌库、天赋”标签当成本作必须拥有的同名系统；本作要用事件选择和个人自动斗法重新定义。
- 不复制任何作品的完整内容、文本、角色、图像、数值曲线、关卡布局或可识别的组合表。
