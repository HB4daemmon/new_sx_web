# 山海版战斗与成长规则

> 状态：共同规则提案；具体数值、概率、状态时长和触发上限待走读与测试。
> 玩家先读[功法树总览](./CULTIVATION_TREES.md)，开发与验收再读本页和对应分册。

## 1. 成长与自动战斗

1. 一局只有一门当前主修。主修提供基础动作、怒技、行旅能力和自己的天赋树；炼气为基础，筑基、金丹、元婴、化神各选一次 A/B/C，四次选择可跨方向组合。
2. 战斗为单目标自动斗法，按回合推进。每轮开始，在双方仍存活且战斗继续时，速度较高者先行动，固定本轮先后；双方各有一个主动作，按现有优先级用普攻或怒技替换，怒技不是额外行动。速度变化从下一轮排序生效，不在行动中插队；同速使用战前确定并显示的固定先后，战内不重掷。
3. 普攻完成即获得基础怒气；若特殊闪避明确使该次普攻的某段未命中，动作仍完成并获得基础怒气。没有强制普攻时，达到当前怒技门槛就把下一主动作改为怒技，否则继续普攻。
4. 怒技先支付怒气，再按卡面顺序结算伤害、状态、消耗和追加。最低怒耗仍为正，高门槛不超过怒气上限；返怒只供下一主动作，不额外开启完整行动。
5. 新天赋可以直接增伤、加速积怒、降低怒耗、提高护盾或治疗，也可以少量改写触发。门槛与支付必须同步调整；强制普攻优先于当前怒技阈值。
6. 速度只决定每轮先后，不增加每轮主动作数、行动频率，也不直接增加伤害、积怒、施毒、治疗或造盾触发次数；回合末持续伤害次数与昼夜自己的主动作计数不因速度增加。追击、连段和其他追加不生成第二个完整主动作或手动操作。战斗在死亡或非致命败北触发时立刻终止，未行动方不补一回合。

## 2. 资源、属性与状态

1. 公共战斗属性为攻击、防御、最大气血、暴击率和速度；功法天赋、装备带来的属性加成只属于当前主修与当前装备，卸下就移除，不变成角色永久属性。
2. 修为与境界是成长记录；灵石和气血是跨节点损耗。怒气、护盾和其他战斗临时状态在战斗末清理，下一战从统一初始规则开始。
3. 护盾是额外承伤量，不是额外减防算法；卡面需区分获得、实际吸收、主动消耗、完全击破和到期。
4. 虚弱统一表示有限时长的减攻击，破甲统一表示有限时长的减防；二者都不是默认“下一击即清”。燃烧较短、中毒较长，状态有层数或时长上限，新层不能无限刷新旧层，战末清理。
5. 每门至多保留一种专属战斗状态；当前专属核心仅为剑势、蓄运、昼夜。其它功法可直接使用护盾、燃烧、中毒、虚弱和破甲，不要求生机。
6. 治疗先补足缺失气血，剩余部分才是溢出；同一治疗量不能同时算作有效治疗与溢出。追加效果可以读取同次治疗，替换或消耗效果不能重复花费同一部分。

## 3. 速度、命中与闪避

1. 常规攻击默认命中，不设命中率基础属性与命中对抗，也不设人人都有的基础闪避率。特殊闪避只来自卡面明确给予的少量功法、天赋或法宝能力；本轮没有为现有十门功法、天赋或八件法宝新增闪避效果。
2. 每项特殊闪避须明示触发条件、概率或次数，以及作用于单段还是整次攻击；只作用于直接攻击，不能躲避已经产生的燃烧、中毒结算或事件扣血。不凭空定义所有攻击都可被整次躲避。
3. 被明确闪避的段不计命中，不发该段伤害及其命中附效；普攻动作仍完成并保留基础怒气，已支付的怒技怒气不返还。按动作完成触发的自身护盾或治疗与命中触发效果分别判断，不把闪避视为跳过对方整回合。

## 4. 事件粒度与多段结算

1. 按每击/每行动/每回合的明示粒度结算。默认同一能力对同源事件只处理一次；卡面明示逐段时，仅作用于有限的基础段，派生段不自造新段重入。
2. KF07 的基础二段或三段雷技，每段都有独立且有限的追雷检定；KF09 怒技的每个基础段都附火。公共规则不能粗暴禁止所有多段基础效果或明示逐击效果。
3. 同一份怒气、护盾、治疗、毒层、燃烧或剑势只能消费一次。不同法宝可以多跳读取已记录结果，但不得双花同一份资源；同类伤害加成不因派生段反复复利，具体预算和数值待测。
4. 卡面写明触发输入、顺序、消费、概率、次数、时长和替代关系；未写出的能力不凭空创造资源、主动作或新的状态。

## 5. 非致命与致命

1. 非致命比试必须在开战前标出正气血败北线，具体值待定。若伤害将使气血触线或越线，则在该线截停并结束比试，不继续追加伤害；不是降至零后复活。入场前已在该线及以下则不能应战，可离开或先恢复，不因进入比试补血。
2. 致命战以气血降至 0 为本局结束条件；不能生成复活或公共路保底。事件若会扣血，必须在选项或确认页标出战斗类型与结果边界。
3. 气血和灵石的实际损耗可以跨节点保留；事件不能扣除跨节点带入的临时护盾或怒气。节点或事件的恢复只按卡面明示结算，不能默认满血。
4. 死亡或非致命败北一旦触发，战斗立即终止；另一方即使尚未行动也不补一回合。

## 6. 行旅、换法与保存

1. 进入行旅节点时绑定当时的当前主修；活着完成一次才结算，且同一节点只结算一次。没有节点不自动触发行旅收益，自动大战也不能代领。
2. 仅在明确提供换法的事件或有限休整机会中切换，不能在战斗中或结算前自由换法。首次启用一门功法时，补选已到达境界的天赋；各功法分别保存选择，切回恢复原选择，不提供免费洗点。旧法加成随卸下失效，独立永久收益保留。
3. 功法或装备改变最大气血时，只把当前气血截断到新上限，不免费治疗；卸下加成同理。换法不继承怒气、护盾、燃烧、中毒或其它临时增益。
4. 每门功法的下一战准备最多存一份，不叠加；仅该法主修时可使用。切走时冻结旧法未完成的行旅进度，切回续计，不重置、不补领。节点仍按进入时绑定的功法结算，不能在结束前换法追领另一门收益。
5. 通关构筑只保存当前主修及其已选天赋、独立永久属性和已取得的法宝与强化；境界、修为另作成长记录。暂存法本不作为同时生效的功法封存，临时资源、一次性准备、场景外援和未完成奖励均不带入后续大战。

## 7. 法宝边界

1. 法宝持有件数与同时生效件数都不设统一上限，成长速度由节点产出控制。只有卡面明写的唯一组或互斥改写需要替换。
2. 法宝可以追加、转换或放大已有结果，但不能偷偷提供第二门主修功法或第二个完整主动作。不同能力可继续读取前一步的真实结果，直到明示次数、时长或事件边界结束。
3. 同一能力、同一来源不得无成本重入；替代与追加必须写清先后。护盾额外承伤、状态消费和多跳联动均遵守同一资源只花一次。

## 8. 评审检查

逐门检查：无怒气能普攻，被特殊闪避的普攻仍积基础怒气，怒技先付后结算，强制普攻优先，返怒不多开主动作；
逐场检查速度与闪避：快者先行动、慢者后行动；同速沿用战前固定先后；被明确闪避的普攻仍回基础怒气；被明确闪避的命中附效不发；怒技已支付怒气不退款；燃烧和中毒结算不被闪避。
逐场检查：虚弱减攻、破甲减防、状态按时清理，多段按明示粒度，行旅只在节点结算，换法不回血不重洗。
本文只提供共同边界；任何具体数值、概率、时长、败北线和法宝目录必须在分册、事件卡与测试记录中保持一致。
