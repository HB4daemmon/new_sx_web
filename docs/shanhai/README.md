## 先读懂这一局

照海山随山海潮重现，玩家原本只是想求一门延寿法；在潮头集得法后，必须把它练成自己的本事，再把早期所得炼成器物，争取登山的主动路线，最后以已经修成的能力渡劫成仙。照海山是求道窗口，不是每局都要拯救的末日；同行者、竞争者和主角都可以在同一轮潮退前成仙，主角不是唯一赢家。

玩家可在渡劫后做三种同级叙事选择：回人间自在游仙、留在照海山开府、继续追索山海外境。三者都代表完成修成，不绑定不同永久强度；保存只记录主角已经练成的个人能力。

| 角色 | 当局欲望与返场作用 |
| --- | --- |
| 闻岫 | 看潮采药的散修，想完成药法并治好旧伤；返场检验药法、伤势与最后一剂。 |
| 鲛绫 | 鲛人行舟者，想开自己的潮路并尊重兄长自主远航；返场决定共享、交换或竞争路线。 |
| 夔野 | 山中斗士，想用自创打法赢过老对手；返场由试身、约战和登山时机决定。 |
| 灼九 | 离师自立的炼器师，想在扶桑余辉炉火中证明自己的作品；返场提供共炼、改炼或保留阶段成品。 |
| 陆照 | 提前布局的竞争者，想在寿期压力前登山；返场把成果交换、公开约战或暂时同行兑现。 |

角色不是固定善恶或唯一通关答案；未抽中的角色不补写决定终局的线索。

## E01-E08 长事件入口

下表是已撰写核心事件候选的评审概览；阶段节点、回访、奖励示例和替代入口见 [CORE_EVENTS.md](./CORE_EVENTS.md)。

| 事件 | 长事件形式差异 | 实质选择与回收 |
| --- | --- | --- |
| E01《潮口借火》 | 神话夜宴中的即时取法，取得后当场运转，不是连续领奖。 | 选潮灯、第一法或同档即用机缘；公开或保留先手会改变人物态度与敌人准备。 |
| E02《断碑听潮》 | 同一断碑提供“先取当前一式”或“保留后续再悟”的分岔。 | 两条路都能沿公共正路继续，区别在启动方式、材料保留与之后的准备空档。 |
| E03《夔鼓试身》 | 可预览招式的连续试身，战前可止步，阶段奖励和最终奖励分开。 | 完成阶段可得资源或防护；失败保留已学法，夔野与老对手的关系改变。 |
| E04《九炼无主炉》 | 限时共炼、改炼、保留半成品或继续投入，不以一件神器包办终战。 | 器物成为个人成品；灼九的帮助有公共修行替代，成品缺口会在后续返场。 |
| E05《鲛市竞珍》 | 估值交换与可退出竞价，重点是一次故事后果，不是实时交易系统。 | 旧件换路线功能、稳补给或时机；退出只损失该次机会，不堵公共正路。 |
| E06《山根移府》 | 移动洞府的近宝稳炼与深处新遗藏二选一，窗口和路线同时变化。 | 追深处换更强机缘但承受压力，取近宝换稳定准备；不涉及聚落治理。 |
| E07《故敌同行》 | 竞争者提出成果交换、公开约战或有条件合作，关系状态可转化。 | 胜负换路线情报、成果或终局时机；未守约的压力在终局前出现。 |
| E08《归墟开缝》 | 高风险捷径的路线事件，风险提前显示，不完成也有公共正路。 | 以资源、先手或路线压力换更短登山；不把未完成的人物线变成出口堵点。 |

每局试案抽取两到三条核心长线；第一法和公共正路不依赖抽中某个唯一 NPC。

本轮建议优先评审 E03、E04、E07：它们分别检验可止步连续挑战、阶段共炼分岔、合作与竞争转化，形式差异最明显。

## 构筑重设

当前提案为一门主修，开局自带普攻、怒技及行旅能力；普攻完成积怒，无怒时仍能战斗。
炼气提供基础，筑基、金丹、元婴、化神各从本门对应层选一项天赋；前层保留，后层可强化或转型。
主树固定可预览，不把整个修炼方向交给完全随机抽取。完整节点见三份分册：

| 分册 | 功法 | 核心差异 |
| --- | --- | --- |
| [KF01-KF03](./CULTIVATION_TREES_01_03.md) | 金刚功、归元诀、回春功 | 护盾、怒气、治疗各自派生多条路线 |
| [KF04-KF06](./CULTIVATION_TREES_04_06.md) | 御火诀、养剑诀、五毒经 | 燃烧、叠势追剑、毒层与负面轮换 |
| [KF07-KF10](./CULTIVATION_TREES_07_10.md) | 奔雷诀、太阴经、金乌真经、烛龙真经 | 概率、负面兑现、传奇火法与自动昼夜 |

前五门为普通，中三门为珍稀，后两门由传奇事件取得。传奇基础更强，普通通过专精、属性与法宝配合保留反超空间；这需要同预算对照验证，不能当作已测结论。

法宝不分行旅与斗法，不设持有或生效数量上限。有限节点产出控制成长，少数确实冲突的唯一改写需要替换；不再以装备槽限制组合。
同一已发生事件可以被不同追加效果利用；同一份资源不能重复消费，同一能力不能无成本无限触发自身。

## 取得、替换与保存

事件取得功法时可选择换法或保留法本，常规换法在有限整备机会进行。
换法保留境界、修为、角色永久属性和法宝，卸下旧法及其整棵树；新法按已达境界补选，切回旧法恢复原选择而非免费洗点。

只有当前主修的行旅能力生效。节点进入绑定，完成时结算一次；气血代价按明确顺序修正，不能靠节点末回复复活。
通关保存主修、已选节点、个人永久属性和法宝；不带走临时怒气、盾、增益、一次性下一战准备或剧情外援。
功法与法宝自身的长期能力可以保留，但行旅触发在没有节点的后续自动大战中不凭空发生，也不免费换成战斗加成。
