## 这是什么

山海潮把仙山、洞府和异境重新接回人间。玩家在潮头取得一门能立刻使用的功法，
在自动斗法和旅途中练成自己的打法，决定帮助、竞争、交换或暂时同行的人，
最后用已经修成的本事渡劫。故事和事件让选择留下回声，但不把某个阵营写成唯一正确答案。

## 玩家怎么走

一局只有一门当前主修功法；玩家主要选择四次 A/B/C 进阶、法宝组合、行旅取舍和换法时机。
普攻、怒技与行旅能力由功法提供，战斗自动执行；灵石、气血会跨节点留下损耗，怒气和护盾在战斗末清理。
换法保存各功法自己的树选择和独立永久收益，不回血、不免费洗点；进入节点后绑定的行旅进度也不会刷回。
五幕最终汇入同一场昆仑天门渡劫；故事、事件和后续大战仍是提案，不表示已实现或已测平衡。

## 当前提案边界

- 五门普通、三门珍稀、两门传奇；普通成长和法宝适配可能在某一项表现上反超传奇，尚未测试。
- 基础属性为攻击、防御、最大气血、暴击率、速度。速度只决定每轮先后，不增加行动次数；常规攻击默认命中，闪避只由明确的特殊能力提供，不是通用基础属性。
- 直接增伤、积怒提速、降低怒耗、护盾、治疗和触发概率都可以是合法天赋，不要求每次转换资源。
- 人物线采用神农、精卫、哪吒、太上老君、铁扇公主与女娲；敌方另有十四位神话人物。使用跨典籍原创时间线，不把神话人物称作历史真人，也不把游戏中的功法搭配说成原典记载。
- 事件用短场景和直接选项表达，取舍来自即时成长、以后恢复、路线风险、旧宝强化与连续挑战；不靠多次确认拉长故事。
- 非致命比试须在开战前标出正气血败北线；触线结束比试，不从零血复活，也不免费回满。
- 共同状态、换法、节点绑定和多段结算的准确定义见[战斗规则](./COMBAT_RULES.md)；具体数值待走读与测试。
