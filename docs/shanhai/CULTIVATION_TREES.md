# 功法树总览

> 日期：2026-09-19。状态：设计草案；具体数值、概率和强弱关系待测。
> 本页只帮助玩家一次读懂十门功法；卡面细节见三份分册，公共边界见[COMBAT_RULES.md](./COMBAT_RULES.md)。

## 共通骨架

一局只有一门当前主修。炼气提供基础动作；筑基、金丹、元婴、化神各从 A/B/C 选一项，
四次选择可以跨方向组合。每门都有普攻、怒技和行旅能力；普通强化、资源提速和少量机制改写都可出现。
五项基础战斗属性为攻击、防御、最大气血、暴击率和速度。常规攻击默认命中，不设命中率基础属性或命中对抗。
速度第一版只用于每轮开始确定出手先后，不增加每轮主动作数、行动频率，也不直接增加伤害、积怒、施毒、治疗或造盾触发次数。
这里的“提速”只指积怒、怒技循环或昼夜换相等卡面效果，不自动增加速度或出手次数。
普攻积攒怒气；达到门槛且无强制普攻时，按优先级将下一主动作改为怒技；怒技不是额外行动。
多数天赋直接加强现有能力，不要求先搭出资源转换链。
法宝不设统一持有或生效上限，换法、节点绑定和保存边界以公共规则为准。

## 读表边界

分册统一使用“天赋名 / 快速选择 / 效果说明”：如“金刚护体 / 护盾增厚 / 普攻获得的护盾量提高。”
四字名保留修仙味，快速选择便于比较，效果说明写清条件与代价；三者始终对应同一个天赋。
上表的“可走方向”是比较用的候选，不是三套固定模板、硬前置或互斥路线。
普通成长与法宝适配可能反超传奇某一项，尚未测试；总览不填具体倍率、概率、时长或卡面前置。

[04-06 分册](./CULTIVATION_TREES_04_06.md)与[07-10 分册](./CULTIVATION_TREES_07_10.md)。
