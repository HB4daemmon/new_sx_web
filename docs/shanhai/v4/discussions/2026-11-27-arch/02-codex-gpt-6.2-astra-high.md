# Codex gpt-6.2-astra high

开局一句话就给玩家一件想做的事：“五灵根，山门不收。师父把最后一枚筑基丹押给了药铺，只给你留下药契和一面裂镜。离大限还有六十年。”这一世可以从赎回那枚丹开始，也可以把药契一卖，自己闯一条路。

- **战斗｜看招、蓄势、反打。** 敌人亮出下一招，玩家每回合从已装备的几式神通里选一式。对方连攻，可以护身，每接一击便攒一分势；对方聚气，可以抢攻打断，也可以趁机运功，赌自己下一招足以定胜负。势能强化神通。前几境让人爽在接住杀招后一掌翻盘，后几境则能靠功法和法宝，把当年只能硬扛的一轮围攻变成自己的起手式。
- **成长｜破境既续命，也改打法。** 功法决定怎样攒势，神通决定怎样花势。奇遇让人学新招，闭关能改进熟招。每过一境都续寿、换幕，并让玩家挑一式旧招练出新用法。局外留下历世传记，达成特别结局可解锁新身世；第一世就有机会走完整条仙路。
- **寿元与行程｜让“值不值得去”成为常见决定。** 每幕只展示眼下几件值得亲自去做的事，出发前标明耗年与所求。闭关打磨护身术、赴约夺丹、提前冲关，各自都能说得通。路上遭遇并入这趟行程结算，战斗按回合打，寿元按行程扣。这样玩家能安心读招，竖屏上也无需铺一张大地图。
- **法宝｜让一件旧物陪人过完一生。** 开局旧物或早期奇遇所得皆可炼成本命法宝，此后逢破境便有机会重炼。譬如裂镜起初只能替你挡一击，重炼后能把挡下的术法存到镜中，由你挑一回合放回去。其余法宝从斗法、交易和人情中得来，择少量随身携带，补眼前的短处；丹药、符箓承担一次性的救急和脱身。
- **故事与终局｜让旧人带着旧事回来。** 每世抽一段身世、几位有名有姓的人，每幕接续一两件旧事。若当年赎丹救了师兄，元婴时他可以来替你护关；若卖掉药契，也许多年后登门求丹，开门的正是他。用少量手写的重逢场景读取当年的选择。到化神时，最重的一桩旧事化为心魔，随后以一生练就的招式渡天劫；中途寿尽也有结局，譬如救过弟子的人可得“一脉长明”，由弟子为他写最后一句。

去哪里决定寿元花在谁和什么本事上，下一场斗法检验那门本事，下一次重逢交代那个人的下落。最先验证的是**玩家愿不愿意为自己喜欢的一招押上几年寿命**：先做从练气到筑基的一小幕，看玩家能否在“现在冲关”和“再花几年炼镜”之间做出自己的判断，并在关底亲手打出预想的那次反击。
