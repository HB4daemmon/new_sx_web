# Claude

一句话架构：**寿元是唯一的货币，底牌是唯一的爽点，账本是唯一的故事线。**其余系统都挂在这三根柱子上。

## 核心战斗：明牌对招，掀底牌越级
- **是什么**：
  - 对手亮出接下来要出的三招，每招的强度和效果都明写。玩家用常规出手去接，接下两招算胜。
  - 接不住的那一招，用底牌来补：本命法宝、符、丹、燃寿。
  - 界面提前算出结果，比如"可胜，需耗一张符"。
- **玩家在战斗里的决定**：底牌在哪一招掀、掀哪一张，以及要不要为对手挂出的彩头（例如"三招全接"）多花一张。
- **爽点**：
  - 越级时先看到"本来必败"，再看到自己用一张牌把局面翻过来。
  - 破境之后回头碾压从前打不过的人。
- **为什么这样做**：
  - 回合制卡组太重；全自动没有参与感。
  - 明牌三招最便宜、最好懂，小深度全部集中在"何时掀牌"这一个决定上。
  - 杂鱼战一次选择直接结算，不打。

## 成长：境界是骨，神通是肉
- **境界**：
  - 境界就是幕，每幕末冲关。
  - 冲关是押注：可以稳冲，也可以花年数、吞丹、折寿把品质往上推。
  - 品质决定能从几张神通里挑：三选一、二选一，或者一张也没有。
- **功法**：不做功法库。主修功法开局随出身定下，它决定常规出手怎么算，比如"每接一招，下一招 +1"。
- **神通**：每次破境获得一张，是改变战斗规则的被动或主动技能。一局 4 张，构成这一世的打法。
- **局外**：只加花样，不加强度。
  - 解锁出身、金手指、神通进池、结局图鉴。
  - 不做永久属性；否则"废柴开局"会被磨平。

## 故事：模板拼的短篇，靠账本前后呼应
- **生成方式**：
  - 每幕是固定的"起承转合"几拍，每拍从三张事件卡里挑一张。
  - 每张卡写明耗几年、风险多大、收益是什么，正文只有两三行。
- **前后呼应**：重大选择写进**因果账本**，并当场提示玩家。
  - 有些选择会往后面几幕塞一张**因果签**，例如"杀了纨绔 → 金丹期他家老祖上门"。
  - 前面的事在后面真的会回来。
- **人物**：一个贯穿全局的**对头**，同一张脸三次出场。玩家躲过他一次，他下次就高你一境。
- **收尾**：
  - 心魔按账本上最重的那一项生成，天劫按各境品质来定强度。
  - 最后用模板拼出四到六行的本世仙传，加上一个结局名。

## 法宝：一件本命，吃出名字
- **本命法宝**：
  - 全局只有一件，开局是凡物。
  - 战利品和敌人的法宝可以"喂"给它，一共只升三阶。每升一阶，加一种战斗用法，名字也跟着变，例如锈剑吞了蛟丹，就成了"蛟吟剑"。
  - 定型后的名字写进仙传。
- **其他法宝**：不做装备栏。捡到的法宝只有两个去处：喂给本命法宝，或者当一次性底牌砸出去。
- **为什么**：玩家只养一件，才有感情，也省掉装备比较的 UI。

## 其他系统
- **底牌（丹、符、阵）**：一个容量很小的囊，只放 2–3 件，拿新的就得丢旧的。
  - 丹用来扛招或冲关；
  - 符用来保住一招，或者越级；
  - 阵封住对手的一条特殊规则，或者在渡劫时挡雷。
  - **丹毒**：嗑丹越多，天劫越重。
- **寿元经济**：
  - 年数是唯一的硬通货。闭关、炼丹、赶路都花年数；
  - 燃寿可以立即换战力；
  - 破境时寿元大涨，越接近大限破境，回馈越大，也就是"白发转青丝"。
  - 灵石只在坊市那一拍里出现，不单独做成一条经济线。
- **护道者**：道侣或灵兽，规则相同，作用只有一个：在关键时刻替你挡一次。
- **心魔与天劫**：心魔从账本里来，天劫看品质和丹毒，过劫就是一次三招。渡劫失败照样给一个有名字的结局。

## 怎么咬合，先验证什么
**咬合**：
1. 寿元在每一拍都逼玩家取舍：攒底牌、喂法宝、冲品质，还是去抢机缘。
2. 攒下的底牌在三招斗法里换成越级和打脸。
3. 这一路的选择记在账本上，终局变成心魔、天劫和仙传。

三者是同一个循环：**花年数 → 攒牌 → 掀牌 → 记账 → 清算**。

**最该先验证**：三招斗法里"何时掀牌"是不是真有取舍，以及越级翻盘爽不爽。这一点不成立，寿元和故事都没有出口。
