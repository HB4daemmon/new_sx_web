# 随时修仙 · 用户画像视角的世界观（Claude 独立稿，2026-11-25）

## 一、先想清楚是给谁做的

**目标玩家**：20–40 岁男性。看修仙网文和各类爽文，刷短剧，玩过 roguelike，喜欢随机性。

| 他要什么 | 对世界观的要求 |
| --- | --- |
| 前 3 秒有钩子（短剧习惯） | 一句话能讲完的开局：废柴、金手指、打脸 |
| 金手指要明确 | 主角凭什么能「随时修仙」，必须是一个看得见、摸得着的东西 |
| 升级快、反馈密 | 一局 15 分钟里至少升 3 次品，每次都有身份变化和演出 |
| 扮猪吃虎、苟中带爆 | 稳健不是怂，而是憋大招；最后一下要炸 |
| 装逼打脸 | 名门弟子、天骄、长老被小人物当场打脸 |
| 悬念和反转 | 每升一个大境界，揭开一层「原来如此」 |
| 随机、每局不同 | 每局的身份、副本、机缘都在变；死了也想马上再开 |
| 熟悉的梗 | 封神、八仙、诡秘的序列、大奉的九品和诗词装逼、师兄的苟道 |

**由此定下的设计原则**：
- **爽字当头**：轻松，但不是佛系治愈；要有对手、有打脸、有越级。
- **随机就是设定**：用网文读者熟悉的「无限流」副本结构来解释每局重开。
- **长线要有境界**：局内每次重置，局外的境界永久增长，满足网文读者对「变强」的执念。

## 二、一句话
> **封神榜里，还在打封神。**
> 你捡到一页封神榜残页，从此可以随时翻开它，以一个小人物的身份，掉进那场三千年前的封神大劫里截胡机缘。

**宣传语**：别人闭关三百年，我摸鱼十五分钟。

## 三、世界：两层

### 现实层（主角真正生活的地方）
- 封神大战已经过去三千年，天庭有编制，人间有王朝**大胤**。
- 修仙是门槛很高的正经事：名门大派垄断功法和资源，散修和凡人基本没机会。
- 民间流传着八仙的传说：八个凡人出身的怪人，「各显神通」成了仙，没人知道他们是怎么做到的。

**主角**：太乙门最没用的外门杂役，灵根稀烂，修了五年还在练气一层。为人极度稳健：扫个地都要先在扫帚上布三道防御阵。
- 开局短剧桥段：宗门大比当天，被内门天骄当众嘲笑「练气一层也配叫修士？」，被罚去后山扫藏经阁废纸堆。

### 榜中层（金手指，也就是 roguelike 的每一局）
在废纸堆里，主角捡到一页残破的金色纸页：**封神榜残页**。

- **封神榜记下的不只是 365 个神名，而是整场封神量劫**。榜里的那场大战从来没有真正结束，一直在里面一遍遍重演。
- 翻开残页，主角的神魂就会以一个随机的小人物身份进入榜中，可能是陈塘关的卖肉屠户、朝歌城外的算命先生、万仙阵边上跑腿的小道童。
- 在里面修出的**修为是真的**，出来以后会带回现实，就是一局结束时的结算。
- 在里面死了也没关系：榜中的死者都会被「封神」，你只是被封了个神，然后被踢回现实。

**为什么叫「随时修仙」**：残页随时能翻。蹲坑、排队、摸鱼的时候翻开一页，十五分钟后，带着修为回来。

## 四、一局：翻开一页
1. **翻页（开局随机）**：
   - **哪一劫**：陈塘关、黄河阵、万仙阵、朝歌、西岐、东海龙宫……每一劫有自己的规则和首领池；
   - **什么身份**：随机给三个市井身份，三选一，身份就是途径；
   - **什么世道**：「今日阐教巡山」「截教在发法宝」「申公豹在拉人」……
2. **在大劫里苟着、截胡**：
   - 地图分三段，每段若干节点，内容是斗法、机缘、事件、商人、路过的大能。
   - 大能们在天上斗法，你在地上**捡漏**：截胡被打落的法宝、偷学大能的一招、给落难的散仙递一碗水换一份人情。
   - **劫气**：你越高调（越级杀人、抢大能的东西、当众显圣），劫气越高，伤害倍率也越高；劫气到顶就会被量劫「点名」，引来天兵或大能出手。
     - 这就是师兄的苟道：稳健攒底牌，关键时刻一把梭哈。
3. **升品**：攒满修为，再完成本途径这一品的晋升仪式，当场升品，身份、称号、神通一起变。
   - 一局从九品打到六品左右，越往后越难。
4. **结算**：
   - **活着出来**：修为带回现实；
   - **死了或失控**：被「封神」，弹一张封神榜金字诏书，例如「敕封：扫帚星」「敕封：逢赌必输偏财童子」，修为打折带回。

**每局为什么不同**：哪一劫、什么身份、什么世道、路过哪位大能、捡到什么法宝，全是随机组合。

## 五、途径：市井身份，一路修到神位
- **核心**：凡人靠「把一个身份演到极致」成仙，八仙就是这么成的。这是本世界的修炼原理，对应《诡秘》的扮演法、大奉的九品体系。
- **晋升**：修为够了以后，还要完成本品的晋升仪式。
- **准则**：每条途径有几条行为准则，守住了心魔下降，违背了心魔上升；心魔满了就走火入魔，也被「封神」。

| 途径 | 别称 | 九品 → 一品（节选） | 爽点 | 准则举例 | 仪式举例 |
| --- | --- | --- | --- | --- | --- |
| **屠夫** | 武道 | 杀猪匠 → 刀客 → … → 人间武圣 | 越打越强、刀刀暴击；大奉武夫那种肉身硬抗 | 不退半步；刀出必见血 | 一刀斩下比你高三品的敌人 |
| **书生** | 儒道 | 落第秀才 → 举人 → … → 言出法随 → 文圣 | **当众吟诗装逼**，一句诗就是一个大招（大奉最爽的那一下） | 不说假话；当众出手 | 在敌人阵前作一首诗，让对方当场破防 |
| **算命** | 天机 | 摆摊先生 → 铁口 → 半仙 → … → 太公 | 预言敌人什么时候死，然后让它应验 | 算了就要说；不给自己算 | 当众预言首领三回合内倒下，并且应验 |
| **乞丐** | 百衲 | 叫花子 → … → 铁拐仙 | 越惨越强；残血反杀 | 不花钱，只讨；给的必须收 | 一成血时赢下精英战 |
| **戏子** | 千面 | 跑龙套 → 名角 → … → 戏神 | 偷敌人的招，变成敌人的样子 | 一场戏不换角；台下有人就要演完 | 扮成首领，骗过它的手下 |
| **货郎** | 玄坛 | 挑担郎 → 掌柜 → … → 财神 | 钞能力：用钱买断敌人的大招 | 不做亏本买卖 | 花钱把精英的法宝买下来，让它不战而退 |

- **兼修**：中品以后可以学第二条途径的一招，例如「书生 + 屠夫 = 一边吟诗一边砍人」。
- **以后可以加**：郎中、更夫、厨子、媒婆、渔夫……三百六十行，都是新途径。

## 六、局外：现实层的境界（网文读者要的永久成长）
- 局内的品阶每局重置；**现实层的境界只升不降**：练气 → 筑基 → 金丹 → 元婴 → …
- **境界给的是选择，不是数值**：
  - 解锁新的劫（新副本）；
  - 解锁新的身份（新途径）；
  - 解锁更多起手选择。
- **每突破一个大境界，播一段短剧式的打脸剧情**（30 秒内）：
  - 筑基：宗门大比，当初嘲笑你的天骄被你一招放倒；
  - 金丹：长老想收你为亲传弟子，你说「我稳健惯了，再想想」；
  - 元婴：名门大派上门求合作，因为他们发现榜中的机缘被人截胡了……

## 七、悬念：每升一层，揭开一层
基调保持轻松，用「原来如此」代替「苦大仇深」：

1. **筑基**：榜中还有别人。有大派的天骄也拿着残页进来截胡，出现竞争对手。
2. **金丹**：八仙的秘密。八仙当年也是翻残页的人，「各显神通」就是他们在榜中修出的八条途径。
3. **元婴**：姜子牙留了一个空位。封神榜上有一个从来没人坐过的位置，写着「留给后来人」。残页之所以会落到你手里，是因为它在找人。
4. **化神**（新的开始）：坐上那个位置，封神这一章就合上了，但榜的后面还有新的一页：**西游量劫**，然后是**八仙过海**。每一章都是一套新的副本、新的身份、新的规则。

这就是「揭开以后重新开始」：每一章都是一个赛季，内容可以一直往后写。

## 八、为什么适合这个画像
1. **开局就是短剧钩子**：废柴杂役、捡到金手指、宗门大比打脸，三秒就懂。
2. **「无限流 + 封神」**：网文读者最熟悉的爽点结构（主神空间、副本、截胡机缘），套上中国玩家最熟悉的神话，随机和重开都由设定本身来解释。
3. **苟和爽是一根条**：劫气。稳健的人攒底牌，激进的人当场梭哈，两种爽都能玩。
4. **死了也好笑**：被「封神」，领一张奇葩诏书，截图就能分享。
5. **永久境界加短剧式打脸**：满足网文读者「我在变强」的执念，又不破坏 roguelike 每局的公平和随机。
6. **内容可以一直扩展**：每个量劫是一个赛季，每个行当是一条途径。

## 九、需要拍板
1. 「封神榜里还在打封神」，用无限流副本的结构，可以吗？
2. 现实层的设定：废柴杂役加宗门打脸，要不要？还是只保留榜中层？
3. 死亡和失控等于「被封神」，发一张诏书，可以吗？
4. 首发途径：屠夫（武）、书生（儒，吟诗装逼）、算命、乞丐、戏子、货郎，可以吗？
