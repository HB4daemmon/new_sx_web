# Claude（盲写，未看其他四家）

先说我理解的「易懂 + 爽 + 能循环」：玩家开局 10 秒内要知道「我是谁、要去哪、死了会怎样」；爽点最好来自**网文里早就被验证过的情绪**（以弱胜强、捡到神器、越级反杀、打脸、一路突破）；循环要让「死」本身就是剧情的一部分，而不是惩罚。

下面 6 个方向，最后挑一个。

---

## 方向一：一世修仙（一局 = 一辈子）

- **背景**：凡人想成仙，就得在百年寿元内从炼气一路修到渡劫。成功飞升，失败就转世重来。
- **玩家是谁**：一个刚测出灵根的凡人少年。每局开局随机出身（樵夫之子、落魄世家、魔门弃徒……），带一个小特性。
- **循环**：一局 = 一生，分 5 个大境界（炼气/筑基/金丹/元婴/渡劫），每个境界是一张小地图，打完境界瓶颈（Boss）才能突破。寿元是总时钟，到点就坐化。
- **局外留下**：「宿慧」——前世学会的功法残页、认识的人、见过的秘境。转世时可以选择「觉醒前世记忆」带一样东西进来。
- **爽点**：15 分钟走完一条完整爽文弧线：废柴 → 天骄 → 一方大能 → 渡劫。每次突破有一次「数值大跃迁」的爽。
- **小深度**：寿元是资源——闭关更强但耗寿，冒进省寿但可能走火入魔。

## 方向二：收妖炼宝（敌人就是你的构筑）

- **背景**：封神大战后，天下散落着无数被打散的妖魔、法宝残灵。你手里只有一个破葫芦，能把打残的东西收进去。
- **玩法核心**：战斗中把敌人打到残血可以「收」，收进来的妖怪炼成法宝 / 招式 / 护法。**每一个敌人都是潜在的卡**。
- **爽点**：Boss 打残一收，下一层就用它的招式碾压它的同类；越强的敌人收进来越离谱。
- **小深度**：葫芦容量有限，要选择收谁；同类妖物合炼会进化；收了凶物会反噬。
- **循环**：葫芦每局清空（妖怪跑了），但「图鉴」留下——收过的妖解锁成以后可能遇到的变种和可炼的配方。

## 方向三：稳健下山（准备即爽）

- **背景**：你是宗门里最怕死的弟子，师父逼你下山历练。山下处处是陷阱，但你准备充足。
- **玩法核心**：每局分两段——**山门备战**（用资源画符、布阵、炼丹，决定带什么）+ **下山闯关**（随机遭遇，用准备好的东西对付）。
- **爽点**：「早就料到了」。敌人掏出底牌，你恰好带了克制的符——那一下的爽是"智商碾压"。
- **循环**：每次被打回山（不真死，重伤逃回），带回见闻，下次准备更精准。
- **风险**：前段准备容易拖节奏，要把备战压到 1 分钟内。

## 方向四：天梯九十九层

- **背景**：天上垂下一道天梯，登顶者飞升。所有修士都在爬，你也在爬。
- **循环**：最纯粹的爬塔——每层一个房间（战斗/机缘/商人/休整/精英），每十层一个守关大能。掉下去就回到凡间重爬。
- **爽点**：可视化的「往上爬」，排行榜/层数天然是目标；路上踩着别的修士往上。
- **局外留下**：梯子上会刻下你上次死的位置，下次路过能捡回一部分遗物（以撒/魂系的「尸体回收」）。
- **评价**：最易懂、最好做，但世界观偏薄，需要别的方向补人味。

## 方向五：八仙式散修小队

- **背景**：一个人成不了仙，你沿途结识散修，凑成一支「过海」队伍，各显神通。
- **玩法**：构筑对象不是卡，而是**队友**；每个队友带一件标志法宝和一个被动，队伍组合产生连携。
- **爽点**：凑齐特定组合触发「合击」，全屏大招。
- **风险**：手机竖屏同屏多角色，信息量偏大；更适合做成中后期解锁内容。

## 方向六：天庭外包司（轻喜剧）

- **背景**：天庭人手不够，把下界除妖、送雷劫、查漏网之鱼外包给散修。你是接单的。
- **循环**：每局接一单（悬赏），完成拿功德，功德在天庭换编制/升职。
- **爽点**：吐槽式幽默 + 越级接单的高回报。
- **风险**：容易变成"任务列表"，修仙爽感被冲淡；可以作为方向一或二的外壳语气。

---

## 我最心动：方向一 + 方向二 的合体 ——「一世修仙，收妖为宝」

**一句话**：*你是一个凡人，一局就是一辈子；路上把打败的妖魔收进葫芦炼成自己的本事，在寿元耗尽前渡劫飞升。*

为什么：

1. **易懂**：「一辈子修到飞升」是所有修仙读者的默认剧本，零学习成本；「打残就能收」一句话讲清。
2. **爽点叠加**：方向一给**纵向爽**（境界突破、数值跃迁），方向二给**横向爽**（敌人变我的、Boss 招式为我所用）。两种爽交替出现，节奏不腻。
3. **天然肉鸽**：每局遇到的妖不同 → 收到的不同 → 构筑不同。随机性直接来自世界本身，不需要另造「卡池」概念。
4. **循环有理由**：死 = 坐化转世，不出戏；「宿慧」与「妖物图鉴」两条局外线：一条让你更强一点（少量），一条让世界更丰富（主要），符合「越玩越想挖」。
5. **小深度落点明确**：寿元（时间）× 葫芦容量（空间）× 收谁/炼什么（选择）。三个约束都很直观，但组合起来有取舍。
6. **好做**：敌人和奖励共享一套数据，内容量减半；境界即章节，结构天然清楚。

一局大致长这样：

```
出身抽签（10 秒）
 → 炼气：3~4 场遭遇，收第一只妖
 → 筑基瓶颈（Boss）→ 突破：选一门功法
 → 金丹：精英妖出现，葫芦开始满，要合炼/取舍
 → 元婴：心魔事件、高收益冒险
 → 渡劫：九道天雷，用这一世收的所有东西硬扛
飞升 / 坐化 → 宿慧结算 → 转世
```
