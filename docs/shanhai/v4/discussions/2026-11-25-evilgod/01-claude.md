# Claude · 「福地」（盲写，未看其他三方答案）

## 表面：一个太好的村子
你生在**福地村**。这里风调雨顺，没人挨饿，也没人真的死。

- 村里人摔死、病死、被山里的妖怪咬死，第二天都会在自家床上醒来，伸个懒腰说一句：「老祖宗保佑。」
- 村口祠堂供着**老祖宗**：一尊笑眯眯的胖神像。谁想要本事，去上炷香，就能领到「**福气**」：力气、运气、法术，要多少给多少。
- 修仙在村里是一种爱好，像钓鱼。年轻人上后山打妖怪，下山吹牛。

**玩家**：村里最懒的那个年轻人。你觉得福气来得太容易，不太对劲，又说不上哪里不对。

**为什么一局局重来**：死了就在床上醒来，「老祖宗保佑」。一局就是**一天**，从鸡鸣到子时。轻松得像一个修仙版的日常村庄。

## 成长：途径就是「偷」
小世界里的一切都是老祖宗的，所以想修出**自己的**本事，只能偷。每条途径偷一样东西：

| 途径 | 偷什么 | 身份 |
| --- | --- | --- |
| **偷闲** | 偷睡眠：睡着时他看不见你 | 懒汉 → 睡仙。在梦里修行，躺着也能打 |
| **偷师** | 偷别人的招 | 学徒 → 戏子 → 千面。看一遍就会 |
| **偷生** | 偷生命：接生、续命、借命 | 接生婆 → 续命人。管着「生」 |
| **偷天** | 偷时辰 | 更夫 → 算命 → 司晨。让一更提前或推迟 |
| **偷命** | 偷运 | 乞丐 → 赌徒 → 偷命客。越穷越敢押 |

- **扮演准则**：做一个「不起眼的人」，各有规矩。懒汉不能勤快，戏子不能露真身，乞丐身上不能留钱。
- **晋升仪式**：都是「在老祖宗眼皮底下偷一样大东西」。例如在祠堂里，当着神像的面睡一整夜。

**借他的力量**：福气随时能领，又多又猛，用起来很爽。但用得越多，你脸上的笑就越像老祖宗。

**福相条**：
- 满了你就成了「**有福之人**」：永远笑眯眯，站在村口，再也不想离开。本局结束。
- 以后每一局，你都会在村口看见那个笑着的自己，也就是你的「失控」。

**名字的解释**：「随时修仙」就是**趁老祖宗打盹的时候修**。

## 真相分三层
1. **第 1–5 局：好像哪里不对**
   - 村民每天说一样的话；
   - 有福之人越来越多；
   - 小孩永远长不大，老人也不会更老。
2. **第 10 局左右：生老病死是排好的**
   - 祠堂后面有一本黄历，写着谁哪天生病、谁哪天出生。
   - 小孩是从后山的葫芦里抱出来的。
   - 福地是一座**养魂池**，老祖宗吃的是大家的「福」，也就是快乐。
3. **第 20 局左右：老祖宗原本不是恶人**
   - 他是封神量劫时的一个小神，为了不让自己的信徒死在劫里，把整个村子装进了一只葫芦，冻住了生老病死。
   - 几千年过去，外面的量劫早就结束了，他却不敢开门，护佑变成了囚禁，吃福吃成了邪神。
   - 你每次死后能醒来、还记得上一局，是因为你是他偷偷留下的一个「漏洞」：他自己也想被人阻止。

## 揭开之后：重新开始
打倒老祖宗，**葫芦破开**，你第一次看见外面的世界：福地只是挂在一座大庙梁上的成千上万只葫芦之一。外面有更大的神，还有一整个洪荒。

- **第二轮**：你成了福地的新神，轮到你来选：
  - 继续冻住生老病死，大家永远开心，永远不长大；
  - 还是放开轮回，让他们会老、会死，也会真的活一次。
- 新的一轮里，死了回到你自己的福地。你偷来的本事成了你给村民的「福气」。外面的神开始来收你的葫芦。
- **表面又变轻松了**：现在你是那个笑眯眯的神。玩家会慢慢意识到，自己正在变成老祖宗。

## 我最心动的点
「**表面越幸福，越吓人**」。

1. 开局像一个修仙版的日常村庄，轻松、好笑，零门槛。
2. 「死了床上醒来」是重开，也是第一个疑点。
3. 「福气」又是爽点，又是陷阱。
4. 揭开真相后，玩家自己坐上了那个位子。

整个故事和「借他的力量，但不能过度依赖」是同一件事：你不偷，就只能领他的福；你领得越多，就越像他。
