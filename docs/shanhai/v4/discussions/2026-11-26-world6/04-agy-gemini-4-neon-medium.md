# Antigravity gemini-4-neon medium

针对《随时修仙》的定位（手机竖屏、10–20 分钟一局、1–2 人开发、面向爱看修仙爽文与喜欢肉鸽随机性的 20–40 岁男性），围绕**“高重玩动力、单周目完整、纯正修仙味、上手快且有小深度”**这几个核心诉求，同时避开查案、生造概念、按元素/兵器分职业、分身出门等方向，以下发散出 **4 套差异化的基础设定方案**。

---

### 方案一：《百岁飞升录》——“寿元倒计时 + 境界碾压”的一生修仙肉鸽

* **一句话世界观**：凡人寿不过百，修仙便是与天争命。你只有一甲子寿元，必须在寿尽前一路破境、渡过九重天劫，逆天飞升。
* **单局体验（完整的修仙传记）**：
  * 一局就是修士完整的一生，严格走经典爽文的五幕节奏：**练气（苟发育）→ 筑基（宗门大比）→ 金丹（秘境夺宝）→ 元婴（开宗立威/清算宿敌）→ 化神（九重天劫飞升）**。
  * 打通一局就像看完一本节奏紧凑的个人修仙小说，有明确的起承转合和飞升结局，不靠“这局攒资源、下局才能打过”来拖时长。
* **核心循环与玩法**：
  * **核心资源张力是“寿元”**：闭关修炼耗寿元、炼丹布阵耗寿元、强催秘术烧寿元；但**每次突破大境界，寿元暴涨 + 寿险重置 + 对低境界形成“境界压制”**。玩家一直在“现在就冒险强冲破境”和“再攒一波底牌稳健发育”之间博弈。
  * **大地图是“修仙年历/游历卷”**：竖屏滑选每年的去向——闭关、坊市淘宝、闯秘境、接宗门悬赏、结交道侣、拜访丹师、抢夺机缘。
  * **斗法（轻量化构筑回合制）**：不按元素/兵器分职业，而是靠**功法（灵气运转规则）+ 本命法宝（核心机制）+ 丹药/符箓（一次性爆发底牌）+ 阵法（改写战场规则）**自由拼装流派（如嗑药爆发流、法宝连携流、护阵耗血流、以杀养魔流）。
  * **心魔与天劫**：贪婪行为（强抢宝物、嗑禁药、背叛道侣、杀戮过重）会迅速给强力收益，同时积累**心魔**。平时心魔提供高额加成，但在渡劫时会具现为心魔劫，逼玩家在“稳健修仙”和“险中求富贵”间走钢丝。
* **重玩动力**：
  * **开局随机“身世+灵根”**：废柴退婚、宗门杂役、大能转世、天生毒体、气运之子……每次开局剧本感和初期策略完全不同。
  * **数十种“飞升仙号/结局”图鉴**：丹祖飞升、多宝飞升、逍遥散仙、血魔灭世、携侣飞升等，不同通关方式解锁新奇遇池和古宝。
  * **前世遗泽**：上一局哪怕陨落，你的本命法宝或坐化洞府有机会变成下一局地图里可探索的“前辈遗府”，给足叙事惊喜但不强迫刷数值。

### 方案二：《封神劫》——“量劫大势 + 因果博弈”的演义风修仙肉鸽

* **一句话世界观**：三界量劫将至，天道重排封神榜。你是一个刚入山门的小修士，要在三百年大劫爆发前攒足底牌活下来，并在最终封神大战里抢下一个神位——或者直接掀翻封神榜，肉身成圣。
* **单局体验（大时代下的小人物逆袭）**：
  * 带着《封神演义》+《我的师兄实在太稳健了》的爽感。单局分为：**潜龙在渊（拜师学艺）→ 风起青萍（结下因果）→ 量劫降临（各方混战）→ 封神台终战**。
* **核心循环与玩法**：
  * **核心机制是“劫气与因果”**：沾染大人物因果（帮大教抢宝、救名门弟子、和妖王结拜、拐走圣女）能立刻拿到逆天法宝和秘传功法，但头顶**劫气**也会暴涨，招来大能追杀和更狠的天雷。
  * **两种极致的爽文活法**：
    * **稳健老六流**：死磕炼丹、画符、叠护身大阵、攒一堆替死/保命底牌，压低劫气，专靠信息差和阵法阴死高境界大能；
    * **狂徒入劫流**：主动揽因果，以战养战，一路抢各路大能的法宝，把封神榜上的人全打成手下败将。
  * **斗法强调“法宝对轰 + 破阵 + 摇人”**：极富封神演义画面感——你祭出捆仙绳，对面展开九曲黄河阵，你拍出破阵符再磕一颗九转金丹强行破境反杀；平时攒的师门人情、道侣关系还能在绝境触发“传讯摇人”或“借宝一用”。
* **重玩动力**：
  * **可亲手填满的“封神榜”（如 36 天罡 / 72 地煞神位）**：每局通关后，根据你的流派、因果阵营和终战表现，你的名字会被正式刻在某个神位上（如雷部正神、财神、瘟神、散仙、叛道魔尊），并解锁对应神位的特殊事件或新法宝。
  * **动态势力剧本**：大教、散修盟、妖族、人皇朝堂每局的强弱与重宝归属随机，同一件法宝在不同势力手里会触发完全不同的争夺事件。

### 方案三：《掌中仙府》——“随身洞府灵脉引擎 + 秘境探险”的构筑修仙肉鸽

* **一句话世界观**：你意外捡到一枚残破的“掌中乾坤珠”，里面自带一小片灵田、一口破丹炉和一方灵眼。从此你一边出门闯秘境、逛坊市、抓妖兽、结道侣，一边把所有收获塞进随身洞府里布阵、炼丹、温养法宝，滚雪球式暴富，最终举府飞升。
* **单局体验（从草庐到九阶仙府的发育爽剧）**：
  * 把修仙爽文里最让人上头的**“随身空间/捡漏种田 + 越级暴打”**做成一局 15 分钟的完整闭环：从一间 3×3 的破草庐起家，一路练气→筑基→金丹→元婴→化神，把随身空间扩张成 5×5 的九阶仙府，最终灵气太盛引来天道嫉妒，扛过三波**仙府天劫**，举府飞升。
* **核心循环与玩法**：
  * **双节拍循环（极适合手机竖屏单手操作）**：
    * **出门（上半屏：秘境/坊市/宗门奇遇）**：快速选路打妖兽、拍卖行捡漏、收服灵兽、结识道侣/丹童、触发宗门大比与宿敌截杀。
    * **回府（下半屏：洞府灵脉盘构筑）**：把你得到的灵草、丹炉、法宝胚胎、聚灵阵眼、灵兽窝、道侣居所、甚至抓来的心魔，**摆进洞府格子里**。相邻格子会产生强烈的修仙化学反应：
      * `聚灵阵` 挨着 `千年灵草` → 自动催熟，直接喂给旁边的 `丹炉` → 自动出丹；
      * `丹炉` 挨着 `异火/雷池` → 炼出带劫雷的“雷丹”，吃下去涨修为，战斗时直接炸对面一脸；
      * `灵兽窝` 挨着 `本命法宝` → 妖兽吞吐精气持续温养法宝，让法宝进化出妖兽神通；
      * `道侣居所` 挨着 `修炼室` → 双修效率翻倍；但如果旁边放了 `魔道禁典`，道侣可能和你一起堕魔，触发全新魔修连锁；
      * 甚至可以把战斗中产生的 `心魔` 关进 `镇魔塔` 旁边，反过来把心魔炼成大药！
  * **斗法爽感（自动连锁核爆 + 关键手动插牌）**：斗法时，你的洞府灵脉盘像一台修仙引擎按回合自动运转（产灵气→炼丹→自动嗑药→触发法宝→引动阵法→雷霆洗地），满屏连锁触发极其解压；玩家只需在关键节点手动拍出符箓、保命丹药或选择是否强行破境。
* **重玩动力**：
  * **“以撒/小丑牌”级别的组合涌现**：几十种灵物、丹炉、阵眼、法宝、灵兽、道侣、心魔之间的相邻联动与进化配方，玩到第几十局依然能开发出全新邪道套路（如“丹炉炸炉核爆流”“心魔发电厂流”“万兽养剑流”“合欢双修流”“纯靠符箓白嫖流”）。
  * **不同开局洞府雏形**：药王残炉、万妖图录、太古灵泉、合欢秘境、幽冥鬼市……开局地形和初始核心建筑不同，构筑思路彻底改变。
  * **图鉴与飞升奇观**：记录你每一次举府飞升时的仙府布局与奇葩套路（类似“仙府快照”），满足收集欲和晒图欲。

### 方案四：《逍遥登仙路》——“八仙式修仙怪杰 + 红尘九难”的游历肉鸽

* **一句话世界观**：蓬莱仙会重开，不问出身、不论正邪，只看谁能在红尘游历中度过九重劫难、凑齐机缘道果，凭自己的独门神通横渡弱水沧海，登临仙班。
* **单局体验（一部轻喜剧风的修仙公路片）**：
  * 取材《八仙过海》的“各显神通”与市井烟火气。单局走**红尘市井 → 宗门秘境 → 弱水天劫**三段大路，每段结尾过一关标志性大劫（如恶蛟拦江、心魔幻境、天雷拷问），最后亮出你的独门本事横渡沧海登仙。
* **核心循环与玩法**：
  * **不按元素/兵器分职业，而是按“修仙活法（怪杰身份）”开局**，每个角色的底层核心玩法完全不同：
    * **醉道人**：背酒葫芦炼万酒，越醉爆发越离谱，靠醉意触发随机神通；
    * **行脚丹师**：悬壶济世攒功德，背地里顺手炼毒丹阴人；
    * **铁口神算**：看卦象改天命，把坏事件强行算成大机缘，甚至篡改敌人下一回合意图；
    * **散财散修**：用铜钱法宝砸人、坊市低买高卖、直接砸灵石雇宗门大能当打手；
    * **食铁/吞天妖修**：什么都能往嘴里塞——吞妖兽、吞灵草、甚至吞掉对手的法宝来变异成长；
    * **红尘书生**：靠情劫、道侣羁绊与文气破境，一路收服狐妖、女剑修、鬼新娘。
  * **玩法骨架**：竖屏轻卡牌/神通构筑 + 高交互奇遇事件。你身上的丹药、法宝、道侣和当前境界会直接解锁事件的“逃课/装逼选项”（比如别人要苦战的山大王，散财散修直接拿灵石砸服收成小弟）。
* **重玩动力**：
  * **角色差异极大**：通关一个怪杰后，换下一个角色几乎像玩了一套新规则。
  * **“蓬莱仙桌”跨局联动**：每通关一个角色，他就会正式入座你的蓬莱仙桌；之后你玩其他角色时，有概率在路边偶遇“之前飞升的那个老哥”来送法宝、指点破境或切磋喝酒，既有成就感又充满惊喜。

### 我最心动的方案：**方案三《掌中仙府》**

如果只能挑一个立项，我最心动的是 **方案三《掌中仙府》**（并且可以自然吸收方案一的“五境破境节奏”与方案二的“飞升仙号/神位图鉴”）。原因有四点：

1. **它最能把“丰富的修仙元素”变成“真玩法”，而不是贴皮数值**
   很多修仙肉鸽把灵草、丹药、法宝、阵法、妖兽、道侣、心魔都做成了“攻击+15% / 暴击+10%”的词条，玩两局就觉得是换皮。而在《掌中仙府》里，**灵草种出来喂丹炉、异火催出雷丹、灵兽温养法宝、聚灵阵放大周围效率、道侣双修、镇魔塔炼化心魔**——每一个修仙元素都是洞府盘上看得见、摸得着、能互相触发连锁的“活机制”。玩家会真切觉得自己在折腾一套修仙体系，而不是在算加减法。
2. **上手极快，但能撑起几十局以上的“涌现式重玩动力”**
   竖屏把东西拖进格子里摆位置，任何人 30 秒就能懂；战斗时看着自己搭好的修仙流水线自动运转、连环触发、满屏跳字，爽感非常直接（类似《小丑牌》《背包乱斗》那种“引擎启动、数值爆炸”的快感）。更重要的是，**网格相邻联动 + 合成进化**天然会产生海量设计师都没完全预料到的邪道组合，玩家打完一局会立刻产生“下局我要试一下把心魔和丹炉摆一起会怎样”的强烈冲动。
3. **单周目爽文弧光极完整**
   “捡到残破随身空间 → 穷得叮当响 → 秘境捡漏/拍卖会抄底 → 洞府扩建、丹宝成群 → 境界一路暴涨碾压宿敌 → 灵气惊动天道、扛过天劫举府飞升”，这是修仙网文读者最百看不厌的黄金爽感闭环，10–20 分钟打完一局，既有“种田发育的满足感”，又有“渡劫飞升的终局高潮”。
4. **对 1–2 人小团队最友好，研发杠杆最高**
   不需要做复杂的动作演出、不需要画海量精细大地图，也不需要靠写几十万字分支剧情来撑复玩率。核心工作量集中在**“洞府网格连锁规则”+“百来种高辨识度的修仙物件/事件”**，系统搭稳后，每多加 1 个新法宝、新灵兽或新道侣，都能和现有池子产生乘法级的新玩法，非常契合小团队持续迭代。
