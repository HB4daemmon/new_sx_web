# Claude（盲写，未看其他四家）

先拆三个新要求，各自对应一个设计问题：

- **单周目完整** → 一局要有「起承转合」和**结局**，结局要能被叫出名字（"我这局是开宗立派结局"），而不是"死了 / 通关了"两种。
- **重复游玩动力** → 动力最好来自**没见过的东西**（新结局、新出身、新境界、新组合），而不是"再刷一点数值"。数值成长只做调味。
- **修仙元素丰富又不是换皮** → 关键是**每个修仙元素承担一种不同的玩法职能**。如果丹药、符箓、法宝都只是"+攻击"，那就是换皮；如果它们各管一件事，玩家用起来就自然在"修仙"。

我先给一张"修仙元素 → 玩法职能"对照，后面几个方向都可以复用：

| 元素 | 玩法职能 | 玩家感受 |
| --- | --- | --- |
| 灵根 | 开局抽签，决定这一世擅长什么 | "这辈子是天灵根还是废柴" |
| 功法 | 主动招式 / 出牌，构筑核心 | 我的打法 |
| 境界 | 章节 + 数值跃迁，突破时三选一大强化 | 一路往上爽 |
| 法宝 | 被动 / 常驻效果，叠加出流派 | 越攒越离谱 |
| 丹药 | 一次性消耗：回血、临时爆发、冲关加成 | 关键时刻嗑一颗 |
| 符箓 | 一次性战斗道具，可预埋 | 稳健派的底牌 |
| 阵法 | 战场布置：开战前生效的场地规则 | 以弱胜强 |
| 宗门 | 中期选择阵营，决定商店、师父、任务线 | 有归属 |
| 秘境 | 高风险高回报的分支路线 | 搏机缘 |
| 天劫 | 每个大境界的 Boss，形态看得见、可提前准备 | 高光时刻 |
| 心魔 | 你这一局的选择累积出的"内鬼"Boss | 自作自受 |
| 道侣 | 一条可选的人物线，影响结局 | 情感钩子 |
| 妖兽 | 普通敌人，也是可收服 / 取材的资源 | 敌人即奖励 |

---

## 方向一：一世传（一局 = 一个修仙人物的一生）

**一句话**：你投胎成一个修仙界的凡人，这一局就是他的一辈子——测灵根、拜山门、闯秘境、结金丹、斗心魔、渡天劫，最后落一个结局。

**单周目结构（起承转合）**：

| 幕 | 境界 | 内容 | 结束于 |
| --- | --- | --- | --- |
| 起 | 炼气 | 出身事件、测灵根、拜入宗门（三选一） | 宗门入门考核 |
| 承 | 筑基 | 宗门任务、坊市、第一次秘境 | 宗门大比 |
| 转 | 金丹 | 宗门危机 / 正魔之争、道侣线、心魔种子 | 结丹天劫 |
| 合 | 元婴 → 化神 | 自己的道成形；心魔现身；最终大劫 | 飞升或其他结局 |

**结局（每局一定落在其中一个）**：白日飞升、坐化留名、开宗立派、堕入魔道、为道侣兵解、被封神、走火入魔成了下一局的 Boss……结局由你这一局的**选择**和**状态**决定，不只看输赢。死在中途也是一个结局（"陨落于金丹天劫"），会有一段完整的生平碑文收尾。

**重复动力**：
1. **结局图鉴**：二三十个结局，很多要特定出身 + 特定路线才能触发。
2. **出身池**：凡人、世家、魔门弃徒、妖族化形、转世大能……不同出身开局事件和第一幕完全不同。
3. **宗门**：丹鼎、符箓、阵法、御兽、炼体、佛门、合欢……按"修行方式"分，不是按元素兵器。每个宗门有自己的师父、门规和一条任务线。
4. **世界编年史**：你上一世开创的宗门、留下的洞府、结下的仇，会在后面几世以"几百年后"的形式出现。世界在长大，但每一局仍然完整独立。

**爽点**：一局之内完整走一遍"废柴 → 天骄 → 大能"的网文弧线；突破境界时的数值大跃迁；越级斩敌。

## 方向二：宗门一劫（一局 = 一个宗门的生死存亡）

**一句话**：你是没落小宗门的最后一个弟子，魔头三年后打上山门。这一局，你要在三年里把自己和宗门一起拉起来。

- **完整故事**：开局宗门破败 → 招弟子、修大阵、炼镇派法宝 → 魔头攻山的终局之战。守住就是"中兴之主"结局，守不住是"山门陨落"，跑了是"携宗门火种远走"。
- **修仙元素**：大阵、灵脉、丹房、藏经阁、弟子（可当护法）、长老、门派大比、外敌、内奸。
- **重复动力**：每局换一个宗门（剑冢、丹宗、兽宗、佛寺），敌人也换（魔头、妖王、正道伪君子）；不同宗门的终局之战机制不同。
- **风险**：偏经营，和"爽、上手快"有距离，适合做成方向一里的一幕。

## 方向三：秘境百日（一局 = 一次秘境开启）

- 上古秘境开启一百天，各路天骄蜂拥而入。你从外围摸到核心传承殿。
- 完整故事：入境 → 抢机缘 → 遇到并解决几个天骄 → 传承殿争夺 → 出境。
- 修仙元素：秘境禁制、灵药、传承、守护妖兽、天骄、黑吃黑。
- 重复动力：秘境种类多（剑冢、丹宫、龙墓、魔渊），每座秘境主人不同、传承不同。
- 评价：单局完整、节奏紧凑，但"修仙人生"感不如方向一。

## 方向四：仙门大比（一局 = 一届大比）

- 一届正魔共同参加的仙道大会，从海选打到决赛。
- 完整故事：报名 → 小组赛 → 淘汰赛 → 决赛 → 会后的秘境奖励。
- 重复动力：对手池、每届特殊规则。
- 评价：结构清楚、爽点集中（打脸），但内容会偏单一的战斗。

## 我最心动：方向一「一世传」

理由：

1. **单周目完整是天然的**：一辈子本来就有头有尾，"起承转合"直接对上四个大境界；结局有名字、有碑文，打完一局就像看完一本短篇修仙小说。
2. **修仙元素最全**：只有"一生"这个容器能自然装下灵根、宗门、秘境、道侣、心魔、天劫——其他方向都只能装其中一部分。方向二、三、四都可以作为一世里的某一幕。
3. **重复动力来自"没见过"**：结局图鉴 + 出身池 + 宗门 + 世界编年史，四条线都是"看新内容"，不是刷数值。第 30 局想的是"我还没当过魔修""我还没打出被封神结局"。
4. **元素即机制，不是换皮**：上面那张对照表让每个修仙词都有自己的玩法职能，玩家用丹药、贴符、布阵、渡劫时，做的事真的不一样。
5. **小深度清楚**：寿元有限、心魔会累积、宗门门规会限制你、道侣会影响结局——每个选择都写进"这一生"，结局就是这些选择的回报。

**最小可做版本**：两个出身、三个宗门、四个境界、一套天劫、八个结局。先验证"打完一局像看完一个故事"和"想看下一个结局"这两件事成不成立。
