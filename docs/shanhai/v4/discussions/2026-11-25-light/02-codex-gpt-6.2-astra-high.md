《随时修仙》的第一句话，我想写成：**“水还没开，要不要成个仙？”**

我想到三个世界。它们的区别，不在天庭长什么样，而在于玩家打开游戏时，究竟在期待什么。

**一、山中一顿饭：我就出去一会儿**

你住在山脚，家里那口灶有点脾气：锅盖一响，后门外就会多出一条平时没有的山路。山里走半天，家里只够烧开一壶水。你本人穿着草鞋就能去，不必拜师，也不用跟谁请假。

这座山上，仙位跟山川一样古老，坐仙位的人却常常换。渡口不能一天没有摆渡仙，但昨天撑船的是条龙，今天为什么不能是你？**这里的规矩是：先做成一件只有那种神仙才会做的事，天地才肯把法宝交给你。**

- **摆渡人 → 渡主 → 津口水君。** 起初只能捎一个人，后来能把原本互不相通的两处地方接起来。晋升仪式叫“渡船过河”：老船在这条河上跑了三百年，自己从没当过乘客。想办法让它坐一回船。做成以后，连对手刚劈过来的一掌，你都能问一句：“这位，到哪岸？”
- **帮厨 → 掌勺 → 司宴仙。** 别人见火就躲，你能留到下回合开灶。晋升那天，得让两个不肯同桌的人吃完一道菜。雷公和河伯谁也不愿先服软，却都把碗往汤盆边推了推。到了仙位，你敲一下锅沿，全场无论敌友都得先坐下吃第一口。
- **跑堂 → 掌柜 → 留客仙。** 擅长把本该消失的东西留一晚：快散的护身云、只肯帮你一招的猴子、商店里暂时买不起的宝贝。晋升要在客满的夜里，给最后一个客人腾出住处。法宝是一块“尚有空房”的木牌，挂在葫芦上也算数。

所谓失控，不是入魔，而是**做这行做得有点过了**。留客仙若迟迟不肯送客，三个客位都会被老朋友占满；门外来了真想留的白鹿，只好亲手把一位熟客送走。猴子临走还把房里的桃核都带上：“下次我还住这间。”这既是笑点，也是真要做的取舍。

一局收在锅盖响第二声。登顶的人回家，半路摔进溪里的人也回家，区别是今晚人家聊起你，会说“那位水君”，还是“那个连船一块儿背过河的人”。**仙位留在山上，交情带得回来。** 下局你若当了帮厨，也许能遇见接你班的摆渡仙，吃上你昨天亲手渡过去的那船笋。这样重开不是前功尽弃，而是想看看山里后来怎么样了。

**二、人间闲事归我管：我想当个管得特别窄的神**

天上有雷部、斗部，人间也有许多不值得惊动雷部，却值得有个神仙的小事：晒被子的时候别下雨，久别的人别在街口错过，滚到床底的铜钱最好往外滚。你是个还没有庙的小神，每局从街坊的三个愿望里挑一个。**挑的不是任务，是这一局你说了算的那条规矩。**

我最想玩的是“管刚刚好”。挑担人起步时，你替他扶住最后一只要掉的梨，得名**扶秤童子**；后来修成**平斗官**，能把两边的轻重拨匀；封为**分寸星君**以后，面对一头九百斤的山猪和它身后一排小猪，你依然只有最初那个本事：拨匀。只不过现在，九头猪一起缓缓离地了。

另一条路叫“管错过”。你从替人喊一声的**传话郎**，修成专管重逢的**相逢使**。别人扔空的法宝，你能让它在三回合后和原主“久别重逢”。上局是温情故事，这局可能是某位大仙终于又见到了自己扔出去的砖。

每局是一炷香，不按现实时间烧，只随选择往下烧。香尽，愿望了结，小庙多一块街坊送的匾。匾不加攻击力，只写实话，比如“寻物有方”，或者“铜钱找着了，床没了”。这个世界最有意思的地方，是**神职越窄，玩家越想钻研它到底能管多宽**。

**三、神仙散席以后：我还想跟他们再走一段**

很多神话写群仙赴宴，很少写宴席散了，各路神仙怎么回家。我的第三个方案，整款游戏就发生在散席之后。你是席上唯一没喝酒的散仙。出门时随口问一句“谁跟我同路”，一局就开始了。

你不用把所有人送到。送到第一家就可以喝碗醒酒汤收工，也可以贪心，绕远路再送一位。好玩的地方是：**同行的人既是你的本事，也是你要亲手送走的人。** 雷公能震开挡路的山门，但他家就在半山腰。先送他，好处是雷嫂送你一面小鼓；晚点送，他还能帮你开门，可越走越困，下一声雷什么时候响就不由你了。

这里的成长不是越来越有排场，而是从**同路人**，变成大家愿意把法宝托付给你的**领路人**，最后做一次真正的**引路星君**：把最后一位客人送到，独自摸黑走完最后一段。快到家时，抬头看见沿途每一家都给你留了盏灯。这个方案我会少写一半段子，让那一刻安安静静。

**我最心动的是第一种，尤其是“渡船过河”。** 它让我既想知道这船怎么渡，也立刻想试试：既然船能算乘客，还有什么能算？这比告诉玩家“水君解锁了转移技能”更让人手痒。它也适合小团队：先只做一个渡口、一条山路、一桌山宴，让“捎走、留住、开席”三种本事都能作用在同一批人和物上。同一朵雷云，摆渡人想把它送到对岸，掌柜想留到明天，厨子看一眼说：“正好，灶冷了。”**第 50 局的新鲜，最好不是终于刷到了第 50 只怪，而是面对见过十次的东西，忽然起了一个以前没起过的念头。**

至于主界面，我会只画一口灶、一扇后门。门上压张家里人留的纸条：**“去山里可以。回来带把葱。”**
