最心动的是这一句：**仙力是工夫，工夫是没被正事用完的那一点时间。** 你不是天命之人，你是今天下午正好有空的那一个。天上的班表永远缺一个人，缺的不是英雄，是一个愿意绕路、愿意迟到、还愿意把场面圆完的人。

《随时修仙》可以就长在这句话上。闭关依然受人尊敬，那是山上的事；县城里流行的是另一派，见缝插针，修完把扇子还回去，回茶馆继续招呼客人。第 50 局还想打开，是因为每一局都是一个不同的下午，不是因为背后藏着更黑的真相。

## 这个世界

人间是一座沿河的县城：茶馆、集市、渡口、祠堂、一家总在办喜事的大户、一座总说「明日再开」的小庙。天上有衙门，有榜，有官职和法宝，但衙门午后就没什么人。封神的大战是茶馆里的旧段子，讲法像在讲某年年会打起来了，连累全部门加班。八仙是在职的人，各有脾气、各有一件认死理的宝贝，也各有今天不想到场的理由。

修仙在这里是公开的手艺，分两派，互相看不顺眼，也互相借人。

- **山上派**认为要沉住气，留足余地，能不闹就不闹。
- **随时派**认为法力长在多余的那一步：多坐一盏茶，多送一程，多给一个本可以不给的场面。迟到不是失礼，是你在路上把工夫花掉了。花掉的工夫会回来，变成神通。

玩家走的是随时派。稳健师兄是山上派下来观摩的，口袋里永远有十二张便签。他不是来嘲讽你的反派，他是另一种合法的玩法站在旁边：少绕路、少入戏、场面小，但是很少塌。

资源就叫**工夫**。这个词人人懂，既是时间，也是本事。赶最短的路，工夫就少；肯绕，工夫就多。神通是把工夫一次花出去。花得漂亮，满街叫好；花得勉强，宝贝会嫌你敷衍。

失败也停在这个语气里。局可以结束，人会被驴驮回茶馆，师兄递来一碗水和一句「花哨了」。榜上用粉笔写一行评语，下午到此为止。

## 玩家是谁

你在茶馆有一份地面身份，名字普通，下午经常空着。账房先生喜欢在封神榜的边角写临时的名字。你的名字写在边角上，所以你不是真仙，你是**候补**。

候补的意思很具体：今天八仙或哪处神位空出一个席，印、名帖和一件法宝先交给你。人是你自己去。席位是借的，路是你自己走的，神通要你自己出。真仙多半在睡觉、钓鱼、跟驴赌气，或者坚持「我马上到」。

所以你能随时修：县城随时缺一个凑数的，你随时有一个下午。一局就是一个下午，日头落下去，印要还，宝贝自己跑回主人身边。下一局是另一个下午，另一把空着的椅子。

重开不用解释成诅咒。下午总会再来。茶馆老板记得你上次的借口，集市记得你上次的外号，粉笔字被雨冲掉以前，会变成下一局的闲话。

## 途径：每级都是一个别人会这么叫你的身份

途径不按元素分，也不按兵器分。一条途径是一种做人的路数。身份是街坊叫得出口的称呼。晋升靠**入戏**：把这个身份的规矩当真做一遍。仪式都很小，小到像人情。

做过头会**入戏过深**，也就是这套规矩的失控。它不可怕，它是职业病。你开始不得不绕路，不得不把笑话讲满，不得不先写完那三行字再动手。入戏是这一局的趣味枷锁，也是这一局的强度来源。有人喊你茶馆里的本名，或师兄说一声「行了」，就能把戏收一收，代价是这次消化变慢。

一条途径一局能升两三级就够爽。更高的身份多半是你听说过、偶尔客串、很少在头一局里坐稳的。

**闲逛**（迟到、绕路、不请自来）

1. 有空的  
2. 串门的  
3. 垫场的  
4. 不请自来  
5. 座上客  
6. 人未到，名已到  

规矩：每到一处，先接受一件顺路的事，再办正事。能晚到就不要第一个到。  
仪式：比所有人都晚进场，并带一段路上的见闻。  
入戏：你会没法走直线。巷子自己变长，长出来的那一截里总有事。

**说合**（帮腔、圆场、一句话定个气氛）

1. 帮腔的  
2. 圆场的  
3. 保人  
4. 主婚  
5. 一句话的人  
6. 开口就有人应  

规矩：承诺要有人听见；不许背着人改口。  
仪式：让三个原本各说各话的人，为同一件事笑出来，或者把一场吵闹说成两边都有台阶。  
入戏：你的口头话会按字面应验。你说「这杯酒算我的」，酒就真的算到你头上，场面往往比你想的大。

**手艺**（修、煮、配、把坏了的东西哄好）

1. 打杂的  
2. 上手的  
3. 坐堂的  
4. 一味  
5. 偏方  
6. 妙手  

规矩：动手前，得用大白话跟一个外行讲清你在干什么。对方越听得懂，效果越稳。  
仪式：修好一件东西，不收银子，改吃一顿饭。  
入戏：你看什么都像要修，包括天气、桥、和某人的心情。

**体面**（留余地、写短、不抢头功，稳健师兄的本行）

1. 记一笔  
2. 作保的  
3. 主事的  
4. 挂名的  
5. 客卿  
6. 人还在路上，字已经到了  

规矩：先留退路，再表功。报告尽量短。  
仪式：用三行以内的字，把这场乱子写清楚，并且不把自己写成主角。  
入戏：手续不漂亮，你就下不了手；换来的是，归你管的场面不怎么塌。

**凑热闹**（吹拉、起哄、把普通人变成观众）

1. 凑数的  
2. 起哄的  
3. 开场的  
4. 压轴的  
5. 再来一出  
6. 全场都看着你  

规矩：至少要有一个观众。鸡、小孩、驴，都算，只要它们真的在看。  
仪式：让一个没打算鼓掌的人鼓了掌。  
入戏：没有动静你就使不上劲。冷场时，宝贝会闹情绪。

深度在**客串**。你主修一条，临时借用另一条的规矩，工夫会叠，入戏也会叠。闲逛的人去主婚，体面的人去压轴，都是好局，也都容易收不了场。

法宝不是途径，是今天借给你的同事。一件宝贝只有一条脾气。

- **扇**：可以把刚才的小事故重来一遍，但重来必须更好看。洒了的酒会变成敬酒，不会变成「事情没发生」。
- **驴**：在两条路里替你挑。它挑的那条更远，更有事。你跟着走，闲逛就消化得快。
- **葫芦**：替你装一件「等下放」的东西。放着别急，它会变好一点；装太久，它自己消化，再打一个可爱的饱嗝。
- **花篮**：把一件麻烦放进去，拿出来会变成礼物。礼物必须在日落前送掉。
- **笛**：让对面跟着你的节奏走。打架会变成一问一答，吵闹会变成轮唱。
- **玉板**：拍一下，这个场面就「作数」。作了数的场面不容易被搅局，可你也得守场面的礼。
- **荷花**：有人看着的时候，你可以走过一段本来会尴尬的路。没人看，它就是一朵花。
- **剑**：它砍麻烦，不砍人。绳、僵局、过长的致辞、拦路的旧规矩，都是它认识的敌人。

## 一局下午长什么样

账房把你从茶馆喊走。楼上汉钟离在午睡，扇子先归你。今日的空席在河边喜事：八位里缺一位，渡河的彩头就不算数。你的身份是凑数的。便签上师兄写着：少说话，晚到，别接扇子的戏。

驴不归你管，它只是跟任何看起来不赶时间的人走。它把你带进集市。包子掉了一地。你帮着捡，这是绕路，闲逛消化了一点，工夫进账。卖包子的告诉你，新郎的舅舅准备闹一场。

你晚到。舅舅果然闹。酒杯要翻。你没听师兄的，用了扇子。酒停在半空，自己转成一杯敬酒。满场先是静，然后小孩拍起手。扇子很满意，师兄闭上了眼。

这时可以晋升。仪式是：在日落前把这个功劳让出去。你若揽在自己身上，扇子会更兴奋，入戏加深，真仙可能提前醒。你若把舅舅敬成「今日全靠舅公」，说合与凑热闹一起消化，身份从凑数走到能开场的那一档。

收场的神通不需要毁天灭地。嫁妆和人都还在河边，你把工夫一次花掉，让整队人踏着掌声过河。刚登上对岸，楼上那一位到了，看了看，说：「还行。」扇子自己飞回去。账房用粉笔写：候补今日迟到，场面很好。

下一局开场，卖包子的可能会喊你「酒仙」，也可能把你认成「会捡包子的那个」，于是空着的席变成了别的：求一场刚好停在菜地边的雨，给老寿星找一个压轴，或者替师兄去还一把他绝不承认自己借的伞。

## 什么好笑，什么爽，为什么第 50 局还新鲜

好笑来自身份和日子拧在一起。土地收到的祈愿是「隔壁的鸡又来了」。你用玉板把这件事升格成正式公务，鸡就得被郑重地送走。宝贝嫌你不会办事，开口像老师傅骂学徒。街坊拆你的台：「你这主婚的，口音还是茶馆的。」师兄的十二张便签你可以全听，听完会赢得很小很稳；你也可以一张不听，听完会赢得很花，并且在日落前拼命找人收场。

爽是同一件事的三层。

- 当下爽：一件小法宝在一件小事情上大获成功，全街都看见了。
- 身份爽：你靠把规矩做满，当众换了一个更像样的称呼。
- 收场爽：最后那一下神通是你这一路攒下的工夫，不是开局就发的一把大刀。

第 50 局新鲜，靠的是排列，不是揭秘。

- **今天的空席**在变：喜事、过河、赶集、寿宴、小庙开张、送一个人出城。
- **起手身份 × 借到的宝贝 × 师兄今天多管闲事的程度**在变。
- **粉笔闲话**在变。县城用外号记住你。外号会给你方便，也会让你被当成上次那个人，从而逼你客串一条你没主修的途径。
- **宝贝的心情**在变。扇子记得你上次让它好看过；驴记得你上次没跟它走。
- **常驻的人**在轮值：账房、师兄、小孩、永远在办却永远换一家人的喜事、以及最后五分钟才到的真仙。真仙是谁，取决于今天空的是哪一席。

固定的是县城和这一套人情规矩。变的是今天你被叫去当谁。

## 另外三个也能成立的世界

**今日之师。** 教学本身是一种扮演。县城里的仙人发现，收一个下午的徒弟，自己的身份消化得特别快，于是你变成抢手的学生。每一局都有人要当你的临时师父，课表就是途径，学费是你帮他把场面做完。日落出师，师父获得一行光彩的履历，你获得一个下午的身份。分叉在于你跟谁学、让不让师父失望。好笑在于两个师父的规矩互相打架：一个让你晚到，一个让你准时，而准时在这个世界里会让你变弱。

**社戏扮神。** 神话是庙会戏班每年重排的剧目。你是班里随时能顶上的人。途径就是行当，身份就是今晚戏单上的角。仪式是彩排和上台。入戏过深，是散戏以后街上仍按戏词运转：你若在台上答应了送亲，台下就真有一队人等你。重开是因为明天换戏，行头收回箱子。这一方案最容易做出「第 50 局」，因为戏单、配角和即兴可以一直重组。它的危险是整局都像在舞台上，县城的生活感会变薄。

**香火小铺。** 神是街坊服务业，香火是小费。没人值班的小祠堂，你都可以顶一个班：门口的、灶上的、渡口的、学塾里那个不管功名、只管小孩有没有偷偷睡觉的。途径按你伺候的人情分。爽来自把一件鸡毛蒜皮办得极有排面。这一方案最贴「随时」，也最容易滑成看香火数字的铺面经营。要成立，就得让你离开铺子去跑腿，香火只是收场时的掌声，不是主界面。

这三个都能嵌进同一个县城：庙会是凑热闹的主场，小祠堂是某几天的空席，抢徒弟的人是你在路上遇见的真仙。主轴仍是候补那一席。

## 为什么是它

因为它把题目四个字写成了世界，而不是写成口号。

「随时」说明了你是谁：有空的人。「修仙」说明了下午干什么：把工夫花成一个身份、一件神通、一个场面。「一局重来」就是明天还有空席。「途径和晋升」就是街坊对你的称呼越来越像样，做过分了会染上这个称呼的毛病。「八仙」提供了人、席和认死理的宝贝。「封神」提供了榜的边角和粉笔。「稳健师兄」提供了另一套同样能通关的脾气，以及一路上的吐槽。

第 50 局你还想点开，是因为你想知道今天空着的是哪一把椅子，扇子还记不记得你，以及这次你打算听师兄的，还是再花哨一回。
