# Antigravity gemini-4-neon medium

下面基于《一世成仙：大限争渡》的既有骨架，给出一套面向**手机竖屏、1–2 人开发、单局 25–35 分钟**的完整系统设计方案，包含对既有骨架的微调、新增核心系统、单局节奏拆解、成本评估以及最小可玩版本（MVP）建议。

---

## 一、先审视既有骨架：保留什么，调整什么？

既有骨架的立意非常准——**“一局一辈子 + 寿元做时钟 + 破境分品质 + 终局因果清算”**天然解决了修仙肉鸽最容易犯的“换皮爬塔”问题。在动手加系统前，建议对骨架做 **3 处关键微调**：

1. **第五幕（化神渡劫）不做常规地图，改为“纯终局清算幕”**
   - 如果 5 个境界都要完整跑一遍历练地图，单局很容易拖到 45 分钟以上，且元婴到化神极易产生重复疲劳。
   - 调整为：**前四幕（练气、筑基、金丹、元婴）是成长与造因，第五幕是纯高潮收尾（心魔劫 + 九重天劫）**。既守住 25–35 分钟的黄金时长，又让“渡劫飞升”拥有独一无二的仪式感。
2. **四槽构筑明确“不可替代的职能”，避免沦为四个属性栏**
   - **道基**（灵根、命格、主修功法）：决定**玩法规则与战斗引擎**。其中灵根和命格开局定型（仅极少数逆天奇遇可改），局内专注打磨主修功法与破境神通，避免面板过重。
   - **本命法宝**：决定**长期成长爽感**（唯一可一路吞噬祭炼、跟着主角飞升的“养成型装备”）。
   - **百宝囊**（丹药、符箓、阵盘）：决定**临场博弈与“掀底牌”**（强消耗品，带容量上限，逼玩家做取舍）。
   - **护道者**（道侣、灵兽）：**合并底层机制**。不做两套独立的“好感度养成”和“灵兽喂养”，统一为“护道位（最多 1–2 个）”，统一提供**战斗援护 + 因果事件介入 + 渡劫挡灾/化魔**，道侣与灵兽只是题材和事件文案的差异。
3. **极简数值底座，拒绝传统 RPG 十维属性**
   - 不做五行克制表，不做暴击/闪避/穿透等硬核数值堆砌。
   - 全局只保留 5 个直观概念：**寿元（时间/命数）、修为（破境进度）、气血与护盾（生存）、灵力/战力（输出基准）、神识（先机、识破禁制与破绽）**。

## 二、核心新增系统设计

### 1. 局内推进结构：【岁历牌桌】+【押宝秘境】+【压境冲关】

手机竖屏不适合密密麻麻的爬塔节点连线图，而且连线图和“寿元消耗”结合感弱。建议改为**围绕寿元沙漏展开的“岁历抉择”**：

- **日常推进（岁历牌桌）**：
  每次行动，界面弹出 3–4 张【本年机缘】卡片，每张标明**消耗年数**与**收益/风险**，分四大类，各司其职：
  1. **洞府闭关（稳健打底）**：耗 2–5 年，稳定涨修为、祭炼本命法宝、炼丹/画符。零风险，但纯闭关只能攒出下品根基，甚至耗尽寿元坐化。
  2. **坊市/拍卖会（暴富与赌博）**：耗 1–2 年，买卖百宝囊底牌、**赌古修残片（捡漏暴富）**、参与**拍卖竞价（与同代人抬价，甚至散场后黑吃黑劫杀）**。
  3. **秘境探索（赌徒心理 Push-Your-Luck）**：耗 3–6 年，进入一个 3–4 步的微型事件链（如：*外围摸尸 → 破解禁制 → 遭遇同代人争宝 → 核心传承*）。每走一步战利品翻倍但风险剧增，玩家**随时可以“见好就收”撤退，也可以贪心搏命**。
  4. **红尘/邪道（因果与捷径）**：正道奇遇、同代人挑衅、以及寿元告急时的**魔道捷径**（抽魂提修为、吞毒丹破境、杀人夺宝）。捷径能瞬间拉回崩盘的局，但会大幅增加【业力】，让终局天劫变得极其凶险。
- **核心深度取舍：【立刻破境】vs【压境打磨】**：
  - 修为达到 100% 时，玩家随时可以点击冲关破境。
  - 但直接冲关往往只能结出中下品；玩家可以主动选择**继续压境**，多花几年寿元去凑齐【破境奇物】（筑基丹、地脉灵火、无暇剑意等），把品级一路顶到一品甚至天品。
  - **代价**：寿元持续燃烧，且身怀重宝会引来高阶修士窥伺。几句话就能懂，但每一局都在做极具张力的取舍。

> **开发成本**：低。纯卡片抽取 + 状态机 + 微型事件链模板，非常适合竖屏单手操作。

### 2. 战斗系统：【三拍斗法】+【时机掀底牌】

一局 25–35 分钟，单场战斗必须控制在 **15–35 秒**。纯自动碰碰车没有“越级打脸”和“掀底牌”的爽感；复杂打牌又太慢、学习成本高。建议做**半自动快节奏斗法**：

- **自动对轰（省心）**：
  双方每回合自动按【主修功法】与【本命法宝】交锋（1–2 秒一拍，伴随简洁招式飘字、护盾破碎音效与震屏）。日常杂鱼可开倍速 10 秒解决。
- **玩家只管两个核心操作（10 秒上手，爽感拉满）**：
  1. **【掀底牌】与【破招打断】**：
     - 屏幕底部常驻【百宝囊】（上限 4–5 格）和【法宝神通】按钮。
     - **破招爽感**：敌人蓄力大招时会出现醒目预警（如*“血河老祖正在掐诀·血海滔天！”*），此时拍出【破法符】或触发【镇魂类神通】，直接**打断施法并令其陷入重伤破绽**！
     - **越级反杀爽感**：练气期撞见筑基恶霸，正常对轰必死，但你可以把攒了半幕的【金丹剑意符】+【燃血爆气丹】一口气砸出去，越级秒杀！
  2. **【斗法姿态】三选一**：
     - **搏命（强攻）**：功法与法宝威力大幅提升，但自身易露破绽；
     - **守御（蓄势）**：叠护体灵盾、回灵力，硬扛大招等敌人虚弱；
     - **遁走（留得青山）**：修仙世界不讲武德！打不过随时可以**烧一张遁符 / 丢一件宝物 / 损几年寿元**强行逃命，记下仇恨，等破境后再回来清算。

> **开发成本**：中。无需动作动画和寻路，重在数值节奏、破招反馈和 20–30 个特色底牌/神通的效果组合。**简版可先做 3 种姿态 + 4 格底牌 + 蓄力预警打断**。

### 3. 每幕高潮：【破境冲关仪轨】（3 步逆天加码）

破境品质是全游戏最核心的爽点之一，不能只是一个后台算分弹结果的弹窗，必须做成**30 秒的赌博式仪式**：

- **保底与加码**：
  冲关开始，系统先亮出你这一幕的底蕴（灵根 + 功法 + 攒下的破境奇物），给出一个**基础品级**（如“六品金丹”）。
- **三步冲关**（以结丹为例：*引灵入腑 → 炼精化丹 → 丹成聚纹*）：
  每一步玩家都面临一次心跳二选一：
  - **稳妥收束**：锁定当前品级，安全推进。
  - **逆天加码**：消耗额外寿元 / 投入备用高阶丹药 / 赌本命法宝共鸣，强行冲刺更高品级（失败会炸炉损寿元或掉品，成功则触发全屏异象，如**“一品无暇金丹”**甚至**“天道紫金丹”**）。
- **破境后的三重即时爽感**：
  1. **寿元暴涨**：顶部寿元沙漏瞬间注满（如 +150 年），焦虑瞬间释放；
  2. **神通觉醒**：按品级从神通池三选一（高品出逆天质变神通，废丹也有机会走“碎丹重修/邪道魔丹”的特殊流派）；
  3. **境界威压**：进入下一幕后，低阶修士和曾经刁难你的杂鱼再见面会直接颤抖让路/献宝，爽文味拉满。

> **开发成本**：低。四幕共用同一套 3 步冲关框架，仅替换境界文案、品级名和视觉特效色。

### 4. 核心爽文引擎：【本世同代人】与【因果簿】

爽文之所以爽，不是因为刷死了“妖兽#14”，而是因为**打脸了练气期退婚/抢宝的那个具体的人**。

- **本世同代人（每局随机生成 3–4 人）**：
  开局从人设模板池里抽出 3–4 个名字、出身、性格各异的同代修士（例如：*傲慢的剑宗天骄、势利眼的世家公子、亦正亦邪的魔道妖女、老实巴交的散修好友*）。
  - 他们会随时间流逝同步破境、拿机缘，甚至死在别人手里。
  - **跨幕复仇闭环**：练气期被剑宗天骄抢了机缘，你遁走忍辱；筑基期在拍卖会故意抬价坑光他的灵石；金丹期在秘境堵住他，当众反杀并**把他的本命剑喂给自己的法宝吞噬**！
- **因果簿（4–6 条核心标签，直通终局清算）**：
  你这一世的重大抉择都会被记入【因果簿】，例如：
  - *杀伐过重、夺人机缘、丹毒入髓、背弃护道者、恩怨分明、逆天改命*。
  - **到了第五幕【化神渡劫】**：
    - **心魔劫**：直接把你因果簿里的前 3 条具象化（比如你为了结丹献祭了护道者，心魔劫里 TA 会现身问心；你一路杀人夺宝，冤魂会化作心魔围攻）。
    - **九重天劫**：雷劫的强度与属性直接挂钩你的【业力/捷径次数】与【破境品级】。此时玩家把元婴期攒了一兜的避雷阵盘、替死符、护道者援手、本命法宝神通全部掀开硬扛，完成整局情绪总爆发！

> **开发成本**：程序成本低，主要在文案。不需要模拟大世界 AI，本质是“3–4 个固定 NPC 槽位 × 初遇/交锋/清算三阶段模板事件”。先写 25–30 组高浓度网文事件就能撑起极强重玩性。

### 5. 修仙元素的专属玩法职能（拒绝换皮词条）

为了让每个修仙元素都有不可替代的存在感：

| 修仙元素 | 在玩法中的专属职能 |
| :--- | :--- |
| **本命法宝** | **吞噬成长器**。打赢强敌掉的敌方法宝、秘境古宝，可卖灵石，也可直接**喂给本命法宝吞噬**，继承或替换它的核心词条（最多 3–4 条），金丹期后可觉醒**器灵**（会在事件中给提示/吐槽）。 |
| **丹药** | **状态、延寿与破境**。除疗伤和战中爆种外，核心是**破境丹**（冲关保底）和**延寿丹**（直接续命，但有【丹毒】累积，吃多了天劫翻倍）。 |
| **符箓** | **越级杀手锏**。高阶一次性爆发，能打出超越当前境界的伤害或强行破招，是“掀底牌”的核心来源。 |
| **阵盘** | **规则改写器**。可放进战斗或闭关生效（如*聚灵阵*让闭关收益翻倍，*困龙阵*禁止敌人逃跑与蓄力，*替死阵*抵挡一次致命雷劫）。 |
| **护道者** | **羁绊协同与挡劫**。战斗中按条件触发援护/合击；关键剧情里替你出头或牵出分支；渡劫时可为你挡一道致命天雷（但可能导致其重伤或陨落，写入《本世仙传》）。 |

### 6. 局外循环：让第 30 局依然有想试、想追的东西

不做传统“刷货币永久加攻击力”的数值养成树（会毁掉前期紧张感），而是围绕**“轮回感 + 收集欲 + 新流派体验”**：

1. **出身与奇异命格池（局外解锁）**：
   通关特定结局或达成条件，解锁新出身（如*“退婚废柴”“魔尊残魂”“炼丹世家弃子”“天煞孤星”“合欢宗外门”*）。每个出身自带一件**改写规则的开局奇物**，让每一局的打法完全不同。
2. **前世坐化洞府（强化轮回爽感）**：
   上一局无论飞升还是兵解，都会把你上一世的**本命法宝残片 + 一段遗言**打包存档。下一局探索秘境时，有机会撞见“前世的自己”的洞府，继承前世法宝的一条极品词条，甚至触发**“替前世斩杀当年仇敌”**的隐藏爽点。
3. **结局图鉴 & 竖屏《本世仙传》**：
   除常规飞升/坐化/兵解外，埋入一批有意思的命名结局（如*“散仙重修”“魔尊降世”“苟道长生”“丹毒爆体”“器灵夺舍”“情劫双飞”*）。每局结束自动生成一张古风竖屏战报《本世仙传》（含道号、各幕破境品级、宿敌恩怨、最终结局），方便玩家截图发群炫耀。

## 三、单局 25–35 分钟节奏预算

| 阶段 | 境界 | 预计时长 | 节点量 | 核心体验 |
| :--- | :--- | :--- | :--- | :--- |
| **开局** | 降生 | ~1 分钟 | 选出身/命格 | 一句话定本世人设、初始寿元（如 60 年）与初始奇物。 |
| **第一幕** | **练气期** | 5–6 分钟 | 5–6 次岁历 + 1 次冲关 | 快速上手，拿到本命法宝胚子，初遇同代人（吃瘪或小打脸），首次破境筑基。 |
| **第二幕** | **筑基期** | 6–7 分钟 | 6–7 次岁历 + 1 次冲关 | 确定主修功法，体验押宝秘境与拍卖会，收护道者，第一次尝试“压境冲高品”。 |
| **第三幕** | **金丹期** | 7–8 分钟 | 6–7 次岁历 + 1 次冲关 | **全剧最爽中盘**：高品金丹神通质变、法宝吞噬成型、开始越级反杀宿敌、正邪捷径分叉。 |
| **第四幕** | **元婴期** | 6–7 分钟 | 5–6 次岁历 + 1 次冲关 | 因果集中爆发：宿敌最终清算、前世洞府奇遇、为终局天劫疯狂搜罗底牌与阵盘。 |
| **第五幕** | **化神渡劫** | 3–4 分钟 | 心魔劫 + 九重天劫 | **纯高潮收尾**：因果问心 → 掀光所有底牌硬扛天劫 → 飞升/兵解，生成《本世仙传》。 |
| **合计** | **一世** | **28–33 分钟** | **约 22–26 节点 + 4 冲关 + 1 渡劫** | 起承转合完整，无后期垃圾时间。 |

## 四、最小可玩版本（MVP）建议

对于 1–2 人团队，建议以 **4–6 周跑通核心乐趣** 为目标，先做一套“自己玩着就能连开五局”的 MVP，验证战斗爽感、寿元张力和破境正反馈。

### MVP 必须包含的系统
1. **完整的“寿元时钟 + 岁历牌桌 + 押宝秘境”循环**：
   - 先跑通 **练气 → 筑基 → 金丹 → 化神渡劫** 4 幕闭环（约 20 分钟一局，元婴幕等底层调顺后再插入拉满到 30 分钟），确保玩家从第一版就能完整体验“一世成仙”。
2. **【三拍斗法 + 掀底牌 + 破招打断 + 遁走】战斗系统**：
   - 极简竖屏 UI（头像 + 血/盾条 + 敌人蓄力条 + 底部 4 格百宝囊 + 3 种姿态按钮），配合震屏与招式飘字。
3. **【破境冲关仪轨】（3 步逆天加码 + 品质定神通）**：
   - 每幕最核心的情绪高潮，必须第一时间做进去。
4. **三槽构筑（道基 + 本命法宝吞噬 + 百宝囊）**：
   - 最小内容量即可好玩：**4 个出身、6 本主修功法、4 种法宝胚子（配 15 个可吞噬词条）、12 种丹/符/阵**。
5. **轻量版【同代人 + 因果簿】**：
   - 每局先固定生成 **2 名同代人**（1 宿敌 + 1 亦敌亦友），因果簿先做 5 个核心标签，直接控制终局心魔劫文本与天劫难度。
6. **最小局外闭环**：
   - 8–10 个命名结局图鉴 + 文本版《本世仙传》+ **前世坐化洞府**（只需把上一局的法宝存成一条本地 JSON，下一局秘境必刷一次继承事件，成本极低但惊艳感极强）。

### MVP 刻意先不做的系统（及理由）
1. **完整的护道者（道侣/灵兽）养成与援护系统**：
   - *理由*：情感分支文案和额外战斗单位逻辑会大幅拉长首版工期。MVP 中可先将道侣/灵兽作为“特殊事件”或“百宝囊信物”客串，等核心循环验证好玩后，作为 **V1.1 的主打更新**端上来。
2. **炼丹/画符/布阵的独立操作小游戏（如控火、手绘符咒）**：
   - *理由*：容易打断肉鸽心流，且增加大量 UI 适配工作。MVP 中全部用“耗年数 + 选稳妥/加料赌变异”的轻决策表达，已经足够有修仙味。
3. **宗门经营、弟子招募、复杂拍卖会多方 AI 竞价**：
