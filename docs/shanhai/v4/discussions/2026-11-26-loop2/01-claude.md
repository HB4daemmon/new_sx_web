# Claude · 故事背景、循环与新鲜感（第二轮，盲写，未看其他各方本轮答案）

## 方案一：「家族修仙」（我最心动，参考《盗贼遗产》＋网文「家族流」）

**一句话**：你家祖上十八代都是凡人，到你这一代，后山祖坟冒了青烟。**你死了，你儿子接着修；你儿子死了，孙子接着修。**直到李家出一位真仙。

**背景**：
- 封神之后，仙门只收世家子弟，寒门修仙难如登天。
- 李家是青石镇的穷苦人家。某天祖坟冒青烟，挖出一块残碑，上面刻着半部功法和一句话：「李氏子孙，九代之内，必有人上榜。」
- 至于这块碑是谁留的、为什么偏偏是李家，就是长线的谜。

**为什么一局局重来**：每一局就是李家一代人修仙的一生。死了、老了、走火入魔了，就由下一代接班。

**局与局怎么接**：
1. **随机继承人**：每代死后，从三个孩子里挑一个接班。每个孩子带随机的天赋和毛病，比如「天生剑骨，但是路痴」「过目不忘，但是怕鬼」「天生神力，但是一喝酒就醉三天」。同一个家族，每一代都是新角色。
2. **家业会积累**：
   - 上一代挣下的宅子、田产、人情、仇家都会留下来；
   - 祖祠里供着历代先人的牌位，每个牌位给后人一点庇佑。
   - 这是盗贼遗产式的城堡升级，但用的是网文读者最熟悉的「家族崛起」。
3. **仇家也会继承**：你这代打了王家的少爷，下一代王家的孙子就来报仇。两家世仇越积越深，打脸也越来越爽。

**新鲜感的由头**：
1. 每代的继承人随机，天赋和毛病组合不同，打法就不同；
2. 每代出生时的世道随机：太平年、灾年、仙门大比年、封神补录年；
3. 家族越来越大，开局的起点越来越高，从寒门到小族再到世家，能挑战的东西也越来越大；
4. 祖祠里的先人越来越多，每个牌位的庇佑可以随机组合；
5. 奇葩先人会变成家族传说，例如「三代祖：喝醉了跟龙王打赌，赢了一条河」，下一代真的能去那条河领东西。

**长线与真结局**：
1. **第一层**：李家出了第一位筑基，然后金丹、元婴，从镇上小户变成一方世家。
2. **第二层**：发现残碑是封神时被打下来的一位小神留的，他的神位一直空着，在等自己的血脉。
3. **第三层**：上榜之后才发现，神位要用整个家族的气运去换。你要选：让李家世代当神仙的后台，还是把碑砸了，让后人自己选择修不修仙。
4. **新的开始**：砸碑之后，李家后人开枝散叶，各自修成不同的道，新一轮就从「各房分家」开始。

## 方案二：「封神补考」（参考《杀戮尖塔》三幕＋科举）
封神榜上的神位每六十年补录一次，像科举一样考：县试、府试、会试、殿试，四幕对应四次大考。

- 每局是一个新考生，出身随机；
- 落榜了，下一个甲子再考，也就是下一局；
- 考上的人会成为之后的考官和神仙，对你或放水或刁难；
- 进阶就是「这一届题目更难」。

爽点是考场打脸世家子弟；风险是科举的题材感可能盖过修仙。

## 方案三：「仙府拍卖行」（参考《小丑牌》）
三界最大的拍卖行，每局开一场。你是一个穷鬼，靠捡漏、倒卖、借贷，拍下能让自己成仙的东西。

- 每轮竞拍都有刁钻规则；
- 爽点在以小博大。

和上一轮 Neon 的「三界赊账人」相近，留作备选。

## 选哪个
**「家族修仙」**，理由：
1. **网文读者熟悉「家族流」**（例如「我家族修仙」那一类），一代代崛起、打脸世仇，爽点很直接。
2. **重来有天然的解释**：人会死，家族不会。每一代都是新角色，还都是「自己人」，情感能累积。
3. **新鲜感来自随机继承人加家族积累**：盗贼遗产已经证明，这套结构的重玩性很强。
4. **长线清楚**：寒门 → 世家 → 上榜 → 砸碑分家，每层都有一个「原来如此」。
