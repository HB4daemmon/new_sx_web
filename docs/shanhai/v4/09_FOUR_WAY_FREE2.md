## 二、两大方向

### 方向 A：「扮神 / 顶神职」
Claude 的冒充神仙、Grok 的空班、Gemini 的诸神空缺，三方各自独立想到：
- **神是一个职位**。凡人演得像，就能借到那个职位的本事。
- **危险在于演得太像**：被职位吞掉，变成神，名字上了牌位，本局以「成神」告终。
  - Claude 是「露馅」和「入戏」两头都会掉；
  - Grok 是「只在这个职权里厉害，而且有期限」。
- **途径＝神职**（财神、土地、门神、灶君、河伯），或者 Grok 那样的「职位态度」：
  - 香火：答应；
  - 差遣：跑腿；
  - 过路：做完一件事就走；
  - 山场：守住本性。

### 方向 B：「凡人百业，逃榜修仙」
Gemini 的瞒天过海：
- **途径＝行当**：乞儿、百戏、行商、悬壶、巡吏、送葬。这延续了上一轮你认可的方向。
- **单局有明确的目标**：一路向东，在天庭收网前到渡口、过海成仙。
- **局外很省**：
  - 赢了：这个角色坐上主界面的「过海仙槎」，以后会在路上路过救场，或者借你法宝；
  - 输了或失控：被天庭封成「泥神」，以后坐进某座庙里当首领，带着你上一局的法宝。

### 另一个最打动人的开场：Codex 的「渡口换班」
它不像一套完整的世界架构，更像一个能放进任何方向的**主角动机**：
- 娘在等我靠岸；
- 第一次通关，桌上有一盘她包的饺子。

## 三、反复出现的共识

1. **演得太像，就会被职位吞掉**：变成神、变成泥胎、牌位浮出你的名字。这是四方对《诡秘》式「失控」最一致的修仙化理解：成神等于失去自己。
2. **失败的你成为后局的世界**：
   - Gemini：泥神首领；
   - Grok：城南庙里坐着上一局的你，还要向你收香；
   - 上一轮 Codex：讹传。
3. **一局有一条清楚的路**：从山门到空庙（Grok）、向东到渡口（Gemini）、一夜的渡船（Codex）。
4. **品阶缩短**：Gemini、Grok 都建议一局内 4–5 阶。九个品名可以留作长线。

## 四、Claude 的综合建议

**主推 B「瞒天过海」，把 A 的「演太像就成神」作为它的失控规则。** 两者合起来，正好是一个完整的闭环：

1. **世界**：天庭垄断了名山和正统修仙，修到头就是上榜，成了没有自我的泥胎神。八仙证明了另一条路：凡人借自己的吃饭手艺修行，瞒天过海。
2. **玩家**：每局一个市井凡人（三选一出身），**一局就是一路向东**，在天庭收网前到渡口过海。
3. **途径＝行当**：沿用上一轮的乞丐、戏子、商人、算命等，可以加入 Gemini 的悬壶、送葬。每个行当的准则是「本色扮演」。
4. **失控＝泥塑化**：
   - 强吞仙丹、借神明的禁物、违背本色，都会让异化度上涨；
   - 异化度高时有霸道的增益（爽）；
   - 满了就变成泥神，本局结束（险）；
   - 想稳，就留后手，在路上攒一点「人间烟火气」把异化度压下来，这就是稳健流的打法。
5. **跨局**：
   - 成仙的角色上「仙槎」，在之后的局里路过帮忙；
   - 成了泥神的角色进入首领池。
   - 每个玩家的世界都由自己的历史长成，局外不加数值。
6. **主角动机**：可以借用 Codex「渡口」的情感，比如第一个角色是想替娘撑一夜船的渡口孩子，作为教学局和主线开场。

**备选：A「冒充神仙／空班」**。新意更强，途径换成神职；缺点是途径从「行当」变成了「神」，和上一轮你认可的方向不同。
