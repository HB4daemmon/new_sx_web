## 二、四方共识（各自独立想到）

1. **「随时」＝一小段空闲**：
   - Codex：水还没开的工夫；
   - Grok：一个下午的「工夫」；
   - Gemini：买个烧饼的工夫；
   - Claude：随时报名、摸鱼的空当。
   - 玩家现实里摸鱼的那 15 分钟，正好就是游戏里那段空闲，**名字、设定和游玩场景三者同频**。
2. **世界太平，仙位向草根开放**：没有大反派。神仙闲、缺人，凡人可以去顶、去补、去报名、被金光砸中。
3. **途径＝市井行当，或者一种「做人的路数」**：
   - **戏、杂耍、凑热闹**：4/4 都有；
   - **厨子**：Codex、Gemini；
   - **闲人、睡仙、闲逛**：Claude、Gemini、Grok；
   - **和气、体面、说合**（稳健流）：Gemini、Grok；
   - **货郎、算命**：Claude、Gemini；
   - 另有：摆渡、掌柜（留客）、手艺。
4. **失控是好笑的职业病，不是入魔**：
   - Codex：做这行做过头了；
   - Gemini：道心跑偏、「封歪了」；
   - Grok：入戏过深；
   - Claude：上头。
5. **跨局带走的是人情和名声，不是数值**：
   - Codex：仙位留在山上，交情带回家；
   - Grok：街坊用外号记住你；
   - Gemini：以前的角色成了天庭前辈，路过客串；
   - Claude：以前的落选者带着本事回来参赛。

## 三、各方最值得拿的

### Codex
- **开场**：主界面只有一口灶、一扇后门，门上压着家里人留的纸条：「去山里可以。回来带把葱。」
- **晋升仪式是一件「只有那种神仙才会做的事」**：例如「渡船过河」，老船在河上跑了三百年，从没当过乘客，想办法让它坐一回船。做成以后，连对手劈来的一掌，你都能问一句：「这位，到哪岸？」
- **第 50 局的新鲜感**：不是刷到第 50 只怪，而是对见过十次的东西，忽然起了一个以前没起过的念头。比如同一朵雷云，摆渡人想把它送到对岸，掌柜想留到明天，厨子看一眼说「正好，灶冷了」。
- **神职越窄，玩家越想钻研它到底能管多宽**：例如「分寸星君」只会拨匀，九头猪一起缓缓离地。

### Gemini
- **失控 =「封歪了」**：爆表时封神榜叹口气，给你封个野神凑数，比如「逢买必跌散财童子」「闹钟叫不醒回笼觉星君」，再弹一张盖着天庭大印的奇葩奖状。**截图就能发群里传播。**
- **轻度跑偏是一种「怪癖」**：例如「倒骑毛驴」让法宝出场顺序倒过来结算。本来是惩罚，结果可能反而更顺手。
- **自建天庭**：以前的角色（正神和野神）住在你这台手机的天庭里，会下凡来买调料。
- **今日黄历**：每局一句话微调规则，例如「今日宜嫁娶」时法宝成对威力翻倍。
- **单局结构**：集市 → 名山 → 东海，三幕赶海，在龙宫门口亮绝活渡海（厨子踩着铁锅炒浪过去）。

### Grok
- **核心资源只有一个：「工夫」**。绕路、多坐一盏茶、多送一程，攒到的工夫就多；神通是把工夫一次花出去。漂亮的收场靠的是一路攒下的工夫，而不是开局就发的一把大刀。
- **途径都是「做人的路数」**：闲逛、说合、手艺、体面、凑热闹。
  - **准则写成人情小事**，例如「至少要有一个观众，鸡、小孩、驴都算」。
  - **入戏过深**：例如说合的人，口头话会按字面应验。
- **一件法宝只有一条脾气**，就像今天借给你的同事。
- **稳健的人是一种玩法，不是反派**：师兄那种「少绕路、场面小、很少塌」，和你的「花哨」并列为两种都能通关的打法。
- **变的是今天空着的那把椅子**：喜事、过河、赶集、寿宴、小庙开张，每局不同。

### Claude
- 选秀结构：海选 → 复赛 → 决赛，有评委亮分和全场喝彩。
- 拜导师当途径，导师的审美就是准则。
- 前几届落选的你，会成为下一届的选手。

## 四、Claude 的综合建议

**骨架**：

1. **「随时」＝一段闲工夫**：一局就是一段空闲，可以是一壶水开、一个下午，或者一炷香。名字和游玩场景同频。
2. **世界**：太平洪荒，仙位常年缺人，凡人随时可以去补、去顶。没有大反派，封神和八仙都是茶馆里的段子和路过的前辈。
3. **资源**：用 Grok 的「工夫」统一修为和神通。绕路、做人情就攒，神通就是把它一次花掉。这同时解决了「轻松」和「爽在收场」。
4. **途径**：做人的路数加市井行当，首发从共识里挑 4–5 条，例如凑热闹（戏）、闲人（睡、逛）、和气（稳健）、厨子、货郎。晋升仪式用 Codex 的写法：一件只有那种神仙才会做的事。
5. **失控**：好笑的职业病。轻度跑偏是怪癖（Gemini），爆表就「封歪了」，发一张野神奖状（Gemini，自带传播）。
6. **跨局**：人情和名声。外号、交情、以前的角色成为路过的仙人或野神，组成你自己的天庭。

**单局的框架，四选一**：

| 框架 | 优点 | 缺点 |
| --- | --- | --- |
| Codex「灶门后的山」 | 最温馨，主界面最简单（一口灶加一扇门） | 世界偏小 |
| Grok「候补的下午」 | 最贴「随时」和人情喜剧，「今天空哪把椅子」天然随机 | 打斗感偏弱 |
| Gemini「被金光砸中，赶海吃席」 | 最有冒险和爽感，三幕结构清楚 | 和以前的「一路向东」相近 |
| Claude「八仙招新选秀」 | 最热闹，评委打分天然有反馈 | 选秀题材偏综艺 |

我的倾向：**Grok 的「候补下午」加上 Codex 的「灶门」做主界面**。
- 回到家（灶、后门）就是主界面；推开后门，就是一个下午去顶一把空椅子。
- 爽感靠 Gemini 的法宝斗法和「封歪了」来补。
