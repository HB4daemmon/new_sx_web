## 二、共识（四方都同意）

1. **世界观保留骨架，砍掉体量**：天柱折、道髓守恒、巡山司巡夜人、品名用身份名，都留下。
   十二道收到 2–6 条首发；邻道转职、跨节点攒线索都砍掉。Gemini、Grok 都指出，跨节点攒线索其实就是变相的延迟领奖。
2. **候选 B 太重**：一回合 5 珠、多珠成本、相生排序、心魔失控叠在一起，30 秒教不会。
3. **随机失控必须去掉**：代价要明码，写在按钮上，让玩家主动选择。
4. **每回合大约 3 次出手，敌人先亮招，按次数破招**：破招看出手次数，不看伤害（解决 V3 的「赢家通吃」）。
5. **爽点集中在一个时刻**：满了就重演或再演，相当于玉环的「终点放大重演」。四方里有三方各自独立想到了这一点。
6. **一局 15–22 分钟，16–18 个节点**，局外只保留解锁道途、命格、案卷。
7. **原型从 1–2 条道途、一幕开始**，找没玩过的人盲测「30 秒能不能自己出招」。

## 三、分歧

1. **五行进不进战斗**：Codex、Grok 不要五行，最轻，但丢了题材感和 V3 的五行资产；Claude、Gemini 用珠的颜色，有排序深度，但多一层读图。
2. **一局走几品**：Codex 三品（最轻）；Claude、Grok 四品；Gemini 五品一路到一品，高潮最足，但每品都要做内容。
3. **复杂度上限**：Gemini 最丰富（合珠、绝学、煞气），也最重；Codex 最薄，它自己也承认有「见重击就点截」的标准答案风险。
4. **冒进代价**：扣生命上限（Codex）、伤疤开结局（Grok）、煞气百搭珠（Gemini，代价可以被构筑反用，最有趣，也最复杂）、狂＝翻倍（Claude）。

## 四、各家值得拿的亮点

- **Codex**：
  - 「可断」标签：一眼可读的打断。
  - 证据换行动：查案得到的证据当场换成战术，例如毁掉发令的铜铃，取消首领第一回合的召潮。
  - 夺印：升品当场生效，下一击就用新数值。
  - 严格的试玩门槛：30 秒内能独立出招；玩家能说出「我本可以……却选了……」的理由。
- **Grok**：
  - 满 3 次出手就再演，一句话就是爽点。
  - 道途只改「再演多出来的那一下」，内容扩展最省事。
  - 提前预判「永远全攻」的风险，并给了对策：亮出下回合意图，逼玩家留手防守。
- **Gemini**：
  - 一局走完五品到一品，有完整的登顶弧线。
  - 每招每回合限 1 次，防止同一招复读。
  - 两珠合一：缺色时不会卡死。
  - 煞气：代价可以被焚道、武道主动利用。
  - 出招固化时的兜底：改成「身怀 6 招，每回合轮转亮 4 招」。
- **Claude**：
  - 只有 3 枚珠，最多 6 种排法，不用算。
  - 克制珠算两次出手，五行克制有用，但不用背表。

## 五、Claude 的综合建议

**合成方案：「三珠出手，满三重演」**，三条规则：

1. **三珠出招**：每回合来 3 枚五行珠。你有 4 张招式，每张印 1 个元素槽或「任意」槽，每招每回合限用 1 次。每回合可以换一次珠。
2. **满三重演**：一回合放满 3 招，就按原顺序整段再演一遍（来自 Grok）。道途只改「重演多出来的那一下」，例如剑道是飞剑齐射。
3. **蓄力破招**：敌人意图标「蓄力 N」，本回合出手数 ≥ N 就破招：这一击作废，重演 ×2。克制珠算两次出手。

**其余部分**：
- **一局**：三幕 × 6 节点，约 20 分钟。
- **升品**：全屏二选一，当场生效。冒进用夺印或逆吞，代价明码。
- **查案**：单页、当场换战术（来自 Codex）。
- **局外**：只留解锁道途、命格、案卷。

**理由**：
- 吸收了四方的共识：3 次出手、按次数破招、满了重演、明码冒进。
- 五行只留两个最轻的用处：珠的颜色和克制算双，题材和 V3 的五行资产都还在，又不增加算术。
- 相生双发不进核心规则，留给法宝和道途做构筑内容，避免重蹈 V3「层数太多」的覆辙。

## 六、需要拍板

1. 五行进战斗吗？（我建议：只当珠色和克制，不做相生核心规则。）
2. 一局走几品？（三品最轻；五品登顶最爽。我倾向四品，九到六，首领三次升品。）
3. 爽点主轴用「满三重演」吗？
4. 冒进代价用哪种？（夺印扣生命上限最简单；煞气最有趣，可以放到以后的扩展里。）
5. 原型按「剑道 + 一幕 + 盲测门槛」做吗？用 Codex 写，还是四方再出一轮细化？
