**共同的底色**：
- **神是一个职位**：坐上去就不再是自己，成神等于被封神榜「录用」。
- **八仙是逃出去的人**，是榜外的那条路。

**基调差别**：
- Claude 的方向最亲切、最接近修仙往上爬；
- Gemini 的方向最接近大奉的「官差查案」与诡秘的「值夜者」；
- Codex 和 Grok 最诡、最新，接近诡秘的黑色幽默，但对大众玩家门槛更高。

## 三、成长和单局（四方的做法）

- **修为**：都是当场到账，守准则还会多给一点。
- **仪式**：都是修为满了以后，下一个节点出现本品仪式（特殊胜利条件的战斗或事件），代价事先写明，做成当场升品。
  - Gemini 补了一个保底：可以手动「寻觅契机」，不会刷不到仪式。
  - 写得最有画面感的几个例子：
    - 戏子：在三人以上的堂会上冒充大人物，把正主挤走，散场都没被拆穿；
    - 算命：战前断言敌人第几回合怎么死，并且应验；
    - 仵作：熄掉护身灯，躺进死者的棺材，听完三次敲棺声。
- **准则怎么做得不像答题**：
  - Gemini：给事件选项统一打行为标签（守律、挑拨、交易、涉险、伪装、窥命），六条途径共用同一套判定，一套案卷就够。
  - Grok：每条准则绑一种资源（名字、判词、围观人数、亏损、拒赏），破戒先毁掉这种资源，心魔只负责累计。
- **心魔满了**：
  - Grok：满格前一格先出现「失控预兆」，还来得及花代价压下去；
  - Codex：快满时选项上直接写「此举将失控，本案终止」；
  - Gemini：第一次满了给一次「畸变豪赌」，第二次满了才暴毙，暴毙者成为后续局里撞见的疯魔前辈。
- **一局升几品，分歧最大**：
  - Claude：三品；
  - Codex：一到两品，品阶跨局保留；
  - Gemini：四品，然后带存档进下半场，再升四品到一品；
  - Grok：一品，品阶跨局保留，「一夜只跨一阶」。

## 五、Claude 的综合建议

1. **途径**：直接采用两方以上都提到的六条：乞丐、戏子、执笔、算命、仵作、商人。
   - 原型先做三条，倾向乞丐、戏子、算命：手感差别最大，分别是卖血、变身、预言。
   - 说书人、说客、替身、弃爵、守夜人、镖师放进第二批。
2. **力量体系的总纲：「行行出神仙」**
   - 任何一行干到极致都能通神；
   - 每一行顶端只有一个神位（祖师爷），对应《诡秘》的唯一性；
   - 坐上神位就会被封神榜录用，变成泥胎（Gemini）或再也下不来（Grok）。
   - 这条总纲和下面任何一个背景框架都兼容。
3. **背景框架**：在下面两个里选。
   - **缉仙司（Gemini）**：最好懂，最贴大奉和诡秘的官差查案。玩家是抓野仙的捕快，自己也在偷偷修自己那一行。每局是一桩奇案。
     - Codex 的「城隍订棺材」、Grok 的「空座顶班」都可以直接做成其中的案子。
   - **顶班（Grok）**：最新、画面感最强，替神上一夜班本身就是在「扮演」。但对大众玩家门槛较高。
4. **单局**：一局升 2–3 品，并保留一条跨局走到一品的长线。具体是品阶跨局保留，还是解锁高品开局，见下面第 3 个问题。
5. **心魔**：满格前一格先出现「失控预兆」，代价事先写明。失控者成为之后局里的疯魔前辈。
6. **游戏名**：主标题「随时修仙」，副标题按背景来定：
   - 缉仙司：随时修仙：莫上封神 / 缉仙司；
   - 行行出神仙：随时修仙：行行出神仙。

## 六、需要拍板

1. **背景框架选哪个**：缉仙司、顶班、替神办丧、行行出神仙（走江湖），还是组合？
2. **六条途径**：「乞丐、戏子、执笔、算命、仵作、商人」可以吗？原型先做哪三条？
3. **品阶跨不跨局**：
   - A：每局重来，一局升 2–3 品，靠解锁高品开局走到一品；
   - B：品阶跨局保留，一局升 1–2 品，像连载一样一路走到一品。
4. **副标题**：莫上封神、行行出神仙、缉仙司、替神、仙家白事，选哪个，或者另起？
