## 一、世界观：五方的主推方案

各方的备选：

- **Carbon**：量劫倒计时·百世推演；
- **Neon**：八仙劫海、**双界套利**（现实世界和神话废土之间随时切换）；
- **Grok**：一章之内、八仙空一座。

## 二、五方共识

1. **神位空缺，凡人上位（5/5）**：
   - 天庭缺编或请假，仙机散落人间；
   - 凡人顶班、补录、借道、抢位；
   - Claude 的版本是姜子牙在榜上留的空位。
2. **短剧式开局：烂摊子加金手指**：
   - Neon：被退婚、被推去顶罪；
   - Carbon：被东家抵押给黑山老妖；
   - Codex：堂下就剩你一个；
   - Claude：宗门大比上被嘲笑；
   - Grok：白身无名。
3. **品级用九品官制（5/5）**：每一品都是一个叫得出口的身份或头衔。
4. **晋升仪式就是名场面**：Carbon、Neon 都把大关放在六品、三品、一品。
5. **失控做成「越危险越强」的红利条**：
   - Carbon：30%、70%、100% 三段异变；
   - Neon：清明、入魔、半步失控三个区间；
   - Claude：劫气。
   - 失控满了不直接结束，有两种走向：
     - 绝境翻盘：Carbon 叫「欺天斩尸」，Neon 叫「斩心魔」；
     - 失控的你被存档，在之后的局里拦路（Carbon、Neon，Claude 的「被封神」也是这一类）。
6. **前世反哺世界**：
   - Neon：通关的角色进入私人封神榜，以后可以上香请下来助阵；
   - Carbon：通关的角色成了书院供奉的祖师像；
   - Codex：带着「河伯旧识」这样的名号重开；
   - Grok：底蕴槽里只留一句话。
7. **结算是一张可以截图分享的卡（5/5）**：修仙小传、封神判词、战报、留句卡、敕封诏书。

## 三、功法体系：途径按「处世之道」划分，五方高度重合

| 途径类型 | 提出方 | 爽点 |
| --- | --- | --- |
| **显圣、文圣、书生、传名** | Claude、Carbon、Neon、Grok（4/5） | 诗词装逼、当众吹大话再兑现，越多人看越强 |
| **稳健、避劫、留后手、镇煞** | Codex、Carbon、Neon、Grok（4/5） | 苟道攒底牌，最后掀桌 |
| **财神、债主、货郎** | Claude、Carbon、Neon（3/5） | 钞能力：买断大招，放高利贷，雇天雷劈首领 |
| **敕令、立规矩、主簿** | Codex、Neon、Grok（3/5） | 当众立一条规矩（自己也得守），或者改册子 |
| **醉仙** | Carbon、Neon（2/5） | 赌狗流：倍率从 0.1 跳到 100 |
| **食煞、乞丐** | Claude、Carbon（2/5） | 越惨越强，吞下负面状态再反噬给敌人 |
| 其他 | | 戏子、请神（Claude、Carbon）；借庙、香火（Neon）；欠人情（Codex）；屠夫、算命（Claude） |

### 各方体系亮点
- **Neon：隐藏融合果位**。兼修加上特定行为，会在终局触发隐藏神话果位，例如：
  - 显圣 + 醉仙 + 本局饮酒 8 次 → 青莲诗仙；
  - 避劫 + 全程不主动进攻 → 太上无为道祖。
  - 玩家会互相交流「配方」，这是第 30–50 局的琢磨头。
- **Carbon：品级压制显性化**。升到四品再回新手县城，弹出一枚烫金大印「威压·四品大儒——滚！」，直接秒杀。
- **Codex：立规矩是双刃剑**。按钮直接写明「这条禁令也会约束你，还立不立？」，晋升靠兑现自己立下的承诺。
- **Grok：失控是「官腔」**。每一景里会有一个选项被换成职务口吻，效果更强，意思却不一定是你想要的；最高品「真授」就是退休，换来最响的结局，代价是失去「随时」的自由。

## 四、循环

### 一局（五方合起来的节奏）
1. **开局（0–2 分钟）**：抽一个烂摊子出身，主修途径三选一，天命词条三选一（Neon、Carbon），再加上这一劫和世道的随机（Claude）。
2. **中盘（2–14 分钟）**：
   - 竖屏事件签三选一推进；
   - 战斗是轻量的自动连招，玩家只在关键时刻亮底牌（Neon、Carbon）；
   - Carbon 的说法是槽位按倍率连锁，像《小丑牌》那样跳数字。
3. **两个小高潮**：第 5 分钟解决开局的烂摊子、打脸；第 10 分钟完成晋升仪式，流派成型。
4. **终局大劫（14–18 分钟）**：所有积累一把梭哈，大字和倍率狂飙。
5. **结算**：一张判词或战报卡，例如：「此獠本系街边算命瞎子，全程未主动出过一拳……敕封一品【三界第一老阴逼财神】」（Neon）。

**一局走几品，有分歧**：
- Carbon、Neon：一局从九品打到一品，甚至超品，数字指数膨胀；
- Claude：九品到六品，局外另有境界；
- Grok：只走低品，真授就是退休；
- Codex：首版三品。

### 招牌机制候选
- **Neon「临阵渡劫」**：常驻一个按钮。反派正在嘲讽「区区九品也敢放肆」，你当场原地渡劫，天雷回满你的状态，顺手把反派和护卫劈成焦炭。**把「随时修仙」四个字直接做成一个按钮**。
- **Carbon「身份官印」**：关键回合拍桌翻盘。
- **Grok「留一句」**：升品时从三句话里选一句，它从此刻到天亮成为规则，也是结算时分享的那张卡。

### 长线：第 50 局为什么还点开
1. **私人封神榜**：前世可以请下来助阵（Neon），也会成为祖师像（Carbon）。
2. **堕仙拦路**：失控的前世带着当年那身装备来拦路，打赢它能拿回那身装备（Carbon、Neon）。
3. **隐藏果位配方**（Neon）。
4. **每日黄历**：所有人做同一张卷子，比谁的思路最野（Carbon）。
5. **进阶劫数**：难度阶梯，每一层改世界规则，不只是加血（Carbon、Neon）。
6. **同签重打**：同一个种子重打，验证「上回要是不封渡口会怎样」（Codex）。
7. **现实层境界加短剧打脸**：局外的境界只增不减，每突破一个大境界播一段打脸剧情（Claude）。

## 五、Claude 的综合建议

**世界观：「天庭缺编，红尘抢位」**。Neon 的方案为主，吸收 Codex、Grok 的顶班和 Carbon 的红尘借道：
- 量劫将至，神位空缺，天道开「红尘补录」；三百六十种活法都能成仙。
- 主角是短剧式烂摊子开局的普通人，带一个金手指，可以随时、临阵破境。
- 封神和八仙作为格局和彩蛋：八仙是第一批红尘成仙的人，旧神在躲劫。

**功法体系**：
- 九品官制。一局从九品冲到一品，冲到一品就封神留名（采用 Carbon、Neon 的节奏，最贴爽文读者）。
- **首发六条处世途径**，按五方投票：

| 途径 | 爽点 |
| --- | --- |
| 显圣 | 诗词装逼 |
| 稳健 | 苟道掀桌 |
| 财神 | 钞能力 |
| 敕令 | 立规矩 |
| 醉仙 | 赌狗倍率 |
| 食煞 | 越惨越强 |

- **成长规则沿用作者已定的**：修为、晋升仪式（六品、三品、一品是名场面）、扮演准则（守则心魔降，违背则涨）。
- **心魔做成红利条**：越高越强，满了先给一次「斩心魔」翻盘，失败就堕仙，进入存档。
- **兼修**：兼修触发隐藏果位，作为长线的琢磨头。

**循环**：
- 开局三抽（出身烂摊子、途径、天命）；
- 事件签推进，自动连招加手动亮底牌；
- 招牌按钮「**临阵渡劫**」；
- 两个小高潮加一个终局大劫；
- 结算发**封神判词卡**。

**长线**：
- 私人封神榜：请前世助阵；
- 堕仙拦路：打赢拿回旧装备；
- 隐藏果位配方；
- 每日黄历；
- 进阶劫数；
- 局外只解锁内容，不加数值。

**可以保留的 Claude 方案元素**（可选）：
- 「封神榜残页」作为金手指的外形；
- 死亡时「被封神」，领一张奇葩诏书。
