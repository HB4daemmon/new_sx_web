## 一、设计总纲

玩家在事件中取得、舍弃、精炼和改炼能力，在每一幕结束时看见自己的修行方向。
战斗是个人自动斗法；玩家决定带什么、以何法为主、接受什么取舍，不在战斗中逐次点选。
构筑的爽点来自可复述的因果链：谁先产出，谁改变它，谁把它兑现，下一主行动靠什么继续。
每件能力先写效果规则、来源事件和限制，再写数值；规则说不清时不能用更大的数字遮盖。
功法负责常态行动和资源出口，法宝负责转换与改形，天赋负责规则取舍和风险边界。
怒气是唯一通用战斗释放资源；旧称甲息、步势、脉引、逆息、晷息、潮息、火种不再作为独立资源。
每门主修功法的无怒气基础式完成一次真实原生行动，就产生少量派生怒气并留到下一主行动；不要求命中。
神通的怒气档位和每档消耗待测，不把“一份怒气一次神通”写成系统承诺；资源不足时基础式继续行动。
护持、回复、直接伤害和状态施加在各自声明的结算点即时完成，不能以系统默认延迟制造收益。
只有明确写出的项目才延迟，例如 B10 的待筑石或 B11 的战前蓄锋转换。
六种构筑意图是观察和配对语言，不是六个职业、阵营或封闭掉落池。
转换是跨意图的桥接；任何路线都可以转向、跳过或混搭，不锁死人物、神话意象和地点来源。
不引入手动抽牌出牌、棋盘布阵、召唤编队或玩家编写逻辑程序。

## 二、三类能力的职责

### 2.1 功法

功法定义修士平时如何行动、从何处得到怒气，以及何时释放神通。
每门功法必须写明主修模式的原生行动、无怒气起步方式和作为辅修时的触发条件。
主修模式必须在没有怒气时仍能行动；有资源时写神通，不足时写可用的基础式。
无怒气基础式必须真正完成一次原生行动并产生少量怒气，不能只写“等待命中”或资格标签。
辅修模式是被主法行动或明确事件带出的派生效果，不额外获得完整主行动。
若一门功法不能作为辅修，应明确标为“仅主用”，不能留下含糊的第二套行动。
功法的输入通常是怒气、当前气血、已有状态、命中事实或上一轮结果。
功法的产物通常是资源、直接伤害、护持、状态、有效回复或下一主行动可用的条件。
功法不能只写成“攻击提高”或“回复提高”，必须说明行动何时发生、消耗什么和产出什么。

### 2.2 法宝

法宝改变既有作用的形态、触发时机、作用对象或资源转换方式。
法宝可以把一次有效回复转成怒气、把溢出回复转成护持、把状态最后一跳转成集中爆发。
法宝主要改变已经发生的结果，不替代功法成为第二套常态原生行动。
少量法宝可以提供来源型起手，但必须写出真实来源、支付和次数，不能凭空制造循环。
法宝默认只承接明确声明的事件；想承接派生伤害、派生回复或派生状态，必须明写“可承接派生”。
每件能力默认只改变一个结果；替换原结果还是在原结果后追加，必须在规则中二选一或写出优先级。
法宝的组合价值必须建立在另一件能力已经提供的真实输入上，缺少输入时界面应显示断点。

### 2.3 天赋

天赋改变修行或斗法的规则取舍，而不是再加一栏百分比装备。
天赋可以改变选择代价、触发资格、失败后的退路、容量用法、资源支付顺序或行动优先级。
天赋可以是正向成长；其取舍也可以来自天赋名额、互斥分岔或放弃另一候选。
天赋不应单独制造完整循环，可以改变循环的门槛、出口、节奏或风险。
天赋与功法、法宝交互时，按统一装配顺序读取其规则改写。
改变支付条件、可用模式或禁用项的常驻规则先在战前装配时确定；监听战中事件的触发效果才进入派生队列。
修行、斗法和风险三类天赋都要有内容，但不要求每项天赋都人为附加负面词条。

## 三、资源、状态与事件词表

### 3.1 资源定义

气血是当前剩余的生存值；最大气血是单独记录的上限，二者分别记录。
气血实损是受伤前后当前气血的差额；护持吸收或被消耗不等于气血实损。
护持是临时承受伤害的保护量，获得、剩余、吸收、被消耗和自然到期都是独立事实事件。
怒气是战斗内通用的释放资源，必须由功法、明确法宝或天赋从真实事件产生。
灵石是事件与修行经济资源，只在局外或事件结算使用，不作为自动斗法即时资源。
派生怒气只能在下一主行动开始前读取，不能在当前结算栈支付并重开主法。
局部状态只对声明它的机制有效，必须写明施加者、持有者、推进时点、结束条件和转换出口。
本轮目录的持续术式默认不刷新已有实例的结束时点；实例仍在时，后续神通改为直接结果而不重新挂印。否则自动重复施法可能让自然结束链永远没有入口。主动延长等特例必须写明单实例次数限制。
状态被明确清除不等于自然结束；状态自然到期也不等于护持消耗。
任何资源的起始值、上限、持续时间和每轮预算都是候选参数，未经测试不写成平衡事实。

### 3.2 伤害、回复和命中标签

敌方原生命中是敌方原生行动通过命中判定的事实；即使护持完全吸收，也仍可产生被命中事件。
敌方原生行动造成的伤害是独立标签；持续伤害、追加伤害和反击不能默认冒充敌方原生伤害。
自身主动支付气血是独立标签，必须明确支付量和支付时点，不能与敌方命中或持续伤害混写。
持续伤害由状态在规定时点造成，默认不是原生行动，也不触发被敌方原生行动命中的资源产出。
直接伤害属于原生行动的直接结果；追加伤害附着在已发生行动上，默认不产生新的原生行动。
反击由被命中、护持被消耗或气血实际损失触发，具体来源必须写明，且不能递归触发同一反击。
有效回复只填补已经损失的气血；达到最大气血后的部分是溢出回复，二者必须产生可区分事件。
满血时发生的回复可以只有溢出回复，但不能因此把所有回复相关规则判定为“没有事件”。
伤害转化、回复转化或状态转化必须明确是替换原结果还是在原结果后追加，不能默认两者同时成立。

### 3.3 原生行动与来源事件

原生行动是主功法在一个行动周期直接发起的行动；多段直伤仍属于同一次原生事件。
辅功法、法宝和天赋触发的效果都是派生效果，不因造成伤害、回复或资源而成为新的原生行动。
每个原生行动和每次回合末状态结算都有唯一来源事件 ID；派生结果继承来源，不自行换源。
同一能力 ID 对同一来源事件最多发动一次；不同标签、复制效果或多段结果不能绕过这个限制。
能力默认只监听规则中明确写出的事件类型；想监听派生结果必须写明“可承接派生”和每源或每轮上限。
“资源达到门槛”只在跨过门槛或规定的行动开始检查时成立，不能在每次读取时重复触发。
“状态结束”只在该状态自然结束或明确被移除时成立，重新施加必须来自新的原生行动。

### 3.4 自然结束预处理

回合末处理状态时，先推进状态并确定本次固有结果；若状态即将自然结束且仍有最后伤害待结算，先发预处理事件。
B03 等明确转换件可以在该预处理事件上替换最后一跳为派生集中爆发，放弃该一跳原伤害。
预处理完成后才发真正的自然结束事件，G03、G05 等自然结束监听者仍可读取它。
同一待结算输入由冻结席位顺序中的第一个合资格替换者消费；同一 ID 不重入，后续能力只读取剩余事件。
如果没有最后一跳，状态仍可自然结束，但没有“替换最后伤害”的输入。
被清除、主动移除或自然到期的事件必须分开；延迟队列保留原来源，不成为新的 root。

## 四、候选容量、取得与成长

候选容量为四席功法、三席法宝、三枚天赋；四席功法中一席为主法，其他三席为辅法。
这是供目录、评审和试玩使用的完整候选上限，不是必须填满的任务；空席和跳过奖励都合法。
初始阶段开放一主一辅、一件法宝和一枚天赋，保证首幕可理解且主法能自给起步。
第二幕至少可达到两件法宝，使首个组合有机会连续发挥，而不是只在终局才看见转换接口。
第三幕成势阶段前后开放到候选上限，四功法、三法宝和三天赋都可纳入或被明确放弃。
第四幕主要用于校正、替换、精炼和验证，不把关键连锁槽位拖到第四幕才第一次出现。
安全修整节点可切换主辅、替换一件已装备能力或处理一次明确标记的精炼分支，次数和成本待测。
主辅切换只影响下一场自动斗法的默认节奏，不重置当前战斗资源，也不追溯既有触发。
同一门功法在一次装配中只执行选定的主法模式或辅法模式，不能双算同一份输入。
取得、替换和精炼不按获取次序决定同时触发顺序；装配席位顺序才是稳定结算依据。
封存记录装配顺序和选择分支，保证同一配置在之后自动斗法中有可复现的顺序。

### 4.1 精炼、跳过与第四幕公共分岔

功法精炼可以开出新的资源出口，也可以只提高稳定性、幅度或作用窗口，不要求每次升级都增加新机制。
法宝精炼可以改触发时机、转换方向、作用对象或可承接派生的资格，必须注明替换与追加关系。
天赋精炼只强化原有取舍方向，不能无条件抹去原有门槛，也不能变成纯数值叠加。
跳过和有限改炼都是完整选项；跳过不生成补偿资源，改炼和替换要有明确的次数、成本或机会损失。
修行或经济型天赋仍占统一天赋容量，不得通过事件经济多买出无限永久战斗能力。
T01-T04 共用一条固定规则：每局只有一次第四幕公共整备转换机会，且不要求 NPC 或事件在场。
该窗口只能把 T01、T02、T03、T04 中的一枚修行天赋转成其固定战斗分支。
成本是在同一公共窗口放弃一次其他精炼或候选机会；转化后的天赋容量不变，不保留旧经济效果，不可来回切换。
历史已修能力可以保留，但总装备数和单项精炼上限不变；未转化的经济天赋即使保留修行记录，也不自动给后续大战战斗效果。不保证所有经济天赋都转化完成，组合代价待测。
安全整备可以处理已标记分支，但不能在战斗结算时免费补选、补怒气或补护持。

## 五、统一自动节奏与触发顺序

每方每轮各有一个行动周期；行动先后由战斗规则固定，玩家不在周期中逐次点选。
每个行动周期，主法至多发起一次原生行动；一次原生行动可以包含多段直伤，但仍只有一个来源事件 ID。
辅法、法宝和天赋在声明的行动事件或回合末事件中作为派生效果介入，不额外获得完整主行动。
主法有足够怒气时执行目录写明的神通，不足时执行同一门功法写明的基础式，不因缺资源而停机。
无怒气基础式完成一次真实行动后立即产生少量派生怒气，资源排入下一主行动窗口；命中不是其唯一启动条件。
主法的原生行动成本先读取并支付；主法直接结果完成后，才进入同周期的派生读取。
同周期读取资源的固定顺序为：主法原生支付，功法席位派生，法宝席位派生，天赋席位派生。
在每个席位内按固定装配顺序读取；能力不能以获取次序插队，也不能在同一来源事件重复读取。
转换效果先按其声明决定替换或追加，再按固定顺序产生追加伤害、护持、回复或资源。
护持获得、护持消耗、回复和持续状态施加按条目在当前事件即时结算；不要统一挪到下一周期。
派生得到的怒气默认只供下一行动周期消费；它不能在当前结算栈中立刻支付并再次发起原生行动。
“下一次行动资格”也只在下一周期检查，不能把它解释成当前周期的第二个完整主行动。
一方行动完成后，按固定的对手行动顺序继续；双方周期都完成后才进行回合末结算。
回合末按预处理、持续伤害/回复、状态推进、自然结束和过期效果的冻结顺序执行。
回合末结算拥有新的来源事件 ID，但不因此获得额外主法行动；自然结束产生的资源留到下一周期。

### 5.1 派生队列和同源规则

队列按“事件发生时间、功法席位、法宝席位、天赋席位、冻结席位顺序”稳定处理，不是只扫描一次初始席位。
后序派生如果产生了新的明确事件，可以触发队列中尚未使用且声明可监听的不同能力；新事件仍继承原 root。
同一 ID 对同一 root 已发动后不得重入；尚未发动的能力可在后序派生事件到达时正常触发。
已预定的延迟兑现属于之前发动的完成，不因兑现事件重新把同一 root 当成新发动。
若同一 ID、同一主源同时满足“兑现旧标记”和“再次蓄能”，默认兑现优先，本主源不再次充能；能力另有明文时才可二选一。
派生效果可以触发下一件不同能力，下一件能力可以继续转换结果，但不能生成新的原生行动。
同一来源事件上，已经处理过的能力不得再次回到该来源形成有向回环；回到已处理节点时直接封止。
连锁允许跨不同能力多跳，限制对象是回环和无成本重入，不是所有第二跳。
执行深度、派生次数和单轮预算是待测安全上限，用于防止内容失控，不替代实际消耗和事件定义。
安全上限不能把所有连锁粗暴截断为单次派生，也不能把同一来源的重复触发伪装成新的事件。
零成本自触发不成立：触发条件不能由自身无代价反复制造；新的预定行动或回合推进才允许建立新的 root。

### 5.2 自损安全边界

安全自损要求支付后当前气血严格大于零且满足候选安全底线，不保证接下来敌方攻击、持续伤害或延迟回复前的生存。
安全检查必须在支付前完成；支付失败不生成怒气、护持、反击或血痕。
自损、敌方原生实损、持续实损和护持消耗是不同标签，只有条目明确声明的能力可以读取对应标签。
G06 即使不能安全自损也必须有不自损基础直伤和较慢怒气出口；T09 只改善少量神通支付差额。

## 六、六种可混搭的构筑意图

### 6.1 I01 聚息爆发

启动：主法用无资源基础式完成原生行动，再从行动完成、状态结束或敌方事件取得有限怒气。
兑现：消耗怒气执行一次高质量主法神通，或让 B11 把一份派生怒气换成下一主行动集中标记。
弱点：战斗过短、原生行动被打断或没有合法资源来源时，爆发窗口尚未形成。
接口：可接 I02 的护持消耗反击链，也可接 I03 的自然结束资源出口。
强势表现：资源反馈在下一轮兑现，单次原生行动明显超出单件能力，但不增加额外主行动。

### 6.2 I02 御护反击

启动：主法获得护持，或敌方原生行动命中并造成护持消耗、气血实际损失等明确事件。
兑现：把护持被消耗或被命中的事实转成一次反击、护持穿透或有限怒气，不复制护持本身。
弱点：持续伤害、没有命中判定的压力和极短战斗会减少合资格的反击窗口。
接口：可接 I01 把反击命中或护持消耗交给下一轮爆发，也可接 I06 读取未被护持吸收的真实气血损失。
强势表现：敌人的主动进攻越清晰，构筑越能把防守转成可控回应，但每个来源事件有独立上限。

### 6.3 I03 持续炼化

启动：主法立即施加有自然结束时点的持续术式，或以跨回合原生行动积累局部状态。
兑现：状态推进、最后一跳、自然结束、回复和资源转换在等待后形成后续主法窗口。
弱点：短战、清除状态、无法连续完成原生行动时，尚未成熟的收益无法兑现。
接口：可接 I05 读取有效回复与溢出回复，也可接 I04 用 B18 推进既有状态。
强势表现：长战中的回合末结算持续扩大行动质量，但重新施加必须来自新的原生行动。

### 6.4 I04 连击追斩

启动：一次原生多段行动，或连续几个不同来源的原生行动，产生锋势、追斩标记或集中窗口。
兑现：在下一次主法原生行动中消耗局部势，附加集中伤害或改变作用对象，不把每一段变成完整新行动。
弱点：单段攻击、无法获得下一次原生行动或局部状态被清除时，积累的势无法兑现。
接口：可接 I01 把怒气爆发集中在下一次主法，也可接 I02 让反击经 B16 接入集中窗口。
强势表现：同一原生事件内可以记录多个实际命中段数，监听能力只发动一次、读取累计段数。

### 6.5 I05 调息生生

启动：主法必须有不依赖有效回复的基础式；有效回复、溢出回复或状态结束可以分别成为不同转换入口。
兑现：有效回复维持当前气血，溢出回复即时转护持或留作下一轮怒气，两个方向不能合并成模糊“回复”。
弱点：既没有可填补的损失、也没有允许读取溢出的出口时，转换收益降低，但满血起手不能让主法停机。
接口：可接 I03 让持续术式结束产生回复，再把溢出转护持；也可接 I02 把护持用于敌方命中后的反击。
强势表现：从濒死维持到满血溢出都能找到不同出口，且有效回复和溢出各自受每源或每轮限制。

### 6.6 I06 借创逆转

启动：敌方原生命中造成气血实际损失，或能力明确要求自身主动支付气血；两者都必须有真实事件。
兑现：把自损或敌方造成的实际损失转成怒气、护持、反击资格或下一轮主法窗口，不能由溢出回复伪造。
弱点：敌人只施持续伤害、完全打不中，或玩家不愿承担自损时，可转化的真实输入变少。
接口：可接 I01 使用逆转所得怒气，也可接 I02 先以护持控制可承受损失。
强势表现：危险越接近可控阈值，构筑越能换得明确反转；自损、敌伤和持续伤害标签必须严格分开。

## 七、三条统一组合与反例

### 7.1 护持消耗→反击→有限怒气→下一轮主爆发

主法先用无怒气基础式建立护持，敌方原生行动命中并消耗护持。
B08 监听护持消耗并只触发一次反击；反击命中后 T07 承接派生反击并追加少量怒气。
该怒气留到下一行动周期，主法支付后执行神通；反击不在本周期重新发起主法。
B02 可以取代 T07，将同一护持消耗直接转怒气，但那是不同的护持→资源链，不是反击→回怒链。
反例：敌方只造成持续伤害，或攻击没有命中判定且没有护持消耗事件，链条在反击入口断开。

### 7.2 持续术式自然结束→回复→溢出转护持

主法以一次原生行动施加持续术式，术式立即挂上并按规定回合推进。
若最后一跳待结算，先进入 B03 自然结束预处理；替换后仍发真正自然结束事件。
法宝或天赋在结束事件上产生回复；有缺失气血时先记录有效回复，达到上限后的剩余部分另记为溢出。
另一能力明确承接溢出回复，把它即时转换成护持；转换发生在回复完成后，不把回复本身抹掉。
反例：状态被提前清除且没有清除出口时，自然结束事件不存在；若能力只监听有效回复，满血时只有溢出也不能误触发。

### 7.3 主法一次多段→局部锋势→下一次主法集中伤害

主法一次原生行动包含多段直伤，先记录本次实际命中段数，再由 B04/T08 在行动完成时一次性结算有限锋势。
原生行动结束后不立刻再发起主法；锋势保留到下一次主法原生行动开始时。
下一次主法消耗局部锋势，给该次原生行动追加一次集中结果，仍只有一个新的主法来源事件。
如果下一次主法被打断、角色在轮到行动前败北或锋势过期，积累的局部势可以自然失效。
若新主动作同时满足旧锋势兑现和新多段蓄势，默认先兑现旧锋势；同一 B04 不在同一 root 上重复蓄取。
反例：单段主法没有多段输入，不能假造触发；复制同一段伤害也不能获得新来源事件。

## 八、成长节奏与事件联动

首幕“误入仙缘”至少给出一门能独立行动的主法，并让一件早期法宝在首幕可见其转换或改形方向。
首幕天赋优先展示规则取舍，例如保留空席换稳定起手，或承受事件风险换提前精炼。
第二幕“炼法成器”应让首个组合完成一次可复述的产出、转换、兑现，并验证一处自然弱点。
第二幕至少可装备第二件法宝，但不能因席位增加而得到第二个完整主行动。
第三幕“名动山海”前后开放完整候选容量，允许跨意图桥接并让构筑达到成势阶段。
第四幕“自择仙途”提供公共窗口校正、替换、精炼或放弃不合适能力，重点是理解和修正已有因果链。
第五幕“一劫成仙”主要检验已有构筑，终局压力应有多种解法，不用剧情借来的神器代替修成能力。
长事件至少有继续、止步或转向节点；阶段奖励与最终奖励分开，退出人物线不摧毁已经修成的能力。
人物机缘可以给独特叙事版本，但同档核心功能必须能从其他合理人物、地点或修行方式取得。
不同人物路线都应提供产出、转换、兑现和校正机会，不能把所有强引擎锁给单一效忠对象。
事件经济和战斗成长分开记录；重复走事件不能无限增加可保存战力，来源要有上限或临时性。

## 九、候选内容目录规范

稳定内容 ID 使用 `G01-G12` 表示功法、`B01-B18` 表示法宝、`T01-T12` 表示天赋。
ID 只表示类型和稳定序号，不编码人物、地点、品阶、意图或强弱；公开后不得因平衡改名而重排。
目录记录必须有：来源条件、效果规则、输入、监听事件、作用对象、产物、消耗、限制、装配模式和至少一条配合。
每条记录还要写出缺少什么输入时不会成立，以及会在哪个自然压力下失效。
功法记录必须分别写主修原生行动、无怒气基础式、辅修触发、支付先后和同周期上限。
功法可切换者必须同时具备主修与辅修规则；仅主用者必须明示仅主用，不能用模糊触发代替。
法宝记录以转换和改形为主，少量来源型法宝要写真实来源；早期核心法宝应在首幕可见其输入缺口和兑现方向。
天赋记录可分四项修行、四项斗法、四项风险取舍；三类可以混分，不要求每个意图固定配额。
六种意图的覆盖检查目标是每意图至少两条功法、三条法宝、两条天赋，但这只是候选覆盖，不锁定掉落池。
同一 ID 可以在不同事件以不同叙事版本出现，核心规则和稳定 ID 不随人物路线漂移。
配合字段至少连接另一类型能力，优先连接两个不同意图；不得只写“与所有输出能力配合”。
目录评审先冻结 ID、输入、事件和限制，再调整数值、品阶、精炼幅度和获取幕次。

## 十、通关封存、经济与未决项

玩家自愿确认封存后，只记录能力配置、主辅关系、装配顺序、精炼结果和已选择的规则分岔。
封存不记录护持、怒气、气血、局部状态、临时事件加成、敌人弱点或本局借来的外援。
后续自动大战从规定的基础状态开始，不把上一局资源池当作永久起手。
只有玩家真正修成的能力 ID 才能进入封存；剧情借力若未转为已修成能力，不得保存。
灵石可以用于内容解锁或事件选择，但不能通过无限刷战斗换成无上限永久战斗属性。
终局封存的具体资格时点、后续大战形式、PvP/PvE 与赛季规则仍由主代理和其他模块决定。
正式幕数、单局时长、事件数量、回炉次数、触发预算和各类数值均待测试，不得写成实现承诺。
需要重点测试：第三幕前后容量开放是否足够形成组合，第四幕公共窗口是否仍有价值，辅法派生是否过于嘈杂。
还需测试：多跳连锁的真实深度上限、多段汇总可读性、满血 I05 的持续行动、I06 的自损风险和自然结束预处理。

## 收束清单

资源词表区分当前气血、最大气血、气血实损、护持获得、护持消耗、怒气、灵石和局部状态。
伤害词表区分敌方原生命中、敌方原生伤害、自身主动支付气血、持续伤害、直接伤害、追加伤害和反击。
回复词表区分有效回复与溢出回复；溢出是独立事件，可被明确声明的天赋或法宝读取。
调度规则是每方每轮一个行动周期，主法至多一次原生行动，派生不额外获得完整主行动，回合末统一结算持续状态。
护持、回复和状态施加按事件即时结算；派生怒气留到下一主行动，B10 等明确延迟项单独列明。
自然结束最后一跳先经过预处理，再发真正自然结束；清除不自然结束，状态和来源不能被延迟队列重造。
同时触发按功法席位、法宝席位、天赋席位及冻结的装配顺序结算，不按获取次序结算。
派生队列稳定推进，后序新事件可触发尚未使用的不同能力；已兑现的延迟项不重开同一 root。
连锁以来源事件 ID、同能力同源一次、显式可承接派生、回环封止和真实成本或时间预算控制。
连锁允许跨能力多跳；资源反馈留到下一主行动，不把安全深度上限当成事件定义或实际消耗。
六种构筑意图为 I01 聚息爆发、I02 御护反击、I03 持续炼化、I04 连击追斩、I05 调息生生、I06 借创逆转。
三条组合分别验证护持消耗到下一轮爆发、持续术式结束到回复溢出护持、一次多段到下一次集中伤害，并各有断点反例。
候选目录使用 `G01-G12`、`B01-B18`、`T01-T12`；四功法、三法宝、三天赋是完整候选容量，三幕成势前后开放。
所有容量、次数、数值、正式幕数、封存时点和后续赛制仍是待定事项，不应被引用为已经实现或已经平衡。
