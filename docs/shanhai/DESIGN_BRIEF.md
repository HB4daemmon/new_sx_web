# 《随时修仙》山海版设计简报

> 状态：评审提案，不是实现规格、数值承诺或平衡结论。
> 本页只定体验和范围；共同战斗口径见[COMBAT_RULES.md](./COMBAT_RULES.md)。

## 目标

- 玩家在一局内取得一门能马上使用的功法，并能说明自己的成长选择。
- 自动斗法负责执行构筑；玩家在战斗外决定功法、进阶、法宝、事件和行旅风险。
- 人物有自己的目标与底线，事件选择要在当下给出清楚得失，并在后续产生可见回响。
- 正向机缘可以保持正向；风险必须在选择前说清，不靠隐藏惩罚制造复杂度。

## 当前设计方向

- 当前主修只有一门；功法提供基础动作、怒技、行旅能力和天赋树。当前提案以炼气为基础，筑基、金丹、元婴、化神各选一次 A/B/C，四次选择可跨方向组合；境界划分仍待评审。
- 五普通、三珍稀、二传奇共十门。稀有度影响取得难度和起步表现，不封死成长方向；普通功法在合适属性、法宝和战斗长度下可反超传奇某一项，尚未测试。
- 直接伤害、积怒提速、降低怒耗、护盾、治疗和触发概率都是有效强化。资源转换、触发改写和路线转向留给少量合适节点，不是每张卡的义务。
- 法宝不设统一持有或生效槽位；只按产出控制成长，只有卡面明写的唯一冲突才互斥。
- 气血与灵石是跨节点损耗；怒气、护盾和临时状态在战斗末清理。换法保存各功法的树选择与独立永久收益，不回血、不免费洗点。
