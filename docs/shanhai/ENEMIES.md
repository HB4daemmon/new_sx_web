## 共同接口与初始化

### 读法

- `炼气`只提供该门功法的基础普攻、怒技和行旅；正文必须写“无进阶天赋”，不得用隐藏被动补足。
- `筑基/金丹/元婴/化神`分别解锁 J1/J2/J3/J4；每个已解锁层只选一项 A/B/C，正文同时写层号、选项字母、准确天赋名和固定 ID。
- 正文使用 `J1-A` 这类短写；它与同一条目主修组合成完整固定 ID，例如 `KF08` 条目的 `J1-A` 就是 `KF08-J1-A`，不会指向另一门功法的同名层。
- 普攻、怒技、追加段、追击和法宝追加都属于当前主动作的结算；敌人每轮最多一个主动作。怒技先支付当前门槛，再按功法卡面结算。
- 速度只决定每轮先后，不增加每轮动作数。常规攻击默认命中；特殊闪避只在法宝 `FB33 流霞带` 的每战一次概率机会内作用于首个合资格直接攻击段，不能躲燃烧、中毒或事件扣血。检定失败也消耗该机会，不能写成保证闪避。
- 负面状态不默认免疫。敌人可以被施加燃烧、中毒、虚弱和破甲；持续时间、层数、概率和倍率沿用共用卡面，均以 `<待测>` 表示时由首测锁定。

### 相对属性档

正文的属性顺序固定为“攻击 / 防御 / 最大气血 / 暴击率 / 速度”，只写相对档，不预填平衡数字：

`极低 < 低 < 常规 < 中 < 高 < 极高`

法宝和天赋的加成在战斗前叠加到该档位；“高+”不另设新档。若同一件法宝只改变速度，仍不产生额外动作。

### 统一开战状态

所有 35 个敌人在装备触发前统一为：

`气血 = 该敌人最大气血的满格；怒气 = 0；护盾 = 0；燃烧/中毒/虚弱/破甲 = 无；阶段 = I；相位或蓄运计数 = 该功法开战默认值。`

随后只结算真实的入战法宝输入。例如持有 `FB09 护身佩` 的敌人先按上述规则为零护盾，再由 `FB09` 的“入战护盾”获得护盾；没有任何规则可以开局空降怒气、治疗或已经叠好的负面。`FB33` 的一次闪避、`FB39` 的失败回怒以及所有怒技后法宝都必须等到对应真实事件后才可用。

### 行动、奖励和行旅边界

- 战前预览先展示“功法、境界/天赋、敌方装备、属性档、稳定行为位、胜利奖励入口”。展开卡面后可追溯每一项压力的输入。
- 第一轮按速度和战前固定同速顺序决定先后。没有强制普攻时，敌人达到当前怒技门槛就把下一主动作改为怒技，否则继续普攻；每个条目在下方写出其起手序列。
- 下方“应对”只描述战前可准备的速度、虚弱、破甲、护盾、回复、持续伤害和法宝输入，以及自动战斗中会自然出现的窗口；不假定玩家能预留怒技资源、延后怒气、手动跳过普攻或临场改写主动作。
- 敌人没有玩家的行旅节点、主修切换、修为领取或行旅准备。任何只读取真实节点的法宝效果（如 `FB28 采灵葫芦`、`FB29 行医囊`、`FB40 长明灯`）对敌人不触发；敌人不会因为战斗胜利自动把节点收益带入下一战。
- 一般胜利只进入该节点已锁定的奖励入口，不等于取得敌方全套装备。除守器者事件明确授予的 `FB41-FB48` 外，敌方装备不会自动转移；公共 `FB09-FB40` 也只有奖励池明确列出时才可能成为单件候选。
- 普通奖励入口为“该幕普通战奖励池”；精英奖励入口为“该幕有限精英奖励池”；幕首领奖励入口为“该幕首领结算/强化候选”。未由事件或投放表明确列出的装备均不掉落。
- 若 `COMMON_EVENTS.md` 或 `OPPORTUNITY_EVENTS.md` 把某个 `EN` 作为事件内非致命/生死战并明示单件奖励（例如 `EN12` 胜后发 `FB17`），该事件奖励字段覆盖普通池入口且只结算一次；仍不自动转移敌方整套装备。

## EN01 潮口迅徒

- **来源与定位：** 原创潮口巡路者；稳定行为位为先手轻击。
- **允许幕次/成长：** 第一幕首见；允许第一至第四幕，后续按“普通敌人逐幕成长”读取；第五幕不投放普通敌人。
- **属性档（攻/防/气血/暴击/速度）：** 低 / 低 / 低 / 低 / 高。
- **主修与天赋：** `KF02 归元诀`，炼气；无进阶天赋。
- **敌方装备：** `FB27 疾风履`（提高速度，不增加动作）；`FB25 剑穗`（普攻直接增伤）。
- **玩家短预览：** 高速度、低耐久；展开可见 `KF02` 炼气、两件普攻向法宝。
- **构筑运行与主压力：** `KF02` 普攻完成积基础怒气，`FB25` 放大普攻；`FB27` 让它更常先手，但不让它每轮多打一回合。怒技仍只在达到归元诀当前门槛后替换下一次主动作。
- **初始状态与动作序列：** 初始化为满气血、0 怒、0 盾、无状态；首轮优先普攻，第二轮若已达怒技门槛则施放怒技，否则继续普攻。怒技支付实际怒气后回到普攻积怒。
- **应对：** 先手护盾或提高速度，降低第一次普攻的收益；或直接用持续伤害/高防拖过其低气血。它没有闪避、免毒或免火。
- **胜利奖励入口：** 该幕普通战奖励池；不自动取得 `FB27`、`FB25` 或敌方全套装备。
