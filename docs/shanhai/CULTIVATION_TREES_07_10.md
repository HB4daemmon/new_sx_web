## 0.统一边界与自动规则

- 本文件只定义四门原创功法树。意象取自天象、灵木和昼夜想象，不声称任何古籍事实。KF07、KF08 为珍稀，KF09、KF10 为传奇。
- KF07、KF08 由普通深层或长事件阶段获得；KF09、KF10 由下文独立传奇画面直接兑现。当前个人只有一门主修功法，换法时旧法整树卸下，不形成主辅叠加。
- 换法保留境界、属性、法宝和已经结算的局外修为；已达境界按同次数补选新树层级，未达层级不预领。节点只因进入后完成一次结算而生效，切法时未结算计数随原法冻结，不得来回切换刷新。
- 个人战斗自动锁定一个目标；每方每轮只能开始一个主动作。怒气是唯一战斗通用资源，其他能量不参与战斗。普攻结算后固定增加基础怒气，是否命中不影响这次增加；怒气达到本门怒技门槛时，下一主动作自动放怒技，否则放普攻。
- 怒技支付本门门槛所需的怒气，不默认清空额外积怒。返怒只能供下一主动作使用，不能让当前动作再次开大。普攻和怒技的主要伤害均取攻击力；暴击率与逐电等独立触发概率分开记录。
- 真实气血是生存资源，修为只在明确的节点或一次性战斗结算处获得。战斗不会反复产永久修为，也不引入额外的休整规则或延迟动作规则。有限状态、临时增益、目标负面在战斗结束清除，叠层必须有小上限。
- 护盾是实际可承伤的真实护盾；各门凡写护盾，均按“自身防御为主项、最大气血为次项”的固定公式计算，具体系数待平衡。治疗先结算缺口内的有效值，溢出值单独记账，不能重复算作一次完整治疗。
- 法宝统一不限持有数量和生效数量；只限制产出数量，并在同一法宝的互斥效果处明确唯一冲突。不按行旅、斗法拆分法宝规则。
- 行旅节点进入时绑定当前主修，完成时只结算一次；节点效果必须写明战斗外用途，不能读取战斗相位来刷收益。以下“少量”“有限层”是待数值化的上限，不是新增通用资源。

### 1.KF07 奔雷诀（珍稀）

#### 1.1来源、基础与行旅

普通深层“断崖雷井”：雷光沿井壁向下奔跑，银色草根倒生在井口。封住回窜雷脉后取得 KF07；长事件后段“逐电过峡”完成雷脉校准也可取得。

普攻“引雷试步”按攻击力造成一段原生雷伤，命中施加一层有限雷痕；命中的原生雷段进行逐电检定，逐电不是暴击。成功立即追加雷伤并清零本能力的蓄运，恢复基础概率；失败累积蓄运并提高后续合资格段的概率，层数和概率均有上限。未命中只领取普攻基础怒气，不视作逐电失败；派生段不再检定本能力。

怒技“惊雷逐电”支付本门怒气门槛，按攻击力造成两段原生雷伤，命中的各段独立检定逐电；怒技结束保留雷痕，返怒供下一行动。蓄运、节点准备及定点层均为有限战斗状态，不形成另一条释放资源。

行旅“雷脉疾行”：完成进入时绑定本法的战斗节点后，准备一份额外灵砂，最多待领一份；下一个仍绑定本法的非战斗节点完成时领取并清除。未领取前再战不叠存，换法只冻结，不重新发放。

#### 1.3路径、弱点与死链

- 路径 A：J1-A → J2-B → J3-B → J4-A。普攻挂引雷，失败蓄运换首段必定逐电，成功后为后续原生段增加一次检定；化神将怒技稳定改成更高门槛的三段峰值。
- 路径 B：J1-C → J2-A → J3-A → J4-B。护盾承受压力，成功逐电返怒，防御转雷伤，最后锁定同一雷痕目标；换目标会清定点层。
- 路径 C：J1-B → J2-C → J3-C → J4-C。来源是雷痕与逐电失败：雷痕提供恢复和下一动作增益，怒技失败也能有效回血并回怒，战中把成功逐电导向下一主动作，节点完成再导向下一非战斗节点。
- 逐电连续失败只增加有限蓄运，不会永久提高概率；雷痕、定点层、护盾、返怒均在战斗结束清理。所有派生段不重触发原检定，蓄运只被一次消费。

### 2.KF08 太阴经（珍稀）

#### 2.1来源、基础与行旅

普通深层“无月长阶”：干涸湖床下的石阶影子与人的脚步方向相反。照出倒影中的出口后取得 KF08；长事件后段“月沉井口”完成破绽兑现也可取得。

阴痕使目标下一次直接伤害降低；这次减伤用过后印记仍保留至到期或被怒技消费，不会因为敌人每轮出手而永远无法生成破绽。基础阴痕至少保留到下一次己方主动作的判定窗口。普攻“太阴照影”按攻击造成阴影伤，命中前无阴痕则施加，有阴痕则额外施加破绽；普攻不消费它们。两种负面均有有限寿命，动作完成积怒与命中无关。

怒技“太阴反照”支付本门怒气门槛，先造成原生阴影伤，再消费至多两层本门负面：两种都有时各取一层，仅有一种时取其可用层数。破绽提供追加阴伤，阴痕提供下一次受击减伤；零负面仍有基础输出。两层是局部预算，追加节点共享实际消费记录，不重复扣除。基础怒技门槛应允许在无外援时至少完成两次普攻后释放，以便破绽确实有起手窗口。

行旅“月影藏踪”：完成事件节点时，若玩家主动承担了气血代价且结算后仍存活，返还其中一部分实际扣除的气血，返还不超过最大气血，不会把死亡者复活；每个事件节点只结算一次。

#### 2.3路径、弱点与死链

- 路径 A：J1-A → J2-C → J3-C → J4-C。稳定削弱与恢复，再从攻击负面目标积累月华，转入自身增益输出；节点胜利后的少量修为不是战内拖延收益。
- 路径 B：J1-B → J2-A → J3-B → J4-A。暴击生成破绽，怒技兑现追加阴伤，两种负面同时消费换暴击率，首怒再多出一次破绽预算。
- 路径 C：J1-C → J2-B → J3-A → J4-B。负面消费生成护盾与攻防增益，防御转阴伤，终层把同一消费预算转为真实护盾而非重复追加伤害。
- 阴痕始终只削弱下一次直接伤害；零负面时怒技仍有完整原生伤害。治疗、护盾、负面消费和固定战末修为均有明确次数，战斗拖长不会产生无限永久成长。

### 3.KF09 金乌真经（传奇）

#### 3.1传奇来源、基础与行旅

传奇事件“扶桑海潮倒悬”：赤海向天卷起，海底露出巨木，十轮不同颜色的日轮沿枝冠滑入木心。玩家在潮壁第二次翻转时把日轮引回木心裂隙，以自身修为封住木心余火，完成结算后直接取得 KF09；事件不要求献祭，不附加未定义诅咒。

传奇基础预期强于低稀有度的无配合起手：普攻“扶桑引日”按攻击造成较强火伤，命中积日曜并建立一个独立到期火实例；怒技“十日燎原”支付所需怒气，造成三段原生火伤，各次命中建立独立火实例。所有实例伤害读取攻击，并受同时在场上限约束；达到上限时只增强最早到期实例的有限强度，不延长其寿命。普攻完成固定积怒。

怒技开始时执行唯一的日曜消费预算：按原生段顺序消费实际存在的日曜，每层只强化一个对应火段；没有日曜也照常打三段。J1-B、J3-B 只能改这份预算的消费方式，不能另扣同一层。火实例、日曜、临时火势战末清除。

行旅“金乌照途”：每完成一个合资格开阔路线节点，增加一次日照计数；计数累计到系统规定的小周期时，结算一次固定少量修为并清零。战斗不增加、不读取日照计数，切法时未完成周期随原法冻结，不能靠拖战刷修为。

- 路径 C：J1-C → J2-C → J3-C → J4-C。实例自然到期转护盾和血量火伤，行旅周期为下一战提供晨火，敌方清除也保留一次实际剩余伤害。
- 传奇强项是无搭配也有较强普攻、独立火实例与三段怒技；持续路线受清除和自然到期限制，爆发路线消费完后须重新铺火。是否强于普通完整构筑仍需同预算测试。

### 4.KF10 烛龙真经（传奇）

#### 4.1传奇来源、基础与行旅

传奇事件“烛龙垂天”：赤鳞长影横过天幕，眼睑开合让山谷先亮后暗，白昼河流倒悬在云下，暗相时沉入黑水。玩家在两次眼睑开合间接通白昼河流与黑水，完成“让昼光在暗处继续流动”后直接取得 KF10；事件不要求先开另一相，也不附加诅咒。

本门的基础状态为明相、暗相、日辉、夜烬和敌方晦痕；节点另有一次性准备记录。每战开局明相，基础每相完成两次主动作后自动换相：锁定相位并执行动作，完成派生与资源结算，检查一次延相资格，最后判定换相。日辉、夜烬各有有限上限；怒技先消费其可用份额，J3-C换相只消费剩余部分，J4-C读取已经完成的两相怒技而不重复花资源。全部战斗状态战末清除。

明相普攻“烛照回息”按攻击造成较强明火伤，按攻击给予少量治疗并生成短时护盾；护盾按防御主项、最大气血次项计算，正常持续到本次明相结束，普攻完成获得日辉与基础怒气。暗相普攻按攻击造成较强暗火伤，命中施加有限晦痕，动作完成获得夜烬与基础怒气。晦痕削弱目标下次直接伤害，用过减伤后印记仍留至到期或怒技消费。

明相怒技“烛照回天”支付所需怒气，造成高基础明火伤并按攻击治疗自己；可消费夜烬增加本次治疗预算，合并后只治疗一次，再把溢出转为护盾。暗相怒技“衔烛吞晦”支付所需怒气，造成高基础暗火伤，消费晦痕追加暗伤，并消费日辉强化本次暗伤；没有这些状态仍有完整基础输出，派生段不重新消费或施加晦痕。

行旅“昼夜行旅”完全不读战斗相位：按本法独立的行旅结算序号交替处理，第一次完成节点回复少量气血，下一次完成节点结算固定少量修为，之后继续交替；每节点只结算一次，不以战斗回合换取收益。

## 5.交付自检

- 唯一节点共 48 个：KF07、KF08、KF09、KF10 各 4 层，每层唯一 A/B/C，共 12 节点；每门均有三条完整四层路径。
- 四门基础动作都能在未选任何天赋时运行；后层候选只读取基础普攻、基础怒技、基础状态、属性或自身节点输入，不要求未选的上层候选。
- 全文没有额外能量收益、战斗内循环修为、固定休整负担或准备时间；战斗通用资源只有怒气，气血只负责生存，修为只在局外或明确的一次节点/战斗结算处增长。
- KF07 失败蓄运有限增长、成功清零，J2-B消费换确定机会，J3-B只影响下一原生段，J4-A稳定改变怒技形态，J4-C同时具有战斗收益和行旅强化。
