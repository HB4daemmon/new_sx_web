# 《随时修仙》山海版故事大纲

日期：2026-09-19

状态：五幕原创故事提案；八个核心事件沿同一条潮路相互照见。

## 一句话故事

山海潮把照海山映回人间，主角只想多活几年，却在潮口学会一门真正属于自己的法，带着新结下的恩怨登山渡劫。

## 故事梗概

潮头集夜宴散场，海面升起一座旧地图上没有的山。照海山随潮显形，山顶的雷火只留到退潮以前；有人求仙，有人求药，有人要赶在寿期之前证明自己。

主角起初只求延寿。他在潮口先学会一门寻常主修，第一次出手便知道这不是借来一晚的灵光。此后每次收获都要经过自己的手：法本要练成打法，成胚要炼成器物，同行者的承诺要靠实际相处换来。

五幕沿着潮水向山顶推进。闻岫、鲛绫、夔野、灼九、陆照各自带着旧伤、航向、老对手、师门阴影和将尽的寿期出现；每局只交汇当时遇见的两三条长线，未相逢的人保留自己的生活。

以下人物片段和幕间句是相逢版本；未抽中的人物不出场，其位置用公共地点见闻承接，不凭空产生赠礼或关系。

## 五个人，各自想走到哪里

### 闻岫

看潮采药的散修，想把未完的药法收尾，好让旧伤不再替她决定能活多久。她愿意拿药材和看潮经验换帮助，也会在主角抢走同一处药岸时转身竞争。

### 鲛绫

鲛人行舟者，想让自己的船驶向自己选的海。她辨潮、看船位，远游的兄长却留下两种相反的航向；主角与她同看一张潮图时，必须说明自己是并行还是各走各路。

### 夔野

山中斗士，想在山神宴上赢过压了自己多年的老对手。他把每一阵的重击和连段说在前面，尊重能把一门法练成自己打法的人，却不会因为一次胜负永远站到谁身边。

### 灼九

离师自立的炼器师，想在扶桑余辉下炼出一件不再属于师父的作品。她可以替主角看火候，却要主角自己决定器物要护住什么、打中什么。

### 陆照

提前研究照海山路数的修士，寿期正在缩短。他第一次见面便报姓名、所求和能交换的东西；他不替主角让路，也不愿把最后几年耗在没有约定的争斗上。

## 五幕展开

### 第一幕：误入仙缘

**目标：** 从潮头集走到潮口，学会一门普通主修，带着第一件真实所得离岸。

**小故事：** E01《潮口借火》里，潮灯照出法本，主角先学会一门能出手的法，再决定公开试身还是收好法本离开。E02《断碑听潮》让他在一块断碑前选择眼下的修为，或把未完的后句留到第二幕再面对守碑妖。

**幕间句：** 闻岫把盐霜药种放进主角掌心：“它会在你还肯往前走的时候发芽。”

### 第二幕：炼法成器

**目标：** 让学会的功法经受真实压力，再带走一件说得清来历和作用的个人法宝。

**小故事：** E03《夔鼓试身》在山神宴上敲响三阵鼓，夔野和老对手用重击、连段检验主角的打法。E04《九炼无主炉》让主角在新成胚与旧器之间选一件；可以收好新器就走，也可以付灵石参加非致命试器，胜利后只把选定原物炼得更强。

**幕间句：** 灼九把新成的器物推回来：“火候我看得见，拿它护谁由你开口。”

### 第三幕：名动山海

**目标：** 用已经练成的法和器物换到更好的山路，同时决定哪些东西值得付出灵石。

**小故事：** E05《鲛市竞珍》里，珍物和航图各有明码；航图指向一处额外休整，主角可以独自前往，也可以放弃它，随鲛绫绕行潮标、提前看清深门招式。E06《山根移府》把浅门和深门摆在同一片下沉岩层里，稳住脚步的人获得修为，敢进深处的人面对一场有生死预告的守关。

**幕间句：** 鲛绫收起潮图：“船不是因为走得快才是你的，得是你知道它为何向那里去。”

### 第四幕：自择仙途

**目标：** 在潮退前处理最后一段关系，决定是少走一道山门，还是多拿一份胜利后的收获。

**小故事：** E07《故敌同行》中，陆照说起寿期和登山法，主角可以用灵石、物品换路，也可以约一场早晚有别的晨战；若谈成合作，两人各自迎敌，只少打一处已经预告的守关。E08《归墟开缝》给出捷径、短探和公共正路，捷径跳过已知守关，却把那场战利品和一次整备留在身后。

**幕间句：** 陆照把日期写在潮图背面：“我赶我的寿数，你走你的路；真要交手，先把话说完。”

### 第五幕：一劫成仙

**目标：** 带着已学会的法、已经炼好的器和真实发生过的关系，登上照海山完成渡劫。

**小故事：** 山顶雷火沿着前四幕留下的痕迹落下：公开过的招式会被强敌记住，守住的器物会替主角挡下一次险处，曾经的约定会改变谁站在山门另一侧。同行者各自迎向自己的劫，主角必须用自己练成的本事走完最后一段。

**幕间句：** 退潮前，几道身影同时登上山脊；没有谁替谁封仙，只有各自走过的路在雷光里留下颜色。

## 八个事件如何相连

| 事件 | 现场 | 留下的故事痕迹 |
| --- | --- | --- |
| E01《潮口借火》 | 潮头集夜宴后的潮口 | 主角学会第一门法，公开的招式被后来的人记住 |
| E02《断碑听潮》 | 海泥里的断碑 | 一句当下修为或一段回到守碑妖面前的约定 |
| E03《夔鼓试身》 | 山神宴的三阵鼓 | 夔野和老对手承认主角自己的打法 |
| E04《九炼无主炉》 | 扶桑余辉下的无主炉 | 同一件法宝留下可辨认的炼痕 |
| E05《鲛市竞珍》 | 涨潮时靠岸的鲛人舟市 | 买下的器物或共享的航向改变下一段路 |
| E06《山根移府》 | 随岩层下沉的移动洞府 | 浅门的稳当或深门的伤痕伴主角继续登山 |
| E07《故敌同行》 | 照海山根的潮图边 | 陆照按实际约定成为同行者、竞争者或远去的人 |
| E08《归墟开缝》 | 归墟潮眼与两条山路 | 捷径留下的缺口或正路赢来的战利品进入终局 |

## 终局余波

主角可以回到人间，在熟悉的航路上继续做一个有本事的游仙；可以留在照海山开府，把山当作新的居所；也可以趁退潮后的缝隙继续追索山海外境。三种选择都承认同一件事：成仙不是替别人收齐故事，而是终于能用自己的名字承担下一步。
