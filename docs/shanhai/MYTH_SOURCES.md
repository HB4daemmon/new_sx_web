## 1. 核验口径

- 本地古籍库只读使用 `/product/ssxx2/tools/knowledge_search.py` 定位线索；指定段落再通过 `knowledge_review._conn()`，设置 `conn.read_only=True`，以精确 `SELECT` 按 `segment_id` 串接。没有写入、编辑、状态流转、ETL 或迁移。
- 精确段落读取属于非向量核验，不沿用语义检索相关度；安装到本地的 `knowledge-search` skill 只提供检索流程，不是游戏设定的证明。
- 向量检索的相关度只作定位信号，不能替代引文。下表给出的段号和短引文来自实际读取的源段落；`canon.fengshen_yanyi` 与 `canon.fengshen_yanyi.txt` 是两个不同文档，不能混作同一版本。
- 本地实体记录当前大多为 `draft`；按 `segment_id` 精读段落只确认原文与出处，不会把实体状态升级为 `reviewed` 或 `locked`。没有实际语义检索结果时，本页不填写或推断不存在的相关度。
- 本地 `source_documents` 未收录《山海经》；精卫改用公开维基文库页面实际读取。赭鞭的公开补证使用维基文库可访问路径 `搜神記/第01卷`；用户常见的 `搜神記/卷一` 路径本次返回 404，不记作成功检索。
- 短引文只用于核对人物、器物和典故，不抄录长段原文。原典未证明游戏的奖励、战斗触发、数值、同场时间线或路线结果，以下内容均单独标为游戏原创/改编。

## 2. 固定来源

<a id="N01"></a>

### N01 女娲

**原典依据**

- 本地段落：`canon.fengshen_yanyi:ch.001.sec.026`（《封神演义》第一回，第 26 段；本地文档 ID 为 `canon.fengshen_yanyi`）。
- 精确短引文：“女媧乃採五色石，煉之以補青天，故有功於百姓。”
- 公开阅读入口：[《封神演义》维基文库总页](https://zh.wikisource.org/wiki/封神演义)。

**游戏原创/改编边界**

- 原典支持女娲、五色石与补天材料的关联。
- `FB08 五色石`把补天材料改成可持有法宝，并设为入战护盾；原典没有“女娲把战斗护盾交给玩家”的情节。
- `E08` 的女娲赠石、强化旧宝或加强主修三选一，以及女娲作为公共主线人物，都是本作原创接口。

<a id="N02"></a>

### N02 神农

**原典依据**

- 本地段落：`canon.fengshen_yanyi:ch.058.sec.026`（《封神演义》第五十八回，第 26 段；本地文档 ID 为 `canon.fengshen_yanyi`）。
- 短引文：“取了丹藥，付與楊戩”；同段又写神农拔草，称其“可治傳染之疾”。
- 赭鞭补证：维基文库《搜神记》卷一正文写“神農以赭鞭鞭百草，盡知其平毒寒溫之性”。本次实际读取的公开页面为 [`搜神記/第01卷`](https://zh.wikisource.org/wiki/搜神記/第01卷)，HTTP 200。
- 公开阅读入口：[《封神演义》维基文库总页](https://zh.wikisource.org/wiki/封神演义)。

**游戏原创/改编边界**

- 原典支持神农分药、辨草和赭鞭的器物典故。
- `FB07 赭鞭` 的“每节点完成后回复少量气血”是游戏效果；原典只证明赭鞭与辨识百草有关，不证明节点回血。
- `E01` 的神农分药、候选奖励、正式授予和后续事件关系均为本作原创；不把原典丹药直接当成玩家永久法宝。

<a id="N03"></a>

### N03 精卫

**原典依据**

- 本地古籍库没有《山海经》源段；本次用公开维基文库页面实际读取，HTTP 200：[《山海经·北山经》](https://zh.wikisource.org/wiki/山海經/北山經)。
- 短引文：“名曰精衛……炎帝之少女，名曰女娃……常銜西山之木石，以堙于東海。”
- 原文明确写的是“女娃”，不是“女娲”；两者不能因字形相近而合并。

**游戏原创/改编边界**

- 原典支持精卫由女娃溺水而化、衔木石填东海这一事件和路线意象。
- `E02` 只把精卫填海转译为改变路线、开放或关闭后续道路；本作不虚构“精卫石”或一件有原典归属的精卫专属神器。
- 精卫的长线出现、回访、路线收益和与其他人物同场，均为游戏原创；未遇到精卫时，公共路线不能凭空发放她的独占真品。

<a id="N04"></a>

### N04 哪吒

**原典依据**

- 本地段落：`canon.fengshen_yanyi.txt:ch.012.sec.005`（《封神演义》第十二回，第 5 段）。
- 短引文：“金鐲是『乾坤圈』，紅綾名曰『混天綾』。”
- 本地段落：`canon.fengshen_yanyi.txt:ch.012.sec.014`。短引文写哪吒以“七尺混天綾”裹住敖丙，再“提起乾坤圈”击打。
- 风火轮补核：`canon.fengshen_yanyi.txt:ch.014.sec.014` 明写太乙真人“賜你腳踏風火二輪”，并把乾坤圈、混天绫放入豹皮囊；同章第 15 至 17 段继续写“脚踏金霞风火轮”及其追赶作用。这样确认了风火轮确在第十四回，不把它误归到第十二回。
- 公开阅读入口：[《封神演义》维基文库总页](https://zh.wikisource.org/wiki/封神演义)。

**游戏原创/改编边界**

- 原典支持哪吒与乾坤圈、混天绫、风火轮的归属和使用典故。
- `FB01`、`FB02`、`FB03` 的普攻追加、普攻施虚弱、节点额外修为，以及 `E03` 两段非致命试阵、护人语境和两胜后三宝三选一，都是本作自动斗法和奖励设计；原典只证三宝的归属与使用，不证“哪吒试阵护人”或玩家取得。
- 原典没有“玩家通过哪吒试阵取得这些法宝”的情节；正式授予、唯一持有和不重复发放是游戏保存规则。

<a id="N05"></a>

### N05 太上老君

**原典依据**

- 金刚琢：`canon.xiyou_ji:ch.052.sec.227-234`（《西游记》第五十二回，第 227 至 234 段）。短引文：“止不見了金剛琢……這孽畜偷了我金剛琢去”；老君又说它是“自幼煉成之寶”，兵器、水火都不能近。
- 紫金红葫芦：`canon.xiyou_ji:ch.035.sec.034-036` 写葫芦由仙藤结出、是“老君留下到如今”；`canon.xiyou_ji:ch.035.sec.211-220` 又写老君说“葫蘆是我盛丹的”，并收回葫芦等宝物。
- 公开阅读入口：[《西游记》维基文库总页](https://zh.wikisource.org/wiki/西游记)。

**游戏原创/改编边界**

- 原典支持金刚琢属于老君、曾被青牛偷走，也支持紫金红葫芦与老君盛丹的关联。
- `FB05 金刚琢` 的“每战只减首次敌方怒技的首个命中段，结算后仍存活才回怒”，以及不防即死、不复活，是游戏规则；原典的兵器水火难近不能直接换写成玩家战斗免死或整段多击免伤。
- `FB06 紫金红葫芦` 的“每个怒技主动作首个命中追加一次伤害，结算时目标有虚弱或破甲则加强一次；两种状态不重复叠加”，也是游戏原创。
- `E04` 的即时取葫芦、强化旧宝或把金刚琢留给未来守炉的单项取舍，是游戏事件设计；“守炉未来金刚琢”不能写成当场已经持有。
- 第五十二回第 234 段提到老君自己的“芭蕉扇儿”。那是老君的另一件宝物线索，不是 `N06` 铁扇公主的扇子，也不是 `FB04` 的归属依据。

<a id="N06"></a>

### N06 铁扇公主

**原典依据**

- 本地段落：`canon.xiyou_ji:ch.061.sec.247-249`（《西游记》第六十一回，第 247 至 249 段）。短引文：“連搧四十九扇，永遠再不發了。”
- 同章第 251 至 253 段写悟空“把扇子還了羅剎”，罗刹女收回本扇；这确认了扇子归还铁扇公主/罗刹女，而不是老君。
- 公开阅读入口：[《西游记》维基文库总页](https://zh.wikisource.org/wiki/西游记)。

**游戏原创/改编边界**

- 原典支持铁扇公主/罗刹女持有芭蕉扇，并由她解释“连搧四十九扇”可断火；实际灭火动作是行者执扇连搧四十九扇，最后再把扇子还给罗刹女，不能写成铁扇公主本人在本段亲自灭火。
- `FB04 芭蕉扇` 的“怒技完成后清自身一层燃烧，再获得护盾；无燃烧也照常有盾”是游戏效果。原典没有燃烧状态、怒技或护盾系统。
- `E05` 的临借、个人除火患获胜后的正式赠予和把原典人物交付改成玩家法宝，均为本作原创；临借只产生当前场景权益，不能封存为永久法宝。

## 4. 统一改编边界

- 神话人物不是历史真人；五条随机人物长线加女娲公共线、授宝给玩家、赌约路线、自动斗法数值和最终昆仑天门渡劫，都是本作原创时间线。女娲不占五条随机名额，因此不是第六条随机线。
- 原典证据只证明人物、器物、归属或典故，不证明玩家奖励、法宝数值、触发顺序、状态时长、节点收益或事件后果。
- 同一原器在一局中只保留一个唯一件；正式授予或取得后才进入保存构筑，临借、场景权益和未完成奖励不能封存。
- 法宝不提供第二门主修或第二个完整主动作；具体触发输入、次数、消费和结算顺序以 [COMBAT_RULES.md](./COMBAT_RULES.md) 及法宝卡面为准。
- 节点型法宝只按活着完成的真实节点结算一次；E03、E07 的单节点两战不能触发两次。进入节点时绑定有效行旅法宝，节点中新取得的 `FB03` 风火轮或 `FB07` 赭鞭从下个节点生效，具体对应 E03 两胜后的风火轮和 E01 深探胜后的赭鞭。
- 本轮已确认的赭鞭证据来自《搜神记》卷一可访问页面，不再把 `FB07` 标作“待证”；其节点回血仍是待测的游戏数值与改编效果。
