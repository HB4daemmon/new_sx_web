# 山海版法宝与获得接口

> 状态：评审提案；以下是首批 8 件有来源的法宝样例，不代表完整目录或数量上限。
> 数值、概率、状态时长和强化幅度待走读与测试；共同边界见 [COMBAT_RULES.md](./COMBAT_RULES.md)。

## 1. 法宝边界

- 一局只有一门当前主修；法宝只修改已有的普攻、怒技、节点结果或入战结果，不提供第二门主修、第二个完整主动作或未声明的新状态。
- 法宝不设统一持有件数或同时生效槽位，成长速度由节点产出控制。同一原器在一局中只生成一个唯一件；已经持有时不得复制同一原件，改为公开的强化、修为或其他候选。
- 永久法宝必须正式授予或正式取得后才能进入保存构筑。临借只提供当前场景权益，不能封存、带入后续大战或伪装成已取得的原器。
- 场景效果与战斗效果记录在同一件法宝上，不另开一套场景装备系统。所有触发都写清输入、结算时点、次数与失效情形。
- “追加伤害”是当前主动作的追加结算，不生成第二个完整行动；护盾、状态和回怒仍遵守同一份资源只花一次的共同规则。
- 节点型法宝只在玩家活着完成真实节点时结算一次；E03、E07 节点内两战不能按战斗次数重复触发。进入节点时绑定当时有效的行旅法宝及版本，结算时仍有效才触发；本节点新得或强化的行旅效果从下一个节点生效，和 [COMBAT_RULES.md](./COMBAT_RULES.md) 的主修绑定同一时点。战斗效果取得后即可用于下一场战斗，不必等下个节点。

## 4. 人物线与终局接口

- 五条随机人物长线为神农、精卫、哪吒、太上老君、铁扇公主；每局随机出现其中 2 至 3 条。女娲是公共线，不占随机名额，因此是“五条随机人物线加一条公共线”，不是六条随机线；未抽到的人物不能为玩家提供其独占真品。
- 女娲作为公共主线出现，负责 `E08` 的公共机缘接口；她不因未抽到角色线而消失。
- 最终路线汇入昆仑天门渡劫。人物同场、正式授宝、赌约路线、自动斗法数值和“谁在何时出现”均属游戏原创，不由原典段落直接推出。
- `MYTH_SOURCES.md` 记录的是原典人物、器物和典故；本页的法宝触发和事件奖励属于本作改编，不能反向当作原典出处。
