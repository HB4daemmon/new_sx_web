# 山海版全量内容验收与测试计划

> 日期：2026-09-19。状态：测试设计，不代表已实现、已模拟或已平衡。
> 本页定义文档和未来实现的验收口径；本轮只做文档结构、引用和合同断言，不启动服务，
> 不运行旧游戏冒称新设计有效，也不把自动模拟当作真人数据。
> 投放合同见 [CONTENT_DISTRIBUTION.md](./CONTENT_DISTRIBUTION.md)，共同规则见
> [COMBAT_RULES.md](./COMBAT_RULES.md) 与 [rules/EVENT_RULES.md](./rules/EVENT_RULES.md)。

## 1. 验收原则

1. 先验证结构、引用、资格和状态转移，再做数值首测；没有合法 ID、奖励对象或路径时，不进入“平衡感觉”讨论。
2. 每项测试要记录 `test_id`、输入种子/存档、节点序列、预期状态、实际状态和失败位置；截图或日志只作为证据，不替代规则字段。
3. 事件预览、战斗敌情和胜利奖励分开断言。敌人持有法宝不等于胜利掉落，名器转移必须有明确同一实体记录；
   公共事件卡面明示的固定奖励是合法来源，不得被测试器一概排除。
4. 自动模拟只能回答状态、计数、资源和多策略差异，不能证明玩家理解、乐趣或真实难度；理解性测试必须由真人完成。
5. “首轮预算”“稀有度权重”“大致境界”和法宝件数区间都是试测目标，不是已通过的 cap。
   任何数值结论都要附样本、种子、版本和失败分布。

## 4. 功法、换法和休整状态

### 4.1 换法状态机

建议用以下状态做断言，而不是依赖按钮是否出现：

```text
current_method = KF01-KF10
known_methods = 当前已成功取得的法本
talent_selections[method_id] = 到达境界后的固定 A/B/C
swap_slot_used = {SW2, SW3, SW4}
temporary_resources = 怒气/护盾/燃烧/中毒/虚弱/破甲
```

| 测试 ID | 操作 | 预期 |
| --- | --- | --- |
| `SWAP-001` | 起手选择 `KF01-KF05` | 当前只绑定一门主修；未选的普通功法不凭空进入已拥有法本。 |
| `SWAP-002` | L 成功后查看法本 | `L01-L05` 与 `KF06-KF10` 映射正确；成功只增加可用法本，不强制切换。 |
| `SWAP-003` | E06 经阁 | 不生成 `L/R`，从本幕合资格且未拥有/未暂存的 `KF01-KF08` 中给候选；不要求先成功完成 `L01-L03`；不越级提供 `KF09/KF10`，无合法候选时按事件卡回退。 |
| `SWAP-004` | 商店打开 | 固定 5 格公共库存，不出现方法、天赋、L/R、人物门控法宝或传奇名器；购买后不刷新。 |
