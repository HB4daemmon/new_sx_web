## 1. 保留的基础

- 五幕沿山海潮路前往昆仑天门，最终由主角独自渡劫，保存个人构筑。
- 五条人物线每局抽二至三条，女娲为公共终幕。未相逢的人物不凭空回访、赠宝。
- 十门功法、一百二十个天赋及八个核心事件的主要选择不重写。
- 五项基础属性：攻击、防御、最大气血、暴击率、速度。
- 速度只决定每轮先后；常规攻击默认命中；特殊闪避不成为通用基础闪避率。
- 法宝不分行旅与斗法，不设持有或生效总数上限；用有限产出、同名唯一和有限强化控制成长。
- 玩家文案保持短场景、直接选项、明确得失；开发边界与原典出处另列。

## 3. 法宝分工

- FB01-FB08 保留原效果与人物资格，不能混进公共随机池。
- FB09-FB40 为公共法宝：24 件普通、8 件珍稀。不绑定某一功法，只按实际输入、效果与标签协作。
- 公共法宝可用修仙器物的直白名称，但须标为游戏原创，不能冒充古籍中有名有姓的真品。
- FB41-FB48 为新增传奇名器，来源以实际古籍核验为准；取得经过与战斗效果是游戏改编。
- 每件只保留一个主要变化，可兼有直接相关的行旅效果，不要求每件都转换资源。
- 每件都有名字、快速选择、短效果、输入与输出标签、触发粒度、取得范围和失效条件。
- 护盾反伤、怒气循环、治疗与毒奶、毒火持续、负面压制、概率、叠加增益均有公共支持件。
- 速度、有限闪避及行旅成长也有少量选择；不把风火轮原有效果擅自改成速度。
- 同一 ID 本局只持有一件；重复候选在确认前改为同器强化或修为，不暗发副本。
- 同器最多强化两次，仍是原物；只提高原有效果，不新增第二条行动链。已到强化上限时预告修为替代。

### 首稿整合裁决

以下覆盖首稿分册中不一致的临时设计，最终分册必须同步，不留两套规则：

1. 构筑应持续运行。FB11 每敌方主动作最多反伤一次；FB34-FB37、FB39 各每回合最多一次，
   不设整场两次后永久停机的额外限制。FB32 仍保留每战前两次回血，作为有限恢复来源。
   FB33 明写“每战一次概率闪避机会，作用于首个合资格直接攻击段”，不能用保证闪避的短文案隐藏概率。
2. 法宝属性不因换功法而消失；只有法宝被移除、抵押、牺牲或明确停用才失效。
   FB15 提高每次自身治疗一次，FB17 可读取其有效治疗；FB35 每回合读取一次真实溢出。
   由法宝产生的治疗也可参与合法搭配，使用来源链防重入及各自次数限制，而非把所有派生治疗一刀切禁用。
   战外治疗只处理战外允许的恢复与增量，不凭空生成可带入战斗的盾、毒或怒气。
3. 公共普通法宝 FB09-FB32 第一幕起全部合资格；珍稀 FB33-FB40 第二幕起。
   分册所写的“某幕常见”只能是权重建议，不变成隐藏取得禁令；普通事件的固定奖励亦按此边界。

## 4. 新事件的职责

- 普通事件补足交换、整备、保本、押后领取、有限风险、当前构筑比较等形式，不都写成付灵石换修为。
- 每个事件两至三个直接选项；没有新决定就不拆阶段。至少两项有可说明的用途差异。
- 代价只能使用当前气血、灵石、现有物品或明确的机会；不收费尚不存在的资源。
- 需要旧宝、足额灵石或合法法本时先检查资格，缺少输入不展示无法执行的空选项。
- 求法机缘从 L01 五毒经、L02 奔雷诀、L03 太阴经、L04 金乌真经、L05 烛龙真经依次对应。
- L02 保留“断崖雷井”，L03 保留“无月长阶”，L04 保留“扶桑海潮倒悬”，L05 保留“烛龙垂天”的既有来源场景。
- L04/L05 是传奇事件，不能通过普通商店或 E06 经阁提前发放；一期一局最多抽中其中一条。
- R01-R08 各有自己的取得风险和收手选择，不只是同一场战斗换八个名字；名器必须胜利或完成明示条件后才能取得。
- 单事件内多战只结算一次节点收益。后续回访使用现有正常节点，不添加免费收益节点。

配置中不能只写“毒系”“雷法”“反伤装备”等标签，也不能引用不存在的技能或法宝。

- 战前至少展示一项关键压力与两项主要能力，展开后可核对完整构筑。
  每名敌人的关键效果均要能追溯到功法、天赋、法宝或明示的阶段规则。
- 玩家专属人物线仍只有五条。新神话敌人不是新同伴路线，不回忆未发生的授宝或相逢。
  不把神话人物称作历史真人；为其配置本作功法与原创法宝属于游戏改编，不宣称是原著所练所持。

## 6. 一局编排草案

一期以第一至第四幕各八个主进度位、第五幕一场最终战为排布起点，最多 33 个真实节点。
这是用于验证投放的草案，不是已经测定的最佳局长。

| 幕 | 必须保留的位置与机会 |
| --- | --- |
| 第一幕 | 普通战、E01、一次公共法宝三选一、E02、公共内容位、商店或风险路线、休整、BS01 |
| 第二幕 | E01 留药入口、可被 E02 绕过的普通战、E03、公共内容位、E04、机缘或精英分支、整备、BS02 |
| 第三幕 | E02 海堤入口；E05 使用两个普通战位置或一条短路；E06、机缘内容位、商店、休整、BS03 |
| 第四幕 | 入口、公共内容位、机缘或精英分支、E07、E04 回访或普通事件、最后整备、BS04、E08 |
| 第五幕 | BS05 昆仑天门雷劫；无新增商店、求法或临借奖励 |

- E03/E07 的连续战不增加真实节点数；E05 的选路页与风止石不算额外节点。
- E02 绕行减少一个普通战节点；E05 借风或除火患比常路少一个节点，均不补发跳过的奖励或行旅收益。
- E01/E02 的约定入口为必经路；E04 成功预约才替换第四幕普通事件位，不额外插入回访。
- 法宝成长主要来自明确宝物点、部分首领、有限精英与机缘、商店；普通战不场场掉法宝。
- 数量目标用于首测，不是持有上限。正式目标区间、稀有度投放和商店经济见投放文档。
