## 1. 一句话方向

**功法决定“我是谁”，天赋决定“我练成什么”，普通法宝让每次冒险都有积累，
稀有与传奇法宝再带来值得改路、改打法的机会。**

借用的是分支冒险和职业分化的设计思路，不照搬参考作品的设定、职业名或战斗系统。
战斗仍为自动斗法，玩家的决定集中在路线、奖励、进阶、交易、事件和有限换法。

## 2. 为什么要重构

旧稿的主要矛盾不是事件文案不够短，而是日常成长让位给了核心事件：

- 第一幕八节点安排两个核心事件；人物未出现时，仍用同结构公共版本占位置。
- 普通战主要给修为和灵石，改变构筑往往要等特殊奖励或剧情。
- 普通法宝多是触发组件，同名只一件再强化，拿到重复物品的积累感不足。
- 功法分支虽有标签，但属性追求不够鲜明，部分核心能力要靠后续选择才出现。

本轮调整的是这些职责，不只是把核心事件的出现率调低。

## 3. 新的单局循环

```text
选择一门能独立运行的功法
  → 看路线和敌情
  → 普通斗法 / 普通事件
  → 取得或叠加普通法宝
  → 实际修为够了，突破并选择天赋
  → 按气血、灵石与构筑决定是否挑战精英、进店、休整
  → 少量核心机缘提供特殊承诺、法本或名器
  → 击败幕首领，短幕间推进整体故事
  → 带真正练成的构筑完成渡劫并保存
```

普通战不是等待剧情的过场。拿到第二层玄铁甲、选择第一次进阶、把回血补齐，
都应在下一场战斗有能看见、能说明的变化。

## 4. 路线和故事

建议首测采用 **四个冒险幕 + 一个终局渡劫段**。
每幕基准十一节点：四普通战、三个事件位、一精英、一商店、一休整、一首领。
全程共四十五个真实节点；这是试排，不是必须保留的新局长。

| 内容 | 基准一局中的位置 | 作用 |
| --- | --- | --- |
| 普通斗法 | 16 场 | 主要取得普通法宝，消耗气血并积累资源 |
| 普通事件 | 核心替换后约 9-10 个 | 回复、交换、属性方向、资源与风险取舍 |
| 核心事件 | 潜在 2-3 个，实际可绕过为 0-3 个 | 少量人物线、传奇求法、特殊名器，不分开重复加预算 |
| 精英 | 基准 4 场，可以绕行或选额外风险 | 更高风险换稀有能力 |
| 商店与休整 | 基准各 4 个，并非每条路径都经过两者 | 花资源补缺，或恢复与准备 |
| 首领与终战 | 4 个幕首领 + 1 场最终渡劫 | 验证阶段构筑并推进大目标 |

基准含二至三个核心时，普通战加普通事件占全局约 56%-58%；
核心占约 4%-7%，不是每走几步就读一段长故事。不同分支的下限与算术见路线页。
核心每幕最多一个，回访也占名额，跨幕两次核心之间至少隔两个普通或功能节点。

每局先抽一条两次相遇的人物线，再抽零或一个独立核心机缘。未相逢不回忆，
未完成不补发；初遇被绕过，后续回访回退普通事件。
这比每局塞入多条完整人物线更适合作为第一轮低频验证。

整体故事仍存在：潮口立身、断桥试法、穿过火海、抵达昆仑，最后独自渡劫。
幕前给目标，普通敌人和短事件表现当地处境，首领战结束给结果，幕间接上下一幕。
共同主线不要求认识某个人，也不靠免费对白节点发奖励。

## 5. 法宝分层

| 层级 | 主要内容 | 取得与重复 |
| --- | --- | --- |
| 普通 | 纯属性，或属性加简单伤害、治疗、护盾、怒气、行旅收益 | 普通战主要收获；同名叠层，有明确上限 |
| 稀有 | 属性加额外能力 | 精英、首领及少量其它来源；通常同 ID 一件 |
| 传奇 | 属性加标志性能力或转换 | 低频核心或首领候选；不是每局保证，也不是额外白送 |

所有法宝都有五维属性中的至少一项。不同法宝不设总持有或生效槽位；
普通同名上限与少数唯一冲突仍保留取舍。
纯固定攻防血暂用五层试算，其它多为三层；同类加成合加，不逐件乘算。
位阶的战斗/旅途预算、`A/J/U` 口径和 44 个 ID 的复标方法见
[法宝位阶战斗与旅途基线](./ARTIFACT_BASELINE.md)。

三层稀有度不意味着只有传奇才有趣，也不意味着稀有一定比满层普通更适合：
防御盾返正在成型时，继续取得普通防御器物可以比换一件不相干的传奇更有价值。

普通战每次固定获得修为和灵石，并有从三个普通法宝候选中选一件的机会；法宝三选一只
占一次法宝机会，不是固定资源三选一；
精英和幕首领提供稀有质量三选一，传奇只替换其中一项，不另外送。
叠满物品在抽奖前过滤，未满的旧物可以继续出现；玩家可放弃物品取公开的小额灵石。

## 6. 功法像基础职业，天赋让职业长出方向

保留十个容易理解的功法名作为候选，但**不再把旧一百二十张天赋当作不可修改合同**。
功法提供基础动作、怒技、固有特色、行旅和进阶选择；不是一个只有标签的容器。

以金刚功为例：

- 炼气就会普攻造盾、怒技造盾、持盾受击后盾返，不等特定法宝才能启动。
- 基础普攻和怒技看攻击，造盾和盾返看防御。
- 筑基先加强一个容易理解的优势；金丹、元婴让属性追求逐渐分化；化神完成主要打法。
- 每层三选一，可以混选；“武僧”“法僧”是玩家练成的方向，不另设转职按钮或职业经验。

| 成长方向 | 主要追求 | 最终体验 |
| --- | --- | --- |
| 护法金刚 | 防御、盾返加成、持盾能力 | 越打越稳，靠按防御计算的反击取胜 |
| 降魔武僧 | 攻击、普攻/怒技加成、怒气循环 | 主动进攻，怒技后接强化普攻，后期攻击也能加强盾返 |
| 护体法僧 | 最大气血、护盾加成、恢复 | 气血直接增加造盾，能长期护持，也能明确耗盾换爆发 |

示例天赋保留四字正式名和直白摘要：

- **金刚厚壁｜普攻怒技加盾**：提高本门造盾量。
- **法相护体｜气血越高盾越厚**：本门造盾额外按最大气血增加，不扣当前气血。
- **反震定势｜盾返伤害提高**：直接提高已有反击，不再添加转换。
- **盾转破阵｜怒技耗盾增伤**：用真实已有护盾换伤害，取代怒技本次造盾。

不是每门功法都必须安排“攻击、防御、气血”三列。回春追求气血与治疗，养剑追求剑势与
攻击，奔雷追求有限连雷，太阴追求减益覆盖与输出窗口；属性必须服务不同的固有打法。
这些效果修正不新增法强、治疗强度等一排基础属性。

### 怒气不只有“攒满后放一次”

怒气构筑拆成**开场爆发、受击与自然回怒、快速循环、削怒对抗**，不把所有收益都写成
同一种回怒。当前是设计提案，未实现、未平衡：基础上限 **100**，下限 **60** 暂定，
独立开场 **50**，基础普攻主动作完成 **+25**，敌方主动直接攻击每个有效段 **+5**，
每轮轮尾自然 **+10**（怒技轮也有）。

- **开场爆发**：额外开场怒气只进入独立开场窗口，窗口以 50 为削怒上限；它能让第一次
  怒技更早，但不预支后续轮收入。
- **受击与自然回怒**：有效段只要造成正气血损失或正护盾吸收就登记一次，气血和护盾同段
  不重复；多段逐段算，零伤害、闪避、毒火 tick、反震反伤、自伤和事件扣血不算。收入都
  由轮尾统一结算，角色死亡或战斗结束时未到轮尾的收入不入账。
- **快速循环**：降低上限会同步降低怒技门槛和实际支付；普攻、轮尾、固定返怒和比例返怒
  则增加不同阶段的收入。当前试算方向从裸基线 `3/7/11`，经过归元固有返怒 `3/6/9`、
  中投入 `2/4/6`，到高投入 `2/3/4`，是测试阶梯而非强度承诺。
- **削怒对抗**：外来削怒先合并同类抗性、向下取整，再受每目标每轮 **20** 的统一上限；
  它不取消轮初已锁定的怒技、不偷怒、不扣已支付值。太阴的普攻削怒入口与法宝削怒可以
  叠加，但削怒请求不自动成为持续减益。

每轮开始先锁定动作与怒耗，轮内所有收入和削怒只登记，轮尾按公共公式结算；相同实际输入
下先后手不改变怒技轮次，速度仍会通过存活、护盾承伤/盾返和治疗时点改变真实输入。完整
边界见[基础怒气节奏](./ARTIFACT_SYSTEM.md#基础怒气节奏)、[怒气来源与结算时点](./ARTIFACT_SYSTEM.md#怒气来源与结算时点)
和[怒气上限与怒技节奏](./ARTIFACT_SYSTEM.md#怒气上限与怒技节奏)。

归元诀已补齐四境界、十二张天赋，固有怒技返还实际消耗 **20%**；`J1-A + J2-C` 是
返怒与降上限的中投入读法，`J4-A` 可再增加返怒，`J4-C` 则把下一轮主动作改成一次
基础积怒额外 **+15** 的强化普攻（无其它天赋时合计 +40）。金丹 `J2-A/B/C` 仍是三选一，法宝不锁功法，也不增加
奖励节点或掉落保证。具体卡面见[归元诀完整树](./METHODS.md#_4-5-rkf02-归元诀完整树)。

### 功法与天赋有共同强度基线

以十五回合作为统一测试上限，普通参照的输出、有效承伤都归一化为 100。每阶天赋
按初始预算增加约 25 点，普通累计目标为 `100/125/150/175/200`；稀有总预算比普通高
10%，传奇高 25%，不在攻击、防御和气血上重复加成。

防御、治疗和回怒按实际结果折算，不能把回怒量增加 25% 当作伤害增加 25%，也不能每阶
固定减少 25 点承伤直至归零。十门基础倾向、各阶目标与测试矩阵见
[功法与天赋强度基线](./BALANCE_BASELINE.md)。该页同时统一伤害、恢复、护盾、持续伤害、
增益与减益的实际账本、时序、预算归属和 `3/5/10/15` 回合验收；其中效果 fixture 已能
核对确定性事件账和原始量，但不提供正式参照指数，也不覆盖运行时动态敌方伤害/削怒重算。
这些仍是校准目标，当前资源算例不代表逐卡强度已经达标。

## 7. 不变的基础

- 一门当前主修；基础属性仍为攻击、防御、最大气血、暴击率、速度。
- 速度只决定先后；常规攻击默认命中；怒技替换主动作，不额外加回合。
- 灵石、怒气、修为继续使用熟悉名称；突破依赖真实修为，不到幕自动升级。
- 普通功法能长期成长；传奇有基础与机制优势，但不是各方面无条件替代普通。
- 换法有有限机会并预览旧能力损失，树选择各自保存，不回血、不免费洗点。
- 敌人继续使用真实的同源功法、天赋、法宝及合法叠层；神话人物可以担任敌人，
  但本作配装不冒充原典。旧敌人具体配置必须重做，不能直接套新属性后宣称平衡。
- 通关只保存实际构筑。后续自动大战赛制本轮不设计，也不为它预设所有路线必须相同强度。

### 基线阅读顺序

先读[功法与天赋强度](./BALANCE_BASELINE.md)和[法宝位阶预算](./ARTIFACT_BASELINE.md)，
确定构筑本身的衡量方式；再读[事件](./EVENT_BASELINE.md)确定收益与代价、
[敌人](./ENEMY_BASELINE.md)确定阶段压力，最后读[四幕](./ACT_BASELINE.md)检查成长与补给时序。
首测目标、手算输入和实测结果分开记录，不能把名义法宝预算直接换成战力或胜率。

旧的故事、人物和原典核验可保留作为素材；旧投放、旧 FB 效果、旧天赋、旧敌人配置
不能与新规则混合，旧全量检查结果也不验证本轮方案。

首发内容已按这些基线扩成整套，独立于旧版游戏数据。下一步顺序为：
卡库评审 → 新规则运行时接线 → 逐卡及整局真实校准 → 整局浏览器试玩。
已有的结构、算术与状态检查继续保留，但不能代替新运行时中的战斗和选择体验。

## 9. 验收与风险

结构验收首先问：

1. 不遇核心事件、不拿传奇，是否仍能通过普通斗法把功法练成清楚的方向？
2. 同一门金刚功换一组天赋，防御、攻击、最大气血的选择排序是否确实改变？
3. 拿到第二层普通法宝时，玩家能否解释增加了什么，而不是觉得抽到了废重复？
4. 核心回访、传奇求法、传奇寻宝是否真的共用低频预算，没有换名字绕过？
5. 玩家是否能在承受普通战损耗、追逐稀有能力、回复和花钱之间作出不同选择？
6. 玩家能否区别独立开场 50、普攻完成 25、受击有效段 5、轮尾自然 10，以及攻击回怒、
   轮尾回怒、入场额外加成、怒技返怒和外来削怒，并看出本局缺哪一环？

重点风险：

- 四十五节点比旧常规三十三节点多约 36%，要测试停留与重复感，不能以内容量代替节奏。
- 防御同时参与减伤、造盾、盾返，可能形成单属性过强；必须比较边际收益。
- 回复、护盾、行旅收益叠层可能让资源管理消失；限制单件层数不等于已经平衡。
- 三选一如果总是选同一个属性，说明敌人压力、天赋分化或成长预算还不够。
- 无总槽位仍要控制触发器数量；普通器物负责积累，不应每件都新增一条战报。
- 降上限与多路回怒需要一起测试；合法每轮怒技可以保留，但不能靠固定返怒与护盾治疗
