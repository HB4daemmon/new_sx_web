# 事件收益与选择基线
> 日期：2026-09-21  
> 状态：首轮设计目标，非实测；`target` 用于首测，`measured` 统一为 `null`。  
> 范围：普通事件、核心机缘、事件奖励与账本；不代表运行时已经实现。

本页承接[运行结构](./RUN_STRUCTURE.md)、[法宝基线](./ARTIFACT_BASELINE.md)和[功法方法](./METHODS.md)。
普通事件与核心机缘都占一个真实事件位；对白、选项页、领奖确认和事件内部战不另算节点。

## 1. 结构与硬边界
每幕固定 11 个真实节点，基准路线为 `4C + 3E + 1L + 1S + 1R + 1B`。其它合法路线按
运行结构替换节点，不必保持同样的类型数量。四幕为 44 个节点，终局只有 1 场渡劫战，全局 `45`。

| 项目 | 目标 | 边界 |
| --- | ---: | --- |
| 每幕总数 | `11` | 核心、内部战、重复确认均不加节点 |
| 基准普通斗法/事件位 | `4/3` | 普通斗法至少 3；核心最多替换 1 个事件位 |
| 基准精英/商店/休整/首领 | `1/1/1/1` | 精英、商店、休整可按路线替换；首领不可绕过 |
| 终战 | `1` | 不补装备、商店或休整 |

普通斗法奖励固定为：**本幕一笔修为 + 一笔灵石 + 普通法宝三选一取一**。这是资源固定发放、
非资源法宝三选一，不是三类奖励互相替代。放弃法宝才可领取公开的小额灵石回退，不能两者并得。

每局计划一条人物线的两次相遇，再计划 `0` 或 `1` 个独立核心；计划为 `2/3` 个，实际进入
并完成为 `0-3` 个。两次相遇在不同幕，独立核心若有则在第三个不同幕；每幕最多一个核心，
核心之间至少隔两个已经走过的非核心节点。核心可绕开，绕开不补奖励、对白、回访或终战前礼包。
第二次相遇只有初遇完成且承诺仍有效才显示兑现，否则回退普通事件；首领和终战不以核心为门槛。

核心内部的战斗、非致命挑战、谈判与多段选择仍是一个事件节点。普通事件内部战不领取通用
普通战修为、灵石和法宝三选一，不触发额外节点或重复行旅收益；`RR06` 只读真实 `C/L/B`，
不读 `E/K` 内部战。事件也不得复制普通战固定资源包。

普通、稀有、传奇法宝机会尺为 `B=1/2.4/4`；它们是设计预算，不是价格、胜率或通关保证。
法宝取得、加层、购买、换法确认后生效；取得节点不追领取得前收益，行旅效果从下一个真实
节点开始，死亡、跳过、未完成不补发。

## 2. 首轮目标与计分
目标是设计范围，不是生产常数；缺少正式 `C*`、`X*`、`H*` 或有效用途时写 `null/unknown`，
不得把目标数写进 `measured`。

| 事件机会 | `target gross` | 建议形状 | `measured` |
| --- | ---: | --- | --- |
| 轻补给 | `0.4-0.6U` | 小额灵石、修为或有效战外恢复一项 | `null` |
| 普通无代价构筑/补给 | `0.8-1.2U` | 一层普通法宝或等尺资源一项 | `null` |
| 付费普通物品 | `0.75-1C*` 报价 | 真实购买一层普通法宝，价格待测 | `null` |
| 血价/非致命挑战 | `1.5-2U` | 公开主动代价或战斗风险，成功才取高收益 | `null` |
| 人物线初遇 | `0-0.5U` | 小额资源加可追踪承诺 | `null` |
| 人物线兑现 | `2.4-4U` | 稀有或传奇质量的真实兑现 | `null` |
| 人物线高投入兑现合计 | `3-4.5U` | 初遇与兑现分开记账；安全付费分支可低于此带 | `null` |
| 独立高风险核心 | `2.4-4U` | 低频且有公开风险，不白送同额安全奖励 | `null` |

`J` 沿用[法宝基线](./ARTIFACT_BASELINE.md#_6-旅途换算尺-j)，只是设计尺：

```text
1 J = 0.5 C* 灵石
1 J = 0.2 X* 额外修为
1 J = 0.2 H* 有效战外回血
J = S / (0.5 C*) + XP / (0.2 X*) + Heal / (0.2 H*)
U = A / 5 + J
```

事件只记录选中分支，不把全部候选相加。一次直接授予的名义机会记为
`G_event = 新授予法宝的 B 合计 + 本次直接资源的 J`。法宝的 `B` 已包含自身战斗与旅途
预算，不再把它的 `A/J` 加一遍；直接资源按本次实际量计算，不乘 11 个节点。
`G_event` 是内容投放尺，区别于法宝实测 `U`，不表示实际战力或不同选择等价。

普通无代价选择可参考一层普通法宝 `B=1`，或 `.5C*` 灵石、`.2X*` 修为、`.2H*` 有效恢复
三者择一，不能同时免费拿满三项。高收益血价可以公开支付 `0.10-0.15H*` 或公开非致命
挑战；支付后 `hp>0`。安全选项只给小收获；血价单列，不能用负 `J` 直接抵扣高收益。

事件不强制每次有风险。高血线、已有稳定构筑、敌情可见时风险选项合理；低血、精英将近、
法宝已满层或灵石有明确下一节点用途时安全选项合理。每类选项都要给出至少两种合理时机。

付费普通物品的 `0.75-1C*` 只是待测报价。物品 `B` 是灵石转化，不是免费新增收益；缺正式
价格时不算折扣实值。只有真实购买才记 `discount_saving = C-price`，不能同时把购买物品 `B`、
花钱来源的 `J`、折扣 `J` 合成净新增预算。

## 3. 输入状态与可用性
展示选项前读取以下状态；未定义用途的数据保留 `unknown`，不猜成 0。

| 输入 | 用途 |
| --- | --- |
| `hp/max_hp` | 过滤致死血价，拆有效治疗与浪费 |
| `stones`、下一可见价格 | 购买、保留或资源转化 |
| `xp/next_xp` | 完整需求用于估价，当前进度与剩余缺口只用于判断突破距离 |
| `main_method_id`、`talent_ids` | 当前唯一主修和已确认天赋 |
| `artifact_layers` | `item_id`、层数、`3/5` 上限、唯一组、满层过滤 |
| `act/node_id`、已走节点 | 核心隔距、事件位、行旅窗口、一次性结算 |
| `next_enemy` | 公开敌情、失败线和下一节点风险 |
| `core_flags` | 初遇、承诺、回访资格和兑现状态 |

候选生成顺序：锁定 `event_instance_id`、固定种子、公共敌情和进入快照；过滤满层普通、已持有
单件稀有/传奇、不满足卡面明示获取条件的法本和支付后 `hp<=0` 的选项；可暂存的法本不能
仅因尚未主修就被过滤。合法池不足时使用确定资源
回退并写明来源；保存选项快照后等待确认，读档不重抽。

一局只有一门当前主修；真实修为满足条件才突破。法本获取不等于已装备，不等于免费突破，
换法不等于洗点，也不附送回血。法本获取与换法选择权单独记录，不能把传奇功法 `P=125`
强按传奇物品 `B=4`，也不能把通关收益当法本物品价值。

## 4. 选项文字模板
每张普通事件给 2-3 个按钮：

1. **场景**：1-2 句，写清眼前事实，不写隐藏检定。
2. **按钮动作**：以“取药、付石炼甲、承接赌斗、离开”等动词开头。
3. **即时成本/收益**：直白写气血、灵石、修为、层数和失败线。
4. **延后承诺**：写触发条件、后续有效节点和未完成结果。

概率必须公开成功率和失败结果，后台保存固定种子和候选快照；首测样例优先确定性。一次确认只结算
一次，第二个选项页不是新节点。“离开/放弃”可保留真实资产，但不返还已付成本或未兑现承诺。

| 类型 | 选项 A 何时合理 | 选项 B 何时合理 |
| --- | --- | --- |
| 轻补给 | 低血且下一战近，选有效恢复 | 血线稳或满血，选灵石/修为 |
| 无代价构筑 | 缺攻击、护盾或生命，拿未满层普通 | 构筑成型，拿有明确用途的资源 |
| 付费交换 | 灵石富余、下一商店价值低，直接买 | 灵石紧或价格未知，保留资源 |
| 血价/挑战 | 支付后安全且高收益能改变后段 | 低血或敌情不利，选小收益 |
| 核心承诺 | 愿意占用后续事件位并追兑现 | 不追踪，走公共事件并放弃核心奖励 |
| 求法/换法 | 已有属性和法宝更适合新法，接受预览中的旧能力损失 | 当前循环完整，保留旧法；取得法本不强制立即换法 |

## 5. 六张首测短样例
下列均是确定性草案；每张占一个 `E` 节点，内部战仍不发普通战固定资源包。

### 5.1 潮痕药篓
潮水退去，药粉能马上补缺，瓶胆只能改变之后的治疗。
- **熬药疗伤**：立即进行治疗量为 `.2H*` 的战外恢复，超过缺口的部分记 `wasted`；低血、下一战近时合理。
- **封存成回春瓶**：取得 `RC12` 一层，不立即回血；卡面是最大气血 `+10`、自身治疗量 `+6%`，
  有稳定治疗来源、准备长线时合理。`RC12` 不是直接回血。
- **收起药篓**：取得 `.2C*` 灵石，目标 `J=0.4`；满层过滤后无合法法宝时合理。

### 5.2 旧炉余温
炉主只能再做一件小器，先报价格，玩家可付石或离开。
- **付石炼锋**：实际支付 `p_common`，取得 `RC01` 一层，报价目标 `0.75-1C*`；输出不足且商店不近时合理。
- **付石炼甲**：同价取得 `RC03` 一层；已有输出、下一战压力高时合理。
- **熄炉离开**：不改资源和法宝；灵石紧、商店近或两物满层时合理。

### 5.3 灰烬石匣
匣底压着两枚法片，外沿有散石；灼伤与取得结果在确认页先公开。
- **探入匣底**：支付 `0.10-0.15H*`，支付后仍须 `hp>0`；确定取得 `RC01×2` 或 `RC03×2`，
  目标 `gross` 约 `2U`；高血线、有构筑缺口时合理。
- **拾取外沿**：取得 `.2C*` 灵石，`J=0.4`；低血、精英近或法片会满层时合理。
两个选项均无需隐藏检定；两层奖励必须有两个合法空余层位，否则先换成预告的合法等额候选，
不能收全额血价后静默只给一层。外沿收益也须展示是否仍有后续消费用途。

### 5.4 无主石印
空白石印只能刻一道纹，不改变功法，不自动突破。
- **刻攻纹**：取得 `RC01` 一层；输出不足或要补普攻前段时合理。
- **刻守纹**：取得 `RC03` 一层；下一战压力高、已有攻击时合理。
- **留印观潮**：取得不超过 `.2X*` 的修为；接近真实突破但尚未满足条件时合理。
三项择一；普通上限按卡面 `3/5` 过滤，不把未选法宝延迟成免费候选。

### 5.5 散修赌斗
散修押器物，约定点到为止；战前公开非致命败北线、风险、奖励和交换价。
- **接下比试**：固定种子执行挑战；成功取得 `RC01×2` 或同预算指定普通法宝，目标 `1.5-2U`；
  高血线、构筑缺口且能承受失败时合理，失败不补普通战奖励。
- **出价交换**：付真实 `p_common` 取得预告一层；灵石足且不想承受战斗风险时合理。
- **不参与**：保留灵石和气血；构筑够用、敌情不利或价格/风险不划算时合理。

### 5.6 驿站余火
余粮只够安排一次恢复、盘缠或修行；不附免费护盾、法宝或地图步数。
- **借火养伤**：治疗量 `.2H*` 的战外恢复；低血且无更近休整时合理，溢出不计 `J`。
- **换取盘缠**：`.5C*` 灵石，目标 `J=1`；下一商店有可买候选且当前资源不足时合理。
- **静坐修行**：`.2X*` 额外修为，目标 `J=1`；接近境界且后续有用途时合理。
三项择一。若改写为 `RC17`，只能写完成真实节点后治疗 `2` 点、最大气血 `+10`，不能当本次立即回血。

## 6. 核心两节点与预算算例
初遇给 `.2C*` 灵石，记 `J=0.4`，并写入可取消但不可伪造的兑现承诺。后段三选一：

| 后段按钮 | 即时成本/风险 | 成功收益 | 目标 |
| --- | --- | --- | ---: |
| 真实挑战 | 公开非致命战，失败放弃后段奖励 | 传奇法宝 `B=4` | `0.4+4=4.4U` |
| 稳妥路线 | 支付公开的 `.5C*`，不承担挑战风险 | 稀有法宝 `B=2.4` | 毛取得 `0.4+2.4=2.8U`，付款另列 |
| 放弃兑现 | 不支付、不挑战 | 保留初遇 `.2C*`，无终奖 | `0.4U` |

三项不同时发。初遇已领不追回，未完成不补终奖；两节点替代两个普通事件位而非新增节点。
承诺内容、实际风险、已付款项、跳过奖励和最终取得必须分列，不能用一笔负成本抵扣全部。
核心也可给法本、换法机会或法宝，三种选择权单独入账；不得把 `P=125` 当 `B=4` 或通关收益。
独立核心目标 `2.4-4U`，低频且高风险，不得用安全按钮白送同额传奇。

## 7. 一次性结算与账本 schema
事件由固定 `event_instance_id`、`run_seed`、`act`、`slot_id`、`event_revision` 标识；
一个 `selected_option_id` 只能结算一次，读档/刷新/重开只读事实账。

```json
{
  "event_instance_id": "E-A2-SLOT03-0007",
  "event_id": "RC-E03", "act": 2, "slot_id": "A2-E03",
  "run_seed": "seed-fixed-001", "status": "completed",
  "selected_option_id": "take_artifact",
  "target": {"gross_U": 1.0, "J": null},
  "measured": {"gross_U": null, "J": null},
  "source_ledger": [], "obtain_ledger": [], "risk_ledger": [],
  "skipped_reward_ledger": [], "unknown": []
}
```

每条账至少带 `source_kind`、`resource`、`raw`、`effective`、`wasted`、`unit`、`anchor_id`、
`node_id`、`cause`、`settled_once`。来源标识建议为：
`fixed_battle_package`、`event_reward`、`artifact_acquire`、`purchase`、`discount_saving`、
`core_commitment`、`risk_payment`、`skipped_reward`、`enemy_info`、`fallback`。

- `source_ledger` 记资源从哪里来，`obtain_ledger` 记实际得到的法宝、法本、修为或灵石；
  两者不能合并。
- `raw` 是原始量，`effective` 是有用途的量，`wasted` 是满血溢出、满层或无消费用途，
  `unknown` 是缺锚点、资格或用途；未知不填 0。
- `discount_saving` 仅真实购买可写；公共免费敌情不可出售；固定战资源和事件奖励分开。
- 死亡立即停止后续奖励和节点被动。非致命败北停止挑战后续效果并走明示失败分支，不领胜利
  奖励；若失败分支仍完成该真实事件节点，原有合法节点被动只结算一次，不补治疗或另算战斗节点。
  已支付部分保留，未完成奖励不延迟发放。
- 节点、奖励、来源各自只写一次；重复确认返回原账，不生成新账。

普通同名法宝按新卡上限 `3/5` 过滤，稀有/传奇默认单件；合法池为空时只用预写的资源回退，
不同时保留被过滤物品。概率若正式使用，公开 `p_success` 与失败结果，保存 `run_seed`、
版本和候选快照；同一种子重放同一结果。战斗随机由敌人接口提供，不能把胜负目标当实际结果。
