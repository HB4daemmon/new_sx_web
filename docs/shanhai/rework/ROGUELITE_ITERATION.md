# 构筑与路线迭代

> 2026-10-23。构筑与路线迭代，开发于 `feat/roguelite-choices` 独立工作区。
> 用户已授权验收版本合入远端 `main`；后续难度校准另行记录。数值仍是设计目标。

## 范围

保留四幕各十一节点、加一场终战的四十五节点流程；保留一门当前主修、
各门功法分别保存天赋的换法规则，不增加副功法槽、第二套养成货币或额外领奖节点。
沿用已获认可的 UI、美术与连续帧战斗呈现，不增加新的素材生产任务。

本次从法宝、事件、选路、资源取舍和战斗反馈切入，不把内容数量增加当作构筑深度。
本页的候选规则补充旧基线中对应条目，不代表全部法宝和首领已完成重做。

## 法宝满层

先试五件普通法宝，未满层保留原效果；达上限后自动生效，不增加“激活”按钮。

| 法宝 | 质变 | 限制 |
| --- | --- | --- |
| RC09 剑穗 | 普攻首个有效基础命中额外施加破甲 | 每轮一次 |
| RC11 铁壁符 | 首次遭敌方主动直接攻击破盾且存活时，按最大气血续盾 | 每战一次；不由自耗盾触发 |
| RC12 回春瓶 | 正数治疗时净化一层毒、火、虚弱或破甲 | 每战一次；保留琉璃法印溢疗转盾 |
| RC14 蛇纹瓶 | 敌人已灼烧时，强化本次新施加的中毒层 | 每轮一次；不追溯强化旧层 |
| RC15 赤炎珠 | 敌人已中毒时，强化本次新施加的灼烧层 | 每轮一次；不追溯强化旧层 |

卡面使用 `awakening`，效果顶层用 `min_stacks` 标明开启门槛。觉醒效果满足门槛后
只按一次效果计算，不能再按法宝总层数乘算。敌我使用相同规则。
属性与状态条件里的最低层数不等于法宝觉醒门槛。

## 即时事件

库仍为五十二个事件、二十一个选项内挑战。八个普通事件接入即时检定：
RE001、RE002、RE006、RE011、RE020、RE025、RE029、RE031。

- 属性检定使用支付前五维属性或当前气血比例；概率检定可从属性、已学功法或法宝获得加成。
- 固定命名种子绑定本局、幕、节点、事件和选项。预览、返回、刷新与读取存档不换签。
- 选择只支付一次公开成本；成功与失败分别结算奖励、结果和行迹快照。
- 选择前显示线索、确定成本与失败风险，不普遍提前列出具体所得。
- 失败不额外暗扣资源；有风险的折价尝试与确定交易不使用相同价格。
- RE023、RE032 各新增一个无成本、无奖励的离开选项。原 A/B/C 含义不改，
  总选项从一百五十五增至一百五十七，避免满层、低血、没钱时所有按钮不可用。

新选择不再创建“完成若干节点、避开商店或休整后领奖”的延迟任务。
RE001-C、RE002-B 的旧承诺定义仅用于还原既有付费存档；不清空已付代价、
不提前补发奖励、不把旧选择写成新检定成功。跨幕人物相遇仍沿原来的低频框架，
不新增延迟资源任务。

## 路线与服务

第一幕保留现有两种节奏；第二至第四幕各增加两套固定种子节奏，
旧存档已冻结的地图继续使用原图。事件仍占原有三个层位，幕末首领不变。

| 幕 | 两种节奏 | 取舍 |
| --- | --- | --- |
| 第二幕 | 桥市取舍 / 精英押注 | 早休整与中段坊市，或较早坊市与双精英机会 |
| 第三幕 | 火道连战 / 灰烬补给 | 早休整后长程压力，或早补给后较晚休整 |
| 第四幕 | 末段整备 / 关前储备 | 商店与休整集中在终局前，精英机会前置 |

额外精英仍受全局与每幕上限约束，始终可绕；每条完整图路径至少三场普通战。
地图展示本幕已经冻结的首领压力，对策线索默认折叠、按需展开。本次未新增首领阶段脚本，
不会把旧机制说明写成已实现的新回合考卷。

坊市增加折叠的普通法宝重铸：献祭一层已持有普通法宝，再支付当幕普通法宝价格的
20%（向上取整），从该店、该来源器物绑定的最多三个普通目标中选择一个，获得一层。
每店一次；返回、读档和洗髓后不能重置。已满或冲突目标不替换成新的随机候选。
献祭导致最大气血下降时只截断上限，不能免费治疗。

休整增加折叠的温养：支付当幕普通法宝价格的50%（向上取整），使一件已持有、
尚未满层的普通法宝增加一层。温养消耗整次休整，与调息、备战、换法互斥。
事件授予的换法机会不能转作温养。

## 战斗反馈

战斗结束才展示最多两条独立贡献亮点和一条关键伤害记录，完整明细仍放在详情。
伤害、有效治疗、护盾、怒气分别记账，不混加成一个无量纲的“MVP占比”。
关键伤害按相邻有效帧的真实气血与护盾差值描述，不把包含护盾吸收的伤害字段
称为“未减免伤害”。属性增益不伪装成可精确归因的伤害贡献。

旧存档战斗输入无规则标记时仍按旧法宝规则重建回放；新战斗用
`awakening-v1` 标记。仅还原回放，不重复结算资源。

全图路径、五十二事件极端资源下的安全选择，以及390/430像素手机和桌面的实际点击。
手机内容区独立滚动，底部导航占据布局空间；新摘要不能压成窄列或被底栏覆盖。
