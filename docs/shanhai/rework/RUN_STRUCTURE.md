# 《随时修仙》山海版运行结构提案

> 日期：2026-09-20
> 状态：结构评审稿，未实现、未调平衡，未承诺单局时长。
> 范围：本页只定义一局的地图节点、路线约束、事件频率、奖励预算和故事幕结构；它是《随时修仙》的游戏原创方案，不宣称与任何现成作品的规则一致。

本页与后续拆分的接口页保持相对链接：[METHODS.md](./METHODS.md)、[ARTIFACT_SYSTEM.md](./ARTIFACT_SYSTEM.md)、[README.md](./README.md)。数值、候选生成和法宝卡面必须由对应模块继续定义；本页不把提案写成已迁移、已实现或已实测的规则。

配套首测预算见[事件收益与选择基线](./EVENT_BASELINE.md)、[敌人强度与配装基线](./ENEMY_BASELINE.md)
和[四幕成长与资源基线](./ACT_BASELINE.md)。其中的示例价格、恢复和修为是校验时序的显式输入，
不是本页已经冻结的正式经济，也不代表真实战斗已调平衡。

## 1. 结构决定

### 1.1 一局的外形

一局由 **4 个冒险幕 + 1 个终局渡劫段**组成。终局渡劫段不是第五个完整冒险幕，只保留一场终战和结局结算。

| 区段 | 真实节点数 | 结构 |
| --- | ---: | --- |
| 第一幕至第四幕 | `4 x 11 = 44` | 每幕一条基准路线走过 11 个真实节点 |
| 终局渡劫段 | `1` | 终战一场，不补装备、不补商店、不补休整 |
| **全局** | **`45`** | **`44 + 1`** |

这里的“真实节点”是玩家进入、确认并完成一次地图结算的地点。路牌、选路预览、敌情预览、领奖确认、事件中的第二个选项页、幕前/幕后/兑现对话都不另算节点，也不发独立的行旅奖励。

本提案不把旧稿的 8 个核心事件固定为本局必出内容，也不要求旧稿的 2 至 3 条人物线全部出现。每局由调度器计划一条两次相遇的人物线，再决定是否放入一条独立核心机缘；未被选中或未被走到的核心内容不通过对白、回访或终战前补发来补齐。

### 1.2 每幕基准预算

每幕的 11 个节点不是把同一串固定位置换名字，而是地图生成器必须提供的一条可走基准路线的节点预算。基准计数如下：

| 节点类型 | 每幕基准数 | 计数边界 |
| --- | ---: | --- |
| 普通斗法 | `4` | 一场普通生死战；结算普通战奖励 |
| 普通事件位 | `3` | 默认是普通事件；最多 1 位可被核心事件替换 |
| 精英 | `1` | 一场精英生死战；占一个真实节点 |
| 商店 | `1` | 一个商店节点；库存、价格由法宝/经济模块给出 |
| 休整 | `1` | 一次休整节点；回复和其它效果由规则页给出 |
| 幕首领 | `1` | 一场本幕首领战；战后直接进入下一幕 |
| **合计** | **`11`** | **`4 + 3 + 1 + 1 + 1 + 1`** |

“普通事件位”是地图预算中的事件槽，不保证每次都显示同一张普通事件卡。一个事件槽可以显示普通事件，也可以在资格满足且玩家选择进入时显示核心事件；两者只占一个节点。核心事件内部若有一场或两场战斗，仍只计核心事件节点，不把其中的战斗重复计入普通斗法。

### 1.3 全局节点算术

没有核心替换、没有额外精英、每幕走基准路线时，四幕汇总为：

| 类型 | 四幕汇总 |
| --- | ---: |
| 普通斗法 | `16` |
| 普通事件位 | `12` |
| 精英 | `4` |
| 商店 | `4` |
| 休整 | `4` |
| 幕首领 | `4` |
| 冒险幕小计 | **`44`** |
| 终局渡劫 | `1` |
| **全局** | **`45`** |

若某一事件位变成核心事件，节点仍留在原位，但“普通事件”计数减 1、“核心事件”计数加 1。若路线需要额外精英，额外精英必须替换一个普通斗法或普通事件位，不能把地图从 11 节点加到 12 节点。商店或休整被跳过时，也必须用同一预算中的其它节点补位，不能出现空步或自动追加节点。

## 2. 核心事件与普通内容比例

### 2.1 核心事件的计划方式

每局计划器只挂一条人物线，并为这条人物线安排两次相遇；此外可有 `0` 或 `1` 个独立核心机缘。因此本局潜在核心节点为 `2` 或 `3` 个，实际进入并结算的核心节点可为 `0` 至 `3` 个：

1. 两次人物相遇必须占两个不同冒险幕的事件位。
2. 独立核心机缘若存在，必须占第三个不同冒险幕的事件位；同一冒险幕最多一个核心事件。
3. 计划出的核心事件可以被绕开：玩家可在同一事件位选择公共普通事件，或选择通向另一条普通路线的边。
4. 玩家绕开核心后不获得核心奖励，也不在后续对白、回访或终战前自动补发。
5. 回访是同一条人物线的第二次相遇时，占用它原本预留的事件位；未发生初遇则回访位回退普通事件，不伪造认识或承诺。
6. 核心事件中的内部战斗、非致命挑战和多段选项都属于该核心节点的内部内容；它们不进入普通斗法数量。
7. 传奇求法、传奇寻宝和人物回访共用这个预算，不能换一个“机缘”名称再加三条长线。
   普通法本的交易、换法和短试炼可放普通事件，但不能附带多幕追踪结构来规避核心计数。
8. 核心之间至少隔两个已走过的非核心节点，跨幕也检查；不能把前幕末和后幕初的核心连在一起。

因此，“人物线两次相遇”不是“每局强制触发两次”，而是调度层提供两次可见机会。玩家可以全程走公共内容，也可以只进入其中一部分；剧情仍由幕目标和首领推进，不以核心事件作为通关门槛。

### 2.2 普通内容下限

普通斗法与普通事件必须在非终战路线中占主体。计数只看地图节点，不看事件内部战斗：

- 每幕合法路径至少有 `3` 场普通斗法。
- 四幕冒险段一共 44 个节点；普通斗法 + 普通事件的全局下限为 `22` 个。
- 基准有 `16 + 12 = 28` 个普通节点。最多 `3` 个核心替换和最多 `3` 个额外精英替换后，最坏仍为 `28 - 3 - 3 = 22`。
- 每幕最多允许 1 个额外精英替换；额外精英总数最多 3 个。一幕同时有 1 个核心和 1 个额外精英时，普通节点仍至少 5 个：可能是 3 战加 2 事件，也可能是 4 战加 1 事件。
- 核心事件内部的战斗不增加上述普通战数量；普通事件内部若有一次战斗，也仍只占一个普通事件节点。
- 跳过商店或休整时若以普通事件或普通斗法补位，只会增加普通内容，不会削弱这个下限。

这条比例约束是地图生成和测试的硬条件，不是写作上的“尽量多放普通内容”。如果一个路线为了追逐核心或精英而低于下限，该路线必须被判为非法。

### 2.3 商店与休整：可达但不强制同行

每幕地图都要在生成时保证商店与休整各自可达，但不强制玩家同时走过二者：

1. 从幕入口的可见图上，必须至少存在一条通向商店的合法路径和一条通向休整的合法路径。
2. 必须存在至少一条“走商店、不走休整”的 11 节点路径，以及至少一条“走休整、不走商店”的 11 节点路径；两个节点都跳过的路径可以存在，但不是默认奖励路线。
3. 跳过商店时，用普通事件或普通斗法补位；不发免费库存、免费购买或之后的强制商店。
4. 跳过休整时，用普通事件或普通斗法补位；不发自动回血、满血转资源或首领前隐藏安全点。
5. 进入商店或休整后不能循环返回，也不能把一次节点拆成“先拿路线奖励、再领第二份节点奖励”。
6. “可达”只表示图结构可达，不保证玩家在所有战斗中存活；战斗失败仍按战斗规则结束本局。
7. 精英不是强制通关门槛；每幕至少提供一条把基准精英替换为普通战的避险路径。
   这条路线获得普通战收益，不能再领精英稀有奖励。

## 4. 地图生成与可见性

地图生成必须让玩家能看见真实的分支差异，而不是把一条 11 步直线换成不同名字：

- 每次分叉至少展示下一节点的类型、敌情或商店/休整标记；核心机会如果满足资格，必须以核心标记或清楚的公共替代项显示。
- 选路之后，未选分支消失或记录为已放弃，不在后面以补票、回访免费节点或重复地图重现。
- 事件槽的公共版本和核心版本共享一个位置 ID。核心机会被绕开时，该位置仍只结算一次普通事件。
- 额外精英只替换原本会出现的普通斗法或普通事件。精英奖励更高不等于路线增加一步，也不允许用两份普通奖励伪装为一场精英。
- 商店库存只在商店节点生成一次；休整只在休整节点结算一次。没有走到对应节点，后续不自动发库存或恢复。
- 幕首领是该幕最后一个冒险节点。首领前的对话、预览和奖励确认不产生第 12 个节点。
- 入幕即预览本幕首领压力；进入任意战斗前，完整敌方功法、天赋、法宝、目标、胜败边界与奖励类型免费可查。不能先点开战才知道生存目标，也不能把完整敌情当事件付费奖励。
- 上表是路径规格示例，不是已经实现的地图图结构；生成器还需验证分叉、合流、可达性和所有路径的配额。

### 4.1 人物线和独立核心的占位

人物线的两个相遇可以分别落在第一至第四幕的不同事件位，独立核心机缘若存在则落在另一幕。调度器应优先保证三者分布在不同幕，避免核心连续堆在同一幕；若人物线只有一部分资格成立，剩余事件位回退到普通事件，不伪造人物对白。

本结构不要求神农、精卫、哪吒、太上老君、铁扇公主等旧稿人物全部出现，也不要求旧稿 `E01-E08` 全部被复用。若内容模块复用某个旧事件，必须把它接入本页已有事件位和回访预算，不能把“旧事件回访”写成免费新增节点。

## 5. 奖励与法宝经济

### 5.1 通用战斗奖励

以下只定义奖励形状，不填写具体数量、价格、概率或胜率。具体候选合法性、属性和叠层规则由 [ARTIFACT_SYSTEM.md](./ARTIFACT_SYSTEM.md) 维护。

| 战斗类型 | 固定奖励 | 法宝候选 | 其它边界 |
| --- | --- | --- | --- |
| 普通斗法 | 本幕的一笔修为及灵石 | 普通法宝三选一，取 1 | 可放弃法宝，换取少量预告灵石；不以敌方装备自动掉落替代奖励 |
| 精英 | 一笔高于普通战的资源包 | 必有稀有法宝三选一，取 1 | 失败不把未拿候选存成免费节点；精英占一个节点 |
| 幕首领 | 本幕结束资源结算 | 三项稀有质量候选，取 1 | 传奇是低频机会，可替代其中一项，不额外附送；合法池不足时按法宝规则预告资源回退 |
| 终战 | 通关、保存实际构筑和结局 | 无新法宝、无新候选 | 终战不补装备、不补商店、不补休整 |

普通战的“三选一”是每场战斗的普通法宝机会，不代表每个候选都适合当前功法；候选的基础属性、当前收益和机会成本必须在战前或结算页可读。普通战若放弃法宝，所得少量预告灵石不能被描述成另一件隐藏法宝。

路线经济还必须满足一个反避战约束：绕过普通斗法的分支不能同时拿走该战的资源包和普通法宝，普通事件也不能用一项轻量选择无成本复制两者。首测若发现“全程避战”在资源、法宝和终局强度上都不劣于至少一条实际战斗路线，应调整候选权重、资源预算或路线代价，而不是追加免费节点；同理，精英路线的更高候选质量必须伴随真实战斗风险。

### 5.2 法宝和普通物品边界

- 每件法宝都有基础属性，再叠加其卡面效果；本结构不把法宝写成只有触发文字、没有可比较底子的空卡。
- 总持有量不限；同一局可以持有多个不同法宝，不因为达到一个全局件数槽而强制替换。
- 普通物品允许同名叠层，层数和上限由法宝/物品模块明定；叠层不是凭空增加一个地图节点。
- 普通法宝、稀有法宝的池、候选去重、同名加层和价格由法宝页维护，不恢复旧 v0-v2 强化轴。未实现前不能从“普通战每场给一件”推断确定商店价格或实测胜率。
- 核心事件的固定奖励按其事件卡结算，不再叠一份普通斗法奖励。事件中有战斗，也不自动获得“普通战资源 + 普通法宝三选一”。
- 普通事件可以改变路线、预览、资源或属性取舍，但不能用一句幕前/幕后台词发放独立行旅奖励。

## 6. 普通事件的写法和新样例

普通事件是短场景，不承担长篇核心剧情。每个普通事件提供 2 至 3 个清楚的选项，选择深度来自当前气血、灵石、修为、攻击/防御/最大气血、已有护盾类法宝和下一段敌情预览。选项不应靠连续确认、隐藏道德分或“唯一正确解”拉长流程。

下面只给 6 个短样例，不替代完整普通事件池：

| 样例名 | 2 至 3 个选项 | 取舍来源和边界 |
| --- | --- | --- |
| **潮痕药篓** | 药篓里只剩一份完好的药。`熬药疗伤`：立即治疗；`研成药引`：取得一层回春瓶，不立即治疗。 | 现在回复，还是提高此后已有治疗的效果；回春瓶同时有最大气血属性，增加上限不等于回血。 |
| **旧炉余温** | 炉火尚能炼一件小器。`炼甲`：付灵石取得一层玄铁甲；`炼锋`：付同档灵石取得一层青锋石；`离开`：保留灵石。 | 攻防需求与下一家商店预算；已满层的选项先过滤，不收钱换空收益。 |
| **灰烬石匣** | 石匣深处发红，外沿还留着散落灵石。`探入匣底`：承受公开气血代价，取得两层指定普通法宝；`拾取外沿`：只拿小额灵石。 | 用当前气血换更多属性，或保命；代价明示且要求支付后仍存活，不使用隐藏检定。 |
| **无主石印** | 空白石印只能刻一道纹。`刻攻纹`：取得一层青锋石；`刻守纹`：取得一层玄铁甲。 | 简短的定向构筑选择，不给免费收益再配一个无意义的“空手离开”。 |
| **散修赌斗** | 散修把器物押在石上，约定点到为止。`接下比试`：公开非致命战，胜利取预告普通法宝；`出价交换`：付灵石直接取得同物；`不参与`：保留资源。 | 构筑把握、当前气血与灵石之间取舍；败北线提前展示，无免费治疗；战斗仍只算这个事件节点。 |
| **驿站余火** | 驿站余粮够疗伤，也可换给过路人。`借火养伤`：恢复一笔气血；`换取盘缠`：拿一笔灵石；`静坐修行`：取得修为。 | 眼前生存、下一商店、逼近突破三者取一；不加免费护盾，不增加地图步数。 |

地图地点名和事件卡名分开记录，例如第一幕地点“旧烽火”可抽到通用事件“驿站余火”；
地名不是另一张同名事件。上面的路线地名只作示例，未写事件卡的位置属于待扩充内容。
普通事件卡若自行包含一次战斗或检定，应在卡面标注“事件内部内容”，其战斗奖励由事件卡单独给出；不得把同一场战斗重复写进普通斗法计数和普通事件计数。

## 7. 四幕与终局故事框架

山海潮仍把主角推向昆仑，主角靠本局实际练成的功法、法宝和取舍独自渡劫。每幕的达成条件只有击败本幕首领，不要求抽中或完成任何核心人物；核心事件只留下可选的叙事和构筑回声。

| 区段 | 目标 | 达成条件 | 两句框架 |
| --- | --- | --- | --- |
| **第一幕：潮口立身** | 在潮口建立能持续前进的基础构筑，决定先补资源、保气血还是承担第一段风险。 | 击败第一幕首领。 | 山海潮刚露出通向昆仑的断续石阶，主角以一门普通功法起步，在潮声和第一批斗法中找到自己的节奏。人物相遇若被计划且被进入，只是潮口的可选回声，不改变首领通路。 |
| **第二幕：断桥试法** | 让功法与法宝开始形成稳定组合，能承受连续节点的资源损耗。 | 击败第二幕首领。 | 潮路抬升成断桥，前一幕的选择在药棚、旧炉和浮桥边留下痕迹。主角可以追逐一次核心机缘，也可以只靠普通事件、斗法和精英继续修成自己的法。 |
| **第三幕：火海取舍** | 在火山、海底旧路和转型机会之间决定是继续放大当前构筑，还是为后段承担换法成本。 | 击败第三幕首领。 | 潮水退到山根，火海与旧经阁把每一点气血、护盾和灵石的机会成本放大。核心人物缺席时，公共事件仍把路指向昆仑，不用临时补写人物来制造剧情密度。 |
| **第四幕：昆仑前门** | 完成渡劫前的最后整备，保留真正赢来的东西，放下未兑现的承诺。 | 击败第四幕首领。 | 云层已能看见昆仑天门，剩下的是一条只允许主角自己走过的窄路。女娲等公共终局意象可以在这里收束，但任何人物线和独立机缘都不是入场必需品。 |
| **终局渡劫段：天门独渡** | 用这一局的当前主修、天赋、法宝和资源赢下雷劫。 | 击败唯一终战。 | 女娲补住天裂，天门只提供让渡劫发生的天光，不替主角承受雷火。终战检验真实带入的构筑，胜利后直接保存结局，不补装、不追加第五幕冒险。 |

这些人物、事件组合和幕内因果都是游戏原创改编，不把神话原典中的人物、法宝或时间线写成游戏流程的历史证明。

## 8. 第一幕 11 步走读：金刚功与四类普通法宝

以下是基准路线的示意走读，不是实测胜率、确定价格或固定候选表。`RKF01 金刚功`起手就能按防御造盾和盾返，不需要先遇核心人物。实际数值、出现概率和层数上限交给 [ARTIFACT_SYSTEM.md](./ARTIFACT_SYSTEM.md)。

以下只使用新法宝页的候选，不把旧 FB 的能力和新 RC 的属性混用。同名反复取得能继续成长，
但实际是否出现这些候选仍由种子决定。全幕没有核心事件，也应有完整的成长体验。

| 步 | 真实节点 | 走读中的构筑和选择 | 收益 | 机会成本/约束 |

## 9. 结构自检与验收口径

在实现或内容接入前，至少执行以下检查：

1. **总数**：四个冒险幕各 11 个真实节点，终局 1 个节点，合计 `4 x 11 + 1 = 45`。
2. **基准类型**：每幕基准为普通斗法 4、事件位 3、精英 1、商店 1、休整 1、首领 1。
3. **核心上限**：每幕核心最多 1 个；每局计划为一条两次相遇人物线加 `0/1` 独立机缘；实际核心 `0-3`。
4. **普通下限**：每幕普通斗法至少 3；四幕汇总普通斗法 + 普通事件至少 22 个。事件内部战斗不重复计数。
5. **替换规则**：额外精英和核心都只能占已有预算；任何路线列表出现第 12 个节点即非法。
6. **可达性**：每幕商店和休整都有各自可达路径；至少有一条路径跳过商店、至少有一条路径跳过休整，跳过后仍保持 11 节点。
7. **奖励边界**：普通战有资源 + 普通法宝三选一，放弃法宝才可换少量预告灵石；精英和首领有稀有三选一；传奇只替代候选；终战不补装备。
8. **故事门槛**：四幕只以各自首领作为达成条件；核心人物和独立机缘均可绕开，不阻断昆仑和终战。

按最坏普通比例核算：基准普通节点为 `28`，最多 3 个核心替换和 3 个额外精英替换后为 `22`；商店/休整跳过或放弃精英会以普通节点补位，不压低 `22/44` 下限。路径表六条路线均须逐行数到 11 步。

## 10. 节奏风险与首测计划

相对旧稿常规路线的 33 个节点，45 个节点多 12 个，增幅为 `12 / 33 = 36.4%`。这不是“多 12 个奖励”的承诺，而是地图进入、战斗、结算、选择和阅读都可能增加的单局时长风险；核心事件变少并不能抵消普通战和普通事件主体带来的操作次数。

首测先测节奏，不承诺时长或胜率。应记录：

- 每幕完成率、放弃率和走过的真实节点数；
- 普通斗法/普通事件/精英/商店/休整的平均停留和重看次数；
- 玩家是否能看懂核心替换、商店/休整分叉和额外精英的机会成本；
- 第三幕以后气血、灵石和法宝候选是否出现明显的资源断崖；
- 终局前是否因 44 个冒险节点产生重复感或疲劳；
- 不同功法、普通法宝四类方向和精英选择是否有一条“必然最优路线”。

数值、价格、候选权重、精英强度、首领阈值和总时长都属于未解决参数，必须以实际实现和走读结果回填，不能在本结构稿中伪装为已平衡。
