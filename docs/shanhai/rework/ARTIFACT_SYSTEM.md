# 法宝：普通积累、稀有补能力、传奇改打法

> 日期：2026-09-20。状态：重构评审稿，未实现、未调平衡。本轮数字是方案提案与资源试算，
> 不是逐项确认的战斗平衡结论。`RC/RR/RL` 是本稿法宝 ID；功法、路线与奖励规则分别见
> [重构总纲](./README.md)、[功法](./METHODS.md)、[路线](./RUN_STRUCTURE.md)。

## 1. 分层与目录

| 层级 | 玩家看到的价值 | 设计边界 |
| --- | --- | --- |
| 普通 | 一项明确属性，或属性加一项简单修正 | 主要收获；同名可叠，通常不新增复杂触发器 |
| 稀有 | 属性加一项条件能力 | 通常单件；补出搭配，不接管整门功法 |
| 传奇 | 属性加一项能改打法的能力 | 通常单件；不是必需品，不保证每局获得 |

每件法宝至少提供攻击、防御、最大气血、暴击率、速度中的一项实际加成。普攻增伤、
治疗加成、护盾加成等属于效果修正，不另造基础属性。功法本体可以独立运行；没有传奇、
没有配套稀有，也应能形成有效打法。

本稿示例严格为 **24 个普通、15 个稀有、5 个传奇，共 44 项**。新增 ID 不增加掉落节点，
也不保证传奇。普通同名最多按卡面上限叠层，稀有和传奇默认单件；不设总持有数或总生效槽位。
本页器物是游戏设计示例，不据名称声称已有原典依据；历史名器的来源与效果须另行映射。
功法和天赋的整体强度目标见[十五回合强度基线](./BALANCE_BASELINE.md)，不能用资源循环
已经成立代替伤害与生存达标。
跨位阶的战斗/旅途预算、`A/J/U`、作用窗口和 44 个 ID 的复标方法见
[法宝位阶战斗与旅途基线](./ARTIFACT_BASELINE.md)；本页仍是卡面、层数、触发和怒气
公共合同的权威入口。

- `RC01-RC18` 的属性和简单效果沿用短卡面语义；暴击率按百分点相加，速度只决定先后。

- `RC20` 每层只读取一次普攻主动作完成，不要求命中；它不替代公共基础普攻 +25。
- `RC21` 每层是公共自然回怒 +10 之上的额外 +5；只在整轮结束、角色存活且战斗未结束时

- `RC23` 每层在怒技实际执行并完成后固定返 +5；不按消耗比例，不在普攻后触发。
- `RC24` 的“最多 3”是同名叠层上限；每层对每个有效受击段 +2。它与公共每段 +5

### 新增条目的技术说明

- **`RC24 血气石`**：每层对每个有效敌方主动直接攻击段额外登记 +2，最多三层；同一段
  同时打掉护盾和气血仍只算一次。毒火、燃烧、反震、自伤和事件扣血不输入。它的每段
  触发与公共基础 +5 同步，但不拥有 `RR08` 的“每敌方主动作一次”语义。
- **`RR13 截脉针`**：只读取普攻首个有效基础命中，每个己方主动作一次；怒技、追加段、
  反震和持续伤害不触发。它登记的是敌方本轮削怒请求 +10，受目标每轮外来削怒 20
  总上限约束，不在命中时立即扣敌方怒气。
- **`RR14 封元镜`**：开场独立窗口向敌方登记削怒请求 30，一场真实战斗一次；它不占用
  R1 常规每目标 20 的削怒额度，读档不重发，敌我规则对称。
- **`RR15 定心佩`**：这是明示法宝提供的抗削怒比例，不是新的基础属性。多个明示来源
  先合加并封顶 100%，再按统一公式向下取整；它只影响外来削怒，不限制回怒收入或受击段数。
- **`RL04 启明玉`**：开场独立窗口额外回怒 +50，与基础入战 50 和其它开场额外回怒
  合算后只截一次；不把未满上限的 50 直接写成“开场必满”。
- **`RL05 回澜印`**：怒技实际执行并完成后固定登记 +50，仍受轮尾支付、收入合并和新
  上限统一截断；不在动作中生成第二次怒技。

未要求改动的已有条目边界也保持不变：`RR02` 每个自身主动作首次有效自疗按比例加盾且
治疗保留；`RR03` 只在普攻首个基础命中施毒，多段只施一次；`RR04` 每个普攻主动作只
检定一次首命中追加；`RR05` 每次自身主动作完成叠攻击层，最多三层，战末清除；`RR06`
每个真实战斗节点只结算一次战后恢复，节点内多战不重复，非战斗节点不触发。

原有传奇的技术语义保持不变：`RL01` 将战斗中真实溢出的治疗改走护盾出口，替代该份
溢出原本要走的直接伤害或施毒出口，有效治疗本身保留；`RL02` 每轮只读取首次自身燃烧
造成的实际气血伤害并按比例治疗，燃烧伤害保留；`RL03` 每次普攻首个基础命中追加两段
攻击伤害，每个普攻只触发一次，追加段不再触发普攻追加。

`RR01`、`RR07`、`RR08-RR12` 和 `RL01-RL03` 的触发方向不因新增条目自动迁移其它旧效果：
`RR01` 是基础攻击有效命中额外 +10，`RR07` 首怒后上限 -15，`RR08` 是真实掉血每敌方主动作
一次，`RR09` 是已有盾返每敌方主动作一次，`RR10` 是直接暴击每己方主动作最多两次，
`RR11` 是毒火实际掉血每轮一次，`RR12` 是有效自疗每己方主动作一次。新增条目不改变
掉落节点预算。

“有效基础命中”要求该基础直接段造成正气血损失或正护盾吸收。`RR01` 覆盖普攻和怒技，
不读取追加、反震或持续伤害；多段基础命中也只登记一次。`RR08` 必须真实掉血，护盾
全部吸收不触发；`RR09` 要求已有盾返造成正伤害或盾吸收，既不授予盾返，也不让被反震
的一方领取基础受击回怒。`RR10` 可读基础或追加直接攻击的有效暴击，但不读毒火或反震。
`RR11` 只读自己施加的毒火造成的敌方实际气血损失；`RR12` 不读满血溢出或战外治疗。
没有输入时不发额外怒气，条件试算不能当作每轮必然发生。

## 4. 叠层、属性与效果公共规则

### 同名与唯一

1. 同一 `item_id` 保存一个 `stack_count`，普通法宝增加层数但不超过卡面上限；稀有、
   传奇默认单件。
2. 同名普通法宝只显示一行，例如 `玄铁甲 ×3/5`；固定值、百分比、暴击百分点和效果
   修正按同类线性合加，不把层数当成品质升级。
3. 旧强化事件只能重写为增加未满层普通法宝，或给出另一项明示奖励；不同时叠层又升级
   品质。
4. 传奇唯一组只有确实改写同一输出的能力才互斥。`RL01` 的 `overflow_outlet` 同一份
   溢出只能选择一个替代出口，替代与其它来源施毒不是同一件事。
5. 交换唯一组时明示替换损失；移除法宝立即移除对应属性和能力，已结算伤害与奖励不回滚。
6. 唯一组冲突可选择保留旧物或整件替换，不只关闭旧能力却保留属性，也不引入随时切换的
   备用背包。真正的神话唯一实体仍只有一个持有者；普通器物和非唯一稀有可由敌我分别持有。

### 属性与一次效果

```text
当前属性 = (角色基础值 + 功法固定加成 + 法宝固定加成)
           × (1 + 功法百分比加成 + 法宝百分比加成 + 合法临时百分比加成)
```

条件加成只在条件满足时参与；暴击率以百分点合加后截在 0%-100%。最大气血变高不免费
回血，变低只把当前气血截到新上限。
一次伤害、治疗或护盾先算原始量，再合并同类修正并结算实际结果；治疗先修正总量，
再拆成有效治疗和溢出。派生效果读取已经记录的实际结果，保留来源链，同一能力不能沿
自身输出重入。死亡或非致命败北立即停止战斗内后续效果。
普攻、怒技加成默认只放大功法基础直接段，不自动放大毒火、盾返或法宝追加。不同类别的
合法派生可以继续读取已发生结果；同一份资源不二次消费，追加不再触发自身追加，反伤
不递归反伤。治疗产生护盾可再享受一次护盾加成，但不再次放大原治疗。

## 5. 怒气公共规则

### 怒气上限与怒技节奏

这是法宝、功法和天赋共用的公共结算锚点；其它文档只引用本节，不另写怒气公式。
基础上限 100、下限 60 暂定，均为本轮提案与试算护栏，未实现、未调平衡。

```text
新上限 = max(60, 100 + 全部合法上限增加 - 全部合法上限减少)

B = 轮初怒气 - 本轮怒技实际支付 + 本轮全部有效怒气收入
D = min(20, floor(本轮全部外来削怒请求 × (1 - 抗削怒比例)))
轮尾怒气 = min(新上限, max(0, B - D))
```

- 每轮开始先读取上一轮已结算怒气，并同时锁定双方动作；满怒且没有更高优先级强制普攻
  时锁定怒技，成本就是当时锁定的当前上限。怒技实际执行时才支付一次。
- 本轮全部怒气收入（包括基础普攻、基础受击、自然回怒和法宝/功法返怒）及外来削怒都
  只登记，不在动作中改变可花余额。
  轮尾先完成毒火、燃烧、派生效果和死亡判定；仍在战斗后才应用本轮上限变化，计算
  `B`、`D`，再一次性 clamp。
- `D` 在 clamp 前从净额中抵消：不能先把 `B` 填满新上限再扣削怒，也不能用削怒取消
  本轮已经锁定的怒技、扣已支付值或把怒气偷给攻击者。外来技能、物品、敌方规则共享
  每目标每轮 20 的削怒上限，多段不重置。
- 上限变化不追溯本轮动作或成本；移除减上限来源、上限回升也不补怒。比例返怒以本轮
  实际支付值为基数，固定返怒同样只能供下一轮。收入满溢也不生成额外主动作。
  同次比例先合加，再按实际支付乘算并向下取整一次，最后与固定返怒合并。回元佩首怒
  仍按降低前的锁定成本支付，降上限不退差额。
- 敌我使用同一公式、同一输入顺序和同一段边界；只要输入相同，先后手不因结算时点白得
  或少得一轮。公共规则只保证“正常能普攻时不会仅靠削怒永久锁死”，不保证叠加眩晕、
  死亡或其它无法普攻状态时仍能放招。

### 基础怒气节奏

- 入战基础怒气为 50。先清理上一战临时状态、计算当前上限，再把 50 与所有明确开场
  额外回怒合算并只截一次；节点、读档不重发，战末清除。
- 每次普攻主动作完成登记基础 +25，一次主动作只算一次，不要求命中；怒技、追加攻击、
  反震反伤不领取这 25。
- 每个有效敌方主动直接攻击段登记基础 +5。该段造成正气血伤害或正护盾吸收即算一次；
  同段同时打盾和血仍一次。零伤害、闪避、毒火/燃烧、自伤、反震反伤和事件扣血不算。
- 每整轮存活且战斗未结束，轮尾额外登记自然 +10。它独立于普攻、受击和法宝，不在
  开场预发；战斗结束或角色死亡的该轮不领取。
- 基础来源和法宝来源均只登记待结算收入；轮尾统一入账。额外来源的动作、轮次和战斗
  限次不能反过来限制公共 +5。

### 怒气来源与结算时点

| 来源 | 登记时点 | 次数与边界 |
| --- | --- | --- |
| 入战基础 | 开场窗口 | 固定 +50；与开场额外回怒合算后只截一次 |
| 普攻基础 | 普攻主动作完成 | +25，每主动作一次；怒技和追加不算 |
| 受击基础 | 有效敌方主动直接段发生 | +5，每有效段一次；不按敌方主动作合并 |
| 自然回怒 | 轮尾确认存活且战斗未结束 | +10，每整轮一次 |
| `RC20` | 普攻完成 | 每层 +5，每主动作一次 |
| `RC21` | 轮尾自然回怒登记后 | 每层 +5，每整轮一次 |
| `RC22` | 开场窗口 | 每层 +15，每场真实战斗一次 |
| `RL04` | 开场窗口 | 额外 +50，每场真实战斗一次 |
| `RC23` | 怒技实际完成 | 每层固定 +5 |
| `RC24` | 有效受击段发生 | 每层每段 +2，与公共 +5 同边界 |
| `RR01` | 基础攻击有效命中 | 每主动作最多一次，额外 +10；不限制公共 +5 |
| `RR07` | 首次怒技完成 | 登记本战上限 -15，轮尾生效一次 |
| `RR08` | 敌方主动作及派生完成 | 真实掉血时额外 +10，每敌方主动作一次 |
| `RR09` | 已有盾返有效完成 | 额外 +10，每敌方主动作一次；不授予盾返 |
| `RR10` | 直接攻击暴击检定完成 | 每次 +5，每己方主动作最多两次 |
| `RR11` | 持续伤害及派生结算 | 自身毒火实际掉血时 +10，每轮一次 |
| `RR12` | 自身主动作及治疗派生完成 | 有效自疗 +10，每己方主动作一次 |
| `RR13` | 普攻首个有效基础命中 | 登记敌方本轮削怒请求 +10，每己方主动作一次；怒技、追加不触发 |
| `RR14` | 开场窗口 | 向敌方登记削怒请求 30，一次；独立于 R1 常规额度 |
| `RL05` | 怒技实际完成 | 固定 +50 |

以上登记值在角色死亡或战斗结束时丢弃；轮尾先完成持续伤害、派生和死亡判定，再将
支付后的余额、全部有效收入和外来削怒请求统一结算。外来削怒不产生攻击者怒气。

### 开场削怒与回怒

开场是独立于 R1 常规动作的窗口。开场法宝每场各触发一次，读档不重发：

```text
开场怒气 = min(
  当前上限,
  max(0, 50 + 全部开场额外回怒
        - min(50, floor(全部开场削怒请求 × (1 - 抗削怒比例))))
)
```

`RR14` 的开场 -30 不占用 R1 的每目标 20 常规削怒额度；R1 及以后仍按每目标每轮
`D = min(20, floor(...))` 计算。抗削怒只来自明示法宝（当前为 `RR15`），同类比例
先相加并封顶 100%，再统一向下取整。开场上限 50、轮内上限 20 和抗削怒比例都是试测
护栏，不能限制回怒收入或受击段数。

## 6. 功法并行合同与节奏对照

### 功法并行合同

其它法宝可以自由搭配，不把以下选择写成法宝套装：

- 归元固有：怒技完成后返还本次实际消耗的 20%（向下取整）。
- `RKF02-J1-A`：怒气上限 -10。
- `RKF02-J1-B`：基础普攻额外回怒 +10。
- `RKF02-J2-A/B/C` 三选一：A 有效基础攻击回怒 +10；B 每轮额外回怒 +10；
  C 返怒率增加 20 个百分点。
- `RKF02-J4-A`：返怒率再增加 20 个百分点。
- 太阴新增金丹 `RKF08-J2-A`：普攻首个有效基础命中登记敌方本轮削怒请求 +10；与 `RR13`
  合计仍受目标每轮 20 上限约束。

下文“中投入、高投入”中的 `J1A/J2C/J4A` 均为归元 `RKF02` 的简写，不是太阴天赋。

### 节奏试算：跨过门槛才会提前出手

以下只核算资源，不模拟伤害、胜负或平衡。默认双方存活、对方每轮一段有效敌方主动
直接攻击、无其它未注明来源；每轮初锁定动作，轮尾才合并收入。`a/b` 表示首次和第二次
怒技回合，数值是对照，不是承诺。

#### 裸基线逐回合尾值

| 回合 | 轮初怒气 | 锁定动作 | 本轮收入 | 轮尾怒气 |
| --- | ---: | --- | --- | ---: |
| R1 | 50 | 普攻 | +25 普攻、+5 受击、+10 自然 = +40 | 90 |
| R2 | 90 | 普攻 | +40 | 100（130 截断） |
| R3 | 100 | 怒技，支付 100 | +5 受击、+10 自然 = +15 | 15 |
| R4 | 15 | 普攻 | +40 | 55 |
| R5 | 55 | 普攻 | +40 | 95 |
| R6 | 95 | 普攻 | +40 | 100（135 截断） |
| R7 | 100 | 怒技，支付 100 | +15 | 15 |

因此裸基线动作是 **普、普、怒、普、普、普、怒**，尾值为
`90, 100, 15, 55, 95, 100, 15`，首两怒为 `3/7`。R1 的开场 50 没有被当作
“永久余额”，R3 支付也没有被轮尾收入补回；R6 的多余收入在一次 clamp 时损失。

#### 普通单项隔离

每行只加入一项，`x1/x2/x3` 是同名层数；除卡面来源外仍用一段有效受击。

| 法宝 | x1 | x2 | x3 | 说明 |
| --- | --- | --- | --- | --- |
| `RC19` | `3/6` | `2/5` | `2/5` | `cap=95/90/85`，只改容量、门槛和支付 |
| `RC20` | `3/6` | `2/5` | `2/5` | 每个普攻轮额外 +5/+10/+15 |
| `RC21` | `3/6` | `2/5` | `2/5` | 自然 +10 之外每轮额外 +5/+10/+15 |
| `RC22` | `2/6` | `2/6` | `2/6` | 开场额外 +15/+30/+45；三层为 95，不是默认满 100 |
| `RC23` | `3/6` | `3/6` | `3/6` | 每次怒技完成固定返 +5/+10/+15 |
| `RC24` | `3/6` | `3/6` | `3/6` | 每段额外 +2/+4/+6；一段有效受击假设 |

`RC24` 若没有有效受击，仍是 `3/7`；下面的两段/三段数字是**不叠加 RC24 额外每段值**
的公共受击压力参照：每轮两段有效受击为 `3/6`，三段为 `2/5`。这是压力输入对照，
不是承诺敌人每轮固定段数。

#### 其它单项与功法

| 配置 | 怒气节奏 | 计算要点 |
| --- | --- | --- |
| `RR01` 单件 | `2/5` | 假设每个自身主动作有一次基础攻击有效命中，额外 +10 |
| `RR07` 单件 | `3/6` | 首怒按 100 支付；完成后上限 -15 在轮尾生效 |
| `RR08` 单件 | `2/5` | 假设每敌方主动作真实掉血，额外 +10 |
| `RR09` 单件 | `2/5` | 假设已有盾返每敌方主动作有效，额外 +10 |
| `RR10` 单件 | `3/6` | 假设每个自身主动作一次有效直接暴击，额外 +5 |
| `RR11` 单件 | `2/5` | 假设每轮毒火实际掉血，额外 +10 |
| `RR12` 单件 | `2/5` | 假设每个自身主动作有效自疗，额外 +10 |
| `RL04` 单件 | `1/5/9` | 开场 +50，R1 直接锁怒技 |
| `RL05` 单件 | `3/5/7` | 每次怒技完成固定返 +50 |
| 归元固有 20% | `3/6/9` | 只有固有返实际消耗 20%，无其它额外来源 |

上表的条件输入均从 R1 起满足，怒技轮也满足；不默认盾返、自疗或暴击必然存在。
`RR10` 若每主动作两次有效直接暴击，资源试算为 `2/5`，但需要相应攻击段数和实际暴击，
多段还会给对手受击回怒，不能把此行当成完整对局的胜负结论。

#### 投入梯级

- **中投入**：`J1A + J2C`，`cap=90`、返怒率 40%，前三次怒技为 `2/4/6`。
- **高投入**：`J1A + J2C + J4A`，`cap=90`、返怒率 60%，再加 `RC21×3` 与
  `RC23×3`，首三次怒技为 `2/3/4`。怒技轮收入拆为
  `54（90×60%） + 25（自然10+RC21额外15） + 15（RC23固定返） + 5（受击） = 99`。
- 高投入不需要传奇才能成型，但会牺牲直伤天赋与六层普通预算；能成型不代表输出更强。
  降低 `cap` 只能改变跨门槛位置，未必每降一档都再提前一回合。组合降低上限后，未满
  50 的开场额外回怒才可能提前首轮；普通 `RC22×3` 的开场额外 45 在裸 `cap=100`
  时只是把 50 变成 95，不应写成默认开场满怒。

#### 持续削怒压力

把每个目标从 R1 起都注入满额外削怒 20，只用于压力测试：

| 配置 | 无持续削怒 | 每轮削怒 20 |
| --- | --- | --- |
| 裸基线 | `3/7` | `4/10/16` |
| 高投入 | `2/3/4` | `3/5/7` |

这里的 20 是全局每目标每轮上限，不是说某一件法宝单独每轮必减 20；`RR13`、太阴
金丹 `J2A` 和其它外来规则合计仍只能提供不超过该目标本轮额度。削怒在 clamp 前从
净额抵消，不能取消已锁怒技或扣攻击者已支付怒气。

#### 开场对抗

开场先按独立窗口公式结算，再锁定 R1 动作。`RC22×3` 只提供额外 45，基础 50 合计
95；`RL04` 单件提供额外 50，基础 50 合计 100。`RR14` 对敌方登记开场 -30，不占
R1 常规 20；与其它开场削怒请求相加后受开场 50 护栏和 `RR15` 抗性公式处理。

## 7. 奖励、行旅与保存

### 奖励与商店

- 普通战胜利获得修为、灵石，并从三件普通法宝候选中选一件，不是在三种奖励类型中
  三选一。法宝候选 ID 不重复，满层普通和已拥有的单件稀有/传奇从合法池过滤。
- 未满层普通仍可出现；玩家可以放弃法宝取公开的小额灵石回退。合法池不足时显示确定
  的资源回退，不生成不可选空卡。
- 精英、首领和事件按路线预算投放；新增 `RC24/RR13-RR15/RL04-RL05` 不增节点，
  不保证传奇。展示候选时确定并保存，读档不重抽、不重复发奖。
- 商店库存打开时固定；购买普通法宝明示增加层数、价格、库存和当前层数，满层不可买。
  牺牲普通是明示减少层数，稀有/传奇是整件移除；没有写明返还就不默认退款。
- 普通战的基础资源与放弃法宝所得小额灵石是不同项目，不重复发放法宝回退。
  合法唯一组替换仍可展示，不因冲突直接删除候选；商店不开放无限刷新。
- 基准路线仍为四幕各十一节点加终战，共四十五节点：十六次普通战法宝机会、八次精英/
  首领稀有质量机会。传奇只替换原候选，不额外送一份；终战只通关与保存，不补装备。
  分支会改变实际机会，完整预算以[冒险结构](./RUN_STRUCTURE.md)为准。

### 行旅生效

1. 法宝取得或加层后，战斗属性用于之后尚未发生的战斗；不回放已经结束的战斗。
2. 节点收益以入场时的物品与层数为准；节点中途取得的行旅能力从下一真实节点生效。
3. 移除或抵押后立即停用；本节点结束时不以失效层领取收益。内部多战、领奖和旁白不
   重复结算节点；移除后新买的层数不能冒充入场时有资格的原层，跳过节点不领奖。
4. 战外治疗只回血，不生成毒、怒气或下一战护盾；战斗临时怒气、上限修正和触发标记
   在战末清除。

### 显示与存档

- 普通显示如 `玄铁甲 ×3/5：防御 +15`；稀有和传奇先显示属性，再显示一行能力。
- `RC19` 同时显示名义层数、上限减少和触底后的实际降低；移除减上限来源只恢复后续
  容量，不补怒。
- 战报按来源显示登记值、轮尾实际到账、统一 clamp 的浪费和未触发原因；不把每几轮
  放怒技写成固定承诺。
- 存档至少保存内容版本、功法/天赋 ID、法宝 ID 与层数、独立永久属性。战斗中保存还
  要保存轮初动作锁、已锁怒技成本、支付标记、待结算收入、削怒请求、临时上限变化和
  开场触发标记；读档不重发开场怒气、不重复支付或领取收入，也不新增主动作。
- 战斗死亡或终止时尚未结算的收入全部丢弃；敌人读取同一法宝定义和合法层数，但不自动
  获得玩家节点奖励。

## 8. 迁移与验收

本稿保留不限总槽位、敌我共用法宝定义、唯一名器所有权、装备与掉落分离、行旅不重复
结算和终战不补装；旧 `FB` 定义、事件奖励与敌人配装仍需另做显式迁移，本稿不伪造旧
存档转换。

- [ ] 示例条目精确为 24 普通、15 稀有、5 传奇，共 44 个唯一 ID；新增 ID 不增加掉落节点。
- [ ] 全部法宝至少提供攻击、防御、最大气血、暴击率、速度之一；普通以属性或简单修正为主。
- [ ] 同名普通叠层上限明确，稀有/传奇默认单件；属性和同类效果线性合加，不新增隐藏强化轴。
- [ ] 基础合同为 `cap=100`、下限 60 暂定、入战 50、普攻完成 +25、有效受击段 +5、
      存活完整轮自然 +10；怒技不领普攻 +25。
- [ ] 公共有效受击边界统一：正气血或正护盾同段一次；毒火/燃烧、反震、自伤、事件扣血

      额度；抗削怒仅来自明示法宝，比例合加封顶后统一 floor。

- [ ] 基线尾值为 `90,100,15,55,95,100,15`，动作序列为普普怒普普普怒；公共来源、

- [ ] 奖励、行旅和保存不重复发放；死亡丢弃待结算收入；旧数据迁移单列，不由本稿假设完成。

或最终战斗平衡。
