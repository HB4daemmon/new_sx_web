# V2：功法、法宝与旅途共同构筑

> 2026-10-29。状态：第二轮可玩的实验版本，分支 `feat/v2-build-engine`，内容版本
> `shanhai-content-0.2`。V1 冻结在标签 `V1`、提交 `2f08f08`。
> 本实验不替换正式 `main`，也不宣称已达到 V1 的累计通关率目标。

## 第一原则：好玩、爽、想再开一局

系统数量、选择数量和低胜率都不能单独证明肉鸽感。这次实验的首要验收是：
玩家拿到一个东西后，能不能马上期待下一场，打完能不能看出它如何改变了打法。
允许有代价、需要配合的强组合形成压制，不为追求整齐的面板强度把所有流派磨平。

以下是试玩验收标准，不是已经通过的用户体验结论：

| 检查点 | 要观察的体验 | 不成立时怎么改 |
| --- | --- | --- |
| 第一场奖励 | 核心拿到后的下一战就有追击、施毒、造盾等实际变化 | 调整启动条件，不再追加等待节点 |
| 第一幕成型 | 玩家能说出自己的核心，以及下一件想要的搭配 | 缩短描述、改善候选和搭配入口，而不是增加教程 |
| 联动回报 | 支援与核心配合后的收益明显，战斗帧和来源账能解释 | 检查机制输入、触发次数和系数，不只抬总属性 |
| 中后期爆发 | 成型后可以打出高爆发、连续怒技或持续压制 | 保留局部超常收益，用成型成本和不同敌情约束 |
| 选择阻力 | 装备位和路线让人取舍，但没有反复切页的操作税 | 减少重复确认；必要时修改限制本身 |
| 失败与重开 | 能指出本局缺的环节，并愿意试另一种核心 | 改善败因与构筑反馈，检查是否只剩一种最优解 |

不增加每日任务、倒计时、延迟领奖或伪装概率来制造留存。事件继续保留即时结果、
明示代价和合理的未知后果。“上头”来自发现和兑现组合，而不是无法离开游戏的压力。

## 已实现的底层变化

### 第二轮：器魂、合炼与护道

四幕继续讲述逆潮由潮口、断桥、火海指向昆仑封口；行者是循潮上山的寻常修士。
已有事件与契约仍以实际选择结算，胜利后的破门纪传只读取本局真实记录。

- **器魂觉醒**：24 件普通法宝均有满层效果，只有装备、达到对应层数并满足触发条件才生效。
  新增效果包括追击、补盾、治疗、回怒与毒火，原有五件觉醒保留。青锋石满五层后
  另有一次不可暴击的普攻后追击，不与凝锋合并的基础段混为一谈。
- **两件合炼成品**：蛇纹瓶与赤炎珠可合成九幽毒火幡，青锋石与剑穗可合成雌雄剑。
  对应材料在战斗开始及胜利结算时均持有，累计两次合格胜利后各消耗一层；事件战胜利
  也计入，失败与回放不计入。成品不进入普通掉落或坊市，有装备空位时自动装备。
  图鉴在取得相关材料后显示配方和进度，成品效果在取得后公开。
- **护道法相**：第一门已习得、不同于主修的功法自动护道，切换主修时重新按习得顺序确定。
  十门功法都有独立协战；金刚与御火、回春与五毒各有双向合练。烛龙护道在有效命中后
  交替造盾与攻击。协战不是可承伤角色，每个合格主动作最多触发一次，来源独立记账。
- **绝技连斩**：怒技中实际取得的回怒足够时，立即追加怒技，一次行动最多三式。
  既有待结算怒气、回响、强制下次普攻和死亡截断分别遵守原边界，不制造额外回怒。
- **有代价的强器**：启明玉固定 50 怒气上限、防御乘 0.65，可与回澜印的实际返怒组成
  连斩；镇心玉防御减半，直接与派生伤害乘 1.6，毒火、反震、治疗和护盾不吃该倍率。
  敌方装备时使用相同规则，相关敌情同步公开。
- **引雷邀战**：第 1 至 4 幕精英和首领战前可开关。开启后敌人基础气血加 25%，开场获得
  最终气血 15% 的护盾与 20 怒；胜利取得额外 50% 基础战斗修为，并在常规奖励后另选
  一件稀有法宝，稀有池耗尽则选传说，均耗尽时补偿 20 灵石。失败无额外奖励。
- **反馈**：战斗中的连斩与护道按真实事件显示，结算按实际伤害记账列出前三来源，
  折叠区另列实际生成护盾的前三来源；治疗仍单独展示，不把不同维度混成战力总分。

当前使用五个可调序的装备位；同一主动作内的器魂觉醒按阵位顺序结算，其他触发仍按
各自的战斗时序执行。传奇昆仑镜在自身位置复制紧邻右侧满层法宝的出手后觉醒输出一次，
但不复制其属性、行旅、核心、合炼或旧式事件触发觉醒。无条件复制所有触发、铭刻、
1 点气血等尚未实现。
高稀有法宝并非全部重写；本轮明确改造启明玉与镇心玉，其余沿用现有规则。
这是可试玩的机制实验，不将这些未落地的提案写成已有功能。

### 上一轮：攻击形态与奖励炼化

借鉴万象棋中消耗冗余棋子进行定向成长、以及以撒中改写攻击形态的思路，
上一轮先修改已有法宝与奖励的用途。不复制参考作品的名称、文案或素材。

**青锋石成为凝锋核心。**保留每层攻击+6、上限5层，将主普攻本体最终的全部基础段
（含剑丸成阵、归元蓄击及非暴击附加量）汇总，乘1.25后只结算一次不可暴击的直接命中。
怒技、化身、飞剑、连锁和法宝独立追击不合并、不吃这份倍率。零段不凭空产生攻击。
核心规则不随法宝层数重复；第二轮又为满五层增加独立追击觉醒。

这是取舍，不是所有构筑的统一升级：逐段施毒、命中回怒、毒针和宝轮充能只读取真实的一击，
首领蓄势也只削减一份；暴击构筑失去普攻暴击。相反，对逐段成长和反伤的敌人，
可以用更少的命中承受更少的反制。敌方携带同一法宝时遵循同样规则，预览已同步。
战痕显示实际的“N段合一”，伤害仍归功法本体，不把整次输出冒充青锋石净增伤。

**战后炼宝。**第一幕保证核心的首场奖励之后，每幕至多一次，在普通战的普通奖励中：

- 放弃本次整份候选奖励，不获得候选，也不领取拒绝奖励的灵石。
- 消耗一层已持有、未装备的普通法宝，为一件已装备、未满层的普通法宝增加一层。
- 同种不能自炼；精英、首领、稀有或传说奖励不能炼；不额外扣钱或发钱。
- 最后一层材料消失会减少收藏种类，因此与万宝朝宗、备用配装有实际竞争。
- 可用来追满层觉醒，并在达到内容阈值时显示提示。
- 增加气血上限不回血；本节点行旅仍按入场快照结算，不补发新增层数的行旅收益。
- 允许先付费寻缘再决定炼宝，但寻缘费用不退，不能再领第二份奖励。

界面沿用战后折叠工具，确认前显示材料损失、目标层数、放弃的所有候选和剩余次数。
不增加新货币、跨局永久属性或延迟领取。炼化记录、候选和层数一起保存，返回或刷新不重做。

受控对照已经验证单击收益与命中/暴击代价都真实存在；这不等于正常流程的强度或趣味性结论。
完整验收与样本统计见文末本轮记录。

### 持有不再等于生效

- 背包可以保留法宝；同时生效的是 **5 件自由组合的法宝**，可以装备多件机制核心并调整阵位。
- 同名普通法宝仍按原上限叠层，整叠占一个位置。
- 没有装备的法宝不提供属性、战斗效果或行旅收益；事件的持有条件仍能读取背包。
- 获得法宝时，有空位自动装备；满位则收入背包，不静默替换。
- 地图、领奖、坊市、休整和幕间可调整；进入敌情、事件或战斗后锁定。
- 替换预览明确显示失去的法宝与气血上限变化；换装不回血、不刷新候选或敌人。
- 行旅按节点入口时的装备和层数结算，且退出时必须仍持有并装备。中途取得不追补。

YAML 的 `equipment_role` 保留机制定位，不再限制槽位。敌人也受五件总量约束。
多件核心的规则同时执行，代价也同时存在。例如剑穗和回春瓶同时装备，
能得到追击、自疗与转盾，但也同时承受两件的伤害限制。

### 普通核心第一层就改变规则

下表只解释机制，完整参数以[普通法宝内容页](./content/artifacts/COMMON.md)为准。
原有属性、叠层与觉醒效果仍在；核心规则本身不随层数重复执行。

| 核心 | 获得的打法 | 代价或限制 |
| --- | --- | --- |
| 剑穗 `RC09` | 普攻后追加一次派生伤害 | 怒技基础伤害降至 65% |
| 雷纹印 `RC10` | 怒技完成后返还 20 怒气 | 承受直接伤害提高 12% |
| 铁壁符 `RC11` | 开场造盾，怒技将现有护盾转成额外伤害 | 消耗实际护盾，爆发与防护互相竞争 |
| 回春瓶 `RC12` | 普攻自疗，所有有效自疗额外转 60% 护盾 | 直接伤害降至 80%；满血溢出不算有效治疗 |
| 蛇纹瓶 `RC14` | 普攻施毒，怒技引爆全部预存自身毒层 | 消耗毒层，不能再吃同一份后续持续伤害 |
| 赤炎珠 `RC15` | 普攻燃烧，实际燃烧掉血按比例吸血 | 怒技基础伤害降至 80%；打盾不吸血 |

琉璃法印和回澜印保留原有出口；启明玉已加入上文的过载代价；薪火宝炉与裂空宝轮采用下文的新机制，
替换而非叠加原效果，不再增加第二套同名 `core_rule`。
普通核心不是等待传奇的无效过渡物。无核心时的首次普通战奖励改为三个普通核心候选，
替换原奖励机会，不额外增加免费节点。

这些组合的身份不等于已经完成强度校准。例如同为金刚功，铁壁符偏耗盾爆发，
回春瓶偏回复与续盾，剑穗偏普攻追击。需要用同敌情的真实对照判断收益，
不能把来源账里的全部伤害直接当作“换装净提升”。

### 功法本体提供循环，法宝改变循环

本轮重做七门功法的本体。其余五毒经、金乌真经、烛龙真经保留毒层、多段燃烧、
昼夜轮替，通过同一套命中、治疗、持续伤害与反击接点使用新法宝。
不是所有变化都要先抓到金色天赋才会发生。

| 功法 | 本体变化 | 会主动寻找的配合 |
| --- | --- | --- |
| 金刚功 | 盾吸收敌方直接伤害时蓄劲；敌方主动作后达到阈值或破盾则独立反击，余劲可在怒技开头释放 | 开场盾、治疗造盾、反击续盾 |
| 归元诀 | 怒技后强制接一次三段蓄击普攻，再回到怒气循环；与剑丸成阵叠成五段，各段倍率同时折算 | 命中回怒、毒针、宝轮、普攻追击 |
| 回春功 | 治疗及溢疗积累春华，最多储存两个20%气血阈值；敌方主动作后消耗一份，释放气血上限12%的派生伤害 | 治疗量、最大气血、回生佩；旧溢疗出口仍互斥 |
| 御火诀 | 怒技开头提前结算已有己方燃烧的一次剩余跳数，真实减少寿命 | 燃烧延长、赤炎珠吸血、宝炉储火 |
| 养剑诀 | 开场一柄飞剑，完成普攻增至最多三柄，敌方主动作后齐射；原法宝养势与怒技耗势并存 | 多段命中法宝、如意钱、宝轮；留势长锋可选择保势 |
| 奔雷诀 | 普通命中、追击共同蓄雷，每三次命中再引一雷，每行动最多两次 | 多段、法宝追击、引雷针、战意不息 |
| 太阴经 | 按敌方不同负面种类逐种追击、削怒 | 跨门派的毒、火、虚弱、破甲，不只堆同一种层数 |

为把战力移到循环，金刚、归元、回春、养剑和奔雷的部分基础伤害下调。
养剑的本门“剑断连环”替换默认耗势出口，不再重复消费；“留势长锋”保留七层上限，
同时关闭默认耗势。派生攻击不重新执行整个普攻，也不重复普攻回怒。

八件法宝的新效果替换旧触发逻辑，原属性、获取池、层数和装备位不变：

| 法宝 | 新规则 |
| --- | --- |
| 震山环 | 任意功法持盾受击都能反击，不再只放大金刚既有反震 |
| 毒牙钉 | 累计三次有效命中施加两层毒，每行动一次；追击也能充能 |
| 如意钱 | 普攻后追加一至三击，按本场冻结的灵石数量决定段数，不扣钱 |
| 震岳鼓 | 一次敌方行动内首次有效反击后续盾并回怒，能接金刚、震山环和猬甲 |
| 余烬盏 | 消耗最早的一层己方毒与火，按实际剩余伤害合爆；单系仍有少量持续伤害回怒 |
| 回生佩 | 有效自疗蓄最多两把生息刃，在下一次普攻释放；纯溢疗不充能 |
| 薪火宝炉 | 燃烧真实扣血积成炉火，下次怒技分三击释放；不再提供旧燃烧治疗 |
| 裂空宝轮 | 累计六次有效命中释放四段轮击，每行动最多一轮；不再固定普攻追加两击 |

法宝追击可以喂给其他规则，但不能喂回自身；每行动上限在出伤之前登记。
化身不再次消耗蓄劲、剑势、炉火或毒火，也不为这些新循环充能。
御火加速的是剩余跳数，不凭空复制持续伤害。太阴先读取负面种类，余烬盏再合爆。
致死攻击后不再出现死者反击。

蓄劲、归元蓄击、春华、雷引、生息刃、炉火等用短计数显示；
完整规则放在详录，来源账保留功法、天赋和法宝的实际贡献。

### 本次原型：反应循环与主动追构筑

本次不增加卡库数量，先把三种循环从普通出手中分离出来：

- **飞剑齐射**：养剑的飞剑在本场持续存在，独立显示数量和追击节拍，不是可被攻击的召唤角色。
- **架势反击**：金刚只有实际护盾吸收才蓄劲；达到气血12%的蓄劲阈值或真正破盾后反击，
  先清空资源再出伤，怒技不会再消费同一份蓄劲。
- **春生回涌**：回春先积累，敌方完成主动作后再释放一份；毒火结算与化身不额外触发释放。

这些反应可喂给已有的合法命中法宝，但不会递归执行完整普攻、重复主动作回怒或无限触发自身。
独立反应沿用已有素材，战斗显示短名称，最近取得的法宝或天赋只在确有贡献时标注。

战后新增折叠的**寻缘**：每幕一次，支付8灵石，按御剑、护御、生机、侵蚀四类倾向
替换当前候选。免费查看固定结果，不升级稀有度、不增加领奖次数，已出现的传说候选保留。
候选不足三件时按实际数量展示；首次必得核心的奖励不能替换。
消费计入旅途账本，刷新、返回和读档都不会返还费用或重新抽取。

第一幕首领增加公开准备：共工遗影每三回合释放剩余潮汐蓄势，有效直接或派生命中可削减；
河伯试潮遗影每三回合按剩余回雾恢复，中毒或燃烧实际扣血可削减。两者均非无敌或单一流派门槛。
地图与敌情提供完整打断方式。冻结路线同时避开直接相邻战斗的同名敌人，不承诺全幕不重样。

### 首次突破定方向，后续选择形成联动

保留十门功法和原有 120 张本门天赋，现有 **16 张共通洞见**，定义在 `RULES.insights`。
首次突破从七张方向天赋中冻结三张；后续每阶冻结 **一张本门天赋 + 两张共通洞见**。
每阶仍只选一张，因此同阶的选择互为取舍，不能把所有强规则都拿到同一局。

候选按种子、功法、阶数和洗点代次确定；读档、查看、切换功法不重抽。
付费洗点才推进代次。每阶仍只选一张，共通天赋不额外占用或增加突破次数。
本门一阶天赋保留在内容库与天赋谱中，但本实验首破不投放本门候选。

战利生财提供真实胜利奖金，市井仙缘影响之后生成的商店标价，
先天神力保留直接加攻击的简单强项，并不要求每张金色天赋都改变全部玩法。
这些是单局规则，未装备的法宝或不再选中的天赋不会残留效果。

### 战绩成为路线资源

选择破军战骨后，每幕可在一个普通战预览中主动邀战精英。
确认后冻结本幕精英敌人、展示真实精英信息，胜利获得精英结算，失败仍可结束命途。
返回地图、刷新或读档不会恢复次数、换敌人或重抽天赋。总节点数仍是 45。

消费、精英胜场与首领胜场分别记录；事件内的真实战斗也按敌人品级结算战绩和胜利奖金。
终战胜利计入首领战绩，但不发普通战后奖励。战斗使用冻结的旅途快照，
回放不重复扣钱、增加胜场或发奖金。

### 路线一次决定一段

四幕仍各走十一节点，终战一节点，总共四十五节点。
每幕起点后分为三段，每段三节点；进入一段后沿本路走完，段与段之间再分叉，
最后汇入首领。不再每一步都能左右切线拿走所有最有利节点。

生成器保留每条完整路径至少三场普通战、服务点各自可达、精英可绕过、
核心事件间距和全局额外精英额度。服务点可达不代表任意已选路线都能补救抵达。
后三幕沿用差异化功能节奏，本次更改的是连边承诺，不增加节点总量。

### 让构筑反馈紧跟战斗

- 命盘分开显示五个通用装备位与背包，允许任意角色的法宝互换和调整顺序。
- 共通洞见候选、详录与命盘显示当前灵石、消费或战绩对应的数值，不要求玩家心算公式。
- 手机奖励纵向排布，核心机制与代价先于长描述；完整规则留在详录。
- 战斗沿用已批准的人物素材、连续帧表现、伤害飘字和受击反馈。
- 战斗中的核心来源强调只对应我方实际出手，结算读取本场冻结装备。
- 简报保留核心与另一条重要贡献，不将伤害、护盾、治疗相加冒充一个战力分。
- 化身本体输出记到身外化身，法宝后续输出仍归对应法宝；战斗来源标签区分化身。
- 纯属性器物不因为没有触发次数就被标成“未生效”。

当前没有“移除这件法宝后重打”的玩家侧对照功能。来源贡献解释发生了什么，
不等同于因果净收益；不能将它包装成已经完成的逐件提升验证。
