# 哪吒过阵

阵门先重后快，哪吒让你看清第一阵的代价。你可以收下一笔修为或退出；若付出相当于基准气血 8% 并胜过第一阵，第四幕才有资格决定是否继续。

- 人物：哪吒
- 计划：每局最多一条；未完成时不补发兑现奖励。
