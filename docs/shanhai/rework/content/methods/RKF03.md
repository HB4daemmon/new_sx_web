# 回春功

以最大气血强化自疗，并将溢出的治疗转为其他效果的医修功法。

## 固有被动

- 治疗超出气血上限的部分，默认有70%转为一次追加伤害；佩戴琉璃法印时，这部分改为转成护盾，不会重复转化。

## 行旅能力

- 完成非战斗节点后恢复最大气血6%的气血；只填补当前气血缺口，不触发溢疗效果。
