# 金乌真经

以逐段燃烧和多段火攻制造传奇级爆发的御日功法。

- 开发标识：`RKF09`
- 位阶：传奇
- 定位：御日者
- 属性侧重：攻击、最大气血
- 专属机制：无

## 基础动作

- **金乌引焰**：直接火伤并施加燃烧
- **三足焚天**：三段火攻并逐段引燃
