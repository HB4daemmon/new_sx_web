# 金刚功

以防御造盾、承伤反震并把护盾转成攻势的普通护法功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF01`
- 位阶：普通
- 定位：护法
- 属性侧重：主属性=防御；次属性=攻击、最大气血；伤害取值=攻击；护盾取值=防御；护盾加成取值=最大气血
- 专属机制：无
- 十五回合目标：100、125、150、175、200

## 基础动作

- **金刚镇岳**：攻击并按防御造盾
- **撼岳怒印**：怒技攻击并按防御造盾

## 固有被动

- 当前护盾实际吸收敌方主动直接攻击的正伤害时，按防御的0.38倍反震一次；每个敌方主动作最多一次，反震不再次触发本效果。

## 行旅能力

- 完成休整后额外获得24修为；只在该休整节点结算一次，不在战斗中触发。
- 完成休整后为下一场战斗准备相当于当前幕参考气血的12%的护盾；只兑现到下一场且不在当前节点重复结算。
