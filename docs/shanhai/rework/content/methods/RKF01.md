# 金刚功

以防御造盾、承伤反击并把护盾转为攻势的护法功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF01`
- 位阶：普通
- 定位：护法
- 属性侧重：主属性=防御；次属性=攻击、最大气血；伤害取值=攻击；护盾取值=防御；护盾加成取值=最大气血
- 专属机制：无
- 十五回合目标：100、125、150、175、200

## 基础动作

- **金刚镇岳**：攻击并按防御造盾
- **撼岳怒印**：怒技攻击并按防御造盾

## 固有被动

- 护盾吸收敌方主动直接攻击时，反击造成防御0.38倍的伤害；每次敌方行动最多触发一次，反击不会再次触发此效果。

## 行旅能力

- 完成休整节点后额外获得24点修为，每个休整节点只触发一次。
- 完成休整后，为下一场战斗准备护盾；第1幕75点、第2幕93点、第3幕114点、第4幕138点，仅在下一场战斗生效。
