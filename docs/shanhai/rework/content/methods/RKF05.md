# 养剑诀

以唯一剑势状态积累剑锋、强化直接剑击并在需要时耗势追击的普通剑修功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF05`
- 位阶：普通
- 定位：剑势斗士
- 属性侧重：主属性=攻击；次属性=暴击率、防御、最大气血；伤害取值=攻击；critical_direct_only=是；survival_from=防御、最大气血

- 十五回合目标：100、125、150、175、200

## 基础动作

- **养锋出鞘**：直接剑击并积一层剑势
- **断水养锋**：怒技剑击并保留剑势

## 固有被动

- 普攻和怒技的基础直接剑击都读取动作开始时的剑势，每层额外增加攻击0.04倍的直接量；该增量不把暴击率扩展到未明示的派生效果。

## 行旅能力

- 连续完成2个节点后为下一场战斗准备一次攻击0.20倍的首击；准备只存一份、只在下一场兑现，换法或错过战斗不重复追领。
