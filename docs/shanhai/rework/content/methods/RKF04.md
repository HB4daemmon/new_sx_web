# 御火诀

以火焰攻击和燃烧持续伤害压制敌方的火修功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF04`
- 位阶：普通
- 定位：火修
- 属性侧重：主属性=攻击；次属性=防御、最大气血；伤害取值=攻击；burn_from=attack；survival_from=防御、最大气血
- 专属机制：无
- 十五回合目标：100、125、150、175、200

## 基础动作

- **引火灼身**：火伤并施加燃烧
- **炎心爆发**：怒技火伤并叠燃烧

## 固有被动

- 御火诀施加的每层燃烧每次结算时额外造成攻击0.02倍的伤害；燃烧不会暴击，层数和持续时间仍按各项效果说明计算。

## 行旅能力

- 存活完成普通战、精英战或首领战节点后获得3枚灵石；每个战斗节点只获得一次。
