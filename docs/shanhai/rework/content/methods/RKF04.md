# 御火诀

以攻击造成火焰直伤并施加公共燃烧的普通火修功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF04`
- 位阶：普通
- 定位：火修
- 属性侧重：主属性=攻击；次属性=防御、最大气血；伤害取值=攻击；burn_from=attack；survival_from=防御、最大气血
- 专属机制：无
- 十五回合目标：100、125、150、175、200

## 基础动作

- **引火灼身**：火伤并施加燃烧
- **炎心爆发**：怒技火伤并叠燃烧

## 固有被动

- 本门施加的燃烧每层额外读取攻击0.02倍作为首测持续伤害输入；公共燃烧的上限、持续和不暴击规则保持不变。

## 行旅能力

- 活着完成战斗、精英或首领节点后获得3灵石；只在战斗节点结算完成时触发一次，不在战斗动作中重复发放。
