# 太阴经

以虚弱、破甲和削怒压制敌方节奏的阴咒功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF08`
- 位阶：稀有
- 定位：咒师
- 属性侧重：攻击、防御
- 专属机制：无
- 十五回合目标：110、137.5、165、192.5、220

## 基础动作

- **幽月蚀心**：直接阴伤并施加虚弱
- **太阴破妄**：重击并施加破甲
