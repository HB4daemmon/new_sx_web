# 太阴经

以虚弱、破甲和公共削怒请求控制敌方节奏的阴咒功法。

- 位阶：稀有

- 属性侧重：攻击、防御
- 专属机制：无

## 基础动作

- **幽月蚀心**：直接阴伤并施加虚弱
- **太阴破妄**：重击并施加破甲
