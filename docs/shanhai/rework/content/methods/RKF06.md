# 五毒经

叠加中毒并以毒压制敌手的持续战斗功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF06`
- 位阶：稀有
- 定位：毒师
- 属性侧重：攻击、最大气血
- 专属机制：无
- 十五回合目标：110、137.5、165、192.5、220

## 基础动作

- **蚀骨引毒**：一击并叠一层中毒
- **五毒蚀心**：重击并叠两层中毒

## 固有被动

- 每场战斗开始时防御提高8。

## 行旅能力

- 选择五毒经为主修，存活完成节点后额外获得6点修为。
- 主动选择扣除气血的行旅选项时，该事件首次气血代价降低15%；最多减免：第1幕50点、第2幕62点、第3幕76点、第4幕92点。
