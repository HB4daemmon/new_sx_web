# 归元诀

以公共怒气为循环核心，普攻积怒、怒技按实际支付返怒的普通回气功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF02`
- 位阶：普通
- 定位：回气斗士
- 属性侧重：主属性=攻击；次属性=暴击率、防御、最大气血；伤害取值=攻击；critical_direct_only=是；survival_from=防御、最大气血
- 专属机制：无
- 十五回合目标：100、125、150、175、200

## 基础动作

- **归元行气**：普攻并按公共规则积怒
- **归元震脉**：怒技攻击并返还实际怒耗

## 固有被动

- 每次怒技完成后，按本次实际支付怒气的20%登记固有返怒；它与公共开场、普攻、受击和轮尾自然回怒叠加，不改变主动作次数。

## 行旅能力

- 完成休整、事件或商店等非战斗节点后获得18修为；每个节点只结算一次，不在战斗动作中触发。
