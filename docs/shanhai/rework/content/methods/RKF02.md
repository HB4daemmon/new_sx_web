# 归元诀

以怒气循环为核心，普攻积怒、怒技按消耗量返怒的回气功法。

- [内容首页](../INDEX.md)；[共用规则](../RULES.md)；[幕结构基线](../ACTS.md)

- 开发标识：`RKF02`
- 位阶：普通
- 定位：回气斗士
- 属性侧重：主属性=攻击；次属性=暴击率、防御、最大气血；伤害取值=攻击；critical_direct_only=是；survival_from=防御、最大气血
- 专属机制：无
- 十五回合目标：100、125、150、175、200

## 基础动作

- **归元行气**：攻击并回复25点怒气
- **归元震脉**：怒技攻击并返还实际怒耗

::: details 普攻开发详情

:::

::: details 怒技开发详情

## 固有被动

- 每次怒技完成后，按本次消耗怒气的20%返还怒气。

## 行旅能力
