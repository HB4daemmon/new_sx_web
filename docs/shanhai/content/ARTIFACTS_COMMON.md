## 普通法宝

### FB09 护身佩

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**入战护盾。
- **玩家短效果：**每场战斗开始获得一次护盾。
- **输入标签：**战斗｜入战｜自身。
- **输出标签：**护盾｜一次。
- **触发粒度与次数：**每场真实战斗开始时触发一次；同一战斗的回合、阶段和相位变化不重复触发。
- **失效条件：**战斗外、临时借用或战斗已经开始后取得时不追溯；护盾被打破后不自行再生。
- **强化方向：**两次同器强化均只提高入战护盾量，不增加触发次数，不提高护盾上限。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得；普通敌人可作为同类装备使用，但不因此自动掉落。

### FB10 玄铁甲

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**防御提高。
- **玩家短效果：**装备时提高防御。
- **输入标签：**装备｜防御属性。
- **输出标签：**防御｜持续。
- **触发粒度与次数：**持有并生效时持续提供一次属性加成；不按受击次数重复计算。
- **失效条件：**只有移除、抵押、牺牲或明确停用时失效；换功法不卸载属性，不把防御加成折算成护盾或额外减伤层。
- **强化方向：**两次同器强化均只提高防御加成，不新增反伤、护盾或动作。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得；敌方可装备同 ID 同效果。

### FB11 震山环

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**护盾受击反伤。
- **玩家短效果：**护盾实际吸收敌方直接伤害后反伤；每个敌方主动作最多一次。
- **输入标签：**敌方主动作｜直接伤害｜护盾实际吸收。
- **输出标签：**反伤附加伤害｜每个敌方主动作一次。
- **触发粒度与次数：**每个敌方主动作至多触发一次；同一主动作的多段直接攻击合并检查，不设整场两次的额外停机。
- **失效条件：**没有实际护盾吸收、持续伤害或事件扣血均不触发；反伤不再触发任何反伤或新的命中追加。
- **强化方向：**两次同器强化均只提高反伤伤害，不增加每动作或每战次数。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得；普通敌我双方可各持一件同类器物。

### FB12 蓄气珠

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**普攻额外积怒。
- **玩家短效果：**普攻完成后额外获得怒气，每次普攻一次。
- **输入标签：**普攻根动作｜动作完成。
- **输出标签：**怒气｜每个根动作一次。
- **触发粒度与次数：**每个完成的普攻根动作触发一次；普攻被特殊闪避仍算动作完成，但怒技、追击和附加段不另触发。
- **失效条件：**主动作被怒技替换、动作未开始或持有者在结算前死亡时不触发；额外怒气只供后续主动作。
- **强化方向：**两次同器强化均只提高额外怒气量，不让一次普攻多次发放或立即重开怒技。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得。

### FB13 归元佩

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**怒技省怒。
- **玩家短效果：**怒技所需怒气降低，最低仍支付 1 点怒气。
- **输入标签：**怒技门槛｜怒技支付。
- **输出标签：**怒气消耗修正｜同步门槛。
- **触发粒度与次数：**每次计算当前怒技时应用一次；门槛、自动施放条件与实际支付同步变化。
- **失效条件：**不能把支付降为零，不能用返怒抵销本次已支付怒气，不能让一次怒技连续开启下一次主动作；卸下后立即恢复原门槛。
- **强化方向：**两次同器强化均只提高省怒幅度，仍保留正下限，不新增回怒或额外动作。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得。

### FB14 雷纹印

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**怒技直接增伤。
- **玩家短效果：**怒技的基础直接伤害提高，附加伤害不重复放大。
- **输入标签：**怒技根动作｜基础直接伤害。
- **输出标签：**基础伤害修正｜一次预算。
- **触发粒度与次数：**每个怒技根动作应用一次；同一怒技的全部基础段共用一次增伤预算，追击和派生段不重算。
- **失效条件：**普攻、反伤、持续伤害和独立附加段不读取；直接攻击段若被特殊闪避则该段不造成伤害，但不退回已经锁定的怒气。
- **强化方向：**两次同器强化均只提高基础直接伤害修正，不增加段数或追加链。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得。

### FB15 回春瓶

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**治疗量提高。
- **玩家短效果：**由自身产生的每次治疗量提高，再按规则分有效治疗和溢出。
- **输入标签：**自身治疗事件｜根事件或法宝派生。
- **输出标签：**治疗量修正｜每个治疗事件一次。
- **触发粒度与次数：**每个 `treatment_event_id` 只提高一次；根治疗和合法的法宝派生治疗均可读取，同一来源链的本能力不重入。
- **失效条件：**不制造新的治疗事件；同一治疗事件不会因完成队列重放，战外治疗只处理允许的恢复，不派生护盾、毒或怒气。
- **强化方向：**两次同器强化均只提高治疗量，不把溢出同时算作有效治疗，也不增加治疗事件次数。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得。

### FB16 养气玉

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**气血上限提高。
- **玩家短效果：**装备时提高最大气血，不会因此免费回满当前气血。
- **输入标签：**装备｜最大气血。
- **输出标签：**最大气血｜持续。
- **触发粒度与次数：**装备或卸下时各结算一次属性变化；生效期间持续读取新上限。
- **失效条件：**只有移除、抵押、牺牲或明确停用时移除加成；换功法不卸载属性。当前气血只截到新上限，不补血、不转成护盾。
- **强化方向：**两次同器强化均只提高最大气血，不增加治疗、护盾或额外生命条。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得。

### FB17 青木簪

- **稀有度与归属：**普通；游戏原创器物，不对应原典名器。
- **快速选择：**有效治疗加盾。
- **玩家短效果：**战斗内每次治疗有真实有效恢复后获得一次护盾；全是溢出时不触发。
- **输入标签：**自身治疗事件｜实际有效恢复。
- **输出标签：**护盾｜每个治疗事件至多一次。
- **触发粒度与次数：**每个治疗事件分出有效部分后检查一次；有效部分大于零且战斗仍在继续才生成一次护盾，根治疗与合法法宝派生治疗均可读。
- **失效条件：**满血、只有溢出、战外治疗或治疗事件被替换时不加盾；所得护盾不是新的治疗事件，不会再次触发本法宝。
- **强化方向：**两次同器强化均只提高由有效治疗转出的护盾量，不增加触发次数或把溢出计入有效恢复。
- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得。

- **取得途径：**第一幕起；由投放册公共普通池或投放册列明的固定普通事件奖励取得。

### FB20 赤炎珠

- **快速选择：**燃烧伤害提高。
- **玩家短效果：**由自身施加的燃烧持续伤害提高，初始火焰直伤不变。

- **失效条件：**不提高附火时的基础直接伤害，不读取敌方施加的燃烧，不把持续伤害派生为新的燃烧或概率检定。

### FB23 蚀骨铃

- **失效条件：**跳过、死亡、重复完成同一节点或本幕已由本法宝结算过时不触发；战外治疗不造盾、不施毒、不返怒；第五幕天门雷劫按唯一真实战斗节点处理，敌人不获此行旅收益。
- **强化方向：**两次同器强化均只提高每幕这一次恢复量，不增加每幕次数或补发跳过节点收益。
- **取得途径：**第二幕起；由投放册公共珍稀池或投放册列明的固定普通事件奖励取得。

## 公共投放与重复取得

- `FB09-FB32` 从第一幕起进入投放册公共普通池；`FB33-FB40` 从第二幕起进入投放册公共珍稀池。具体商店、公共法宝位、有限精英和固定普通事件奖励由投放册列明，普通战不会默认每场掉宝。
- 固定普通事件若明示某个 `FB09-FB40`，该事件奖励字段覆盖池入口，但仍遵守幕次资格、库存、活着完成和确认时点；不凭空创建新的公共版本名器。
- 同一持有者同 ID 只生效一件；普通器物允许玩家与敌人各自持有同 ID，双方仍分别按本册效果结算。
- 重复候选在确认前公开转为该器的下一次强化或修为替代；强化已满时预告修为替代，不复制新件。已完成的来源事件不会因读档回到完成页而再次领奖。强化、唯一性和敌方装备规则见 [ARTIFACT_RULES.md](../rules/ARTIFACT_RULES.md)。
