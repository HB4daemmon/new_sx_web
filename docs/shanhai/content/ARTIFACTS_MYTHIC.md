## 传奇名器

### FB41 照妖镜

- **稀有度与来源：**传奇；`A01` 采用《西游记》的“照妖镜”。《封神演义》的“照妖鉴”只作异物辨析，不与本器合并。
- **快速选择：**普攻施破甲，怒技读旧破甲。
- **玩家短效果：**每次普攻的首个实际基础命中施破甲；每次怒技开始时，目标已有破甲则提高该怒技的基础直接伤害。
- **输入标签：**普攻根动作｜首个基础命中；怒技根动作｜动作开始｜旧破甲。
- **输出标签：**破甲；基础直接伤害修正｜每个合资格根动作一次。
- **触发粒度与次数：**普攻按基础段顺序只取首个实际命中段；怒技只在根动作开始读取动作前已有的破甲，新施加的破甲不追溯增强同一怒技。
- **失效条件：**全段特殊闪避、没有基础命中或目标没有动作前旧破甲时，对应部分不触发；追加段、持续伤害和反伤不重跑。
- **强化方向：**两次同器强化只提高破甲或基础伤害修正的幅度，不增加段数、动作或信息权限。
- **取得途径：**仅由 `R01 -> FB41` 的明示夺器条件完成后转移同一实体；重复 `R01` 不重抽。

### FB42 定海珠

- **稀有度与来源：**传奇；原典来源位为 [A02](./MYTH_ARTIFACT_SOURCES.md#A02)，本作效果是游戏改编。
- **快速选择：**回合末生盾。
- **玩家短效果：**战斗中每回合结束获得一次护盾；护盾遵守公共上限，不额外行动。
- **输入标签：**回合结束｜持有者存活｜战斗继续。
- **输出标签：**护盾｜每回合一次。
- **触发粒度与次数：**按公共回合末顺序，在持续伤害和死亡检查完成后结算；每个回合只生成一次，下一回合继续有效。
- **失效条件：**战斗外、持有者死亡、战斗已结束或本回合没有完成到回合末时不造盾；所得护盾不再触发本法宝。
- **强化方向：**两次同器强化只提高每回合护盾量，不增加回合次数、不改变护盾上限或主动作数。
- **取得途径：**仅由 `R02 -> FB42` 的明示夺器条件完成后转移同一实体；重复 `R02` 不重抽。

### FB43 阴阳镜

- **稀有度与来源：**传奇；原典来源位为 [A03](./MYTH_ARTIFACT_SOURCES.md#A03)，本作效果是游戏改编。
- **快速选择：**怒技择回血盾。
- **玩家短效果：**每次怒技完成时，当前气血未满则治疗，满血则获得护盾；同次只选一种。
- **输入标签：**怒技根动作｜完成｜根治疗后当前气血。
- **输出标签：**治疗或护盾（二选一）｜每个怒技一次。
- **触发粒度与次数：**先把该怒技已登记的根治疗完整结算一次，再以完成队列快照判断当前气血；缺血走治疗，满血走护盾。
- **失效条件：**怒技未开始、持有者在完成队列前死亡或战斗已停止时不触发；不把一项输出改成两项，也不由派生治疗再次开启本法宝。
- **强化方向：**两次同器强化只提高治疗量或护盾量，不增加每次怒技的选择数量或主动作。
- **取得途径：**仅由 `R03 -> FB43` 的明示夺器条件完成后转移同一实体；重复 `R03` 不重抽。

### FB44 番天印

- **稀有度与来源：**传奇；原典来源位为 [A04](./MYTH_ARTIFACT_SOURCES.md#A04)，本作效果是游戏改编。
- **快速选择：**高耗怒技重击。
- **玩家短效果：**每次怒技的基础直接伤害提高；同时提高该怒技门槛和实际支付，门槛与支付同步且不超过怒气上限。
- **输入标签：**怒技门槛｜怒技支付｜基础直接伤害预算。
- **输出标签：**基础直接伤害修正｜每个怒技一次。
- **触发粒度与次数：**按当前怒技和已有功法/天赋修正先算原门槛，再同步抬高门槛与支付；最高门槛截在怒气上限，实际支付不得超过上限。达到该最高合法门槛并支付对应怒气时，增伤仍作用于本根动作的全部基础段。
- **失效条件：**当前怒气不足提高后的门槛时不施放怒技，不透支、不把普攻改成强制怒技；附加段、反伤和派生段不重复增伤。
- **强化方向：**两次同器强化只提高怒技基础伤害或抬耗的既有幅度，不突破怒气上限，不改写既有功法天赋。
- **取得途径：**固定为 `R04 -> FB44`；`R04` 可在确认页选择“珍稀旧器加灵石的永久交换”或“守器者战斗胜利并完成明示转移条件”两种互斥取得路径，任一完成即转移同一实体，不追加隐藏检定。

### FB45 金蛟剪

- **稀有度与来源：**传奇；原典来源位为 [A05](./MYTH_ARTIFACT_SOURCES.md#A05)，本作效果是游戏改编。
- **快速选择：**普攻双重追加。
- **玩家短效果：**每次普攻首个基础命中后追加两段伤害；追加段不再触发同类追加。
- **输入标签：**普攻根动作｜首个基础命中。
- **输出标签：**附加伤害｜每个普攻一次。
- **触发粒度与次数：**按基础段顺序寻找一次首个实际命中，随后在同一根动作内结算两段追加伤害；两段共享父动作，不生成第二个主动作。
- **失效条件：**全段特殊闪避、没有基础命中、根动作已因死亡停机或只发生持续伤害/反伤时不追加；追加段不再读 `FB45` 或同类追加。
- **强化方向：**两次同器强化只提高两段追加的伤害预算，不增加追加段数、概率或动作。
- **取得途径：**仅由 `R05 -> FB45` 的明示夺器条件完成后转移同一实体；重复 `R05` 不重抽。

### FB46 混元金斗

- **稀有度与来源：**传奇；原典来源位为 [A06](./MYTH_ARTIFACT_SOURCES.md#A06)，本作效果是游戏改编。
- **快速选择：**怒技施弱回怒。
- **玩家短效果：**每次怒技首个基础命中后施加虚弱并返怒一次；返怒只供后续主动作。
- **输入标签：**怒技根动作｜首个基础命中。
- **输出标签：**虚弱；怒气｜每个怒技一次。
- **触发粒度与次数：**按基础段顺序取首个实际命中段；在该段后施弱并登记一次返怒，多段怒技不重复。
- **失效条件：**全段特殊闪避、没有基础命中、根动作已停机或派生/持续伤害命中时不触发；返怒不在当前根动作内重开主动作。
- **强化方向：**两次同器强化只提高虚弱幅度/时长或返怒量，不增加每怒技次数、不生成额外攻击。
- **取得途径：**仅由 `R06 -> FB46` 的明示夺器条件完成后转移同一实体；重复 `R06` 不重抽。

### FB47 九龙神火罩

- **稀有度与来源：**传奇；原典来源位为 [A07](./MYTH_ARTIFACT_SOURCES.md#A07)，本作效果是游戏改编。
- **快速选择：**普攻施火，火伤生盾。
- **玩家短效果：**每次普攻首个基础命中施加燃烧；自身施加的燃烧造成实际伤害后获得护盾，每回合最多一次。
- **输入标签：**普攻根动作｜首个基础命中；自身燃烧 tick｜实际伤害。
- **输出标签：**燃烧｜每次普攻一次；护盾｜每回合一次。
- **触发粒度与次数：**普攻只按首个实际基础命中施火；由本持有者施加的燃烧在持续结算后若扣除目标气血，按回合首次资格加盾，追加 DOT 仍沿父链结算。
- **失效条件：**全段特殊闪避、没有基础命中、燃烧被护盾完全吸收、战斗已停止或本回合已加盾时不触发；加盾不再施火或开启主动作。
- **强化方向：**两次同器强化只提高燃烧或每回合护盾量，不增加普攻附火次数、回合次数或动作。
- **取得途径：**仅由 `R07 -> FB47` 的明示夺器条件完成后转移同一实体；重复 `R07` 不重抽。

### FB48 五火七禽扇

- **稀有度与来源：**传奇；原典来源位为 [A08](./MYTH_ARTIFACT_SOURCES.md#A08)，本作效果是游戏改编。
- **快速选择：**怒技催火。
- **玩家短效果：**每次怒技首个基础命中施加燃烧；该动作末额外结算一次目标现存的己方燃烧，不额外消耗层数或时长，每个怒技一次。
- **输入标签：**怒技根动作｜首个基础命中｜动作末己方燃烧。
- **输出标签：**燃烧｜每个怒技一次施加与一次额外结算。
- **触发粒度与次数：**首个实际基础命中成功施火后，在同一怒技动作末读取该目标当时仍存在的本方燃烧并额外结算一次；额外 DOT 沿父动作，不重新施火、不再次触发 `FB48`。
- **失效条件：**全段特殊闪避、没有基础命中、目标已死亡、战斗已停止或没有本方现存燃烧时不产生额外结算；额外结算不减少燃烧层数或时长。
- **强化方向：**两次同器强化只提高施火或额外结算的既有效果，不增加每怒技次数、不消费旧火、不生成新动作。
- **取得途径：**仅由 `R08 -> FB48` 的明示夺器条件完成后转移同一实体；重复 `R08` 不重抽。

## 名器实体与取得边界

- `R01 -> FB41`、`R02 -> FB42`、`R03 -> FB43`、`R04 -> FB44`、`R05 -> FB45`、`R06 -> FB46`、`R07 -> FB47`、`R08 -> FB48` 是固定一一对应。每件名器是本局一个原典名器实体，守器者持有时与玩家卡面共用同一效果。
- `FB01-FB08` 也按原有卡面作为各自唯一实体；`FB09-FB40` 则是公共器物，同一 `item_id` 对每个持有者各自唯一，不把公共同名制品误写成全局唯一原器。
- 战前完整敌情、装备、先手、关键压力和胜利奖励对所有玩家公开，不要求付费、持有照妖镜或解锁独占技能；`FB41` 不垄断敌情预览。
- 已持有名器、已完成或已发出的对应 `R` 事件均从机会池排除；读档回到已经完成的事件页只读取已结算状态，不重复领奖、不再抽同名器。
- 一般战斗胜利不自动剥离敌人全套装备；只有对应 `R` 事件明确写出的转移或 `R04` 的合法交换/战斗条件完成时，才把同一实体写入玩家构筑。名器重复候选只能预告该实体强化或公开回退，不复制新器。
