# 山海版求法与寻宝机缘目录

状态：扩展设计草案，未实现；价格、气血扣除、修为数量、倍率、概率、状态时长和
非致命败北线均待测。本页只定义 13 个机缘的卡面形式、跨模块接口和结算边界，
不把待测数值写成已经平衡。

## 读法与共通契约

- 导航： [全量计划](../FULL_CONTENT_PLAN.md) · [核心事件](../CORE_EVENTS.md) ·
  [事件规则](../rules/EVENT_RULES.md) · [战斗规则](../COMBAT_RULES.md) ·
  [功法树](../CULTIVATION_TREES.md) · [公共法宝](./ARTIFACTS_COMMON.md) ·
  [传奇名器](./ARTIFACTS_MYTHIC.md) · [敌人共用定义](../ENEMIES.md) ·
  [投放册](../CONTENT_DISTRIBUTION.md)。
- 玩家卡面只写短场景、直接选项和眼前得失；`EN/KF/FB`、节点 ID、状态字段和
  完整构筑只出现在每条的“开发合同”中。数值未测时写“公开小额”或“待测”。
- L 事件成功结果写入 `stored_method`，不是立即换法。只有 `SW2`、`SW3`、`SW4`
  明确提供的换法机会才能启用；启用不回血、不洗点、不创建第二门主修。
- `L01 -> KF06`、`L02 -> KF07`、`L03 -> KF08`、`L04 -> KF09`、`L05 -> KF10`。
  目标法本已持有或已暂存时，ID 在发牌前排除，不生成第二本。
- L04/L05 从第三幕起在 `A3.5` 或第四幕 `A4.3` 合资格；一局最多发其中一条。
  发牌确认前写入 `legendary_l_drawn=true`，所以拒绝、失败、离开都消费名额；
  但已经发出的那一条不能因该字段变为真而把自己的选项隐藏。成功暂存后再写入
  `legendary_method_claimed=true`，另一条从本局池移除。
- 生死战入场只要求当前气血 `>0`，不凭空设置安全阈值；降至 0 立即结束本局。
  非致命战在确认前显示正气血败北线，到线立刻结束并保留正气血。事件直接扣血
  必须明示并保证结算后仍 `>0`，不足时不显示该选项。战斗间不免费回血。
- 单事件内的多战、分段战和停止点仍只占一个节点，不重复结算行旅收益；临时怒气、
  护盾、状态在战末按共同规则清理。R 事件不按玩家主修、法宝或火/盾标签硬锁。
- `FB41-FB48` 是各自唯一实体。名器、法本、价格和奖励均不凭空复制；没有合法
  奖励的候选在发牌前换成合资格 ID 或精英 fallback，不发空卡。
- 已完成事件重入只显示已记录结果，不再次给奖励，也不把失败/离开静默改成强化；
  源页回放只读展示结果。重复 ID、同器满强化和已取得法本都在确认前处理。

## L01《五毒入脉》

**玩家短场景：** 腐木后的黑池吐出五色雾，池底的经页被毒丝缠住。你可以冒险
封住毒池，也可以付出一口气血把经页引到手边。

| 选项 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `封池取经` | 参加高风险的非致命试炼；受伤带出。 | 胜利后暂存五毒经；失败不发法本。 |
| `以血引页` | 支付公开小额灵石，承受一次明示的 `<待测>` 气血扣除；不战斗。 | 暂存五毒经，以当前气血继续前行。 |
| `退毒留身` | 不付资源、不战斗，放弃这次求法。 | 保留当前主修和法宝，黑池关闭。 |

**开发合同：**

- `封池取经`读取 `EN06` 的非致命构筑；正气血败北线、敌方装备、先手和中毒压力
  在确认前展示。它是本条的高风险求法，败北只结束该段，不进入隐藏第二战。
- `以血引页`为事件直接扣血，扣除不受特殊闪避影响，结算后必须仍有气血；灵石
  或气血不足时隐藏。两条成功路径都只写入 `stored_method=KF06`，不回血、不立即换法。
- `KF06` 已持有/暂存时不发 `L01`；回用只能在发牌前改成战前预览的当前主修强化、
  合法旧宝强化或公开小额修为，不能暗发第二本。

## L02《断崖雷井》

**玩家短场景：** 断崖雷井把石阶劈成两半，外井的雷光还在回窜。先封住外井，
才看得见井底的经页。

| 选项 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `封外井` | 参加第一段非致命试炼；伤势保留。 | 第一胜结算一笔公开小额修为，然后可以收手或继续封内井。 |
| `退下断崖` | 不战斗、不付资源，放弃雷井法本。 | 保留当前构筑离开，雷井不回访。 |

**第一胜后的直接选择：**

| 选项 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `收手离井` | 保留已经结算的公开小额修为，不再冒险。 | 事件完成，不取得奔雷诀。 |
| `再封内井` | 不回血，参加第二段非致命试炼。 | 第二胜后暂存奔雷诀；失败只保留第一胜已得的修为。 |

**开发合同：**

- `封外井`和`再封内井`都是同一 `L02` 节点内的两段 `EN08` 非致命战斗档；每段
  的敌情、先手、装备和正气血败北线在进入前分别展示。第一胜收手是合法完成路径，
  不是额外节点。
- 第一胜修为只发一次；第二胜只新增 `stored_method=KF07`，不再发一份修为或行旅收益。
  任一段到败北线立即结束，事件不自动补气。
- `KF07` 已持有/暂存时不发 `L02`；重复回用只允许预览中的当前主修强化、旧宝强化
  或公开小额修为。

## L03《无月长阶》

**玩家短场景：** 无月长阶的影子逆着脚步延伸，阶顶的黑水照出两条路：取走一门
新法，或把眼前这门法推得更深。

| 选项 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `照影取经` | 参加非致命试炼；受伤带出。 | 胜利后暂存太阴经。 |
| `借阶磨法` | 放弃本次太阴经机会，选择当前主修的具体怒技，确认一项公开强化。 | 强化只作用于当前主修，不换法、不回血。 |
| `熄月回头` | 不战斗、不付资源，放弃长阶。 | 保留现有构筑离开。 |

**开发合同：**

- `照影取经`读取 `EN13` 非致命构筑，战前公开先手施弱、装备和正气血败北线；
  胜利写入 `stored_method=KF08`，失败不发法本。
- `借阶磨法`必须在确认前显示当前 `method_id` 的具体怒技名称、前后效果和唯一
  机会成本；确认即关闭本次 `KF08` 取得，不生成暂存法本。没有合法强化候选时不
  显示此项，不用空奖励占位。
- `KF08` 已持有/暂存时不发 `L03`；重复回用只能采用战前明确的当前主修/旧宝强化
  或公开小额修为。

## L04《扶桑倒潮》

**玩家短场景：** 扶桑海潮倒悬，赤海卷上天穹，日光正滑入巨木。你可以献出一件
珍稀旧宝换取经火，也可以冒险把日光扶回去。

| 选项 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `献宝换经` | 选一件已经拥有的珍稀旧宝并支付公开小额灵石；旧宝永久离开。 | 不战斗，暂存金乌真经。 |
| `扶日求经` | 参加一场强敌生死战；气血归零即本局结束。 | 胜利后暂存金乌真经。 |
| `放回潮光` | 不战斗、不付资源，放弃本次传奇求法。 | 传奇名额已消费，继续赶路。 |

**开发合同：**

- `L04` 从第三幕 `A3.5` 或第四幕 `A4.3` 可见；页面发出时先写
  `legendary_l_drawn=true`，再渲染本条选项。该字段为真不禁用本条自己的三个
  选项；只有成功暂存后才写 `legendary_method_claimed=true`。
- `献宝换经`的输入严格限于玩家当前拥有、未暂押、未停用的 `FB33-FB40`；不能献
  暂押物、不能以不足灵石进入确认、旧宝移除后不能回收。灵石价格待测，成功后把
  唯一的 `KF09` 写入 `stored_method`，不复制或立即启用。
- `扶日求经`读取 `EL09` 强敌生死战，完整敌情、装备、先手和胜利结果在确认前展示；
  只需当前气血 `>0` 才可入场，不设额外安全阈值。失败归零结束本局且不发法本。
- L05 在本局发出时从机会池移除；`KF09` 已持有/暂存或另一传奇法本已成功时不发
  `L04`。重复回用不能把失败或离开静默替换为强化。

## L05《烛龙垂天》

**玩家短场景：** 烛龙睁眼，山谷骤亮；闭眼，河流沉进黑水。你只能在战前决定
迎接一场偏防的对手，还是一场偏爆发的对手。

| 选项 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `守势求经` | 选择偏防的真实对手配置，参加一场生死战。 | 胜利后暂存烛龙真经；失败归零即本局结束。 |
| `爆发求经` | 选择偏爆发的真实对手配置，参加一场生死战。 | 胜利后暂存烛龙真经；失败归零即本局结束。 |
| `闭眼离天` | 不战斗、不付资源，放弃本次传奇求法。 | 传奇名额已消费，保留现有构筑。 |

**开发合同：**

- `L05` 与 `L04` 相同，从第三幕 `A3.5` 或第四幕 `A4.3` 可见；发牌先消费
  `legendary_l_drawn`，但不因该字段为真隐藏本条选项。成功暂存后写入
  `legendary_method_claimed=true`，并移除本局另一传奇 ID。
- 两个战前选择都读取 `EN20/KF07` 的真实敌人接口，并切换下列公开预设，而不是
  只改场景文案：

  | 预设 | 实际配置 |
  | --- | --- |
  | `守势求经` | 防御优先属性档，公共装备 `FB38`、`FB39`；具体数值和先手待测 |
  | `爆发求经` | 爆发优先属性档，公共装备 `FB14`、`FB39`；具体数值和先手待测 |

  两套预设的属性档、装备、先手、关键压力和胜利结果必须在确认前完整展示；
  不读取玩家流派，不临时关闭 `FB40` 或其它行旅效果。
- 生死战只以气血归零结束本局；没有安全阈值、非战斗取经或法宝停用换经路径。
  `KF10` 已持有/暂存或另一传奇法本已成功时不发 `L05`。
