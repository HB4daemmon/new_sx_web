# 山海版普通事件目录

状态：扩展设计草案，未实现；价格、概率、伤害倍率、治疗量、修为/灵石数量和
非致命败北线仍待首测。本页只维护 `E101-E124`，不改写 `E01-E08`。

## 技术共通边界

- 投放位置固定为：第一幕 `A1.5` 的 `E101-E106`，第二幕 `A2.4` 的
  `E107-E112`，第三幕 `A3.6`（普通事件态）的 `E113-E118`，第四幕
  `A4.2` 或 `A4.5`（未被 E04 终火台替换）的 `E119-E124`。事件不增加节点。
- 抽牌前按当前状态过滤选项：至少要有两项可执行，且用途不同；否则该 ID 不进
  本局该位置的候选。池为空或全部事件被过滤时使用 `通用整备`，二选一且不付
  资源：`静心记功`获得公开小额修为，或`清点行装`获得公开小额灵石。兜底不
  生成法宝、不自动胜利、不创建新节点。
- `ENxx`、`ELxx` 只引用 [敌人目录](../ENEMIES.md) 的完整功法、天赋、法宝和
  阶段规则；本页只写稳定压力。战前显示完整构筑、先手、战斗类型、胜利奖励和
  边界，不在事件卡自造敌方输入。第一至四幕的普通敌人分别使用 `EN01-05`、
  `EN06-10`、`EN11-15`、`EN16-20`；精英按敌人目录的允许幕次过滤。
- 非致命战须高于战前展示的正气血败北线，触线即停在正气血并保留实际损耗；
  生死战只要求当前气血 `>0`，不另加安全门槛，归零立即结束本局。直接扣气血
  的事件费用必须让结算后气血仍 `>0`。没有免费回血、失败转胜或失败后补发。
- `FB09-FB32` 第一幕起合资格，`FB33-FB40` 第二幕起合资格；普通法宝不按功法
  硬锁。`FB01-FB08`、`KF09-KF10`、`FB41-FB48` 不由普通事件生成。
- 同一公共法宝的候选在确认前显示版本：未持有为 `v0`，已有 `v0/v1` 时为下一
  次强化，`v2` 时改为明确的公开小额修为；不复制同名器，不把满级强化写成空
  选项。强化只提高原效果，不增加第二门功法或第二个主动作。
- 换法不会使已持有法宝属性无故失效；只有卸下、永久献出或暂押才停用。暂押时
  法宝的战斗、属性、行旅效果全部停用，按原版本在指定节点归还，不追补停用
  期间收益。永久献出只接受 `FB09-FB40` 公共器物，不接受人物法宝或唯一名器。
- 延后事实只落到确定节点：`A1.5 -> A1.7`，`A2.4 -> A2.7`，
  `A3.6 -> A3.7`，`A4.2/A4.5 -> A4.6`。满血不把治疗换成其它资源；延后
  事实兑现一次后清除，路径不经过该节点则不提前或凭空兑现。
- 触发文案遵循法宝整合裁决：`FB11` 每个敌方主动作最多一次，不另设整场两次
  后停机；`FB34-FB37` 和 `FB39` 每回合最多一次，不另设整场两次后停机，且
  必须读取真实伤害、溢出治疗或概率失败；`FB33`
  是每战一次的概率闪避机会，不保证成功，失败也消耗机会；`FB40` 在持有生效
  期间每幕首次活着完成的战斗节点触发一次，不追溯已完成节点。`FB20` 只提高
  已存在的燃烧伤害，不负责施火。
- 表中“取得”均为胜利或确认后的真实结算点；失败关闭未开始的后续奖励。事件
  内多场战仍只算一个节点，事件新取得的行旅效果不追溯本节点。

## 统一验收口径

- 24 个 ID 各出现一次，分组严格为 `E101-E106`、`E107-E112`、`E113-E118`、
  `E119-E124`；本页不引用未抽中角色、`FB01-FB08` 或传奇法宝/功法。
- 每项战斗奖励都在胜利后结算；非致命失败停在正气血，生死失败结束本局；
  每项直接扣血均保留正气血。事件不售卖默认可见的完整敌情。
- 延后和暂押只能读取四个真实节点；暂押恢复原版本且无补偿，永久献出只针对
  公共器物。公共法宝不会因换法消失。
- 通过抽牌前双选过滤和 `通用整备`，不生成只有一个空选项的事件，也不以免费
  新法宝、自动胜利或隐藏安全门槛填充空池。
