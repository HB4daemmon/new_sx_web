## 2. 五幕真实节点布局

### 2.1 计数口径

1. 一行只代表一个可以进入、确认、结算一次的真实地图节点。路牌、选路页、敌情预览、领奖点击、事件内部的停止点都不是额外节点。
2. `E03` 的两场非致命试阵是一个 `E03` 事件节点；第一胜收手和两胜取宝不拆行。
3. `E07` 的两场生死追逐是一个 `E07` 事件节点；第一胜后的收手/继续不拆行。
4. `E04` 第二幕守炉和第四幕终火台是同一事件的两个真实地图节点；终火台替换第四幕普通事件位，不加节点。
5. `E01` 第二幕药棚入口、`E02` 第三幕海堤入口即使没有对应预约，也仍是共同路线上的真实节点。
   预约回血先兑现，然后在同一个入口节点提供固定的“小额灵石 / 小额修为”二选一物资整备；
   没有预约时仍有这项二选一，不得把入口压缩成点“继续”或只刷行旅。
6. 第五幕只有 `BS05` 一战。所有路径在去重后为 31、32 或 33 个真实节点。

### 3.2 有限产出、强化和满强化回退

1. 产出上限是每个节点、商店库存、事件事实和机缘抽取次数的上限，不是跨玩家的全局件数上限；
   普通节点不会每场免费掉法宝。
2. 同一 `item_id` 使用版本 `v0 -> v1 -> v2`，最多强化两次。强化只提高原有效果，不增加第二门功法、第二个主动作或第二条隐藏行动链。
3. 候选确认前展示原版和强化后版本。已持有且 `version < v2` 的候选显示同器强化，不暗发第二件；已持有且 `version = v2` 的候选显示本来源预先预算的修为回退。
4. `FB01-FB08` 的人物候选也遵守同器强化和公开回退；公共版不能因缺少人物资格而把空候选替换成名器。
5. 十六件原典名器（`FB01-FB08`、`FB41-FB48`）是本局唯一实体。对应 `R` 已被完成或明确消费后，
   不再生成同名器；若本局已持有该器，`R` 事件在抽取前排除，不用“重复强化”伪造第二个守器者。
6. 已到强化上限的回退不会打开新节点、补发未拿到的奖励或刷新商店，只在当前来源结算一次。

### 3.3 敌方装备和胜利奖励必须分离

每场战前展示两个不同字段：

```text
enemy_loadout.item_id    = 敌人本场实际装备，共用 FB 规则计算
victory_reward            = 本场胜利后明确授予的奖励，可能为空、修为、灵石、强化或指定法宝
```

- 敌人有真实 `KF01-KF10` 主修、已解锁层的 A/B/C 天赋、目录内 `FB` 装备 ID、开战状态和公开行为；不得只写“毒系”“反伤装”标签。
- 敌人装备共用玩家法宝效果，但装备存在不等于战后掉落；普通战、精英战和首领战都只按 `victory_reward` 结算。
- `R01-R08` 的守器者可以真实装备对应 `FB41-FB48`。完成该 R 明示的胜利条件，或 R04 的合法交换后，才把同一实体转为玩家 `owned_items`，不创建副本。
- 如果玩家已经持有 `FB01-FB08` 或 `FB41-FB48` 中某件原典名器，任何会生成同名器持有敌人的模板在抽取前剔除；
  不得先生成再偷偷改名。若该 R 事件已完成，整个 `R` ID 从本局无放回池移除。
- `FB01-FB08` 的人物资格仍由事件事实控制；普通敌人不能因为拥有一个同名或相近效果的公共器物而授予人物奖励。

普通战、精英战和幕首领都必须在战前展示 `victory_reward` 的类型和候选数；敌方装备

### 3.5 机缘形式与名器启动

真实抽取规则：

1. 每个槽位同时预览一个当时合资格且未曾展示的随机 `L/R`，以及一个该幕合资格的 `EL`；

3. `O2/O3/O4` 的随机权重只用于生成“机缘预览”这一项，精英是同步可见的替代路线，
   不是池空才出现的兜底。权重是首轮抽样目标，不是平衡结论或内容数量上限。
4. 非传奇求法保底按“是否已经展示过 `L01-L03`”判断，而不是按玩家是否选择、胜利或成功取得判断；

5. 单局最多展示三个机缘 ID、最多完成三个 `O` 节点；剩余 13 条机缘内容通过不同局覆盖。

   不发免费修为、不制造空卡；正常合资格状态下必须同时有机缘预览和精英预览。

### 4.3 经阁、商店和换法边界

- `E06` 经阁不是 `L/R` 抽取槽，也不是商店。它可以给出本幕合资格、尚未拥有且未暂存的
  `KF01-KF08` 法本候选；不要求先成功完成对应 `L`，也不因先持有其它法本就把合法池清空。
 传奇 `KF09-KF10` 永不由 E06 或商店越级取得。若没有合法新法本，回退为卡面预告的当前主修
 怒技强化或修为。
- 每个商店节点固定生成五格库存：三格公共法宝/同器强化候选、一格固定小额回血物资、
  一格固定的修为或属性整备候选；候选类型和价格在打开时明示。商店不卖 `KF`、`L/R`、
  人物门控法宝、传奇名器或第五幕权益。第一幕只可出现 `FB09-FB32`，第二幕起可出现
  `FB33-FB40`；购买后该格售罄，不刷新、不补格、不跨节点携带库存。
- 有限换法位只有 `SW2=A2.7`、`SW3=A3.7`、`SW4=A4.6`。每个位置最多确认一次功法切换；战斗中、E05 战斗之间、E08 确认后和第五幕都不能换法。
- 换法确认前必须并列预览旧法和新法的原始普攻、怒技、行旅、已选天赋、最大气血变化、当前气血截断结果和支付。预览不扣费、不改状态；确认后才支付灵石并写入 `current_method_id`。
- 换法支付只从当前灵石扣除；没有足额灵石时确认按钮不可用，不借贷、不从未拥有资源扣费。
  费用档位仅作首测目标，最终数值待测试；`SW3/SW4` 是 `L04/L05` 成功后的合法启用位置。
- 每门功法分别保存自己的 A/B/C 选择和独立永久收益。首次启用新法时只补选已经到达的境界层；切回旧法恢复原选择，不免费洗点。换法不治疗、不继承怒气/护盾/状态、不追补之前节点行旅收益。
