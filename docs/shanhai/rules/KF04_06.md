## 共同补充

- 五项基础属性为攻击、防御、最大气血、暴击率和速度；各卡面原有属性读取保持不变，速度只按公共规则决定每轮先后，不直接改写伤害、怒气、护盾、治疗、施毒或附效次数。灵石、怒气、修为是通用资源，剑势是 KF05 唯一专属层数。
- 卡面中的耗火、耗势、耗毒均在当前动作自动判断，无战中点击；条件不足时不扣资源，基础动作仍完成。
- 护盾是额外承伤量，不是按防御减伤；后层只读取同次动作已经锁定的状态或资源，不要求未选前层。
- 同一动作先锁定输入，再统一消费同一份资源；后层升级前层结果，不二次扣除、不把追加段递归成主动作。

## KF04 御火诀

- 普攻顺序：火焰伤害 → 命中附燃烧 → J1-B/J3-C获得护盾 → 基础怒气；J3-A只延长新施加层的寿命，不刷新旧层。
- 怒技顺序：扣怒 → 火焰直接伤害 → 命中后判断已有燃烧 → J2-B/J3-B/J4-B共同耗一层 → 结算火伤、回怒和破甲；该直接攻击段被特殊闪避时，不判定耗火。
- J2-A读取回合内首次燃烧伤害事件；若燃烧已被怒技耗掉，则该回合没有该事件，回怒只供后续动作。
- 同时选 J2-B、J3-B、J4-B时只扣一层燃烧，三者的火伤、回怒、破甲收益同次保留；没有 J2-B 也不妨碍 J3-B/J4-B自动耗火。
- J3-C可独立在普攻后造盾；与 J1-B同选时合为一次更强的造盾，不追踪护盾来源或要求已有余盾。J4-C读取敌人当前燃烧降低直接伤害，护盾仍按承伤量独立结算。

## KF05 养剑诀

- 剑势每层提高攻击并受上限约束，战斗结束清空；普攻命中先获得剑势并独立判追剑，怒技基础不耗势。
- 普攻追加顺序：追剑判定 → J4-C在成功时追加第二击且不重判 → J3-C在本次普攻至多回一次怒气 → 基础怒气。
- 怒技顺序：扣怒 → 剑伤 → 按最高耗势档位自动消费 → 结算追剑、破甲或多段；消费后按剩余剑势读取增攻。
- 同时选耗势天赋时，J4-B全耗优先，其次 J3-B全耗，否则 J2-B耗一层；低层已选收益随同次保留，J4-B不要求选 J3-B。
- J4-C只把一次成功追剑变成两段伤害，不提高概率、不再判定、不连锁下一次追剑。

## KF06 五毒经

- 中毒是持续伤害状态；J2-A只延长新施加层寿命，不刷新旧层。J1-C的最大气血只在主修时生效，换法即卸下。
- 普攻顺序：初始毒伤 → 按命中前已有中毒判 J2-B → 叠加新中毒 → 基础怒气；新叠中毒不参加本次耗毒。
- 怒技顺序：扣怒 → 单体伤害并锁定命中前已有中毒 → 命中后 J3-B按锁定状态附破甲 → J2-C/J3-C/J4-C共同决定耗毒；该直接攻击段被特殊闪避时，不附破甲、不判定耗毒。
- 同次耗毒只扣一次；J2-C回血、J3-C护盾和 J4-C爆发读取同一批锁定毒层，J4-C明确耗尽全部，并失去对应持续。
- J4-B读取每回合首次中毒伤害事件；若毒层先被耗尽则不产生该事件，回血和护盾不按耗毒层数重复结算。

## 行旅与换法

- KF04绑定战斗节点完成并存活，战后结算多枚灵石；KF05完成两个绑定节点后准备下一战首个普攻一次；KF06毒瘴先减气血代价，存活完成后结算修为。
- 绑定前完成、切法追领、退出重进和重复完成都不补发；换法不重置节点计数，也不保留怒气、护盾、燃烧、中毒或临时增益。
