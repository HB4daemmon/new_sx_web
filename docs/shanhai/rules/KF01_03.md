- 公共规则见[公共战斗规则](../COMBAT_RULES.md)；主卡见[功法树主卡](../CULTIVATION_TREES_01_03.md)。

## 属性与公共边界

| 功法 | 读取对象 | 属性来源 |
|---|---|---|
| KF01 | 伤害、反伤、护盾、防御 | 伤害和反伤读攻击，护盾及上限读最大气血，持盾防御读防御。 |
| KF02 | 普攻、怒技、追加、怒气 | 伤害读攻击，积怒/返怒/门槛读怒气；追加仍属当前动作。 |
| KF03 | 伤害、治疗、溢出、中毒、护盾 | 伤害和治疗读攻击，血量条件读当前/最大气血，中毒读通用状态。 |

- 法宝不限持有件数且均生效；本页只使用攻击、防御、最大气血、暴击率，以及灵石、怒气、修为。
- 具体系数、概率、持续时间和上限待测；不把相对强化写成固定数字。

## 结算顺序

1. 装备功法时应用持续属性加成；行动前应用当前伤害、概率与怒耗修正，再结算基础动作和对应触发。同一事件可被不同追加节点观察一次，不把属性、门槛修正延后到动作结束。
2. KF01 普攻先造成伤害再得盾；怒技先付怒，再结算基础伤害和自动耗盾。敌方攻击的实际耗盾、主动耗盾和完全击破是三种事件。
3. KF01 每次有盾的怒技主动消耗部分护盾，比例与额度待测，通常保留余盾；仅 J4-B 将这次代价改为消耗全部护盾。J3-B、J3-C、J4-B共读同一次主动耗盾，不重复扣盾；J1-B、J2-B共读同一次敌伤耗盾，每次敌方行动只反伤一次。
4. KF02 以当前门槛为准自动放怒技；J2-B提高门槛并同步提高本次消耗，J3-A同步降低当前门槛与消耗，包含蓄怒门槛。J4-B先扣当前门槛，再消费本次真实余怒放大伤害。
5. KF02 的返怒只供后续行动；J2-C在怒技后执行一次强制强化普攻，完成后恢复当前门槛判断；J3-C的追加一击不另起完整行动，基础积怒只算一次；两者同选时追加并入该强化普攻。
6. KF03 治疗先产生一个真实治疗事件，再分有效治疗与溢出治疗；有效部分恢复气血，溢出默认直伤，J1-B把溢出直伤替换为通用中毒，J2-B放大当前的直伤或毒伤。
7. KF03 即使治疗全部溢出，仍有真实治疗事件；J3-A需其中有实际恢复气血，每次行动返怒一次，J3-B按怒技治疗施毒，J4-B按本门治疗施毒，后二者可从同一事件各自追加且不吞掉已有毒层；J4-C在怒技治疗后加盾，治疗不被替换。

## 状态、行旅与生命周期

- 战斗临时只保留怒气、护盾、中毒、强制普攻及卡面写明的增益；战斗结束按公共规则清除，不新增本门专属资源或状态。
- KF01-J4-A每战只认首次被敌人完全击破护盾；KF03-J1-C的最大气血在装备主修时生效，换法后移除，不等到首次行动后才加成。
- 金刚休整完成给修为并准备下一战护盾；归元非战斗节点完成给修为；回春每个节点完成回血、药地另给修为。
- 行旅绑定、换法冻结、节点只结算一次和下一战效果边界遵循[公共战斗规则](../COMBAT_RULES.md)。

## 跨层走读与反例

每门四层各有 `3^4=81` 种选择；逐组检查后，每个 ID 都只依赖上表的基础事件、当前通用状态或自身提供的输入，没有未选前层卡的硬前置。

- KF01 走读：`J1-B → J2-A → J3-C → J4-B`。普攻得盾，J2-A只提高上限；怒技按J4-B消耗全部护盾，J3-C从同一次耗盾返怒。反例：不能把J3-C和J4-B各扣一遍，也不能要求先选J1-B才允许J2-A。
- KF02 走读：`J1-C → J2-C → J3-A → J4-B`。怒技后先做一次强化普攻，J3-A降低当前门槛，J4-B扣门槛后消费真实余怒。反例：J3-A不要求J2-B；强制普攻完成后不能递归强制或用返怒重开本次怒技。
- KF03 走读：`J1-A → J2-B → J3-B → J4-C`。治疗提高，溢出仍直伤且由J2-B放大；怒技治疗触发J3-B施毒，J4-C再加盾。反例：J4-C不要求任何毒节点，J3-B不要求溢出，同一治疗不能重复计算为两份溢出。
