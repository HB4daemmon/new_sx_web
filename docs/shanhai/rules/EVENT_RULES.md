# 山海事件规则

日期：2026-09-19

状态：设计提案的实现与验收口径，未实现；公共自动斗法见 [../COMBAT_RULES.md](../COMBAT_RULES.md)。

## 1. 卡面职责

卡面必须让玩家看见场景、当前战斗是否生死、会失去什么、奖励何时结算和下一次在哪里回访。

| 字段 | 要求 |
| --- | --- |
| `event_id` / `title` | 只用 E01-E08 与固定中文标题 |
| `stage` | 每事件 2 或 3 个有名阶段，阶段结束才展示下一段 |
| `actions` | 2-3 个动词选项，写当下结果与代价 |
| `battle_label` | 明示“生死战”或“预告非致命切磋/验证” |
| `stop_point` | 写出战前拒绝、战后收手或安全回头的位置 |
| `revisit` | 指向一个具体事件、幕间地点或终局回响 |
| `reward_binding` | 指向当前主修、修为、已有法宝或公开法本 |

未胜前的战斗所得一律写“胜利后”；确认前不扣灵石、不交旧器。事件正文不把系统原则藏在抽象词里。

## 2. 初遇与抽取

- 每局首次打开事件卡前，系统先让主角从普通法本中选定并学会一门可战斗主修；法本不因拒绝某项或未抽中人物而消失。
- E01、E02是公共入门地点，E06和公共修行节点也能提供同档主修、修为或整备；角色不是唯一入口。
- 后续事件拿到的法本可换修或暂存，同一时刻只有当前主修生效；事件不要求某个角色在场才能开战。
- 每局从闻岫、鲛绫、夔野、灼九、陆照中抽取两到三条长线，E01、E02、E06、E08仍按公共路线出现。
- 未抽中的人物保持缺席或只留一句远景消息，不突然补完长线，不成为隐藏守关者。
- 场景、幕间句和回访按在场人物选变体；公共地点在人物缺席时使用碑文、路牌或当地消息，不触发未相识者的赠礼、对白或约定。人物专属节点由同档公共节点补位，不减少该幕基础成长机会。
- 抽取记录只保存 `drawn_lines`、已见地点、公开候选、已订回访和未见人物；不新增平行货币。

## 3. 阶段、选择与结算

事件状态为：`未出现 → 已展示 → 进行中 → 阶段完成 → 已完成`。

每次选择按以下顺序执行：

1. 先展示动作、战斗标签、所得、代价和停止点。
2. 玩家确认后写入 `stage`、`choice`、当前主修、法宝和下一回访；未选项不生成承诺。
3. 灵石或旧器只在成交、验证或明确进场确认后扣除；撤回发生在确认前。
4. 战斗奖励等战斗结果，只有胜利后才写入；非战斗奖励在确认动作后写入。
5. 失败只结算已确认所得和实际代价，关闭未开始阶段，不把失败改写为胜利。

气血和灵石是跨事件的持久代价。护盾、怒气及其他战内状态在战末清理，下场按公共战斗规则生成，不能拿护盾或怒气当跨节点费用。

非致命战斗在预告的败北线结束并保留正气血，失败不免费回满；玩家只能战前拒绝或战后收手，不能在自动斗法中撤退。

生死战必须在选项和确认前标出，战前可拒绝；气血归零结束本局，不生成复活、继续公共路或无条件回满。

## 4. 奖励、替代渠道与法宝

- 修为只推进当前成长，不额外发一次境界进阶；事件长期增强落在主修、修为或已有法宝上。
- 直接增强可以提高当前主修伤害、普攻积怒或降低怒技消耗，不必先转换成另一套永久天赋；不新增行动速度属性，每项增强记录目标对象和稳定数值。
- 常规替代渠道集中在公共修行节点、公共熔台、公共舟市、浅层洞府和公共正路；核心事件提供画面与取舍，不锁死基本能力。
- 示例法宝使用短句：`护心玉`（每战首次实际气血受损后获得护盾）；`引雷环`（普攻积怒提高）；`夔鼓片`（反击伤害提高，无反击无输入）；`回春囊`（治疗量提高）。这些是事件样例，不是完整目录。
- 法宝强化只升级原物并记录版本；没有输入就没有触发，不引入模糊的治疗转怒效果，也不创建额外进阶次数。
- 事件记录 `enhancement_target`、`enhancement_value`、`item_version`；主修和法宝的增强不会另开一套永久天赋表。
- 增强跟随目标功法或法宝；卸下目标即失效，切回恢复，不重复发奖。E04新成胚与旧器改炼互斥，只强化目标原有效果；成功更新同一物品，失败保留原物与实际灵石、气血损耗，不另收费用。

## 5. 共享节点

共享只复用已发生的地点、战斗结果或公开信息，不复制奖励；真实冲突时写明一条线推进、另一条线回访或关闭。

| 交汇 | 共享事实 | 后续变化 |
| --- | --- | --- |
| E01 + E02 | 潮口公开过的起手 | 守碑妖会先防同一招，未公开者不触发此回声 |
| E01 + E03 | 已学主修与第一次出手 | 夔野按实际打法安排重击或连段预告 |
| E02 + E06 | 断碑留下的后句记录 | 测脉时补充深门的已知技能，不直接送奖励 |
| E03 + E04 | 夔鼓试身的承受方式 | 推荐护心玉或引雷环，不把旧器原有效果偷换成另一能力 |
| E03 + E07 | 已完成的阵数与胜负 | 陆照调整晨战的公开条件，不把记录当货币 |
| E04 + E05 | 同一件法宝的名称与版本 | 舟市只估当前物，不复制成第二件 |
| E05 + E06 | 买图后的同航或独行 | 航图提供额外休整；同航用它换深门情报，独行前往休整，仍可另付测脉费；未买图保持原路线 |
| E06 + E08 | 浅层、深层或测脉后的事实 | 显示实际剩余休整与已探明敌情，不额外改动敌人先手；死亡不能进入终局 |
| E07 + E08 | 实际订下的同行或晨战 | 只回应已经发生的约定，不追加未约定的守关或再战 |

E07同行的个人战斗必须在确认合作前预告生死类型、敌情、可跳过的守关及所失战利品；角色不提供额外作战单位。E07与E08若跳过同一守关，只记录一次对应节点ID，不能重复领取跳过收益或补发战利品；两路选项按实际剩余节点生成。

E08短探只扣已确认的灵石并解锁情报，随后仍可选捷径或正路；两路基本生死风险免费可见，不把付费情报变成强制入场。

## 6. 失败、回访与保存

非致命失败保留此前已确认的法本、修为和法宝，保留实际气血损失，关闭当前未完成阶段；深层、捷径等生死失败直接结束本局。

回访只读取已写入的事实：公开过的招式、确认成交的物品、已付灵石、战斗胜负和真实约定。未见人物、未成交报价和未开始奖励不得在回访中出现。

通关保存：

- 当前主修及其已选天赋、绑定该法的已确认强化；
- 已取得的法宝、同一件法宝的强化版本及其稳定数值；
- 已结算的独立永久属性；境界与修为作为成长记录。

暂存法本可留在本局背包记录，但不作为同时生效的能力封入通关构筑。不保存当前气血、护盾、怒气、一次性回复、敌人先手、路线提前、人物外援、未胜候选和未成交物品；最大气血仍按构筑属性计算。

## 7. 两局示例

**示例一：** 抽到夔野、灼九、陆照。事件前选好普通主修，E01公开试法，E03两阵后收手，E04以灵石验证护心玉并胜利，E07拒绝晨战，E08走公共正路；保存主修和护心玉强化，陆照不成为守关者。

**示例二：** 抽到闻岫、鲛绫。E02记住后句并在第二幕放弃挑战，E05买共航图后选择保留航向，E06测脉后回头，E08付灵石短探再走公共正路；没有虚构守碑奖励，也没有让短探消耗临时护盾。
