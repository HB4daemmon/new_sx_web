# 山海事件规则

日期：2026-09-19

状态：设计提案的实现与验收口径，未实现；公共自动斗法见
[../COMBAT_RULES.md](../COMBAT_RULES.md)。

## 1. 故事与范围

- 五幕山海潮路通向昆仑天门；玩家先选一门当前主修，最后以自己的构筑渡劫。
- 每局从神农、精卫、哪吒、太上老君、铁扇公主五条人物线中抽取二到三条。
  女娲始终是 E08 的公共终幕，不占抽取名额。
- 事件不改十门功法、一百二十个天赋或自动斗法。人物不组成队伍，不替玩家承伤、战斗或渡劫。
- 事件奖励只能绑定当前主修、修为、目录中的法宝、同一法宝的强化，或明确可转型的法本。
  没有目录依据的公共法宝不得被事件创造。

`event_id` 固定，人物是否抽中只改变 `variant` 和玩家看到的标题。缺席人物的姓名不得出现在
公共标题、场景、对白、赠宝或后续回访中。

| `event_id` | 人物版标题 | 公共版标题 | 幕与资格 |
| --- | --- | --- | --- |
| `E01` | 《神农分药》 | 《分药台》 | 第一幕；`N02` |
| `E02` | 《精卫填海》 | 《海堤》 | 第一幕出现，第三幕入口兑现；`N03` |
| `E03` | 《哪吒试阵》 | 《试阵》 | 第二幕；`N04` |
| `E04` | 《老君开炉》 | 《熔炉》 | 第二幕开启，第四幕回访；`N05` |
| `E05` | 《铁扇借风》 | 《火山风口》 | 第三幕；`N06` |
| `E06` | 《海底寻宝》 | 《海底寻宝》 | 第三幕公共事件 |

`drawn_lines` 中没有对应标识时，人物版不可渲染。

## 3. 抽取、公共变体与事实资格

- `drawn_lines` 只保存本局实际抽中的人物线。缺席人物不能以远景、传闻、梦境、署名、
  临时守关或“本来认识”方式出现。
- E07 的哪吒版要求 `N04` 已抽中；只有玩家实际完成过 E03 阵段，E07 才可引用 E03 的阵序或胜负。
  没有 E03 事实时只能使用当前 E07 的公开敌情。
- 公共变体可以复用战斗类型和路线结构，但奖励必须在确认前写明为修为、当前主修强化、
  已有法宝强化或公开法本；不把人物法宝偷偷放入公共池。
- 公共变体没有人物对白、人物承诺、人物赠与、人物专属法宝名或人物回访。拒绝、收手、绕行都是合法结束，
  不生成隐藏道德惩罚。
- 每个事件只创建一次唯一的 `event_id` 实例；同一实例的回访是已写入事实的后续节点，不是新事件。
- 公共变体的场景与替代奖励以 [CORE_EVENTS.md](../CORE_EVENTS.md#未抽中人物时) 表为准；
  不用“同档成长”作为最终卡面。E01 是普攻增伤；E03 是普攻增伤、修为、旧宝强化
  （无旧宝改怒技增伤）；E04 是即时怒技增伤或未来更高一档旧宝强化
  （无旧宝改更高一档怒技增伤）；E05 是怒技增伤；E07 是怒技增伤或旧宝强化。
  实际强化量与候选在相应战斗或投入前预览，不临胜后换奖。

## 4. 卡面字段与阶段

卡面在确认前必须同时显示场景、选择、收益对象、付出、战斗标签、停止点和回访时间。
每个选项使用下表三列：

| 字段 | 写法 |
| --- | --- |
| 做什么 | 二到三个字或短动词，直接说明行动 |
| 现在得到与付出 | 写明修为、法宝、气血、旧宝、战斗风险或放弃的收益 |
| 之后改变 | 写明下一幕、战斗、节点、候选关闭和回访时间 |

阶段只在存在新的玩家决定时创建。安全返回、展示敌情、等待战斗结果和自动兑现不算新故事阶段。
一次确认能同时结算的选项不拆成“先登记、后领取”的伪阶段。每个事件可因分支提前结束。

事件状态为：
`未出现 -> 已展示 -> 进行中 -> 阶段完成 -> 已完成`。
放弃或失败使用 `提前结束`，不生成尚未开始阶段的奖励。

## 5. 选择与结算顺序

1. 先展示战斗类型、敌情或败北线、奖励对象、明确付出、停止点和回访时点。
2. 玩家确认后才写入 `stage`、`choice`、路线、旧宝版本和待回访事实；确认前可以安全返回。
3. 灵石、旧宝、路线机会和进入战斗的风险只在成交或进场确认时生效。
4. 非战斗奖励在确认后结算；战斗奖励只有胜利后结算；预览候选不等于已经拥有。
5. 失败只保留此前已确认的奖励和实际损耗，关闭未开始阶段，不把失败改写成胜利。
6. 同一 `event_id + branch_id + reward_id` 最多结算一次；重开卡面只读取事实，不能重复领取。

## 6. 战斗、气血与回复

- **预告非致命：** 开战前显示正气血败北线。伤害达到该线时立即截停，玩家以正气血结束；
  不是降到零后复活。入场气血已在败北线及以下时不能应战，可以离开，不因入场补血；
  E03 第二段同样检查。失败保留已结算所得与实际气血损耗，不免费回满。
- **生死战：** 开战前显示敌情、先手、气血归零边界和胜利后候选。气血降至零即结束本局，
  不生成复活、人物代打、公共路保底或延迟奖励。
- 气血、修为和灵石按公共规则跨节点保留。怒气、护盾、燃烧、中毒、虚弱和破甲等战内状态
  在战末清理，不作为另一个节点的支付或免费治疗。
- 多场战斗之间不免费回血。E03 两段试阵和 E07 两场追逐都保留已受伤的实际气血；
  只有公共规则允许的战末清理发生。
- E07 的救人回血只在 E07 整体完成时结算一次；第一胜后尚在比较是否继续时不给，
  选择收手则完成事件并结算，选择继续则待第二胜后结算，死亡不延迟复活。
- E01 第二幕入口、E02 第三幕入口、E07 整体完成和 E06 静室是不同的明示回复时点；
  回复不能任意跨幕携带或改成修为、灵石。
- 回复先补缺失气血，满血时不转成其它资源；最大气血变化只按构筑规则截断当前气血，不免费治疗。

## 7. 八个事件的固定顺序

| ID | 必须执行的顺序与互斥 |
| --- | --- |
| E01 | 三选一：立即获得修为；留药到第二幕入口固定安全节点自动一次回血；非致命药圃挑战胜后取 `FB07`。无二次确认。 |
| E02 | 三选一：帮筑一段堤并放弃同额明示修为，第三幕入口固定一次回血；清礁非致命胜后跳过第二幕一场已明示普通战及其战利品；自己赶路取得本事件修为走常路。 |
| E03 | 选重击或连击作为第一段非致命试炼；第一胜结算一次修为，可收手或接第二段；两胜后一次性在 `FB01` 至 `FB03` 中三选一。 |
| E04 | 三路互斥：立即 `FB06`；不另收费、无试炼地保证强化一件已有法宝；或放弃即时奖励直接进入第一场非致命守炉。第一胜写入第四幕终火台回访，可领预告修为收手，或放弃修为再守第二场争取 `FB05`。 |
| E05 | 三路同达风止石：常路生死战 A、B 各结算正常战利品；抵押一件旧宝只打 B，跳 A 及其战利品；正式除火患打一场更强生死火妖战，胜后直接 `FB04`。 |
| E06 | 器殿只炼已有法宝；经阁胜后选当前主修怒技增伤或一门明确法本；静室立即给少量修为并回复气血。三门只开一门、只结算一项。 |
| E07 | 先救人、先追宝或沿正路离开；第一胜后可收手或接另一场。救人胜得明确修为并在整体完成时一次回血；追宝胜选未得 `FB01` 至 `FB03`，全得时战前预览旧宝强化替代。 |
| E08 | 第四幕末一次三选一并立即结算：`FB08` 入战盾、强化已有法宝、当前主修怒技增伤；第五幕同场渡劫，不再开领奖阶段。 |

E03 和 E07 的双战属于同一事件节点链：第一胜只结算该段明确写出的奖励，不能按战斗次数
重复发节点收益。E01 第二幕入口、E02 第三幕入口及 E04 第四幕终火台是地图上的真实节点，
无论是否触发回访都占原有位置，各自只结算一次；不能在同一入口为每个回访再发一遍节点奖励。
E01/E02 预约的入口位于共同必经路，E02 绕行与 E05 借风不能绕掉它们。

E02 确认清礁前，展示第二幕将被跳过的普通战及奖励；胜利即落实绕行，不再另扣本事件修为。
该战必须是无主线、无人物回访的普通战，不得随机跳过必需事件。
E04 只有第一守炉获胜者把第四幕一个普通事件位替换为终火台，其余路线仍获得原普通事件机会。
首次确认守炉时展示被替换机会的类型与收益，不把回访当成追加奖励位。

E05 卡面中的山腰火道为 A，山口守关为 B。选路页本身不结算独立节点收益；
常路 A、B 分别是两个战斗节点，借风只有 B，除火患只有一个火妖战节点。
风止石只是这些路线的公共归还标记，不是额外的可领奖节点。

## 8. 法宝与强化边界

| ID | 法宝 | 目录固定效果 |
| --- | --- | --- |
| `FB01` | 乾坤圈 | 普攻命中追加伤害，每次普攻最多一次 |
| `FB02` | 混天绫 | 每次普攻首个基础命中段施加一次虚弱，多段不重复 |
| `FB03` | 风火轮 | 完成节点获得额外修为 |
| `FB04` | 芭蕉扇 | 怒技后清自身一层燃烧并得盾；无燃烧时照常得盾 |
| `FB05` | 金刚琢 | 每战只减首次敌怒技的首个基础命中段；该段后存活才回怒一次，不减后续段 |
| `FB06` | 紫金红葫芦 | 每次怒技首个基础命中段追伤一次；结算时敌人有虚弱或破甲则加强一次，两者不叠加 |
| `FB07` | 赭鞭 | 每完成一个节点少量回血 |
| `FB08` | 五色石 | 入战获得护盾 |

- 同一 `item_id` 一局只保留一个原件。已有候选必须在确认前改为同一旧器强化或公开的其它合法成长，
  不能暗发第二件、换成另一件或创建不存在的公共法宝。
- 需要旧宝的选项在没有可选旧宝时隐藏；若规则指定替代，则替代对象必须在卡面上直接显示。
- 旧宝强化更新原 `item_id` 的版本，只增强原有效果，不另开被动。失败保留原件和原版本，
  已发生的气血、灵石或路线机会成本不返还。
- 修为是角色的共同成长记录，不为每门功法创建独立修为条。事件的主修强化绑定确认时
  的 `method_id`，切走时停用、切回恢复；不能当成全功法通用的永久增伤或免费洗点。
- 行旅法宝在节点进入时绑定其有效版本，结算时仍有效才触发；节点内新得或强化的
  行旅效果从下一节点起算。战斗效果在正式取得后可用于下一场战斗，包括 E07 的第二场。
  同一事件内两战不能分别触发赭鞭、风火轮或主修的节点收益。
- E04 的“立即炼旧宝”不试炼、不收费；E06 器殿和 E08 炼旧宝同样先给原效果与强化后效果预览。
- E05 借风的芭蕉扇只写入临时路线事实，不写入 `owned_items`，没有 `FB04` 战斗效果。
  抵押旧宝的战斗、属性和行旅效果从确认起全部停用，到 B 的战利品及节点收益均结算完毕后，
  在风止石自动恢复原 `item_id` 和原版本；不新增归还奖励，不追补抵押期间的行旅收益。
- 法本只在明确允许换法的节点切换，暂存时不与当前主修同时生效，不改变十门功法或一百二十天赋。
- E06 的法本候选从十门功法里筛选尚未拥有、符合本幕取得资格的法本，不借此提前发传奇。
  战前展示名称、普攻、怒技和行旅；没有合法新法本时，第二项改为预告的修为，
  与“当前主修怒技增伤”二选一，不用已知法本充数。

## 9. 回访、记录与保存

回访只读取已写入的事实，不读取“玩家本来可能会选什么”。至少记录以下事实：

| 事实 | 写入时机 | 后续用途 |
| --- | --- | --- |
| `e01_route` / `e01_deep_result` | E01 选择、药圃胜负 | 第二幕入口是否兑现；人物版是否拥有 `FB07` |
| `e02_dike` / `e02_clear_route` / `e02_rest` | E02 选择、清礁结果、第三幕入口 | 固定休整和第二幕少战路线 |
| `e03_first_pattern` / `e03_segments` | 第一段选择、每段胜负 | 第一胜修为、两胜候选、E07 可引用的实际回忆 |
| `e04_item_version` / `e04_guard_count` | 旧宝强化或每道守炉结束 | 终火台是否存在、同一旧宝版本 |
| `e05_collateral` / `e05_return_marker` / `e05_route` | 抵押确认、B 奖励结算、路线完成 | 旧宝停用与恢复、A/B 是否跳过、`FB04` 是否正式取得 |
| `e06_door` / `e06_victory` / `e06_reward` | 选门、战斗结束、胜后选择 | 只保留实际打开的一门和一项奖励 |
| `e07_first_battle` / `e07_second_battle` / `e07_rescue_heal` | 每场结束、整体完成 | 第二战停止点和唯一救人回血 |
| `e08_choice` / `e08_reward` | 一次确认时 | 第五幕同场渡劫预览 |

路线跳过意味着对应战斗与战利品一起跳过；不得在捷径终点补发战利品，不得把看过敌情写成胜利。
回访节点占正常事件位置，不能叠加免费节点。人物版只回访已抽中的人物，公共版只回访公共事实。

通关保存当前主修及天赋、已拥有法宝和同一法宝的强化版本、已结算的独立永久属性、修为与境界记录。
不保存当前气血、护盾、怒气、一次性回复、临借芭蕉扇、抵押状态、未胜候选、未确认交易、
未开始的守炉奖励、人物外援或未结算战利品。生死战死亡结束本局；非致命失败只保留此前确认的结果。

## 10. 验收清单

1. E01-E08 各出现一次，`event_id` 与固定标题映射不重复；公共卡面不显示缺席人物姓名。
2. 每个玩家决定都有明确的收益对象、付出、战斗标签、停止点和回访时点；安全返回不伪装成阶段。
3. E01 无二次确认；E02 无重复扣宝藏或可携带跨幕的休整；E03 无空间位移和失败回满。
4. E04 三路互斥，终火台是正常事件位置；两次守炉失败都不补发未取得的奖励。
5. E05 借风旧宝效果全停、只打 B、风止石归还；正式除火患一次强战直接结算 `FB04`。
6. E06 没有公共法宝池；器殿无可强化旧宝时隐藏；静室写“修为”和“气血”两种不同收益。
7. E07 两战之间无免费回血，死亡无延迟疗伤；只在实际 E03 之后引用阵试回忆。
8. E08 一次确认结算，女娲不代打；重复法宝只强化原件，不复制唯一原器。
9. 运行 `git diff --check -- docs/shanhai/CORE_EVENTS.md docs/shanhai/rules/EVENT_RULES.md`，
   并逐支路走读无重复发奖、无空公共候选、无无代价押行旅宝。
