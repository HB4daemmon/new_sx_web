# 《随时修仙》山海版核心事件

日期：2026-09-19

状态：设计提案，未实现；数值、概率和候选预览仍需测试。

公共战斗边界见 [COMBAT_RULES.md](./COMBAT_RULES.md)，事件状态、抽取和结算见
[事件规则](./rules/EVENT_RULES.md)。本页只写玩家在卡面上能看懂的场景、选择和回响。

## 故事与卡面共识

- 山海潮沿五幕山路退向昆仑天门。玩家已经选定一门普通主修，最后用自己的构筑渡劫。
- 每局从神农、精卫、哪吒、太上老君、铁扇公主五条人物线中随机抽取二到三条；女娲是公共终幕。
- 未抽中的人物不出场、不赠宝、不回访。`event_id` 不变，但公共卡面不显示缺席人物的姓名。
- 公共变体只用修为、当前主修强化、已有法宝强化或明确的公开法本填位，不创建公共法宝池；
  公共卡面不渲染人物版专属法宝名。
- 事件不改十门功法和一百二十个天赋。人物不能组队、代打、承伤或替玩家渡劫。
- 事件表固定使用“做什么 / 现在得到与付出 / 之后改变”三列。战斗所得一律写“胜利后”。
- 数值未测时写“公开的小额”“公开候选”或“待测”；收益对象必须明确，不能只写“获得奖励”。
- 非致命战在开战前显示正气血败北线；已经在该线及以下不能应战，也不会因入场补血。
  生死战气血归零则本局结束。卡面由具体战斗预览补足数值，不用这些相对描述替代实现时的风险提示。

## E01《神农分药》

**幕与显示：** 第一幕。抽中神农时显示人物标题；否则显示《分药台》，场景不出现神农。

**场景：** 潮水将要淹到药圃，神农仍在给赶路的人分药。他指了指山坡上的藤蔓：
“你可以先服药修行，也可以留一份养伤。肯帮我清开药圃，这条赭鞭便交给你。”

### 一次选择

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `服药修行` | 立即获得修为；放弃留药和赭鞭。 | 更早接近下一次进阶。 |
| `留药养伤` | 放弃眼前修为和赭鞭；约定第二幕入口的药棚养伤。 | 到药棚自动回复一次气血，满血无额外收益；不能带到别处使用。 |
| `清开药圃` | 放弃这份药，参加**非致命挑战**；受伤会带到下一节点。 | 胜利后得到赭鞭，此后完成节点可回血；失败无此奖励。 |

**回响：** 留药者到第二幕药棚时，药包上仍系着自己打的结：“药留到了，人也走到了。”
清圃胜利时，神农交鞭：“认得药，也要记得路上还有伤者。”

## E02《精卫填海》

**幕与显示：** 第一幕出现，兑现点在第三幕入口。抽中精卫时显示人物标题；
否则显示《海堤》，场景不出现精卫。

**场景：** 精卫一次次把木石投进缺口，身后是一群等着过海的人。此刻潮气正适合修行，
你却只能留出这一次工夫：帮她筑堤，清开近路，或趁潮修行后独自上路。

### 第一幕选择

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `帮筑一段堤` | 放弃这次修行所得；不战斗。 | 第三幕入口可在新堤休整，自动回复一次气血；满血不另给奖励。 |
| `清礁开近路` | 放弃这次修行，参加**非致命清礁战**。 | 胜利后绕过第二幕已标出的一场普通战，也放弃那场全部奖励；失败走常路。 |
| `修行后赶路` | 立即获得这笔修为；不帮筑堤、不清礁。 | 沿常路前进，保留沿途战斗奖励，没有新堤休整。 |

**回响：** 筑堤者到第三幕，看见有人已在堤上支起歇脚棚；清礁者从第二幕露出的近路穿过。
精卫仍在衔石，东海没有被填平，你帮出的那一段却已经有人在走。

## E03《哪吒试阵》

**幕与显示：** 第二幕。抽中哪吒时显示人物标题；否则显示《试阵》，场景不出现哪吒。

**场景：** 哪吒在山场摆下两阵，一阵势沉，一阵招密。他将三件法宝放在阵外：
“先接哪阵，你定。赢一阵可以停，两阵都过，再挑一件走。伤身，不伤命。”

### 第一段：选阵序

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `先接重击` | 进入预告的**非致命重击段**；胜利后获得第一笔修为，受伤保留。 | 可在第一胜后收手，或继续第二段。 |
| `先接连击` | 进入预告的**非致命连击段**；胜利后获得第一笔修为，受伤保留。 | 可在第一胜后收手，或继续第二段。 |
| `今日不试` | 不战斗，保留气血、灵石、法宝和当前主修。 | 事件结束，错过本次试阵成长。 |

### 第一胜后的决定

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `收手离阵` | 保留已经结算的第一笔修为；不回血，不取法宝候选。 | 事件结束，战后气血进入下一节点。 |
| `接第二阵` | 不补气血，进入另一段预告的**非致命试炼**；第一段伤害继续保留。 | 胜利后只开放一次法宝三选一；失败保留第一笔修为并关闭未开始的法宝奖励。 |

### 两胜后的三选一

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `取乾坤圈` | 得到乾坤圈，放弃另外两件。 | 普攻命中追加伤害，每次普攻最多一次。 |
| `取混天绫` | 得到混天绫，放弃另外两件。 | 每次普攻首次命中施加虚弱，降低敌人攻击。 |
| `取风火轮` | 得到风火轮，放弃另外两件。 | 从下一节点起，完成节点获得额外修为。 |

**回响：** 一胜收手，哪吒让开阵门：“知道还能打，也知道何时该停。”两胜取宝，
他将所选之物抛来：“拿稳。这回不是借你，是你赢的。”

## E04《老君开炉》

**幕与显示：** 第二幕开启，第四幕有固定终火台回访。抽中太上老君时显示人物标题；
否则显示《熔炉》，场景不出现老君。

**场景：** 潮气冲得炉火忽明忽暗，老君却还在打磨一只金环。
“现成葫芦可以给你，旧器也能替你再炼。若想要这只环，就得先后替我守住两次炉火。”

### 第二幕选炉路

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `取紫金红葫芦` | 立即得宝，不付灵石；放弃炼旧宝和守炉。 | 每次怒技首次命中追加伤害；敌人有虚弱或破甲时更强。 |
| `重炼手中旧宝` | 立即强化一件已有法宝，先看强化前后效果；放弃葫芦和守炉。 | 原有搭配变强，不增加一件新宝；无可强化旧宝时不显示此项。 |
| `留下守炉` | 放弃两项即时奖励，参加第一场**非致命守炉战**。 | 胜利后约在第四幕终火台再见，占用当地一次普通事件机会；失败无后奖。 |

### 第四幕终火台

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `领修为收手` | 领取初次相约时已明示的一笔修为。 | 不再守炉，放弃金刚琢。 |
| `再守一炉` | 放弃这笔修为，参加第二场**非致命守炉战**。 | 胜利后得到金刚琢，抵御每战首次敌怒技的首个命中段并在存活后回怒；失败无此奖励。 |

**回响：** 取旧宝者看见熟悉的器物重新发亮；守成者等到金环出炉，老君将它递来：
“炉火两度，你都在。如今它跟你走。”

## E05《铁扇借风》

**幕与显示：** 第三幕。抽中铁扇公主时显示人物标题；否则显示《火山风口》，场景不出现铁扇公主。

**场景：** 火妖躲在山腹，不断吐火。铁扇公主扇出的凉路转眼又被封住。
“只想过去，押一件宝，我借你一阵风。若能除了火根，这把扇子便归你。”

三路都通向风止石。常路有“山腰火道”和“山口守关”两战；敌情、奖励和抵押物停用后的变化先展示。

### 一次定路

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `沿山过关` | 走两场已预告的**普通生死战**；每胜一场拿该场正常奖励。 | 保留全部法宝能力，战后抵达风止石。 |
| `押宝借风` | 暂押一件已有法宝，它的战斗、属性和行旅效果全部停用；借扇只用于赶路。 | 跳过山腰战及其奖励，只打山口生死战；完成该节点结算后，到风止石自动取回旧宝。 |
| `入山除火妖` | 参加一场更强的**生死战**，放弃常路两战及其奖励。 | 胜利后永久得到芭蕉扇：怒技后得盾，并清除自身一层燃烧；无燃烧也得盾。 |

三路只能选一条。没有可抵押法宝时不显示借风；所有生死战气血归零均结束本局。
若抵押物影响最大气血，确认前显示当前气血会被截到多少，归还也不免费补血。

**回响：** 借风者在风止石还扇、取回旧宝；除火者看见山腹的火光第一次熄下去。
铁扇公主将扇柄转向你：“这阵风，往后由你用了。”

## E06《海底寻宝》

**幕与显示：** 第三幕公共事件，不占人物长线。

**场景：** 潮退到山根，三扇门同时露出：器殿有金石声，经阁有墨香，静室没有敌声。
门楣上的字渐渐清楚：“潮只退一刻，开一门，闭两门。”

### 三门择一

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `进器殿` | 选一件已有法宝，先看强化前后效果，再打**生死寻宝战**。无可强化旧宝时不能进器殿。 | 胜利后强化所选法宝。 |
| `入经阁` | 先看敌情和两项奖励，再打**生死寻宝战**。 | 胜利后选“当前主修怒技增伤”或一门已展示的转型法本；法本暂存，下次换法节点才能启用。 |
| `住静室` | 不战斗，立即获得少量修为，并按卡面回复一次气血；两种资源分开结算。 | 关上器殿与经阁，事件结束。 |

器殿和经阁确认前可返回比较；确认后不能再开别的门。生死战气血归零结束本局。

**回响：** 潮水漫回门槛。器殿带出更强的旧宝，经阁带出另一种可能，静室出来的人则气息平稳。

## E07《哪吒追妖》

**幕与显示：** 第四幕。人物版要求已抽中哪吒；否则显示《双线追逐》，使用公共双场，
不出现哪吒或哪吒回忆。

**场景：** 哪吒指向两条岔路：“左边挟着人，右边卷着宝，两边都还没逃远。
你先追哪一个？”救人那边出手密，夺宝那边甲厚力重，敌情和奖励都已看清。

### 第一战

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `先救人` | 打**高频攻击生死战**；胜利后获得修为。 | 可收手或再追宝；获救者的疗伤药要到整个事件结束才使用。 |
| `先追宝` | 打**高防重击生死战**；胜利后从尚未取得的乾坤圈、混天绫、风火轮中选一件。 | 可收手或再救人；新宝的战斗效果可用于第二战，行旅效果从下一节点生效。 |
| `沿正路离开` | 不战斗，不取两份奖励。 | 保留当前气血与构筑，继续前往天门。 |

### 第一胜后的停止点

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `收手` | 保留第一战已结算的修为或法宝；不承受第二战风险。 | 事件完成；若本次救过人，此刻只发一次明示的气血回复。 |
| `接另一战` | 保留第一战所得，进入另一场已预告的生死战；不免费回血，怒气、护盾和战内状态按战末规则重置。 | 胜利后结算另一份奖励；事件完成时若救人战已胜，只发一次救人回血。 |

如果三件法宝都已有，追宝奖励在开战前改为明确的一项旧宝强化。
死亡结束本局，尚未使用的疗伤药不能救回。两场之间不结算节点回血。

**回响：** 救回的人沿正路离开，追回的宝留在手中。两战都胜时，哪吒一笑：
“这回你把两边都留下了。”试阵的旧话只对实际经历过 E03 的玩家说。

## E08《女娲赠石》

**幕与显示：** 第四幕末出现，女娲为公共终幕，不占随机人物线；第五幕在同一场景渡劫。

**场景：** 女娲将最后一道天裂补好，掌中还余一块五色石。她看向你手中的法与器：
“添一层护身，炼一件旧物，或把这一法再向前推一步。你来选。”

### 一次三选一

| 做什么 | 现在得到与付出 | 之后改变 |
| --- | --- | --- |
| `留石护身` | 得到五色石，放弃炼宝和悟法。 | 每次入战获得护盾。 |
| `再炼旧宝` | 强化一件已有法宝，先看强化前后效果；无可强化旧宝时不显示此项。 | 保留原有搭配，把其中一件练得更强。 |
| `借石悟法` | 提高当前主修的怒技伤害，放弃新宝与旧宝强化。 | 不换功法，让现有怒技更有威力。 |

三项只取一项；确认后进入第五幕共同渡劫，女娲不会代战。

**回响：** 天门雷光落下，护身的石、重炼的器或更强的法，回应的是你刚才的选择。

## 未抽中人物时

上文场景和对白用于人物版；公共版按下表替换，不显示缺席人物或专属法宝。
即时奖励、失败边界和回访时点沿用对应事件；强化对象和实际数值必须在选择前展示。

| 事件 | 公共场景 | 专属奖励的替代 |
| --- | --- | --- |
| E01 | 采药人在潮边摆下药台，请人清开藤蔓。 | 深探胜后提高当前主修普攻伤害；另两路仍是修为或固定留药回血。 |
| E02 | 海边工役正填补低堤缺口，潮水即将上涨。 | 保留修行、筑堤休整、清礁绕路；不发专属法宝。 |
| E03 | 旧试炼场的阵碑亮起，重击与连击两阵仍可运转。 | 两胜后在当前主修普攻增伤、修为、已有法宝强化中选一；无旧宝时第三项改为当前主修怒技增伤。 |
| E04 | 无主熔炉尚有余火，炼成的丹药与未熄的炉门都在眼前。 | 即时葫芦改为当前主修怒技增伤；守炉终奖改为更高一档旧宝强化，无旧宝则为更高一档主修怒技增伤。 |
| E05 | 火山渡口可寄存旧宝换一段风路，山腹的火患仍未除。 | 除火妖胜后提高当前主修怒技伤害；借风只给路线效果。 |
| E07 | 岔路留下人质的呼救声和夺宝者的足迹。 | 救人收益不变；追宝胜后提高当前主修怒技伤害，或强化一件旧宝，无旧宝时只显示前者。 |
