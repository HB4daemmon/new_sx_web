# 《随时修仙》山海版核心事件

日期：2026-09-19

状态：设计提案，未实现；以下为八个长事件的场景与选项草案，具体数值待测。
公共战斗细则见 [COMBAT_RULES.md](./COMBAT_RULES.md)，抽取与结算见 [事件规则](./rules/EVENT_RULES.md)。

以下场景采用相关人物在场的版本；未抽中该人物时，公共地点改用路牌、碑文或渡口消息承接，不凭空补完人物关系。

## 先读的共同规则

- 每局第一次遇到事件前，主角已经从普通法本中选定并学会一门可战斗主修；任何选项和人物都不构成入门门槛，学会的法本不会被收回。
- 后续事件拿到的法本可以换修或暂存，但同一时刻只有当前主修生效。
- 气血、灵石是会留到后续节点的代价；护盾、怒气只在本场战斗中存在，战末清理，下场按统一初始规则生成，不拿它们跨节点计价。
- 非致命战斗在预告的败北线结束并保留正气血，失败不免费回满；生死战在表格和确认前明示，玩家可拒绝。
- 表格写“胜利后”才算战斗奖励；未胜前不写成已经得到，战斗外的确认所得才在确认后结算。

## E01《潮口借火》

**场景：** 第一幕，潮头集夜宴散场后的潮口。

> 潮灯一盏盏浮上黑水，山影压住渡口。灯下已有几册普通法本，主角已在出手前选定一册，第一页的字便在掌中发热。

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `公开试法` | 用已学的普通主修马上出手；进入预告非致命切磋，胜利后获得额外修为，刚才的招式会被潮猎客记住。 |
| `收法离岸` | 收好已学法本，保留当前气血和灵石，直接离开潮口；不参加切磋，也不获得这场的额外修为。 |

**后续一：落印。** 选择 `公开试法` 后，先看见潮猎客要用的第一招，再决定 `应战` 或 `带法离开`；应战失败在预告败北线收场，保留正气血和已学主修。

**后续二：潮口收脚。** 公开试法胜利后，选择 `沿火痕去 E02`，断碑会先露出当前句；或选择 `直接离岸`，只把已学主修带入公共路。`收法离岸`直接进入公共路。

**回访：** 断碑边的守碑妖看见主角起手，先用同一招敲碎脚边石片：“原来你把那一下练成了自己的手。”

## E02《断碑听潮》

**场景：** 第一幕末，潮退露出海泥里的断碑。

> 碑面浮着一句已经能落地的法，后一句沉在水声里。鲛绫把船缆系紧，石底的脚步越来越近；主角现在取下的只有眼前这一笔。

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `取下当前句` | 当场结算一笔修为，碑文到此收束，带当前主修走公共路；放弃回到碑下求后句的机会。 |
| `记住后句` | 记下尚未说完的后句，放弃眼下这笔修为；第二幕回访时可挑战守碑妖，胜利后获得更丰厚修为或公开换修候选，也可不挑战而安全离开。 |

**后续一：刻字。** 选择 `取下当前句` 就离开断碑；选择 `记住后句` 则在记录里留下回访地点，当前功法照常可战，碑文不会变成额外境界或独立永久被动。

**后续二：回碑。** 回访时先看见守碑妖的生死预告和胜利后的两项候选，再决定 `挑战` 或 `收笔离开`；拒绝挑战就沿鲛绫指的浅水路走，不触发生死战。

**回访：** 第二幕回到石滩，守碑妖把断掉的石柱拖到水边：“你若要后一句，先让我看看你能不能活着听完。”

## E03《夔鼓试身》

**场景：** 第二幕，山神宴的雨棚下，夔野和老对手隔鼓相望。

> 夔野把鼓槌递给主角，老对手踩碎一块青石，先展示重击，再展示三连的落点。鼓边写着三阵，输到预告的败北线便收鼓。

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `先接重击` | 以重击阵开始非致命试身；胜利后获得一笔修为，承受的气血损失会留下，护盾和怒气在战末清理。 |
| `先接连段` | 以连段阵开始非致命试身；胜利后获得一笔修为，必须看清多段攻击的落点再决定下一阵。 |
| `今日止步` | 不入阵，保留当前气血、灵石和法宝；错过本轮修为与最后一阵的公开法宝候选。 |

**后续一：换阵。** 第一阵胜利后获得修为，选择 `收手离席` 或 `改接另一阵`；失败在正气血的预告线结束，已经结算的修为保留，不免费回满。

**后续二：第三声鼓。** 第二阵胜利后，选择 `带两阵成果离开` 或 `接最后一阵`；最后一阵胜利后，在战前公开的法宝候选中选一件，或改取更高一笔修为。三阵始终是非致命，不提供改签死斗。

**回访：** 夔野替老对手拾起鼓槌，指着主角的脚印说：“你不是照着我的力气赢的；下一次，我会按你的步子来。”

## E04《九炼无主炉》

**场景：** 第二幕，扶桑余辉照着一座没有炉主的石炉。

> 灼九把护心玉和引雷环摆到炉沿：前者护身，后者积怒。炉火还能把其中一件炼得更强。她看了一眼主角的旧器：“也能炼你自己的，但今日只开一炉。”

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `收下成胚` | 从护心玉、引雷环中选一件带走；不花灵石，不试器。 |
| `付灵石试器` | 选一件成胚，付明示灵石参加非致命试器；胜利后原物变强，失败保留原物，但灵石和实际气血损失不返还。 |
| `改炼旧器`（有可强化法宝时） | 放弃新成胚，选一件旧器，付明示灵石参加非致命试器；胜利后加强它原有的能力，失败保留原物和实际损耗。 |

**后续一：落胚。** 试器前先看清原物与强化后的效果：护心玉的护盾更厚，引雷环的普攻积怒更多，旧器只加强已有能力。确认灵石投入和非致命败北线后，选择 `入炉试器` 或 `带原物离开`；选旧器就不再领取新成胚。

**后续二：定火。** 胜利便强化同一件法宝，不另掷成败，也不多发一件。玩家选择 `去舟市` 或 `走公共路`；失败则带原物离开，不再加收灵石。

**回访：** E05 舟市把法宝举到灯下，鲛绫认出炉痕：“这件东西有你的手印，别人报价时不会把它当成路边石头。”

## E05《鲛市竞珍》

**场景：** 第三幕，鲛人舟市在涨潮时靠岸，两盏灯分别照着珍物和航图。

> 灯牌写着引雷环的灵石价，也写着一张通往山根的共航图。鲛绫没有替主角挑，先把一件可能被交出的旧器放在桌面，等一句确定的话。

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `买引雷环` | 付明示灵石，获得“普攻积怒提高”的法宝；不附送航图。 |
| `买共航图` | 付明示灵石，或交出指定旧器，获得航图与一处额外岸边休整的路线；交器会失去它的原有效果。 |
| `放下珍物` | 保留灵石和旧器，走公共正路；不拿本次珍物与航图。 |

**后续一：看牌。** 两项成交条件、物品短句和失去的旧器效果先展示；玩家只在 `确认一项成交` 后付款，或选择 `放下` 离开，未确认的报价不写入记录。

**后续二：分航。** 买图后回到船尾，选择 `与鲛绫同航`：绕行潮标，提前看清 E06 深门的详细招式，但放弃航图找到的额外休整；或选择 `独自行舟`：去该处休整，深门仍只看基本风险。买图时就展示这两种用法；只买法宝或未成交的人走原有公共路，不额外增加或扣除休整。

**回访：** 回到船尾时，鲛绫把两根缆绳一根递来一根收回：“你若愿意同看潮头，我把标记留在图上；你若要独走，我就把自己的船解开。”

## E06《山根移府》

**场景：** 第三幕，照海山山根下沉，洞府像一艘卡在岩层里的船。

> 浅门传来药香，深门传来金石撞击，测脉石把敌人的影子照在墙上。闻岫按住旧伤，告诉主角浅处能稳住气息，深处的门一旦推开便是生死。

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `入浅层` | 当下获得确定修为和一次小幅气血回复，不进入战斗；放弃深层已展示的珍稀法本或法宝候选。 |
| `测脉看深层` | 确认后支付明示灵石，查看更详细的敌方技能、先手和退出处；生死标签与基本风险免费可见，随后可回头或确认深探。 |
| `探深层` | 先看到生死战、敌人先手和胜利后可选的珍稀法本/法宝候选；确认后少一次休整机会，护盾和怒气不作为洞府代价，胜利后才取得候选。 |

**后续一：选门。** 选择 `入浅层` 后领取修为和小幅回复并走公共路；选择 `测脉` 后决定 `回头` 或 `确认深探`，测脉本身不逼出战斗。

**后续二：深门。** 确认深探后若在生死战中胜利，从战前已展示的候选中选一件再离开；若气血归零本局结束，不能带着死亡结果继续公共路。活着离开的人仍可走公共正路。

**回访：** 深探胜利后，公共路的灯火照见主角，闻岫把药包递过去：“你还站着，先把下一口气留给自己的路。”浅层离开或测脉后回头，则回应实际退路，不虚写深门胜利。

## E07《故敌同行》

**场景：** 第四幕，陆照第一次在照海山根的潮图边停步。

> 他先报姓名、寿期和想走的山门：“我叫陆照，想在身体不肯等我以前登顶。”他把灵石、旧器和一段山路图排开，再问主角要不要把话说成约定。

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `换路相看` | 付明示灵石或交出指定旧器，取得路线信息；看完可各走各路，也可另约同行。 |
| `订晨战` | 约定一场早晨山路的预告非致命战，条件写明“胜者早过、败者晚过”；胜利后按约取得路线信息，失败保留正气血并走较晚的公共路。 |
| `拒绝争路` | 不交资源、不战斗，保留公共正路和现有法宝；陆照不成为本局守关者。 |

**后续一：立约。** 换路后可以 `各走各路`；若要 `约定同行`，先看自己要独自面对的敌人、明示生死标签，以及胜利后能绕过的守关和放弃的战利品，再决定是否答应。订晨战时先看招式、非致命败北线和胜负后的通行差别，再选择 `接受` 或 `离开`。

**后续二：各自迎敌。** 同行后两人各自迎敌，主角仍需独自赢下已确认的生死战，才能绕过那处守关；绕过也就不拿该场战利品。陆照不代打、不保胜；E08只回应实际订下的约定，不临时把他变成守关者。

**回访：** 同行并各自胜利后，陆照在山门前数完药丸，把一半收回袖中：“我还剩这些日子，所以今天把路让给约定，不把刀交给猜疑。”未约同行者只保留晨战胜负或各自离开的事实。

## E08《归墟开缝》

**场景：** 第四至第五幕，归墟潮眼在照海山影后裂开，公共正路仍有火把。

> 裂缝里的岩阶短，却能先看见一名守关者举刀。旁边的正路多一道石门，门后有休整和战利品；鲛绫把最后一盏灯放在两条路中间，等主角自己迈步。

**选项：**

| 选项 | 当下结果与代价 |
| --- | --- |
| `入捷径` | 跳过一场已知守关，获得更早登山位置；对应战利品和一次休整留在正路，裂缝首战为明示敌人先手的生死战，胜利后才进入终局。 |
| `付灵石短探` | 支付明示灵石，看清裂缝敌人的详细招式和终局压力，再选捷径或公共正路；短探本身不触发战斗。 |
| `走公共正路` | 挑战预告的守关生死战，胜利后获得战利品和一次休整，再登山；放弃捷径的提前位置。 |

**后续一：看路。** 两路的生死标签、基本敌情和损失免费可见；短探只购买更多情报。看完再选 `入捷径` 或 `走正路`，确认后才开战。若 E07 已绕过同一守关，预览直接显示剩余路线，不重复承诺少打一场。

**后续二：登山。** 捷径战胜利后继续登山；正路守关胜利后带着战利品和休整登山。两路战败气血归零都结束本局。最终是同一场照海山渡劫，先前约定改变谁守关、哪场先打，不改变玩家自己的本事。

**回响：** 山顶雷火落下时，走正路的人听见多拿的一件器物在鞘中鸣响；走捷径的人少了一次休整，却先一步看见海面尽头，所有人都在同一片雷光下抬头。
