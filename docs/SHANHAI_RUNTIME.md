# 山海版运行时说明

更新：2026-10-19。

## 边界

新版由 `src/shanhai/` 独立实现，现作为唯一游戏入口。编辑源为
`content/shanhai/`，构建不读取旧内容，也不迁移旧版存档。
内容库的 `status: design_target` 和 `balance.measured: null` 保持不变；
代码接线与自动测试不等于功法、敌人、法宝和四幕经济已经完成实测校准。

## 运行约定

- 两侧在轮初锁定动作与怒耗，执行时付怒，轮尾统一结算收入和削怒。
- 削怒先合并抗性并封顶 100%，向下取整，再应用轮内 20 或开场 50 的上限。
- 速度决定先后手，不增加主动作；多段有效直接攻击逐段产生受击回怒。
- 毒火独立记录每层快照与剩余 tick；派生伤害不能无限重复触发原事件。
- 同作用域的百分比增伤、造盾和盾返加成合加一次；系数增量、百分比和百分点分开读取。
  回春功的两阶怒技治疗增量可同时生效；溢疗出口的替代不重复消费同一份治疗。
- 盾返在首轮实现中是不暴击的固定派生伤害，受护盾吸收，不再经过目标防御；
  该交互与直接攻击区分，后续流派校准须单独观察。
- 首轮模拟窗口为 256 回合，僵持可按原输入继续推演到最多 4096 回合。
  上限不是失败判定；玩家可明确收手结束本局。15 回合只用于基线观察。
- 较长回放保留首尾记录并明确标记中间折叠；伤害、贡献和胜负仍由完整模拟结算。
- 存档保存战斗输入、种子和摘要，加载后确定性重建回放并比对胜负与余血。
  损坏或不匹配的存档报错，不自动清空。

## 界面与回放

界面保留山河、命盘、因缘导航、桌面人物侧栏、纵向地图和独立双人战斗舞台。
顶栏只常驻天赋树和设置，通关归档、重开和幕次总览收进设置。地图不显示人物侧栏，
按动态视口高度铺满顶栏、资源栏与底部导航之间的空间，仅路线内部滚动；幕名与行程
合为一行，移除重复目标、地图脚注和逐节点说明。节点类型、可达状态、已走标记保留，
遭遇介绍在节点预览中展开。桌面其他页面的侧栏仅保留状态与按需查阅的构筑。
开局仅展示道号输入和随机取名图标，命数种子不在界面显示，新局在内部随机生成并写入
存档，仍可用于回放与复现；功法详录按需展开。
从当前命途返回首页时清除新局种子预填值，新开局自动生成新种子，继续旧局仍保留原种子。
奖励使用紧凑的横向三列，数字与关键机制在正文和详录中加粗着色。
奖励与天赋卡只保留概览和选择动作，完整效果使用统一详录弹窗；坊市可先查看法宝
再购买。命盘法宝默认显示短摘要，桌面侧栏的属性、构筑和持有法宝按需展开。
奖励详情由法宝图像与名称进入，卡底只留收入；叠层统一显示当前及选取后的数量。
战前对手详情合并到敌方姓名，主操作只留返回与开战。事件首屏保留首句，后续前情
按需展开，价格、收益、禁用原因和比试失败风险仍显示在选项中。坊市商品图文直接
进入详录，每行只保留一项购买操作；余额沿用全局状态栏。休整列出调息、备战，
拥有其他功法后才显示换法，换法功法列表与额外规则默认收起。未解锁天赋只显示名称
和状态，完整机制仍可查阅，不在天赋树中反复铺开。
开局道号默认随机生成，可再次随机或手动编辑；切换功法和查看详情不重抽姓名。
留空或只输入空白时使用“无名行者”，最多保留 24 个字符；重开后沿用当前角色姓名。
设置和结算页的重开操作共用确认：确认后结束当前命途、清除本局存档与回放并返回开局；
通关构筑保留。首页存在旧局存档时，入山海同样需要确认，确认后按当前所选参数开始新局。
若清理存档失败，当前内存命途会保留并显示错误。
新命途、继续读档和回封面恢复页面顶部；同页操作保留滚动位置。关闭弹窗将焦点
返回原页面区域的入口，不能误落到另一处同名按钮或折叠内容中。
战斗默认只展示双方法相、姓名、血盾条、怒气条、短动作反馈与回放控制。
血盾同条分段显示，以气血上限加当前护盾作为展示容量，两个色段分别对应真实气血与护盾；
护盾数值显示为气血的加值，超过气血上限也完整计入，低血警示仍按真实气血比例判断。
这只改变显示方式，不改变最大气血、护盾吸收和怒气的结算规则。
构筑、状态、战报和贡献不再以内联折叠面板铺在战场，统一通过小按钮进入详情模态。
模态按我方、敌方、战报、战果分组，战前只提供双方资料；战报只显示当前已播放记录，
战果仅在回放完成或终局开放。天赋、法宝子详情关闭后返回原详情页签与入口焦点。
英文状态键、效果来源和卡面术语在展示层转为中文，不改战斗输入、种子或存档中的标识。
同一场战斗在原位更新立绘、血盾两段、怒气条与控件，不逐帧重建整个页面。
正式版使用手绘资源和十二姿态逐帧动画。构建依据内容加载器中的显式实体清单校验全部
34 个敌人 ID、图集尺寸、独立 PNG 哈希与逐帧矩形。五套主角图和养锋石卫沿用已批准资源；
新增敌人图集仅标记 `agent-reviewed`，不会继承或伪装为用户批准。发布的图集目录含五套
主角与 34 个敌人外观。RKF06..10 分别复用 RKF01..05；敌人立绘按敌人 ID 选择，不再按其
功法套用主角形象。未知敌人明确回退到养锋石卫立绘。该映射只属于展示层，不修改敌人构筑
或规则。宽体敌人按整套动作的 `max(高, 宽 × 0.85)` 计算固定显示尺寸，不拉伸图像；
舞台按完整动作的外侧范围留白，避免长尾和兵器越界，各动作之间不重新缩放。
开局只解码五套主角图；进入战斗后仅解码当前双方图集。战中切换敌人按需加入新图集并释放
旧纹理，不重置共用动画时钟；当前敌人资源失败时显示对应的静态图，不影响游戏流程。
逐帧动作与界面共用游戏时间：普攻在第 19 帧、怒技在第 26 帧接触时推进真实回放结果；
一倍速对应约 316.7 / 433.3 毫秒。怒技用青碧菱纹区分我方、朱金箭纹区分敌方。
暂停、弹窗与后台页面冻结两者，改速保留已播放进度，跳至结算清除动作及光效。
暂停时仍可按窗口尺寸重绘冻结姿态，不推进动画时钟，避免切换屏幕尺寸时拉伸画布。
WebGL 不可用时播放器可转用 Canvas 2D；绘制器或资源加载失败时保留完整姿态 PNG 兜底。
游戏流程不依赖动画完成回调。
战报只在详情打开时渲染，切换简详模式、关闭重开后保留浏览位置与跟随状态。
普攻与怒技保留独立动作节拍，后续连续效果按动作及持续伤害阶段合并展示；
双方各自累计伤害、治疗、护盾吸收与生成，不用净值抵消治疗或将耗盾当作受伤。
合并反馈每方最多两条，四倍速也保留至少 400 毫秒的结果停留时间。
伤害与增益显示在对应角色头顶，数值由当前节拍进度驱动弹出、上浮和淡出，
暂停、改速及后台冻结与动作保持同步；减少动态效果时改为静态数值。
头部锚点与当前姿态范围由逐帧绘制器提供，窗口变化时随冻结姿态一起重新定位。
普通命中增加局部暖金碎光与短促亮身，护盾吸收显示冷色盾弧，不晃动整个画面。
血条采用独立的自适应高度区域，人物舞台预留头顶反馈空间，不再使用底部反馈标签行。
展示游标仍指向原始帧，详录保留全部已播放记录，不改原始帧或结算。
暂停、改速和切换战报模式不会重新触发当前帧动作；打开弹窗或离开战斗页会停止推进。
系统减少动态效果偏好会禁用位移和动画，保留数值、文字与静态状态反馈。

## 天赋与重选

- 天赋选择与随时可查看的天赋树共用四层三列展示，标明已悟、当前可选与未解锁；
  连线记录实际混选路径，不增加同列或前一项天赋的限制。
- 顶部天赋入口只读；查看未解锁天赋不授予能力，战斗中查看仍暂停回放。
- 普通坊市增加洗髓丹，每店一份，首测价格为 40 灵石，价格源位于 RULES 的
  `economy.non_artifact_prices.talent_reset`。购买前确认，购买即用，不另设物品背包。
- 只重选当前功法已经获得的 1..n 阶天赋，不增加境界、修为、回血或节点收益；
  其他功法选择和入节点快照保留，完成后回到原坊市，商品仍为售罄。
- 无已悟天赋时不能购买；重选中可存读档，不重复扣费、不提前发放未来境界天赋。

## 自由选路

- 新命途直接进入山河图，不选择整幕路线。每幕地图包含入口、九层三列分支和首领，
  共 29 个候选节点；实际每层走一个节点，仍为每幕 11 步，终局仅一场战斗。
- 邻列之间分叉与合流，玩家每次从当前相连节点中选择。进入后固定该节点，
  返回地图只恢复当前节点，不重抽事件、奖励或坊市。
- 地图及遭遇在入幕时冻结，刷新不会更换候选。`routeMap.nodes` 保存候选图，
  `routeMap.path` 保存已选节点键；`state.nodes` 仅保存已选路径，不再代表整幕预设路线。
- 商店、休整和精英可绕行，未走的节点不发收益；核心机缘仍受次数、间隔和前事约束。
  每幕第一场精英不占用全局额外精英额度。
- 之前山海运行时的线性存档保留已走及当前节点，未走的预设路线转换为分支地图；
  正在播放的战斗、领奖和突破状态保留。这不提供封神旧版存档兼容。

### 第一幕内容迭代

2026-10-19 起，新命途的第一幕按种子冻结两种功能节奏：早挑战在第三步提供可绕开的
额外精英，第四步休整、第六步坊市；晚整备把休整、坊市移至第七、第九步。两者均保留
第十步的可选精英，每条可达路径至少有三场普通战。精英仍受每幕两场、全局额外三场限制，
不增加节点或奖励次数。已有地图存档不重新生成；第二至第四幕暂沿用原功能层位。
第一幕机缘从合资格候选中只冻结一处，可落在第二、第五或第八步；未完成前事的回访不进入图。

第一幕普通事件增加延后开炉、药箱护送、修为换法宝和下一战护盾准备。开炉与护送分别要求
后续两处不进坊市、三处不进休整，原事件不计入倒计时；进入违约地点时立即中止，
已付代价不退。完成后续地点才兑现，跨幕继续计数，进入终战时未兑现则过期，死亡后不再推进。
约定与倒计时存入命途，因缘页显示进度，节点确认前提示失约风险。奖励未能取得的法宝层数
每层折四灵石；取得的行旅能力从下一个地点生效，不追补兑现地点。约定不额外增加节点。

首幕敌人保留现有形象与合法功法配装，分别展示多段、盾返和治疗压力；调整为降低重复盾返
损耗、给首领循环更多展示时间，不使用隐藏免疫或动态针对玩家的数值。奔雷、金乌的怒技
加段和烛龙的白昼护盾天赋修正已接线，敌我遵循相同规则。上述为内容迭代与行为验收，
不代表自动策略样本已证明平衡。

`npm run test:commitments` 单独覆盖 360、390 宽手机与 1440 宽桌面的约定条款、
付款及读档、因缘进度、节点失约确认、取消预览不写档、实际兑现与重复领奖保护。
该套件通过固定事件 fixture 使用正式内容与真实战斗；完整不注入存档的游玩流程仍由
`npm run test:journey` 验收。

## 旅途解释

- 节点入口绑定当前功法和已有法宝。节点中新获得的旅途法宝不追溯触发。
- 养剑诀每完成两个合资格节点准备一份首击，独立于护盾；首击不增加主动作，
  不触发普攻完成或基础命中专属能力，下一场战斗消耗后不重复领取。
- 金乌真经的“开阔节点”在首轮实现中明确映射普通战、精英战、首领战。
  现有内容没有逐节点地形字段，不把商店、休整、事件或终战算为开阔节点。
- 烛龙真经的行旅交替序号与战斗昼夜分离。换法保留各自已选择天赋与行旅记录。
- 终战不发成长奖励，不触发额外旅途经济或免费恢复，只结算胜负与实际构筑记录。

地图入幕显示一句目标，书卷图标按需查看当前幕前情；地图仍占满可用视口，仅路线滚动。

幕间最多列两条本幕已落定的事件回声；结局的因缘回顾默认折叠。
因缘页以实际已完成事件为准，不再把预选人物线或仅打开事件算成一次人物相逢。
长节点记录放入完整行迹，已立约、回访交易、主动止步与试炼失手分别展示。

事件完成历史新增可选 `eventOutcome: success|failure`，内部战结算先保存结果，再经过
突破或换法流程写入历史。旧档仍可加载；旧内部战历史没有明确结果时不使用成功回声。

气血、灵石、修为、法宝、待领取奖励或节点数。新节点入场清空旧结果文字，防止战斗行迹
误继承上一事件。终战胜利保存实际劫相与归途文案，败北不描述成通关。

`npm run test:story` 单独覆盖三种视口的四幕前情、全高地图、首领战前/战后/幕间、
终局胜败与人物选择。使用正式内容建立分支 fixture，并检查查看叙事不写档、
不改变资源；完整实际游玩仍由 `npm run test:journey` 负责。

## 验收边界

战斗回归覆盖精确怒气轮次、削怒顺序、DOT 快照、护盾、溢疗出口、
追击死亡边界、准备首击和条件替代。810 组天赋测试用于发现运行错误，
不代表每种构筑均已证明达到强度目标。

流程回归覆盖冻结掉落、商店重进、事件一次结算、非致命试炼、
