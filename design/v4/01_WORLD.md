# 山海劫 V4 · 第一步：世界观与成长体系（讨论稿）

> 状态：草案，待讨论。参考《诡秘之主》的「途径 + 序列 + 魔药/扮演 + 失控」与《大奉打更人》的「多体系九品 + 王朝官署 + 查案」，
> 只借结构，不搬名称与设定；背景是高武修仙。所有专名均为本作原创，可改。

## 一、一句话世界观

**天柱折断，天道碎成十二条「道」，散落在山海异兽与死去强者的骨血里。
凡人吞下「道髓」便能窃取一缕天道，从九品一路爬到一品；但每往上一品，都离「人」更远一步。**

玩家扮演大胤王朝「巡山司」的一名巡夜人：白天查案，夜里斩妖，一边往上爬，一边追查「山海倒灌」的真相。

## 二、世界

| 要素 | 设定 | 对游戏的用处 |
| --- | --- | --- |
| 九州与山海 | 人族居九州，四面是《山海经》的蛮荒「山海」。两界之间有天柱镇着。 | 地图分「州内」（城镇、案件）与「山海」（险地、异兽）两种区域 |
| 天柱折 | 三千年前天柱折了一根，天道碎为十二道，修行由此而生。 | 解释为什么人能修行、为什么修行有代价 |
| 逆潮 | 近年山海之水倒灌九州，异兽成群越界，各地怪案频发。 | 主线谜题；承接 V3 的「逆潮之谜」 |
| 大胤王朝 | 以「镇岳鼎」压国运，设巡山司管修士、斩异兽、查怪案。 | 玩家所属势力；任务来源；官阶＝局外成长之一 |
| 道统 | 各门派、世家、教团各守一条或几条道。 | 敌对/中立势力，商店与事件来源 |
| 执道者 | 每条道最多只有一个「超品」，执掌这条道的权柄。十二条道里如今只坐满了七个。 | 终局与隐藏首领；「唯一性」悬念 |

**基调**：高武、凶险、带一点悬疑。打得要硬、要爽；剧情要有「越查越不对劲」的味道，但不走恐怖路线。

## 三、成长体系：道途九品

### 3.1 规则（借《诡秘》的骨架，套《大奉》的九品）

1. **道途**：十二条道，每条九品，从九品往上修到一品；一品之上是超品「执道者」，每条道只能有一人。
2. **道髓**（相当于魔药）：修士或异兽死后，体内的道凝成道髓，**不会消失，只会转移**（道痕守恒）。
   吞对应道途、对应品阶的道髓，才能升到下一品。道髓来自斩杀同道的异兽与修士——
   **所以越往上，敌人就越是同道中人**。
3. **行道**（相当于扮演法）：每条道有自己的「道则」。只有按道则行事，道髓的力量才会被「化开」。
   化开之前强行再升品，就要承担**心魔**。
4. **心魔**（相当于失控）：心魔累积到顶会「道蚀」——人被道吞掉，成为只按道则行事的怪物。
   山海里很多异兽，本来就是道蚀的修士。
5. **邻道**：相邻的道在四品可以互转（像《诡秘》的相邻途径），换来混合能力，但心魔加重。
6. **品阶跨度**：九至七品是「凡躯」（武艺、法术、一招一式）；六至四品「入道」（开始改写战场规则）；
   三至一品「近神」（一个念头改天换地，代价是人性）。

### 3.2 首批六条可玩道途

每条道都有：道则（行道条件）、九品名、主题玩法。品名是角色名（像《诡秘》的「占卜家→小丑」），
不是境界名，玩家一听就知道自己「是什么人」。

| 道途 | 道则（怎样化开道髓） | 九品 → 一品（品名） | 一句话玩法 |
| --- | --- | --- | --- |
| **剑道 · 斩** | 一往无前，出手不留后手 | 磨剑人 · 断水客 · 剑胆 · 御剑师 · 剑魄 · 剑庐主 · 斩业者 · 剑仙 · 剑主 | 越打越锋利，飞剑成阵 |
| **焚道 · 燃** | 以己为薪，宁可烧尽 | 添薪人 · 掌灯客 · 火巫 · 焚书者 · 赤帝使 · 燎原 · 祝融 · 炎君 · 焚天 | 叠火、引爆、拿血换伤 |
| **武道 · 镇** | 以身为器，硬接硬扛 | 炼皮 · 锻骨 · 易筋 · 铜身 · 金刚 · 不坏 · 镇岳 · 武圣 · 武神 | 肉身吃伤再还手，高武核心 |
| **雷道 · 罚** | 审判与惩戒，有罪必罚 | 鸣鼓人 · 引雷师 · 雷判 · 刑雷使 · 雷部正 · 天鼓 · 九霄 · 雷尊 · 天罚 | 给敌人定罪，罪满即劈 |
| **青囊道 · 生** | 救人，不见死不救 | 采药人 · 郎中 · 悬壶 · 续命师 · 回春手 · 枯荣 · 生死人 · 青帝使 · 长生 | 回血转伤害，越奶越痛 |
| **烛照道 · 观** | 窥见并说出真相 | 守夜人 · 观星客 · 窥命者 · 掌灯判 · 日月使 · 烛阴 · 昼夜之主 · 照世 · 烛龙 | 看穿意图、改写顺序，昼夜轮转 |

这六条道和 V3 的六门功法（养剑、御火、金刚、奔雷、回春、烛龙）一一对应，现有美术和玩法经验可以沿用。

**其余六条道**先做敌人与剧情用：巫蛊道（契约与寄生）、儒道（言出法随）、佛道（渡化与业）、
妖道（异兽血脉）、傀道（操纵器物与尸身）、契道（交易与誓约）。之后可以逐步开放成可玩道途。

### 3.3 道途关系（邻道）

```
剑 ─ 雷 ─ 烛照
│         │
武 ─ 焚 ─ 青囊
```

相邻的道共享一部分道则，四品可以互转。例如剑转雷是「先斩后判」，武转焚是「燃血金身」。
**这正好给游戏提供了「中期转职 / 混搭流派」的结构。**

## 四、主线：逆潮之谜

1. **开局**：东海潮口出现一桩怪案：一整村人一夜间变成了半人半鱼。你作为九品巡夜人去查。
2. **中段**：逆潮背后，有人在山海里「养道」——故意让异兽吞人、积累道髓，再收割。
3. **转折**：收割者是七位执道者之一。他想集齐空着的五条道，「重立天柱」，成为唯一的天道。
4. **抉择**（多结局）：
   - 帮他立柱，换来九州太平，但世上从此只有一位神；
   - 斩了他，天道继续破碎，逆潮却只会更凶；
   - 自己吞下他的道髓，坐上那个位置。

**和成长体系的咬合**：你每升一品，就离那个位置近一步；心魔越重，「自己坐上去」的结局越近。
**成长本身就是剧情。**

## 五、这套设定给游戏的「钩子」

| 设定 | 变成玩法 |
| --- | --- |
| 道髓守恒、同道相残 | 击败敌人掉落道髓；首领掉高品道髓，是局内升品的主要来源 |
| 行道（扮演法） | 每条道的「道则」就是战斗里的行为目标，完成即化开道髓，奖励即时兑现 |
| 心魔与道蚀 | 冒进升品＝力量换风险的押注；心魔高时会出现「失控牌 / 失控回合」 |
| 九品名 | 升品＝获得这一品的新能力，品名直接告诉玩家「你变成了什么」 |
| 邻道 | 四品可转道，局中第二次构筑选择 |
| 巡山司、查案 | 地图节点有「查案」类事件，攒线索解开每一幕的真相 |
| 镇物（诡秘式封印物） | 法宝一律带一个负面效果，强而有代价 |
| 执道者唯一 | 终局首领、隐藏首领与多结局 |

## 六、要和你确认的问题

1. **基调**：高武打斗 + 轻悬疑查案，可以吗？还是更偏纯热血、少悬疑？
2. **成长名**：用「品」（九品→一品，像《大奉》），还是用「序列」（序列 9→0，像《诡秘》）？我倾向「品」，更有修仙味。
3. **道途数量**：首批六条可玩（对应 V3 六门功法），其余六条先当敌人。可以吗？
4. **品名风格**：角色名（磨剑人、断水客……），还是传统境界名（炼气、筑基……）？我倾向角色名，更有代入感，也更像《诡秘》。
5. **主角身份**：巡山司巡夜人（官方查案者），还是散修、宗门弟子？
6. **心魔**：要不要做成核心机制（冒进升品的代价）？这会直接影响第二步的核心玩法设计。
