## 一、背景：为什么每局重开、每局不同

| 方 | 框架 | 重开的理由 | 每局不同的来源 |
| --- | --- | --- | --- |
| Claude | **黄粱一梦** | 吕洞宾那口黄粱锅还在，凡人可以在锅边睡下修一世；梦醒了（死、失控或成神），黄粱还没熟，再睡一次 | 每场梦重抽出身、行当、世道 |
| Codex | **榜背空名** | 你是八仙藏在封神榜背面的一个空名；每夜借一个凡人的身子和手艺，五更前过南天门；天一亮墨干，这一页翻过 | 万家新送的「愿单」决定这一夜什么贵、哪座庙灵 |
| Gemini | **第九残魂** | 你是随八仙撕榜越狱失败、只逃出一缕真灵的残魂；每次借一具将死凡人的身体投胎 | 每局随机 1–2 位失控正神当值，改写全局规则 |
| Grok | **空位抓人** | 神位是会饿的空职位，饿了就抓活人坐下；你死、失控或拒坐，这一轮抽签作废，一切重洗 | 世道、空位、命格一起重洗 |

**巧合**：Claude、Codex、Gemini 三方各自想到了「**八仙在找第九个人**」，而且都把玩家写成了那个第九人或第九个空格。

**共同结构**：每局借一具新的凡人身份重来一世，重开本身就是设定的一部分，不靠剧情案件推进。暗线只放碎片，例如残页、旧手印、半句话，不影响重玩。

## 二、重开新鲜感机制（四方投票）

| 机制 | 提出方 | 列为首发必做 | 要点 |
| --- | --- | --- | --- |
| **仪式池** | 4 方 | **4 票** | 修为满后从本品仪式池抽 2 个，明牌二选一，按当前血量、钱、背包加权；只有九、六、三品做专属池，其余品用模板 |
| **世道 / 天象** | 4 方 | 2 票（Claude、Grok） | 每局一条全局规则，挂在已有结算上，成本最低；Gemini 的版本是「值年正神」，两两叠加 |
| **出身命格三选一** | 3 方 | 2 票（Claude、Gemini） | 行当 × 命格，例如「断臂富翁」「欠债商人」；命格常和准则打架 |
| **兼修 / 串途** | 4 方 | 2 票（Codex、Gemini） | Codex：只借一个动作，不背第二套准则；Grok：只借一个低品仪式 |
| **看得见的分岔路线** | 3 方 | 2 票（Codex、Grok） | 岔口亮出两站的种类和收益，不放问号；老玩家认得每一站，仍要算先去哪 |
| 法宝 / 残件 | 4 方 | | 只改规则。Codex 只设一个宝位，拿新的就丢旧的；Gemini 分「八仙遗宝（稳心魔）」和「封神凶器（霸道但涨心魔）」两池 |
| 失控后还能打 | 3 方 | | 本途径变成失控版（乞丐赖上别人的命、戏子下不了台），或者撑过天劫变狂仙；Codex 的版本是红线前可以「借一口气」 |
| 前世残影 | 3 方 | | 上局成神或失控的你进入首领池；Grok 的首领是「空位壳」，会模仿你最常用的招 |
| 进阶难度 | 3 方 | | 类似杀戮尖塔的进阶；Claude 叫「黄粱几熟」 |
| 准则变体 | 2 方 | | 每局只教三条（Claude），或每局换掉一条（Grok） |
| 首领公示庙规 | Codex | | 门神随机挂一块匾，例如「不受二拜」挡连续同招；老手可以骗招 |
| 八仙化身路人 | Claude | | 摆摊老头可能是张果老，认出来有机缘，靠多局见识 |

## 三、四方各自最值得拿的规矩

- **Codex：准则只在机会出现时判定**。每条每站最多判一次，没遇到机会不罚。这样「准则」不会变成「被按头做事」。
- **Grok：同一局里新出现的规则不超过两条**。
  - 仪式的卡面固定三行：付出、风险、所得。
  - 动作只保留砸、写、盖、签、跪、封六种，差别放在规则里，不做六套动画。
- **Gemini：底层只用 5 个原子变量**（生命、铜钱、状态层数、回合或连击计数、词条标签）。所有准则、仪式、天条都写成监听这 5 个变量的配置表，所以不论之后接卡牌、骰子还是自动战，都能直接复用。
- **Codex：世道是「一对价钱」**。例如「买货贵一钱，卖货也贵一钱」，同一条规则能把不同的人推向相反的打法。
- **一局的长度**：三方（Codex、Gemini、Grok）都倾向一局从九品走到一品，只在关键几品做「大仪式」，中间各品按修为自动升，只换称号和小数值。这比「跨局保留品阶」更像纯粹的 roguelike：每局都是一条完整的弧线。

## 五、Claude 的综合建议

### 1. 背景：「黄粱一梦」加上「第九人」
- 钟离权守着吕洞宾那口黄粱锅。凡人在锅边睡下，梦里修一世：
  - 一局就是一场梦；
  - 每场梦抽一种世道，也就是这一世哪位正神当值；
  - 每场梦借一具新的凡人身份，就是出身和命格。
- 暗线：八仙在梦里找第九个人，一个能修到一品、又不肯上榜的人。
- 终点：一品时可以坐上神位，这局算赢，但现实里某座庙会多一尊长着你脸的泥胎；也可以拒坐过海，算另一种结局。

### 2. 一局走完九品到一品
- 三次大仪式：升六品、升三品、登一品，各在一幕的末尾。
- 中间各品按修为自动升，只换称号，加一点小本领。
- 每局都是一条完整的弧线，局外不加初始数值。

### 3. 首发三个机制
- **仪式池**：九、六、三三个关键品各做 2–3 个仪式，抽 2 个明牌二选一。
- **世道**：先写 4–6 条。
- **出身命格三选一**。

「看得见的分岔路线」是地图的基础设计，直接照做，不单列为机制。兼修（只借一个动作）和失控变体放第二批。

### 4. 规矩
- 准则只在机会出现时判定（Codex）。
- 同一局新规则不超过两条（Grok）。
- 底层用 5 个原子变量写配置表（Gemini）。
