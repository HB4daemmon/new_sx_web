# Claude · 自由脑暴（盲写，未看其他三方答案）

## 方案一：「冒充神仙」（我最心动）

**一句话**：你是个江湖骗子，靠冒充神仙混饭吃。离谱的是，信的人越多，你就真的越像神仙。

**世界**：封神之后，天庭编制定死了，人间的庙却越修越多，神仙根本不够用。很多庙里坐着的，其实是冒名顶替的凡人。
- 规矩只有一条：**香火认的是「像不像」，不是「是不是」。**你演得像，香火就把那位神的本事借给你。
- **势力**：
  - **天庭稽查司**：专抓冒名神仙，但自己人手不够，常常睁一眼闭一眼；
  - **两大道门**：一家主张「神位只给正统」，一家主张「谁演得好谁就是神」，两家斗了上千年，人间就是它们的棋盘；
  - **地方豪强和真妖怪**：他们要的是庙里那位「神」替自己办事；
  - **八位前辈**：传说中最早骗成功的八个人，后来真的上了天，人间称他们「八仙」。

**玩家是谁、想要什么**：一个想吃饱饭的小骗子。一开始只想混口饭，后来想混个小庙，再后来，想看看天上那些位子到底是不是也是演的。

**成长（途径＝冒充哪一类神）**：
| 途径 | 品阶（低 → 高） | 本事 |
| --- | --- | --- |
| **财神** | 算命摊 → 招财童 → 福德正神 → … → 五路财神 | 点石成金、借钱给人 |
| **雷公** | 吓唬人的 → 电母侍女 → … → 雷部天君 | 打雷 |
| **月老** | 媒婆 → … → 红鸾星君 | 牵线：两个目标同生共死 |
| **门神** | 看门的 → … → 当境门神 | 拦住一切 |
| **灶君** | 伙夫 → … → 东厨司命 | 记小账：谁害你，你都记得，之后连本带利还 |
| **送子娘娘** | 接生婆 → … → 送子娘娘 | 生出东西：召唤 |

- **扮演准则就是神的人设**：财神不能小气，雷公不能怂，月老不能拆散有情人，门神不能离岗。守人设，香火涨；破人设，露馅值涨。
- **晋升仪式＝一场大型「显灵」**：例如财神升品，要在一场战斗里当众撒出全部的钱，还赢下来。

**核心张力：两头掉**。屏幕上一根条，两端各有一个危险：
- **露馅**：演得不像，香客散去，稽查司上门，这一局被追杀到结束；
- **入戏**：演得太像，你真的变成了那位神，忘了自己是谁，这一局以「成神」结束，赢了，但人没了。

所以条要停在中间。高品的力量更大，条也晃得更厉害。这就是稳健：**别太假，也别太真。**

**为什么一局一局地重来**：骗子跑路，换一个县、换一张脸，再开张。
- 每局开头抽三样：一个县（大旱、闹妖、富庶、兵乱）、县里缺哪位神、手头有什么道具。
- 跨局：你以前骗过的县会留下**传说**，可能是你的庙、你的仇家，或者另一个冒充「你」的骗子。

**暗线**：天庭稽查司的头子，是第一个被抓到冒名、却留下来干活的骗子；八仙之所以「过海」，是因为他们演得太像，差点回不来了。

## 方案二：「天门一甲子」
每六十年，南天门给凡人开一次，只收一个人。

一局就是一个甲子的飞升之争，你是千万凡人里的一个，和别的候选者抢机缘、抢名额。出头太早会被围攻，太晚又抢不到；赢了就飞升，你成为之后每一局天上的神。

偏「赛跑＋苟」，规则清楚，但人设不够鲜明。

## 方案三：「量劫回档」
你是一个在量劫中必死的外门杂役，每次死去都回到量劫开始前的那天早上。

圣人们的落子每次都不同（天机混乱），你靠一次次死亡攒下的见识，越来越稳健。

结构清楚（类似 Hades 的循环），但「重生回档」在网文里太常见，新意弱。

## 选哪个
**「冒充神仙」**，理由：
1. **扮演就是字面意思**：诡秘的「扮演法」在这里一句话就懂，「演得像就有本事」。
2. **一根条两头掉，比单向的心魔更有趣**：既要像，又不能太像。稳健的气质落在了操作上，不用另立规则。
3. **途径是「神」**：中国玩家一看就懂。神的人设就是准则，而且天然好笑。
4. **重开有喜感**：骗子跑路换县。每局抽县、抽缺的神，不靠剧情。
5. **封神、八仙只作为世界格局和传说存在**：天庭编制、八仙是最早骗成功的人。不照搬任何技能和法宝。
