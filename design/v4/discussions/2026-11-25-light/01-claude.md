# Claude · 轻松向自由脑暴（盲写，未看其他三方答案）

## 方案一：「八仙招新」（我最心动）

**一句话**：八仙干了几千年想退休，蓬莱贴出告示：**招第九仙，不限出身，随时报名。**

**世界**：洪荒太平好些年了，神仙们闲得发慌。八仙决定办一场「过海大选」：谁能从岸边一路闯到蓬莱，在八位前辈面前各显神通，谁就是第九仙。
- 天下凡人都疯了：卖豆腐的、算命的、走江湖的、县太爷家的傻儿子，全挤在海边排队报名。
- 天庭派人来维持秩序，龙王嫌吵，海里的妖怪趁机收「过路费」。

**玩家是谁**：海边一个想偷懒成仙的普通人。报名表上「特长」一栏，你填了自己的营生。

**为什么「随时」**：海选全年开放，随时报名，摸鱼的空当也能去比一场。

**为什么一局局重来**：落选了，明天再来排队。一局就是一届海选，分三幕：
1. 海选（岸边）；
2. 复赛（过海）；
3. 决赛（蓬莱）。

**途径＝拜哪位前辈当导师**。每位导师有自己的审美，也就是扮演准则：
| 导师 | 途径 | 审美（准则） | 身份阶梯 |
| --- | --- | --- | --- |
| 铁拐那位 | **乞丐** | 越落魄越有味道，穿得体面会扣分 | 叫花子 → … → 丐仙 |
| 吹笛那位 | **戏子／乐师** | 要有排面，要有观众，冷场扣分 | 卖唱的 → … → 乐仙 |
| 摇扇那位 | **闲人** | 越省力越好，用力过猛扣分 | 懒汉 → … → 闲仙 |
| 倒骑驴那位 | **算命** | 说中了才算本事 | 摆摊的 → … → 卦仙 |
| 提篮那位 | **货郎** | 买卖要漂亮，吃亏扣分 | 挑担的 → … → 财仙 |
| 持板那位 | **账房、读书人** | 规矩要讲究，乱来扣分 | 书生 → … → 文仙 |

- 名字只借八仙的影子，不照搬人物和法宝；导师用外号称呼，不点名。
- **晋升仪式**：每幕结束有一场「才艺展示」（首领战），用本途径的方式赢才算漂亮。

**失控＝「上头」**：
- 太想赢、太用力，你会「上头」：伤害翻倍，但开始乱来，比如乞丐把评委的酒葫芦也讨走了。
- 上头满了就被保安（天兵）请出场，本局结束。
- 效果很好笑，不苦。

**爽点**：
- 海边一路挤掉对手（割草的感觉）；
- 「才艺展示」时全场喝彩、评委亮分；
- 升品时换身份、换造型。

**笑点**：
- 对手都是奇葩选手：豆腐西施能把豆腐甩成飞刀，县太爷的傻儿子靠钱砸评委；
- 评委互相拆台，导师之间也抢人。

**第 50 局为什么还新鲜**：
1. **每届海选的赛题不一样**：本届主题「只许用左手」「必须带着一头驴」「评委今天心情不好」。
2. **对手是随机的奇葩选手**，有些会成为你的固定冤家。
3. **你以前的落选者会变成下一届的选手**：上一局的你练成了什么样，下一局他就带着那套本事来跟你抢名额。
4. **可以中途换导师**：在两位前辈之间跳槽，两种审美混出新打法。

**长线（轻松版的「真相」）**：
- 多届之后你发现，八仙根本不想退休，招新是为了找人帮他们干活；
- 再往后，你当上了第九仙，下一轮轮到你当评委，出题考别人。

## 方案二：「摸鱼修仙」
人人都忙，天庭为了提高全民修为，推出「随时修仙」服务：一炷香的工夫就能修一回。

你是酒楼跑堂，趁掌柜不注意溜出去修仙。一局就是一次「午休」。途径是你的打工身份：跑堂、厨子、账房、说书、更夫。

这个设定的妙处是，玩家现实里摸鱼的状态和游戏同频。缺点是世界的格局比较小。

## 方案三：「蟠桃会临时工」
天庭开蟠桃会，人手不够，从人间临时招工。

一局就是一场宴会：端盘子、拦醉仙、抓偷桃的猴子。干得好就升职：杂役 → 跑堂 → 管事 → 仙官。

热闹、好笑，但修仙的成长感偏弱，更像经营游戏。

## 选哪个
**「八仙招新」**，理由：
1. **基调最阳光**：一场全民选秀，人人都想成仙，热闹又好笑，没有阴谋。
2. **roguelike 结构天然清晰**：海选、复赛、决赛三幕；落选就明天再来；每届赛题和对手都不同。
3. **途径就是拜师**：导师的审美就是扮演准则，一句话就懂。
4. **「随时报名」正好对上《随时修仙》**。
5. **爽点集中在「才艺展示」**：全场喝彩、评委亮分，这和修仙游戏的升阶演出可以做成同一个时刻。
