# 《山海劫 V4》世界观与成长体系设计案

---

## 一、一句话世界观与核心冲突
**一句话世界观**：八仙过海一剑劈碎《封神榜》，三百六十五道神位化作带毒的「神箓」坠落人间；你身为王朝秘署「打神司」的执鞭小吏，吞神箓、巡诡案、斩堕仙，在成神为奴与肉身渡海之间杀出活路。

**核心冲突**：乱世之中，不吞神箓便如蝼蚁任仙妖宰割；吞下神箓则会一步步被旧神怨念侵蚀「堕神」。玩家每一次变强都在与天道枷锁对赌——最终是要重登封神榜顶替唯一神位，还是效仿八仙斩断因果、瞒天过海？

## 二、历史与格局：碎榜之后三百年
千年前**封神大战**的真相并非赐福成仙，而是圣人铸《封神榜》为天地铆钉，将阐截两教败亡练气士与山海大妖的真灵钉死在三百六十五座「正神位」上，永世作天庭运转的苦役。

三百年前，八位不入阐截、出身市井的凡俗奇人（世称**「八仙」**）拒绝受箓上榜。他们各铸一件本命「渡世法宝」，联手强渡东海归墟——史称**「八仙过海」**。那一战意外劈裂悬于九天的《封神榜》：神榜残页携诸神道果坠入九州，化作二十四条登仙道途；八仙自此不知所踪，人间迎来仙神失序的「山海劫」时代。

**当今四大势力**：
1. **大虞朝·打神司**：人皇以万里江山国运铸九鼎抗衡天威，设秘署「打神司」，执半截仿制打神鞭监察百官、侦办诡案、收缴散落神箓，“王法管凡人，本司管神仙”。
2. **堕天庭（阐教与旧神余孽）**：盘踞云端破碎南天门的半疯旧神，视人间修士为“逃逸的榜上耗材”，暗降灾劫企图重铸封神榜。
3. **万仙盟（截教残脉与山海群妖）**：信奉“有教无类、弱肉强食”，主张生吞诸神遗骸肉身成圣，常在州县掀动血祭兽潮。
4. **渡海客（八仙遗脉）**：游走黑市的民间散仙隐会，贩卖法宝仿品与秘闻，信奉“不登天榜、瞒天过海”，立场亦正亦邪。

## 三、力量体系：二十四道途·九品登真

### 1. 阶位命名：九品制 + 唯一极境
共分**二十四道途**（按八卦分八门，每门统摄 3 条相邻道途；首发 6 途）。每途皆从**九品至一品**（数字越小越强：下三品脱凡、中三品通玄、上三品显圣），**每一品皆是具象的身份命格**，而非枯燥的“某层初期”。一品之上，唯有一尊极境真位。

### 2. 晋升与消化：「吞箓即强」+「应命化劫」（零延迟领奖）
- **晋升（吞箓破关）**：炼化散落人间的封神残页**「神箓」**即可升品，**当场解锁该品标志性神通**，绝不延迟发奖。每逢**六品、三品、一品**三大关隘，触发高仪式感的「立命破境」。
- **扮演（应命化劫）**：每条道途皆有一句命格本分。吞箓虽即刻变强，但会累积旧神怨念**「劫煞」**；顺应本分行事称为**「应命」**，触发时**当场消减劫煞并立即获得一次气运/战力爆发**。扮演不是升级前置锁，而是让你敢放心吞凶箓的泄压阀与爽感倍增器。

### 3. 失控与越级代价：明码标价的凶险交易
- **劫煞与堕神**：劫煞（0–100）每越过刻度，肉身便发生「半神异化」（同时获得狂暴增益与明确枷锁）；满 100 则人性泯灭，被旧神残魂夺舍化为怪物，称为**「堕神」**。
- **越级与杂修**：允许**越品强吞**高阶神箓（如八品直吞六品），当场跨越品级拿大招，但选择前明牌告知代价：激增高额劫煞，并永久背负一条具象**「道伤」**（如*泣血天目：首回合自损气血，但招式必破隐暴击*）。

### 4. 道途关系与顶端唯一性
- **相邻换途**：同卦门的道途权柄相通。在**六品、三品**破境时，可无损换乘**相邻道途**，融合双途神通；强转非相邻道途则劫煞翻倍且肉身畸变。
- **双极终局（唯一性）**：每途顶端仅有一尊**「正神敕位」**（天地唯一，登顶须弑旧神夺位，神威盖世但重入天道束缚）；唯有集齐八仙渡世之法者，可在一品巅峰走第二条路——**「劈榜过海」**，散尽神箓枷锁，证逍遥真仙。

## 四、首发 6 条道途（3 组相邻道途）

### 第一组【乾门·社稷兵戈】（武夫气血 ↔ 王朝律令，相邻可互换）
1. **【武煞途】**——以血肉为烘炉，横练破万法，致敬封神“肉身成圣”。
   - **九品阶名**：九品**趟子手** → 八品**碎碑客** → 七品**披甲校** → 六品**虎贲将** → 五品**镇岳宗师** → 四品**烘炉武圣** → 三品**搬山君** → 二品**不坏金身** → 一品**斗战天尊**
   - **能力质变**：九品筋骨反震近身伤；六品气血化罡，直接撞碎低阶法术；三品法天象地，徒手硬接仙神法宝、残血拳威倍增。
   - **扮演戒律**：*「见强不退，受创不避，以堂堂拳脚破诡谲伎俩。」*

2. **【敕律途】**——执打神鞭权柄与王朝律法，口含天宪、画地断罪（封神挂钩）。
   - **九品阶名**：九品**录事吏** → 八品**巡街捕** → 七品**推案官** → 六品**铁面御史** → 五品**执律司直** → 四品**封敕真人** → 三品**掌鞭判官** → 二品**代天巡狩** → 一品**定榜天宪**
   - **能力质变**：九品勘破妖伪弱点；六品颁布「禁法条陈」，违令出手者受打神鞭反噬；三品一言贬神为凡，强削敌方一阶品级。
   - **扮演戒律**：*「先定罪名后落鞭；凡立律条，敌我同遵。」*

### 第二组【震门·阐截劫雷】（天庭雷罚 ↔ 截教剑煞，相邻可互换）
3. **【司雷途】**——承天庭雷部正统，代天行罚，堂皇霸道（封神闻仲雷部挂钩）。
   - **九品阶名**：九品**观云童** → 八品**司雨吏** → 七品**引雷师** → 六品**风雷掌旗** → 五品**五雷正宗** → 四品**巡天雷将** → 三品**紫电神君** → 二品**九霄雷帝** → 一品**普化天尊**
   - **能力质变**：九品掌心引电麻痹；六品布风雷阵触发全场感电连锁；三品强开紫霄天劫无视防御轰杀全场（自身亦扛余雷）。
   - **扮演戒律**：*「行止如天威浩荡，诛邪除恶绝不留隔夜之仇。」*

4. **【戮仙途】**——承通天截教诛仙剑意，截取一线生机，专斩不朽金身（封神截教挂钩）。
   - **九品阶名**：九品**磨剑奴** → 八品**试锋客** → 七品**捉刀人** → 六品**剑丸居士** → 五品**无情剑主** → 四品**斩龙真君** → 三品**陷仙剑尊** → 二品**诛神剑圣** → 一品**通天剑祖**
   - **能力质变**：九品寻隙破甲流血；六品吞吐剑丸，自身越伤出剑越快；三品展开凶煞剑阵，封死仙神再生与护体气运。
   - **扮演戒律**：*「剑出必见血，逢品级高于己者必争先手。」*

### 第三组【兑门·红尘山海】（八仙百戏 ↔ 万妖百相，相邻可互换）
5. **【游仙途】**——混迹市井的红尘谪仙，借假修真、偷换因果（八仙直接挂钩）。
   - **九品阶名**：九品**走方郎中** → 八品**醉酒歌客** → 七品**戏彩艺人** → 六品**折柳奇人** → 五品**壶中隐士** → 四品**换命散仙** → 三品**踏浪真仙** → 二品**逍遥酒圣** → 一品**渡海东华**
   - **能力质变**：九品悬壶调药趋吉避凶；六品点凡物为灵宝、饮酒化消劫煞；三品「瞒天过海」，将自身道伤代价嫁接给强敌或替死脱壳。
   - **扮演戒律**：*「千金散尽不敛财，越处死地越行险招。」*

6. **【百相途】**——食异兽精魄、披万妖皮囊，千变万化（封神梅山七怪/山海大妖挂钩）。
   - **九品阶名**：九品**饲兽徒** → 八品**剥皮匠** → 七品**驭蛊师** → 六品**画皮妖客** → 五品**百兽祭酒** → 四品**吞天大妖** → 三品**千面妖圣** → 二品**山海祖巫** → 一品**万灵真母**
   - **能力质变**：九品炼蛊叠毒；六品剥取手下败将皮相，直接窃用其招牌神通；三品显化山海凶兽真身，吞噬负面诅咒反哺气血。
   - **扮演戒律**：*「弱肉强食，逢异种强敌必取其髓、摹其形。」*

## 五、主角身份与单局「出巡」逻辑
玩家是大虞**打神司**底层的**「替劫执鞭人」**，体内天生嵌有一页**「无字残榜」**。
各地神箓坠落形成封闭的**「山海劫穴」**，高品大能一旦踏入会立刻引爆劫眼，唯有九品小吏能持司内「禹鼎拓片」入内查案平劫。每次出巡（一局），主角借无字残榜在劫穴内极速吞纳神箓、从九品一路破境杀穿劫眼；出劫回司时，必须剥离体内暴走的临时神箓归库（解释单局重置），仅留存本源烙印、结案卷宗与法宝拓影（对应局外成长）。

## 六、主线钩子与三重反转
**核心谜团**：八仙当年劈碎封神榜后为何全员失踪？如今各地劫穴频发，究竟是谁在暗中重铸封神榜？
1. **反转一（庙堂黑幕）**：大虞人皇早已油尽灯枯。打神司收缴神箓并非只为护民，人皇正以江山国运重铸《人道封神榜》，企图将满朝文武与百姓炼作延寿神奴。
2. **反转二（八仙下落）**：八仙并未逍遥远遁。碎榜后他们发现榜单底下镇压着「归墟天裂」，八仙甘愿以身为栓化作八座镇海阵眼；流落人间的八件本命法宝，实为寻找继任者的求救信。
3. **反转三（主角真身）**：玩家并非凡人，体内「无字残榜」即本体——玩家正是当年被一剑劈出灵智的**《封神榜》器灵转世**。终局抉择：重聚诸神化身为榜维系旧世，还是集齐八仙法宝彻底自焚神榜、带人间横渡苦海。

## 七、与 Roguelike 玩法的直接接口

1. **单局晋升节奏（10–20 分钟 / 三幕约 12–14 节点）**：
   - 九品入局，常规一局升 **6–8 阶**直抵一品（每两战一小升；每幕关底迎**六品、三品、一品**三次大破境仪式，可换乘相邻道途）。
   - 偶遇高品凶箓可**明牌越级吞服**：立刻跳阶拿大招，同步吃下写明的劫煞值与道伤词条。
2. **失控机制化**：竖屏顶部一条**「劫煞槽（0–100）」**。30/60/90 刻度触发双刃剑异化；达成单局 12 字「应命条件」（如戮仙途*“满血斩杀或首轮破甲”*）当场扣减劫煞并回血增益，爽快直观。
3. **法宝、敌人、事件的自然衍生**：
   - **法宝**：*《紫金酒葫芦》（八仙系）*——主动将 20 点劫煞当场转为护盾与暴击，代价是本战 15% 概率醉酒偏斜；*《打神鞭残节》（封神系）*——对带「神职」首领伤害翻倍，对无品凡人减半。
   - **敌人**：*「哭丧司雨吏」*（八品司雷途堕神体，敌我不分降酸雨雷击）；关底首领*「窃位雷公」*（三品伪神，借残榜给玩家贴敕令，玩家每次用最高品技能都会被抽血，逼玩家用游仙途“瞒天”或敕律途“反敕”破局）。
   - **事件**：*《河伯娶亲案》*——①亮鞭强杀恶蛟必掉雷/水神箓；②以一件法宝掉包新娘暗算恶蛟（恶蛟半血开战但损毁法宝，【游仙途】额外触发应命消煞）；③收受恶蛟贿赂拿灵石，明牌背负「违命」+25 劫煞。

## 八、潜在风险与对策
1. **风险：6 途 × 9 品看似内容量过大（54 个阶位），一两人团队难以做深。**
   - **对策**：「九品留名号，机制锚三关」。小品级做轻量数值与词条递进，真正改变出招逻辑的核心机制只做在**九品（定底子）、六品（成循环）、三品/一品（开法相与换途融合）**三个节点，单途仅需 8–10 个专属效果即可跑通。
2. **风险：世界观术语在手机竖屏快节奏下造成阅读压力。**
   - **对策**：UI 只露 **1 枚品级印章 + 1 根劫煞槽 + 1 句应命口诀**；所有带代价选项强制采用「绿字即时收益 / 红字即时枷锁」上下对照，3 秒内看懂拍板。
