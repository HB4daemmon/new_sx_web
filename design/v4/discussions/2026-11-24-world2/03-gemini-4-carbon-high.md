### 1. 两个世界背景方向

#### 方向一：朝堂缉仙（冷峻悬疑·体制内无间道）
- **一句话钩子**：凡人修到一品就会被《封神榜》抽走魂魄，塞进庙里当泥塑活尸；你是朝廷“缉仙司”的九品小捕快，一边奉命抓捕抗旨偷渡的野仙，一边偷学八仙禁术准备自己跑路。
- **玩家是谁**：大虞朝“缉仙司”里拿命填坑的九品底层捕快（每局一名新人，前任不是疯了、殉职，就是叛逃了）。
- **为什么一局一局出发**：每局接下一桩限期侦破的**地方奇案**（如河神娶亲、县令借寿、戏班百鬼夜行），进城查案抓凶、借机缘破境升品。
- **主线谜团与反转**：三百年前“八仙”为何宁可自毁仙籍也要逃往东海？各地频发的邪仙失控案又是谁在散播禁术？**反转**：朝廷设缉仙司根本不是除暴安良——当朝天子早就是封神榜上的“紫微泥胎”，衙门实为替天庭催收神魂的屠宰场；而八仙并未远走，他们把道统藏进人间三教九流，正在物色能掀翻封神榜的第九人。

#### 方向二：亡命渡海（荒诞潇洒·市井公路逃杀）
- **一句话钩子**：你的名字昨晚突然浮现在《封神榜》上——七天内天庭雷部就会劈死你，抓你的魂去天上当苦力；活命的唯一办法，是学当年八仙修一身歪门邪道“瞒天过海”。
- **玩家是谁**：每局是一名莫名被封神榜“点名征召”的市井倒霉蛋（落第书生、断腿乞丐、走方货郎等）。
- **为什么一局一局出发**：每局是一趟**从家乡逃往东海渡口的七日亡命路**，天庭追兵步步紧逼，你必须边逃边攒修为破境，赶在雷劫劈下前渡海脱身。
- **主线谜团与反转**：封神大战已过去千年，为何天庭突然疯狂抓凡人填榜？天上的三百六十五正神去哪了？**反转**：东海对岸根本没有仙乡——当年八仙过海全军覆没，尸骸化作拦海的八座魔岛；天庭抓人是因为旧神正在成批失控发疯，而你修炼的“八仙秘传”，其实是在把八仙残魂一点点吃进自己肚子里。

**更推荐方向一**：① 完美咬合《大奉》“官署查案”与《诡秘》“值夜者处理超凡事件”的双重爽感，表面当差办案、背地扮演偷渡的戏剧张力极强；② 对 1–2 人开发最友好，“一局一桩独立奇案”天然模块化，后续每次更新只需加新案卷即可扩展。

### 2. 六条途径设计（基于方向一：三封神源流＋三八仙源流）

*(注：以下行为准则中，`−` 表示心魔降低，`+` 表示心魔增加。)*

#### ① 【刀笔吏】（封神·姜子牙源流）
- **人设**：手握账本与朱笔，连漫天神佛都敢按律定罪、贴条查封的铁面公门人。
- **九品→一品**：抄书匠 → 刑房书办 → 推官 → 按察使 → 铁面御史 → 封敕官 → 代天巡狩 → 执榜真君 → 敕神天尊
- **行为准则**：
  1. 先拿到罪证或口供再动手抓人（−）；无凭无据直接强杀（+）。
  2. 事件中立下字据、限期或判词，吃亏也履约到底（−）；中途毁约（+）。
  3. 查获不义赃款按律充公或销毁（−）；私吞赃款进腰包（+）。
- **晋升仪式**：
  - *七升六（按察使）*：集齐关底恶霸 3 条铁证，当面宣读罪状削弱后再将其正法。
  - *四升三（代天巡狩）*：严拒高品妖神的重金行贿，在其狂暴翻脸时用封条禁绝其神通并活捉。
- **玩起来的手感**：先查证叠“罪状”、再敲惊堂木封禁对手核心技能的规则控制流。

#### ② 【说客】（封神·申公豹源流）
- **人设**：见人说人话、见鬼说鬼话，靠一张嘴挑动死斗、借刀杀人的笑面虎。
- **九品→一品**：帮闲 → 媒人 → 讼师 → 纵横客 → 惑心臣 → 倾国相 → 送劫人 → 留步真君 → 招灾天君
- **行为准则**：
  1. 事件选怂恿、拱火、做交易（−）；自己冲在前面替人挡刀（+）。
  2. 靠随从、陷阱或敌军内讧完成击杀（−）；全程只靠亲手硬砍收头（+）。
  3. 送出钱物后同局内连本带利从对方身上讨回（−）；白送人情不求回报（+）。
- **晋升仪式**：
  - *七升六（纵横客）*：向同一案中死敌双方兜售情报收两家钱，促成火并且全身而退。
  - *五升四（倾国相）*：首领战自己零直接攻击，纯靠策反护卫或反伤让首领死于自家人之手。
- **手感**：自身面板极脆，专靠拉拢、嫁祸与挑动敌我互殴躺赢的腹黑操盘流。

#### ③ 【货郎】（封神·赵公明源流）
- **人设**：摇鼓走街、人鬼通吃，连阳寿、修为与神位都能明码标价倒卖的生意人。
- **九品→一品**：挑担郎 → 牙行客 → 当铺朝奉 → 鬼市掌柜 → 买命商 → 落宝客 → 通宝散人 → 玄坛真君 → 万宝财神
- **行为准则**：
  1. 折价买进或溢价卖出物品（−）；原价硬买或白白丢弃道具（+）。
  2. 遇求助或索取必谈条件银货两讫（−）；白拿不给钱或白送不收钱（+）。
  3. 能花钱赎买摆平的危机绝不死拼（−）；守着巨款宁死不肯破财消灾（+）。
- **晋升仪式**：
  - *八升七（当铺朝奉）*：把诅咒凶物高价卖给局内人物，待其发作遭殃后再低价回购遗物。
  - *五升四（落宝客）*：不开战硬打，当场砸出巨款把强敌手里的成名法宝直接“买”过来使其败北。
- **手感**：万物折算铜钱，靠囤货生息、买空敌人装备与砸钱秒杀的钞能力流。

#### ④ 【乞儿】（八仙·铁拐李源流）
- **人设**：破衣烂衫、百无禁忌，专吞毒秽、越残废越凶悍的街头疯丐。
- **九品→一品**：叫花子 → 拾荒人 → 疥癣僧 → 污衣客 → 吞秽人 → 借尸客 → 悬壶怪医 → 铁拐大仙 → 破衲天尊
- **行为准则**：
  1. 每次休整结束前散尽余钱不留过夜（−）；怀揣巨款守财过夜（+）。
  2. 遇毒食、怪药、脏水或诅咒物一口吞下（−）；嫌脏惜命拒绝（+）。
  3. 半血以下主动迎战强敌（−）；满血健康时临阵脱逃（+）。
- **晋升仪式**：
  - *八升七（疥癣僧）*：身挂至少 3 种负面状态击败头目，且战后放弃疗伤。
  - *五升四（借尸客）*：零铜钱、零护甲被强敌打至濒死，触发借尸替死当场满怒反杀凶手。
- **手感**：不攒钱、专吃负面状态，把中毒、残血与破产全转成爆发力的卖血赌徒流。

#### ⑤ 【戏子】（八仙·蓝采和源流）
- **人设**：涂脂抹粉、唱念做打，披上他人人设“假戏真做”以偷换命格的伶人。
- **九品→一品**：跑龙套 → 变脸伶 → 名角儿 → 戏班主 → 画皮客 → 借命生 → 踏歌仙 → 百相真君 → 瞒天戏祖
- **行为准则**：
  1. 假冒身份后哪怕挨打受罚也演到底不拆台（−）；中途露怯自曝真身（+）。
  2. 在有旁观者围观的热闹场合取胜（−）；在无人暗巷闷头下黑手（+）。
  3. 连续两场遭遇切换不同面具或套路（−）；同一招式从头复读到尾（+）。
- **晋升仪式**：
  - *八升七（名角儿）*：在三人以上在场的堂会上冒充大人物把正主本人挤兑走，散场未被拆穿。
  - *六升五（画皮客）*：披上刚击败敌人的行头，下一战仅用偷学来的对方招式击败其同伙。
- **手感**：靠切换“行头面具”临时借用他派能力或复制首领绝活的百变偷师流。

#### ⑥ 【相师】（八仙·张果老源流）
- **人设**：倒骑毛驴、铁口直断，靠窥破天机甚至硬把瞎话圆成定数来改命的神算。
- **九品→一品**：看相人 → 摸骨客 → 铁口先生 → 巡山风水师 → 窥命客 → 倒骑翁 → 拨算仙 → 逆果真君 → 知命道祖
- **行为准则**：
  1. 提前窥探并押中下一场事件或敌招动向（−）；预言落空被打脸（+）。
  2. 替人指点迷津必收卦资或令其应一劫（−）；白泄天机分文不取（+）。
  3. 看破大凶死局及时绕行化解（−）；明知是死坑还硬拿头撞（+）。
- **晋升仪式**：
  - *七升六（巡山风水师）*：战前断言敌人“死于第几回合及死法”，并在战斗中分毫不差应验。
  - *五升四（倒骑翁）*：连续穿过 3 个高危未知事件，靠提前窥命改运全程零受伤通过。
- **手感**：能提前偷看后续事件与牌序，靠“押注预言成真”触发高倍结算的控顶算计流。

### 3. 单局怎么承载
- **一局升几品**：一局“地方奇案”（10–15 分钟）从九品起步，经 4 次仪式升至五品结案；结案后可重开新人，也可携该五品老档进下半场“京城/东海大案”（再升 4 品登顶一品，直面“上封神榜还是渡东海”终局）。
- **修为从哪来**：查证、战斗与事件抉择均即时到账修为；贴合本途径准则行事时，除降心魔外当场多发一笔“顿悟修为”，绝不延迟领奖。
- **仪式怎么出现**：修为满即刻亮起本品仪式邀约（事前写清条件、风险与升品奖励），随后 1–2 个节点内必刷出对应仪式事件或战斗挑战，完成当场升品，失败不扣修为可重试。
- **心魔满了怎么办**：蓄满即触发**失控**，弹出一次明码标价的“畸变豪赌”（如献祭生命上限或锁死温和选项，换取狂暴神通并削减半数心魔）；二度蓄满则彻底化作泥胎邪祟暴毙，并留档成为后续新捕快在旧案里撞见的疯魔前辈。

### 4. 游戏名建议
1. **《瞒天修仙》**：直指“学八仙瞒天过海、靠扮演骗过封神榜”，带“修仙”好记好搜，自带悬念钩子。
2. **《莫上封神》**：四字反常识拉满好奇心，国民神话零理解门槛，一眼立住最大反转。
3. **《缉仙司》**：点明“朝廷捕快抓野仙”的身份视角，极具网文 IP 质感且重名少。
- **评「随时修仙」**：非常适合竖屏 10 分钟一局的微信小游戏买量与搜索，获客直观；但单看偏轻松挂机，显不出封神八仙的诡谲味。建议保留为主标题、配世界观副标题，如 **《随时修仙：莫上封神》** 或 **《随时修仙：缉仙司》**，兼顾流量与调性。

### 5. 最可能的两个风险与对策
1. **专属内容量爆炸或看脸卡仪式**：若为 6 条途径各写一套剧本，1–2 人根本做不完，且随机刷不到仪式会卡死品级。
   - **对策**：通用事件选项统一打行为标签（`[守律][挑拨][交易][涉险][伪装][窥命]`），一套案卷六途径共用判定；修为满后开放手动“寻觅契机”，强制把下一节点改造成保底仪式场。
2. **扮演准则沦为“按头教玩游戏”**：若违背准则只有纯惩罚，玩家会觉得憋屈、失去肉鸽自由抉择感。
   - **对策**：选项前明标代价收益（如`[心魔+15 / 铜钱+80]`），让“破戒”成为主动权衡的资源置换；同时设计高心魔加成的凶悍词条，让“压线走钢丝”成为高风险高回报玩法。
