## 任务：为「山海劫 V4」发散设计 3 套完全不同的核心玩法

山海劫是一款修仙题材的 roguelike/roguelite **小游戏**，网页运行、手机竖屏优先。
之前做过三版（V1 自动斗法、V2 装备位+怒气、V3 五行符出牌），那些只是作者历史上的想法，**本次 V4 不受任何旧框架约束**：
核心玩法可以完全重新设计——可以是卡牌、骰子、棋盘、消除、弹珠、塔防、自走、动作、节奏、拼图、经营、合成，或任何你认为合适的形态与混合。
请大胆、跳脱、发散，三套方案之间要真正不同（不同的核心动词/操作），不要三个变体。

## 不变的部分
- 题材：高武修仙。成长体系参考《诡秘之主》（途径/序列、魔药+扮演法消化、失控、唯一性）与《大奉打更人》（多体系九品、王朝官署、查案）——只借结构，名称设定原创。可参考 design/v4/01_WORLD.md 的设定（天柱折、道髓守恒、巡山司巡夜人、品名是身份），但可以改。
- 四条原则（最高优先级）：
  1. 易上手：30 秒能教会，决策一眼可读，不需要算组合、凑点数；
  2. 有深度：小而真实的取舍，深度来自构筑与成长，不来自规则堆叠；
  3. 有爽感：连锁、重触发、破招、升阶演出、数字飙升、割草感等；
  4. 小游戏、轻量化：一局 10–20 分钟，系统少而精，一两个人能做完，手机单手或双手可玩。
- 作者偏好：不要延迟领奖/每日任务/倒计时；代价在选择前说清楚；喜欢有代价的强东西、阶段奖励（每一步有反馈，终点放大重演）。

## 每套方案请写（每套 ≤ 700 字）
1. 名字 + 一句话卖点（电梯演讲）
2. 核心动词/操作与一回合（或一分钟）怎么玩；规则 ≤ 3 条；一个具体例子
3. 修仙成长（途径/品阶/代价）怎么嵌进这个玩法
4. 爽点 3 个、深度来源 3 个

6. 参考作品（只借结构）与最大风险
最后用一张表给三套方案按「易上手/有深度/有爽感/轻量」1–5 分自评，并指出你最推荐哪一套、为什么。总篇幅 ≤ 2800 字。
