# 人物骨骼与 Spine 接入

## 历史评估与当前选择

可以使用 Spine。当前纯 HTML 界面不构成障碍：角色在透明画布中绘制，
文字、血盾条、怒气条与操作按钮继续用现有界面渲染。

用户随后要求使用开源骨骼方案。当前已选择 DragonBones 与 PixiJS，
接入说明见 [ANIMATION.md](ANIMATION.md)。以下保留的是此前 Spine 评估，
不是当前运行时说明，也不意味着 Spine 已接入。

此前预览用原生 Canvas2D 完成分层剪纸式骨骼原型：五种初始功法各一套角色皮肤，
石卫一套；每套具有头、躯干、袖臂、前臂、下摆、双腿、武器和装饰九个图像部件。
旧 `public/rig.js` 维护父子骨骼和动作曲线，武器随手、手随肘、肘随肩，
不是整张全身 PNG 的位移。动作包括待机、普攻、怒技、法宝、恢复、受击和格挡。

这不是 Spine，没有装入其运行时、没有导出 `.spine` 工程，也不声称达到最终动画质量。
旧原型的关节绑定已被用户指出错乱，并被开源运行时与重新标定的绑定替换。
新版本仍是刚性部件绑定，不含网格蒙皮、表情切换或成熟动画师制作的逐帧修饰。
原有全身图与姿态切换仍作为素材失败时的回退，不作为骨骼原型的替代说明。

仓库中未发现可用的 Spine 工程或导出包；当前环境未确认有效的编辑器授权。
不下载他人的角色，不把官方示例当作本游戏人物，也不购买或代为接受授权。

## 适合本游戏的接入方式

当前原型与未来 Spine 可以共用“方法皮肤、动作、命中回调、播放时钟”的接口。
原型已核验暂停、详情、倍速、减少动态、页面离开和 Canvas 不可用时的降级；
动画不计算伤害，不决定概率，不写存档。六段循环只是表现夹具，不能用于玩法校准。
真实接入仍需正式运行时的结果事件驱动、全部敌人映射、胜败收束和真实手机性能测试。

若后续改用 Spine，建议一个透明 WebGL 画布共同绘制左右角色，避免为每个角色维护一个完整播放器。
选用官方 `spine-webgl`，无需为了人物动作改换整套游戏框架。
初次素材核验可使用官方 `spine-player`，正式战斗隐藏播放器自带控件。
这是工程建议，尚未实现。

动画只负责表现，不重新结算伤害、不决定概率或先后手。游戏提供一次行动的结果，
画面再依次展示蓄势、出手、命中、回位。一次行动多段伤害仍合并一个反馈，
伤害与护盾、气血变化在同一个命中点显示。

| 动作 | 表现 | 建议时长 |
| --- | --- | --- |
| 待机 `idle` | 呼吸，袖摆轻动，脚底不漂移 | 约 2.5 秒循环 |
| 普攻 `attack` | 蓄势、刺击或挥击、收势 | 约 0.65 秒 |
| 怒技 `rage` | 更清楚的蓄势和斩击，不遮挡状态条 | 约 0.9 秒 |
| 受击 `hit` | 短暂后倾，恢复站姿 | 约 0.3 秒 |
| 格挡 `guard` | 手臂收拢，护盾短促反馈 | 约 0.35 秒 |
| 胜利 `victory` | 收剑，不增加长过场 | 约 0.8 秒 |
| 倒地 `defeat` | 稳定结束姿态 | 约 0.7 秒 |

时长为首轮制作目标，不是实测结果。倍速统一控制动画时钟和行动播放时钟，
暂停、打开详情、后台切换都冻结两者。略过立即停止动画并显示结算，
不能重复结算。减少动态效果保留静态姿态、数值与状态变化。

## 素材交付

先只制作一个修士和一个石卫，确认动作质量后再扩大角色库。

1. 手绘原画按头、前后发、躯干、上臂、前臂、手、腿、靴、袖摆、腰带和剑分层。
2. 补绘遮挡部位，尤其肩肘关节和袖内轮廓。完整 PNG 不能直接变成可用的分层绑定。
3. 在授权编辑器中绑定骨骼，制作上述动作；武器单独挂点，避免换装后重做全部动作。
4. 交付可编辑 `.spine` 工程、分层源文件和导出包
   `character.json` 或 `character.skel`、`character.atlas`、纹理 PNG。
5. 导出记录编辑器版本、运行时版本、素材来源与使用授权；保留工程源文件，
   不只保留运行时导出。

所有动作共用脚底锚点、镜头范围和角色尺寸。不能每换一个动作自动缩放画面，
否则角色会大小跳变。图集须保留透明边距；预乘透明选项必须与导出设置一致。
画布失效、WebGL 不可用或加载失败时，降级为静态人物，保留全部按钮和数值。

## 授权与版本

根据官方运行时及编辑器许可，面向普通玩家集成和分发运行时，需要确认
集成时持有有效的编辑器许可，并随产品保留运行时许可声明。
试用编辑器不提供同等集成与分发权限。最终以项目适用的官方条款为准。
这里是接入前的授权核对清单，不替代法律意见。

运行时公开源码不等于无条件 MIT 授权。编辑器导出的主、次版本必须与运行时匹配；
本轮不锁定尚未制作的素材版本，交付时再共同锁定具体版本，不引用 CDN 的浮动版本。

## 核验边界

`npm run probe:spine` 只在浏览器打开厂商已经发布的 Web Player，
确认官方示例在桌面和手机尺寸下能显示并移动，输出放在不公开的 `captures/`。
不将官方运行时或示例复制进本游戏，不作为本游戏的 Spine 接入。
测试是 Chromium 尺寸模拟，不等于 iPhone、安卓低端机的真实设备认证。

2026-10-13 已执行核验：390×844 和 1440×900 尺寸下均建立 WebGL 画布，
相隔 700 毫秒的角色画布截图不同，主会话也查看了截图确认示例人物可见。
这是厂商示例的浏览器可行性核验，不是本游戏角色的 Spine 实测。

真正接入后需要补测：非空画布、角色框定、动作切换、命中点同步、
两条状态条、暂停与倍速、离页释放、WebGL 丢失与静态降级、减少动态效果。
验收应同时检查截图、画布像素与实际连续动作，不能仅检查资源加载成功。
