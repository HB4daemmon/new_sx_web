# 随时修仙：像素素材模块

## 当前状态

已通过配置的 `gpt-image-2.5` 接口生成并接入独立预览。
素材、布局与浏览器行为已通过本轮检查；用户视觉审批保持 `pending`，正式游戏不变。

本轮由主会话直接处理，不使用子代理。斗法采用同套素材与控件，
已铺开开局、地图和择宝。具体导出、切片与来源见 `ASSETS.md`。

## 画面方向

小体量、清爽的像素修仙游戏，不做网页面板，也不做复杂的古风插画。
人物、法宝、场景、按钮保持相同的像素尺度、轮廓和材质语言。

- 背景以低对比灰绿为主，石台和远山放在下部，上部留给清晰的文字。
- 人物采用约四头身的完整侧身站姿，衣袍、发髻和兵器是主要辨识点。
- 边框采用浅玉石材质、深墨轮廓和少量铜金角饰，边角轻微阶梯化，
  不把所有控件做成同一种直角矩形。
- 法宝采用完整的小物件轮廓，不添加光圈、粒子和底座。
- 强调色分工：青绿用于气血，朱红用于怒气与主要操作，铜金用于护盾和稀有度。
  材质纹理只留在边缘，文字后面保持平静。
- 中文由真实界面渲染，不让图像模型生成按钮名称、数值或说明。
  正文保持清晰的中文字体，不为了像素感牺牲阅读。

## 斗法屏验收

先做一屏，不同时重构所有页面。

1. 顶部只保留双方名称、回合和一个详情入口，不常驻人物介绍。
2. 每方只有两条：气血与护盾合并条、怒气条。两者依靠图案和标识同时区分。
3. 人物完整可见、脚底对齐、朝向正确，背景不与状态条和文字争夺注意力。
4. 操作区简短、位置稳定；详情在模态框内整齐展示。
5. 小伤害继续归并显示，不因换美术恢复逐条刷屏。
6. 在 320×568、390×844 和 1440×900 检查；320×568 可压缩角色区，
   不缩小正文来换取单屏，也不让按钮触摸区小于 44 像素。
7. 同时检查静止、受击、护盾变化、怒技和减少动态效果时的画面。
8. 主会话必须查看实际浏览器截图；用户确认风格前，审批状态保持 `pending`。

其余屏沿用同套模块。择宝仍是三件横排，详按钮独立放右下角；
地图仍是先预览再进入，不改自由选路规则。
