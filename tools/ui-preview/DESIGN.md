# 随时修仙：手绘卡通画面预览

## 方向

简单、清晰、带修仙气质的手绘卡通画面。使用 imagegen 生成的真实位图模块，
不对旧素材套滤镜。人物为紧凑的大头卡通比例，背景、法宝和控件共用墨线与淡色平涂语言。

背景为安静的冷白天空和浅石台，文字为深墨，主要操作为朱红，
气血为青绿、护盾为铜金并附条纹、怒气为朱红。色彩同时有标签作区分。
轻微笔触和玉色装饰限于边缘，文字区域保持干净，不做复杂景物与厚重遮罩。
边角自然弯曲，不统一做直角框，也不依靠网页卡片的阴影制造层次。

## 四屏

开局：上方标题与道号，中间完整人物，下方五项功法按三加二排列和启程按钮。
功法选中时有朱红文字与短线，当前特点只占一行。道号与命数放在设置弹窗。

行旅：顶部紧凑资源栏，地点不加框。小型墨线节点和路线表达可达关系，
点击先预览，再确认进入；只透露背景与功法，不公布完整敌方属性。

斗法：上方两组状态，每方只有气血与护盾合并条、怒气条。
人物保持完整、不与状态混叠；底部四个小操作。人物背景和属性说明不常驻，
通过详情查看。每次行动的多段伤害合并为一行，护盾先于气血扣减。
预览用三次行动循环展示反馈，不是正式战斗模拟。普攻、怒技和敌人出招有不同的
手绘姿态；暂停和详情同时冻结画面与数值。减少动态效果恢复静态姿态。

择宝：三件横排，每件只保留图、名称、属性和短能力。
详按钮位于右下角，独立于选中操作。选中有朱红边线与印记，不放大物件，
不会挤动相邻项。收下按钮居中，详细条件在模态框中查看。

## 素材

背景上方无建筑、云层或噪点，低对比山影和浅石台仅位于下部。
人物、兵器、法宝保持完整轮廓和透明边距，去掉生成中多余的光晕。
保留墨线、平涂和自然边缘，使用平滑采样，不混用像素图或写实人物。
初版偏写实的人物与长绳玉佩不使用，改为明确的卡通比例和紧凑法宝。

活动素材全部为 PNG。墨线纸框、朱红令牌按钮和空槽来自 imagegen，
按实际结果确定九宫格切片；数值、文字和进度填充由真实界面渲染。

## 人物动画

当前只完成独立姿态与轻微动作预览，不能称为 Spine 骨骼动画。
官方 Web Player 已在本地浏览器中核验可显示和连续运动；本游戏的真实接入
仍需要角色分层、补绘、绑定、动作制作及有效的集成授权。具体见 [SPINE.md](SPINE.md)。
不把官方示例角色或未确认授权的运行时装入公网游戏。

## 验收

- 手机分别检查 320×568、320×760、390×844；桌面检查 1440×900。
- 普通页面能在可用屏高内显示，详情弹窗允许自身滚动。
- 文案、状态、人物、按钮不遮挡；三件法宝无需纵向滚动。
- 按钮点击区域至少 44 像素，图标操作有名称与悬停提示。
- 起步、节点预览、斗法、择宝、返回地图形成完整可操作流程。
- 总览直接缩放当前四个页面；缩略画面不可操作，仅标题链接负责跳转。
- 同时检查受击、怒技、护盾扣减、暂停、倍速和减少动态效果。
- 清晰度、场景氛围、人物姿态、法宝辨识度必须由主会话查看实际浏览器截图。
