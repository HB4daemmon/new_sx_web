# 随时修仙：手绘卡通画面预览

## 方向

简单、清晰、带修仙气质的手绘卡通画面。使用 imagegen 生成的真实位图模块，
不对旧素材套滤镜。人物为紧凑的大头卡通比例，背景、法宝和控件共用墨线与淡色平涂语言。

背景为安静的冷白天空和浅石台，文字为深墨，主要操作为朱红，
气血为青绿、护盾为铜金并附条纹、怒气为朱红。色彩同时有标签作区分。
轻微笔触和玉色装饰限于边缘，文字区域保持干净，不做复杂景物与厚重遮罩。
边角自然弯曲，不统一做直角框，也不依靠网页卡片的阴影制造层次。

## 四屏

开局：上方标题与道号，中间完整人物，下方五项功法按三加二排列和启程按钮。
功法选中时有朱红文字与短线，当前特点只占一行。道号与命数放在设置弹窗。

行旅：顶部紧凑资源栏，地点不加框。潮池、石阶、竹林、山门和歇脚处的小插画与路线表达可达关系，
点击先预览，再确认进入；只透露背景与功法，不公布完整敌方属性。

斗法：上方两组状态，每方只有气血与护盾合并条、怒气条。
人物保持完整、不与状态混叠；底部四个小操作。人物背景和属性说明不常驻，
通过详情查看。每次行动的多段伤害合并为一行，护盾先于气血扣减。
预览用六段行动循环展示普攻、格挡、怒技、法宝、恢复及受击，不是正式战斗模拟。
数值在动作命中帧更新；暂停和详情同时冻结逐帧时钟与数值。减少动态效果恢复静态姿态。
每次伤害仍合并一行，不把动作素材增加变成更多常驻说明。

择宝：三件横排，每件只保留图、名称、属性和短能力。
详按钮位于右下角，独立于选中操作。选中有朱红边线与印记，不放大物件，
不会挤动相邻项。收下按钮居中，详细条件在模态框中查看。
预览工具栏的“宝”打开图鉴，按凡品、珍品、传奇分组；点击后查看，再返回图鉴。
图鉴内容从实际 44 件法宝生成，不维护第二套游戏卡面。

## 素材

背景上方无建筑、云层或噪点，低对比山影和浅石台仅位于下部。
人物、兵器、法宝保持完整轮廓和透明边距，去掉生成中多余的光晕。
保留墨线、平涂和自然边缘，使用平滑采样，不混用像素图或写实人物。
初版偏写实的人物与长绳玉佩不使用，改为明确的卡通比例和紧凑法宝。

活动素材全部为 PNG。墨线纸框、朱红令牌按钮和空槽来自 imagegen，
按实际结果确定九宫格切片；数值、文字和进度填充由真实界面渲染。

## 人物造型与动画

五种初始功法各有造型：金刚功为持金刚杵的护法，归元诀为蓝衣斗士，
回春功为持药杖的医修，御火诀为持羽扇的火修，养剑诀为持剑的剑修。
石卫保留石甲、苔痕与石剑。功法选择同时改变开局人物、行旅标签和战斗人物。
开局的功法参数可以在预览 URL 中保存，刷新仍保留，不写正式游戏存档。

当前使用完整人物逐帧姿态和 PixiJS 透明 WebGL 画布，替换刚性分片人物。
六套人物各有十二张 image2.5 重新绘制的完整姿态，保持自然相连的肩、袖、躯干和握柄。
不是把旧骨骼截图烘焙成序列，也不是宣称每秒六十张独立原画。
蓄力、出手、跟随和回收按持帧时长编排；怒技、法宝和恢复采用对应姿态。
受击和格挡共用防御原画，但具有不同节奏和后退位移。
同套人物各姿态共用固定比例与脚底锚点，不逐帧缩放；兵器下垂时预留脚底以下空间。
各功法按待机人物的头顶到脚底校准体量，开局和斗法采用同一固定倍率，不按兵器长度
决定人物身高。敌我站位拉开，最窄手机仍为受击后退与伸展兵器保留空间。
怒技增加蓄力符纹、定向斩光与命中火花，普攻不带该光效。我方青玉菱纹、敌方朱金折纹，
除颜色外也以符纹和方向区分；不遮脸、不叠全屏闪白，暂停与减少动态规则保持一致。
动作与界面分别渲染，人物不带着状态条移动。WebGL 或纹理加载失败时降级为既有全身图。

当前采用开源方案，不依赖 Spine 编辑器，亦不将其官方示例装入公网游戏。
制作与验收见 [ANIMATION.md](ANIMATION.md)，原骨骼代码仅保留作参考和离线测试，
原 Spine 评估保留在 [SPINE.md](SPINE.md)。

## 法宝图像

实际库中的普通器物按石、玉佩、符、珠、环、瓶、袋、钱、针、履和甲共用器形。
五件传奇法宝各有独立轮廓，震岳鼓、长明灯、封元镜、定心佩保留辨识度较高的专图。
“独立图”是美术映射，不改变法宝叠加上限或 `unique_group`。

## 验收

- 手机分别检查 320×568、320×760、390×844；桌面检查 1440×900。
- 普通页面能在可用屏高内显示，详情弹窗允许自身滚动。
- 文案、状态、人物、按钮不遮挡；三件法宝无需纵向滚动。
- 按钮点击区域至少 44 像素，图标操作有名称与悬停提示。
- 起步、节点预览、斗法、择宝、返回地图形成完整可操作流程。
- 总览直接缩放当前四个页面；缩略画面不可操作，仅标题链接负责跳转。
- 同时检查受击、怒技、护盾扣减、暂停、倍速和减少动态效果。
- 检查五种功法的实际人物像素不同、72 张姿态完整且固定比例、两方画布均非空，
  命中前不扣血、减少动态时不丢结算、离页停止时钟、失败可回退。
- 清晰度、场景氛围、人物姿态、法宝辨识度必须由主会话查看实际浏览器截图。

## 状态

本目录仍是独立预览，不改变正式游戏。用户已确认整体手绘卡通风格；
本轮新造型、地图插画和逐帧动作的审批保持 `pending`。
浏览器测试和主会话截图复查不代替用户对新增表现的确认。
