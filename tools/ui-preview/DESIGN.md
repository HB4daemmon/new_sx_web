# 随时修仙：像素画面预览

## 方向

简单、清晰、带修仙气质的掌机像素画面。使用 imagegen 生成的真实位图模块，
不把此前平涂图像打上像素滤镜。背景、人物、法宝和控件共用颜色与轮廓语言。

背景为安静的灰绿天空和浅石台，文字为深墨，主要操作为朱红，
气血为青绿、护盾为铜金并附条纹、怒气为朱红。色彩同时有标签作区分。
纹理和铜饰限于边缘，文字区域保持干净，不做复杂景物与厚重遮罩。

## 四屏

开局：上方标题与道号，中间完整人物，下方五项功法按三加二排列和启程按钮。
功法选中时有朱红文字与短线，当前特点只占一行。道号与命数放在设置弹窗。

行旅：顶部一行资源，地点不加框。小型玉石节点和路线表达可达关系，
点击先预览，再确认进入；只透露背景与功法，不公布完整敌方属性。

斗法：上方两组状态，每方只有气血与护盾合并条、怒气条。
人物站在石台上，不与状态混叠；底部四个小操作。人物背景和属性说明不常驻，
通过详情查看。每次行动的多段伤害合并为一行，护盾先于气血扣减。
预览用三次行动循环展示反馈，不是正式战斗模拟。

择宝：三件横排，每件只保留图、名称、属性和短能力。
详按钮位于右下角，独立于选中操作。选中有朱红边线与印记，不放大物件，
不会挤动相邻项。收下按钮居中，详细条件在模态框中查看。

## 素材

背景上方无建筑、云层或噪点，远山和浅石台仅位于下部。
人物、兵器、法宝保持完整轮廓和透明边距，去掉生成中多余的光晕。
统一最近邻采样与有限调色板，不混用平涂人物或写实场景。

活动素材全部为 PNG。玉石框、朱红按钮和空槽来自 imagegen，
按实际结果确定九宫格切片；数值、文字和进度填充由真实界面渲染。

## 验收

- 手机分别检查 320×568、320×760、390×844；桌面检查 1440×900。
- 普通页面能在可用屏高内显示，详情弹窗允许自身滚动。
- 文案、状态、人物、按钮不遮挡；三件法宝无需纵向滚动。
- 按钮点击区域至少 44 像素，图标操作有名称与悬停提示。
- 起步、节点预览、斗法、择宝、返回地图形成完整可操作流程。
- 总览直接缩放当前四个页面；缩略画面不可操作，仅标题链接负责跳转。
- 同时检查受击、怒技、护盾扣减、暂停、倍速和减少动态效果。
- 清晰度、场景氛围、人物姿态、法宝辨识度必须由主会话查看实际浏览器截图。
