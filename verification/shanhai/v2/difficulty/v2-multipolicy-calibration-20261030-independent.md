## 解释与限制

留出样本比 80% / 65% / 50% / 35% 的目标依然偏高，尤其第二幕；本轮只把中后期压力向目标方向推进，没有声称达成目标，也没有将模拟通过率写回内容的 `measured` 字段。服务策略的留出累计通过率为 97% / 96% / 82% / 72%，而精英路线为 81% / 74% / 61% / 42%，说明策略与构筑差异仍很大。继续压到目标附近可能伤害强构筑体验，应结合真实玩家反馈再校准。

这 300 局共享 20 个种子标签，并在五门起手功法和三种固定启发式策略间配对；它们不是 300 名独立玩家，也不是玩家胜率或技巧估计。原始报告记录了完整逐局结果、种子、源内容哈希与复现命令。
