# Difficulty Calibration Evidence

The reports use real ShanhaiGame commands and combat. They are deterministic-policy
simulations, not human-player win-rate measurements. Content measured fields stay null.

| File | Role | Runs |
| --- | --- | ---: |
| baseline.json | Exploratory pre-adjustment steady-policy baseline; predates runtime hash metadata | 100 |
| validation-v1.json | First holdout subsequently used to diagnose excess act-four survival; NOT the final independent test | 500 |
| train.json | Final frozen-content training cohort, 100 seeds per start method | 500 |
| holdout.json | Final independent cohort, fresh release-prefixed seeds, 100 per start method | 500 |

The JSON is the original evidence; each `.json.md` is generated by
`tests/shanhai-difficulty-report.mjs`. The old `split: holdout` metadata in
`validation-v1.json` is preserved for provenance, not a claim of final independence.

Final seed families:

- Training: `balance-20261023-train-RKF01-0001` through each method's `0100`.
- Independent test: `balance-release-20261023-holdout-RKF01-0001` through each method's `0100`.

Final cumulative rates for acts 1-4:

- Training: 79.0%, 66.4%, 53.4%, 35.0%.
- Independent test: 80.2%, 65.0%, 52.2%, 38.6%.
- Targets: 80%, 65%, 50%, 35%; all are inside the independent test's Wilson 95% intervals.

There are zero errors and zero undecided runs in both final cohorts. The independent
act-four point estimate is 3.6 percentage points above target, not exactly 35%.
No parameter changes were made after examining this final independent test.
Per-method differences, especially the sword method's late survival, remain material.
